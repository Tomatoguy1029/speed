# 本番の武器一覧

最終更新：2026-10-07。対象はGodot本番。[共通の運用ルール](catalog.md) に従い、追加・変更・採否判断・実装の同じ作業で更新する。

本番はゲームシーン・スクリプトが未実装で、登録済みの武器はまだない。現在検討している [demoの武器候補](../demo/docs/weapons.md) を、本番で採用すると決めた時点でこちらへ登録する。同じ項目の管理IDを引き継ぎ、demoへの参照と本番との差分を残す。

| ID | 名称 | 採用状態 | 発動・効果 | ルートへの影響 | 本番の実装状況・コード参照 | demo参照・未決事項 |
|---|---|---|---|---|---|---|

レベル別効果・数値は決定後にIDごとの詳細として追記する。保留・不採用項目は別の区分へ移し、理由を残す。
