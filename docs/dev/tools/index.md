# 制作ツール一覧

Godotエディターのメニューバー **「プロジェクト → ツール」直下**から開く。ステージ起動・実験場・ビジュアル編集には上部の既存ボタンも使える。エディターで動く画面と、別の試遊ウィンドウで動く画面がある。

## 制作・試遊

| ツール | 使う場面 | 開き方 |
|---|---|---|
| [出現タイムライン・編成](spawn-timeline.md) | 出現時刻、敵の数、群れの並びを組む | エディターの画面・2Dシーン |
| [データ編集](data-editor.md) | 共通の `.tres` 値を一覧で編集する | エディターの別ウィンドウ |
| [編集中のステージを起動](stage-launch.md) | 選択中のステージを本番の流れで試す | ゲームを起動 |
| [実験場](enemy-lab.md) | 敵・ボスを試遊し、種類別ヒットストップと選択中のボス技を調整・保存する | 試遊ウィンドウ |
| [ビジュアル編集](visual-editor.md) | 炎・オーラ・後光・マップを見ながら調整する | プレビューウィンドウ |
| [背景編集](background-editor.md) | ステージ背景を配置・調整する | プレビューウィンドウ |
| [ピクセル素材確認](pixel-assets.md) | 敵などの描画見本を確認する | プレビューウィンドウ |
| [ステージ敵調整](stage-enemy-tuning.md) | ステージ固有の敵数値を編集する | エディター右側のドック |
| [ボスAI](boss-ai.md) | ボスの区間・技・条件を編集する | エディターの画面 |

ゲーム実行中に **F4** で開く[ステージ敵調整パネル](f4-enemy-tuning.md)もある。メニューのドックと同じステージ上書きを、遊びながら試せる。

## 開発用の計測

| ツール | 測るもの | 開き方 |
|---|---|---|
| [敵描画ベンチ](enemy-render-benchmark.md) | 大量の敵を描く負荷 | 計測用ウィンドウ |
| [ラン処理・描画ベンチ](run-profile.md) | ラン中の処理・描画時間 | 計測用ウィンドウ |

これらは制作データを編集する画面ではない。通常プレイの[録画と振り返り](../stage-production.md#6-記録と感想で調整する)にはF9を使う。
