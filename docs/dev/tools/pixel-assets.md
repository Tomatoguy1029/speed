# ピクセル素材確認

[ツール一覧](index.md)

**開く：** Godot「プロジェクト → ツール → ピクセル素材確認」。描画見本のウィンドウが開く。

1. 表示された敵などの見本を見て、輪郭・色・アニメーションの読みやすさを確認する。
2. 変更した素材の見え方は、実際に使うステージや[実験場](enemy-lab.md)でも確かめる。

決められた見本を表示する確認画面で、編集・保存操作はない。素材ファイルやゲームの設定は変わらない。

## 表示内容と入力

既定の見本は分裂体・群れ・ドリフター・ダート・射撃敵・分裂敵・ミサイル・装甲敵・大型敵・戦艦に加え、隕石のサイズ違いと被弾フラッシュ。実ゲームと同じ描画器を使い、位置・向き・HPなどは確認用に固定する。画面上で数値を編集する欄はない。

コマンドラインでこの確認シーンを直接開く場合だけ、Godot引数の `--` の後に表示モードを指定できる。`--damage-preview` は隕石の損傷段階、`--path-preview`・`--trace-preview` は描画線、`--smoothing-preview` は線の平滑化、`--exhaust-preview` は排気、`--rear-preview` は後方武器、`--attachments-preview` は装備の接続を固定サンプルで表示する。`--capture` を付けると数フレーム後に `res://.godot/pixel-preview.png` を1枚保存して終了する。メニュー起動ではこれらの引数を指定しない。
