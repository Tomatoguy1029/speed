# 出現タイムライン・編成

[ツール一覧](index.md)／[ステージ制作の流れ](../stage-production.md)

**開く：** Godot「プロジェクト → ツール → 出現タイムライン・編成」。担当ステージの `.tres` を選んで下部「出現タイムライン」からも開ける。

1. 担当ステージを選び、フェーズの境目、雑魚の数の曲線、強敵のクリップ、ボス・終了の位置を置く。
2. クリップの `Types` で敵を選び、`Spawn assets` に編成シーンを登録し、`Formations` の「使用」を選ぶ。`Group counts` と `Interval` で群れ数と補充間隔を決める。
3. 編成シーンを2Dで開き、`FormationLayout` の並び、`FormationMarker` の敵と位置、`FormationEntry` の出現方向を調整する。複数候補の `Weight` は選ばれやすさを決める。
4. 赤い配置警告とクリップのルール違反を解消し、目盛りから途中再生して確かめる。通しの成長は先頭から遊んで確認する。

タイムラインの確定・取り消しは対象 `res://data/stages/stage_<番号>.tres` に自動保存される。編成シーンは `res://data/formations/*.tscn` として保存する。共用編成を変更すると参照先にも影響するので、ステージ専用の並びは別名で保存して参照を差し替える。

## 時間帯と雑魚の曲線

| 画面の項目 | 何を変えるか | 単位・制約 |
|---|---|---|
| フェーズの境目・名前 | 区間の開始時刻と制作上の名前。次の境目までその区間が続く | ラン開始からの実秒。境目をドラッグ、右クリックで追加・削除・改名 |
| 予算 | その時間帯に強敵の攻撃へ同時に使える重み合計。0なら新しい攻撃を待たせる | 0以上の整数。区間の「予算」を選んで変更 |
| 強化区間 | 区間ごとに段階的な敵数・射撃敵の割合・エリート確率の強化を使うか | 時間帯ごとにON/OFF。区間の右クリックから設定 |
| 雑魚敵の曲線の点：時刻 | この種類の目標数が変化する時刻。点の間はなめらかにつながる | 実秒。最初の点より前／最後の点より後は端の値を使う |
| 雑魚敵の曲線の点：数 | フィールドにいてほしい同種の数。増やすと不足分を補充しやすくなる | 体。曲線が1つでもあれば雑魚補充はこの曲線を使う |
| ボスピン・終了ピン | ボスの出現を使うかと時刻、ステージの制限時間 | 実秒。ボスピンを外すとボス出現をOFFにする |

時間帯を選ぶとInspectorで `pop_from`（開始時の敵数）、`pop_to`（終了時の敵数）、`rate`（不足時の補充体/秒）、`xp_bonus`（倒した敵のXP倍率。0は1倍）、`wave_interval`（群れの補充間隔。0は停止）、`wave_type`（群れの敵ID）、`mix`（敵種類ごとの出現重み）も確認できる。ステージに雑魚の数の曲線があると、時間帯の数と重みより曲線を優先する。強化項目 `surge_interval`・`surge_pop`・`surge_ranged`・`surge_elite` は負値で共通設定を継承する。

## 強敵クリップと攻撃

| 画面の項目 | 何を変えるか | 単位・制約 |
|---|---|---|
| クリップの開始・長さ | その群れを出し続ける期間。棒の左で移動、右端で長さ変更 | 実秒。異なるクリップの表示トラックは出現方法を変えない |
| Group counts | このクリップから出た群れが同時に残っていてほしい数。不足時に補充する | 群れ。1群れの体数は選んだ並びで変わる。定義の初期値1 |
| Interval | 1群れを出してから次を出すまでの最短間隔 | 実秒、定義の初期値10 |
| Types | クリップに許す敵種類。ステージの `Enemies` に登録した種類から選ぶ | IDの集合。登録した配置シーン内の全種類を含める |
| Spawn assets | 群れの候補として使う `res://data/formations/*.tscn` | 複数登録でき、出現ごとに候補を選ぶ |
| Formations「使用」 | 登録シーンのどの `FormationLayout` を出すか | 空なら全配置を使用。候補が1つも有効でないシーンは出さない |
| Formations「Auto」「Override」 | 1群れの攻撃予算消費を個体の種類別値から自動計算するか、正の小数で共有値にするか | 正の小数。敵の出現体数には影響しない |
| Attack Priority | このクリップ由来の敵が攻撃を待つ順番。大きいほど先 | 0〜5の整数、初期0。同値は待ち時間で公平に決める。分裂体・増援も引き継ぐ |
| Stage の Enemy attack values | 敵1体の攻撃中に予算から消費する重み | 種類別の0以上の小数。0は予算を消費しない。予算0では新しい攻撃を始めない。未指定は1 |
| Stage の Enemy attack priorities | クリップ外から出た敵が攻撃を待つ優先度 | 種類別0〜5。クリップ由来はクリップの0を含む設定を優先 |

`Types` と登録済みシーン全体の種類が合わないクリップは赤い警告になる。「ルール違反のクリップ」→「詳細」で不足した種類を見て修正する。「使用」から除いた並びでも、登録シーン全体を照合する。

## 編成シーンの項目

| ノードと項目 | 何を変えるか |
|---|---|
| `EnemyFormation` の `Types` | この群れが使う敵種類の候補 |
| `FormationLayout` の位置・向き | 群れの中心と正面。子マーカーとの相対配置を決める |
| `FormationMarker` の `Enemy`・位置・向き | マーカー1つを敵1体として並べる |
| `FormationLayout` の `Weight` | 出現時にその並びを選ぶ比率。初期1、増やすと選ばれやすい |
| `FormationEntry` の位置・`Weight` | 機体に対する出現位置と、その位置が選ばれる比率。初期1。向きは機体の原点へ自動で向く |
| 根の `Preview Layout`・`Preview Entry` | 番号で選んだ並びと出現位置を2D編集上に重ねて確認する。クリップの使用選択は変えない |

クリップを確定・取り消しすると対象ステージの `.tres` を保存する。編成シーンの変更はその `.tscn` を別途保存する。並びの選択と共有valueはシーンと配置のIDで保持し、ファイルや配置の名前を変えても引き継ぐ。途中再生は選択時刻からXP0で始まる確認なので、通しの成長比較は先頭から行う。
