# 出現タイムライン・編成

[ツール一覧](index.md)／[ステージ制作の流れ](../stage-production.md)

**開く：** Godot「プロジェクト → ツール → 出現タイムライン・編成」。担当ステージの `.tres` を選んで下部「出現タイムライン」からも開ける。

1. 担当ステージを選び、フェーズの境目、雑魚の数の曲線、強敵のクリップ、ボス・終了の位置を置く。
2. クリップの `Types` で敵を選び、`Spawn assets` に編成シーンを登録し、`Formations` の「使用」を選ぶ。`Group counts` と `Interval` で群れ数と補充間隔を決める。
3. 編成シーンを2Dで開き、`FormationLayout` の並び、`FormationMarker` の敵と位置、`FormationEntry` の出現方向を調整する。複数候補の `Weight` は選ばれやすさを決める。
4. 赤い配置警告とクリップのルール違反を解消し、目盛りから途中再生して確かめる。通しの成長は先頭から遊んで確認する。

タイムラインの確定・取り消しは対象 `res://data/stages/stage_<番号>.tres` に自動保存される。編成シーンは `res://data/formations/*.tscn` として保存する。共用編成を変更すると参照先にも影響するので、ステージ専用の並びは別名で保存して参照を差し替える。
