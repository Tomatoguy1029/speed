# ビジュアル編集

[ツール一覧](index.md)

**開く：** Godot「プロジェクト → ツール → ビジュアル編集（炎・オーラ・後光・マップ）」または上部「▶ ビジュアル編集」。別のプレビューウィンドウが開く。

1. 左から「炎」「オーラ」「後光」「マップ」を選ぶ。中央で変化を見ながら、右側の調整値を変える。
2. 上部の「保存先」を確認し、残したいタブで「保存」を押す。
3. 保存済みの状態からやり直すときは「再読込」を使う。未保存の変更があれば確認が出る。

| タブ | 調整するもの | 保存先 |
|---|---|---|
| 炎 | PixelFireの形・動き・粒子・層・輪郭、ステージや参照PNGとの合成 | 選択中の `res://data/visuals/*.tres`。別名複製も可能 |
| オーラ・後光 | 伝説モジュール獲得時のオーラと後光 | 選択中の `res://data/legendary_modules/*.tres`。画像ベイクは画面内の別操作 |
| マップ | 線・波形・星図・モニター効果 | `res://data/map_reveal_settings.tres` |

タブを切り替えても調整中の値は保持される。上部「保存」は**表示中の保存先だけ**へ書き込む。未保存タブは印で分かり、閉じる際も確認できる。マップの保存結果は次の通常起動で確かめる。

炎タブは再生・停止・コマ送り・速度切替、配置のドラッグや表示ズーム、[透明PNGの出力確認](pixel-fire-2d.md#透明pngを書き出す)も使える。炎の設定保存とステージへの配置保存は別操作。[炎の2Dシーン入口](pixel-fire-2d.md)でも同じ操作部を使う。
