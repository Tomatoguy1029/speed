# ビジュアル編集

[ツール一覧](index.md)

**開く：** Godot「プロジェクト → ツール → ビジュアル編集（炎・オーラ・後光・マップ・目印・エリート）」または上部「▶ ビジュアル編集」。別のプレビューウィンドウが前面に開く。

1. 上部の「編集対象」で炎・オーラ・後光・マップ・目印の星・エリートから選ぶ。中央で変化を見ながら、右側の対象に応じた調整値を変える。
2. 上部の「保存先」を確認し、残したい対象を表示して「保存」を押す。
3. 保存済みの状態からやり直すときは「再読込」を使う。未保存の変更があれば確認が出る。

| 編集対象 | 調整するもの | 保存先 |
|---|---|---|
| 炎 | PixelFireの形・動き・粒子・層・輪郭、ステージや参照PNGとの合成 | 選択中の `res://data/visuals/*.tres`。別名複製も可能 |
| オーラ・後光 | 伝説モジュール獲得時のオーラと後光 | 選択中の `res://data/legendary_modules/*.tres`。画像ベイクは画面内の別操作 |
| マップ | 線・波形・星図・モニター効果 | `res://data/map_reveal_settings.tres` |
| 目印の星・エリート | ツール内プレビュー用のピクセル演出の密度・形・動き・色。ゲーム本編の描画には適用しない | それぞれ `res://data/visuals/landmark_mark.tres`・`res://data/visuals/elite_mark.tres` |

編集対象を切り替えても調整中の値は保持される。上部「保存」は**表示中の保存先だけ**へ書き込む。未保存の対象は印で分かり、閉じる際も確認できる。ゲーム本編で使う対象の保存結果は次の通常起動で確かめる。

炎タブは再生・停止・コマ送り・速度切替、配置のドラッグや表示ズーム、[透明PNGの出力確認](pixel-fire-2d.md#透明pngを書き出す)も使える。炎の設定保存とステージへの配置保存は別操作。

## 炎タブの項目

炎タブでは形・発生源・発生/秒・寿命・上昇・横揺れ、粒子・3層の色、輪郭・発光、再生と配置、透明PNGを調整できる。各項目の範囲・初期値は[炎の使い方](pixel-fire-2d.md#炎の調整値)を参照する。炎タブ上部の「保存」は現在のプリセットだけに作用する。

## オーラタブの項目

選択中の伝説モジュールだけをプレビューする。値の変更はその場の表示へ反映し、上部「保存」で選択中の `res://data/legendary_modules/*.tres` に残す。
以下の上限はスピン操作の表示範囲。手入力では上限を超える値も受け付けるので、極端な値は実際のプレビューで確認する。

| 画面の項目 | 作用と増減 | 入力範囲・既定 |
|---|---|---|
| モジュール | 編集する獲得演出の対象。切替後も別モジュールの未保存値は保持する | 登録済みモジュールから選択 |
| 生成プレビュー／ベイク再生 | 調整用の生成表示と、ゲームで使うベイク済み画像の表示を切り替える | 表示方法だけの切替 |
| 表示レイヤー | 合成・オーラのみ・後光のみの表示確認 | 表示方法だけの切替 |
| 一時停止 | 演出の時間進行を止めて比較する | プレビューだけ |
| X・Y | オーラの基準位置からのずれ。画像本体の位置は変えない | X −640〜640、Y −360〜360 デザインpx、既定0 |
| 横・縦 | オーラ領域の幅・高さの倍率。画像本体の大きさは変えない | 各0.05〜5倍、既定1 |
| 角度（度） | オーラ領域を中心の周りで回す | −180〜180度、既定0 |
| 形状マスク・マスクを選ぶ | オーラを発生させる輪郭画像。選んだテクスチャを対象モジュールへ設定する | 未指定なら表示画像のアルファを使用 |
| 透過画像：アルファを使う／白黒画像：白を生成元にする | マスクの不透明部か、白い部分を生成領域にする。透明部はどちらも使わない | 2方式、既定はアルファ |
| マスク解除（旧表示の確認用） | 専用マスクを外して表示画像のアルファへ戻す | 明示保存で確定 |
| オーラをベイクして保存 | 現在のマスクと調整値からゲーム用の前後2枚のアトラスを作る | マスク指定が必要。256×186 px、32フレーム、8列、8fpsの既定設定 |

「設定だけ保存」はモジュールの数値を保存する操作。ゲームで使うオーラ画像は「オーラをベイクして保存」で別に生成する。生成プレビューの見た目だけで完成扱いにせず、「ベイク再生」でも確かめる。

## 後光タブの項目

後光も選択中の `LegendaryModuleDef` へ保存する。表の「既定」はモジュールに個別値がないとき演出シーンが使う値で、選択中モジュールの保存値とは限らない。

| 画面の項目 | 作用と増減 | 入力範囲・既定 |
|---|---|---|
| 光条の太さ | 後光の線の幅を増減する | 0.5〜2倍、既定1.1 |
| 主光条の本数 | 太い光条を増減する | 4〜64本、既定18 |
| 細光条の本数 | 細い光条を増減する | 8〜256本、既定96 |
| 光条の長さ | 中心から伸びる距離の倍率 | 0.3〜2倍、既定1 |
| 動きの速さ | 後光の時間変化を速める。0で時間変化を止める | 0〜3倍、既定1 |
| 長さ・幅・明滅の変動幅 | 光条の呼吸する動きの振れ幅 | 0〜1、既定0.85 |
| 後光の明るさ | 後光全体の強さ | 0〜1、既定0.8 |
| 主光条の強さ・細光条の強さ | それぞれの線の寄与を増減する | 各0〜4、既定1.2／0.9 |
| 白い芯の強さ | 中心の白い光を強める | 0〜4、既定2.6 |
| 白い芯の広さ | 白い中心領域を広げる | 0.08〜0.35、既定0.14 |
| 後光の色 | 後光の色調を選ぶ | RGB色。対象モジュールの保存値を確認 |
| 後光を既定値に戻す | 選択モジュールの後光の個別設定を消し、演出シーンの既定値を使う | 上部「保存」で確定 |

## マップタブの項目

「再生 / マップを開く」で演出を再確認する。変更はプレビューへ即時反映し、上部「保存」で `res://data/map_reveal_settings.tres` に保存する。通常ゲームは次の起動から保存値を使う。表の既定値は現在の設定リソースのスクリプト初期値で、保存済み値があれば画面表示を優先する。

| 画面のまとまり・項目 | 作用と増減 | 入力範囲・初期値 |
|---|---|---|
| 接続線と点灯：線の秒数 | 線が伸び切るまで。0で即時表示 | 0〜2秒、0.22 |
| 伸長の減速 | 1は等速。大きいほど線の先端がゆっくり止まる | 1〜4、1.6 |
| 点灯まで秒 | 線の完了後、情報が点灯し始めるまでの待ち | 0〜1秒、0.035 |
| フェード秒 | 情報が通常の明るさになるまで | 0〜2秒、0.28 |
| 発光強度 | 点灯途中の一時的な発光。0で加えない | 0〜1、0.22 |
| 波形：棒の速さ | 棒のアタック・保持・減衰の周期を速める | 0〜5、0.15 |
| 通常の高さ | 持続する波形の高さの中心 | 0〜1、0.45 |
| 振幅の変化量 | 通常の高さから動く幅 | 0〜1、0.85 |
| 帯域の同期 | 隣り合う帯域の反応を混ぜる。0は個別、1は帯域ごとに揃う | 0〜1、0.18 |
| 大きい音/秒 | 全体ピークが重なる頻度。0は無効、1は約1回/秒 | 0〜1、0.08 |
| 大きい音の強さ | ピーク時に波形が高くなる量 | 0〜1、0.95 |
| 天球図：天球の動き | 軌道上の光の移動速度。中心と軌道は固定 | 0〜0.2、0.025。0で静止 |
| モニター効果：CRT | 走査線・画素マスク・周辺減光・にじみの強さ | 0〜1、0.25 |
