# ビジュアル編集

[ツール一覧](index.md)

**開く：** Godot「プロジェクト → ツール → ビジュアル編集」または上部「▶ ビジュアル編集」。別のプレビューウィンドウが前面に開く。

1. 上部の「ツール」で炎・オーラ・後光・マップ・目印の星・エリート・戦闘エフェクトから選ぶ。中央で変化を見ながら、右側の対象に応じた調整値を変える。
2. 上部の「保存先」を確認し、残したい対象を表示して「保存」を押す。
3. 保存済みの状態からやり直すときは「再読込」を使う。未保存の変更があれば確認が出る。

| 編集対象 | 調整するもの | 保存先 |
|---|---|---|
| 炎 | PixelFireの形・動き・粒子・層・輪郭、ステージや参照PNGとの合成 | 選択中の `res://data/visuals/*.tres`。別名複製も可能 |
| オーラ・後光 | 伝説モジュール獲得時のオーラと後光 | 選択中の `res://data/legendary_modules/*.tres`。画像ベイクは画面内の別操作 |
| マップ | 線・波形・星図・モニター効果 | `res://data/map_reveal_settings.tres` |
| 目印の星 | 本編と共通の輪郭オーラを、輪郭・動きと方向・ノイズ・発光と色の組で調整する。方向の統一性、方向場、各ノイズ層の周波数・流速・強さ・位相、濃淡と明滅も保存する | `res://data/visuals/landmark_mark.tres` |
| エリート | ツール内プレビュー用のピクセル演出の密度・形・動き・色 | `res://data/visuals/elite_mark.tres` |
| 戦闘エフェクト | 武器・特性・ボス本体・ボス技・敵の技・HUDの表示を選び、色・形・時間・粒子の表示値を調整する。本番描画を使う試遊で再生・停止・コマ送り・速度切替ができる | `res://data/visuals/effect_settings.tres` |

目印の輪郭素材は、リポジトリルートから `python3 speed/tools/art/bake_landmark_masks.py` で制作する。Pillow・NumPy・SciPyを使い、候補の可視画像と既存の仮図形から `speed/assets/effects/landmark/` だけへ保存する。敵のサイズは本体の倍率へ追従する。候補・外観参照・透過形状を変えたら同じコマンドで更新し、素材をコミットする。正規コンテンツ生成は入力ハッシュと生成済み素材の整合を確認する。

目印の方向は船体の画像座標を基準にし、0度は右、90度は下、-90度は上へ流れる。「方向の統一性」は、指定方向と各位置・ノイズ層の方向場を補間する。1で全層の方向をそろえ、下げるほど「向きのばらつき」と方向場の細かさ・変化速度が作用する。編集欄とshaderの対応は `EnemyMarkSettings.AURA_FIELDS` に持ち、マスク参照・寸法・距離の復号は描画側の固定契約として扱う。

目印の編集値は「保存」で `landmark_mark.tres` へ保存する。本番への反映は、保存後にAIへ依頼するか、リポジトリルートから `python3 speed/tools/art/bake_landmark_aura.py` を実行する。共通の `build_aura.gdshader` と設定の既定値を入力に、38項目を定数へ特殊化した `landmark_aura_runtime.gdshader` と、ノイズを参照する `landmark_aura_material.tres` を保存する。ツールのプレビューは共通shaderで編集値を表示し、本番は明示的に焼き込んだ値を使う。

目印の星とブーストゲージは、ステージを選び、本番の背景・星・敵の塗装と法線・自機・HUDを同時に表示して調整する。「開始地点」「背景素材の付近」で代表配置を切り替える。目印の対象は本編の抽選条件と同じ星2〜5の敵から日本語名で選び、じょうぎ座の合体と各分離部位、ポンプの膨張も切り替える。三角座は可視の3つの星へオーラを表示する。戦闘と入力を止めた専用ランを使い、対象とカメラを固定する。一時停止と先頭への戻しは表示の時計だけに作用し、対象・配置の切替も未保存の調整値を保持する。既存の生成済みステージとマスクを使い、プレビューから本番用素材を再生成しない。

ブーストゲージの本番への反映は、調整を保存してからAIへ依頼するか、`python3 speed/tools/art/bake_boost_gauge.py` を実行する。`effect_settings.tres` の `hud/boost_gauge` だけを読み、未指定の色と半径は共通描画の既定値から解決して `boost_gauge_runtime.tres` へ保存する。本番HUDはこの共有Resourceの色・円帯・目盛りを使い、ツールは編集値から同じ形式を作ってプレビューする。

「敵の技 → 自爆する雑魚 · 自爆の爆発」の「シェーダ」では、外炎の市松の強さを0〜1で調整する。0は半透明の外炎、1は市松の間引きを使う。他の爆発は各武器の専用設定で同じ項目を調整する。

戦闘エフェクトでは、右側の対象一覧で編集対象を選ぶ。右側は武器・特性・ボス本体・ボス技・共通攻撃で区分し、武器と特性には図鑑・装備枠と共通のアイコンを使う。武器と特性を順に選ぶと併用して試遊でき、中央上部のLv指定と解除ボタンは試遊装備だけに作用する。再生・一時停止・コマ送り・先頭からの再生は中央上部のアイコンで操作し、名前と説明はツールチップに表示する。武器・特性のプレビューは装備と敵の本番描画を表示する。「敵を追加」で機体の前方に敵を3体出せる。中央の左ドラッグで発生位置、右クリックで方向を決め、停止状態で新しい位置と方向を表示する。再生中は実際の移動・接触・終点まで進め、発動を繰り返す。調整中の値は停止中の表示にも反映し、「保存」で通常ゲーム用の設定へ書き込む。発生時に粒数を決める項目は次の発生から反映する。

ボス技はステージ順のボスごとに折り畳め、登録された全技を技データの表示名で選ぶ。選択と試遊はボスIDと技IDを使い、専用表示シーンを持つ技も、別の描画部品で表示する技も同じ一覧に置く。保存キーは `boss/move/<ボスID>/<技ID>` とし、既存の表示シーンの保存値を未指定項目の既定値として引き継ぐ。

各技の「本体」は、その技の間だけ使う発光・色・表示サイズを調整する。技が切り替わると「ボス本体」の共通値へ戻す。専用エフェクトを持つ技は、その部品の粒・線・輪・余韻も調整する。組み合わせや猟犬の移動を行う技も同じ一覧から試遊する。

ボス技の試遊はボスと攻撃の広がりを収める専用カメラを使い、標的の吹き飛びから構図を独立させる。一回の試行中は攻撃範囲に合わせて視野を広げ、再実行で構図を初期化する。標的の吸引・吐出は本番の攻撃処理で進める。

大犬の「焼き焦がす光」「追い立てと狙撃」「光を継ぐ群れ」は、それぞれの技で放射する炎を調整する。「シリウスの光」は炎、「燃える猟犬」は点火・猟犬・爆炎、「焼き焦がす光」は焼け跡も調整する。ギアアップの炎は「特性 → ギアアップ」で調整する。密度・表示粒の寿命・揺れ・3層の比率・色・輪郭・ドット・発光を使用元別に保存し、「品質・負荷」では描画域・密度画素・更新FPS・表示粒上限を調整する。変更は表示用プリセットの複製へ適用する。

りゅう座の「吸引と吐き出し」は光線の芯・内側・縁、幅の揺れ、ノイズの密度と流速、光の筋、口元の光の成長、発光と薄まりを調整する。各技の予告線・塗り・軌跡・着弾の余韻も調整する。うみへび座の各技は輪と光条・破片に加え、「攻撃本体」で光線・風・雷・竜巻のノイズ、流れ、芯、輪郭、濃さと明るさを調整する。値は技の `shape/` 内へ保存し、組み合わせ技もその技の所有元を使う。光弾・光の矢を使う技は「弾の表示」でその技だけの大きさ・長さ・幅・芯・色を調整し、降下する矢も同じ `projectile/` の値を読む。表示に必要なsampler・時刻・進行度・種・HDR復号・判定の寸法は描画側が管理する。

「敵の技」では、ほうおう座の着地の炎を13項目で調整し、わし座は進路へ落とす円内放電の本数・長さ・太さ・光と輪郭を調整する。敵の技も本番の敵と描画を使って再生・停止・コマ送り・再実行する。

| 対象 | 試遊で見えるもの |
|---|---|
| 武器・特性 | 武器と特性を各1つまで組み合わせ、各Lvを指定する。標的がなくても射撃や接触の描画イベントを試遊用に起こす。描画は本番の装備と描画器を使う |
| 数値だけの特性 | 固有演出を持たない。射撃数や移動距離など描画に現れる作用は、選択した武器または標準の射撃と移動で比べる。攻撃力や回収量など数値だけの変化は画面上に専用演出を出さない |
| ボス技 | 選択したボスID・技IDを本番のボス試遊で開始する |
| `boss/final_strike` | ボスをおおいぬ座・ケンタウルス座・いっかくじゅう座から選び、制限時間の一撃を開始する。3体が共有する演出設定を表示する |

編集対象を切り替えても調整中の値は保持される。上部「保存」は**表示中の保存先だけ**へ書き込む。未保存の対象は印で分かり、閉じる際も確認できる。ゲーム本編で使う対象の保存結果は次の通常起動で確かめる。

### 戦闘エフェクトの調整項目

項目は選んだ効果が使う値だけを表示する。見出しと区切り線で「色」「形・大きさ」「動き・時間」「粒子」「シェーダ」に分け、増減の作用は各欄のツールチップに示す。倍は元の表示値への倍率、px は画面上の表示幅、秒は表示時間を表す。攻撃判定や威力は変えない。

| 画面の項目 | 表示で変わるもの |
|---|---|
| 全体色 | 描画結果の色。白で元の色を使う |
| 描画サイズ（倍）、ドット幅（倍）、発生粒数（倍）、残光時間（倍） | 快進撃のオーラ、ミラージュの分身 |
| シェーダの項目 | 武器・特性・共通攻撃の演出の shader の値（炎の色と崩れ方、双極ビームの帯、エンドホールのレンズ、震空の歪み、快進撃のオーラの色など）。項目は shader が調整用にまとめた値から並ぶ |
| 炎の表示（秒）、ドット幅（倍）、描画サイズ（倍） | 「ツール：戦闘エフェクト → 共通攻撃 → 自爆の爆発」。専用シーンを反復再生し、再生・停止・コマ送り・先頭への戻しで調整する。炎の4色・ノイズ・崩れ方・燃焼速度は「シェーダ」で調整する |
| ブーストゲージの色・半径 | 「ツール：戦闘エフェクト → HUD → ブーストゲージ」で通常・25%未満の不足色・経路描画中・使用可能時の波紋・下地・使用可能と不足時の目盛り・満タン時のフラッシュをカラーピッカーで選ぶ。1周目と2周目それぞれの内側・外側の半径を独立して保存し、帯幅と周の間隔を決める。目盛り線の太さも保存し、実表示を1周目の帯内へ収める |
| 稲妻の表示（秒） | 接触雷が残る時間 |
| 空間のゆがみ（倍）、分身の不透明度 | 背景のずれ、残像の濃さ |
| 航跡の長さ（px）、航跡の半幅（px）、航跡の消失（秒）、航跡の不透明度、航跡の筋の密度、航跡の色 | ソニックブームの航跡 |
| 予告線の幅（px）、閃光の時間（秒）、爆発ドット幅（倍） | うみへび座の予告と攻撃 |
| 胸の光の半径（px）、胸の光の不透明度、帆の星の大きさ（倍）、シリウスの光の広さ（倍）、推進炎の長さ（倍） | 各ボス本体の表示 |

シェーダの項目は、各 shader の `group_uniforms tuning;` の中の値。保存先は `effect_settings.tres` の装備キーまたは共通攻撃のシーンパスで、同じキーの本番描画に適用する。自爆する雑魚の炎は `res://scenes/attacks/zone_bomber.tscn` の専用キーに4色と崩れ方・燃焼速度・初期サイズ・閃光を保存する。停止中のシェーダ調整もその場で表示へ反映する。装備キーは図鑑の実演にも使う。ギアアップの炎の形は炎タブで `gear_fire.tres` を開いて調整する。

ブーストゲージの試色は通常・不足・経路描画中・使用可能時の波紋・満タンの閃きを切り替え、本番HUDと同じ描画位置・関数を使う。中心はプレビュー内に固定でき、「マウスへ追従」で本番と同じカーソルからの位置を確認できる。色は `effect_settings.tres` の `hud/boost_gauge` に保存し、未設定の色は既定色を使う。他の効果の設定も保持し、保存後の本番への反映は明示的なベイクで行う。

半径の単位は従来のゲージと同じ描画座標のpx。中心から各縁までの距離を指定する。内側が外側へ達した場合は、動かした縁を優先して反対側を補正し、編集欄にも表示する。各帯は正の幅を保ち、目盛り線の実表示の太さは1周目の幅の半分までに制限する。3周目以降は2周目の帯幅を使い、従来の周間隔で外へ並べる。旧保存値の太さは同じ形の4半径へ読み替え、編集画面で保存すると半径の値へ置き換える。

炎タブは再生・停止・コマ送り・速度切替、配置のドラッグや表示ズーム、[透明PNGの出力確認](pixel-fire-2d.md#透明pngを書き出す)も使える。炎の設定保存とステージへの配置保存は別操作。

## 炎タブの項目

炎タブでは形・発生源・発生/秒・寿命・上昇・横揺れ、粒子・3層の色、輪郭・発光、再生と配置、透明PNGを調整できる。各項目の範囲・初期値は[炎の使い方](pixel-fire-2d.md#炎の調整値)を参照する。炎タブ上部の「保存」は現在のプリセットだけに作用する。

## オーラタブの項目

選択中の伝説モジュールだけをプレビューする。値の変更はその場の表示へ反映し、上部「保存」で選択中の `res://data/legendary_modules/*.tres` に残す。
以下の上限はスピン操作の表示範囲。手入力では上限を超える値も受け付けるので、極端な値は実際のプレビューで確認する。

| 画面の項目 | 作用と増減 | 入力範囲・既定 |
|---|---|---|
| モジュール | 編集する獲得演出の対象。切替後も別モジュールの未保存値は保持する | 登録済みモジュールから選択 |
| 生成プレビュー／ベイク再生 | 調整用の生成表示と、ゲームで使うベイク済み画像の表示を切り替える | 表示方法だけの切替 |
| 表示レイヤー | 合成・オーラのみ・後光のみの表示確認 | 表示方法だけの切替 |
| 一時停止 | 演出の時間進行を止めて比較する | プレビューだけ |
| X・Y | オーラの基準位置からのずれ。画像本体の位置は変えない | X −640〜640、Y −360〜360 デザインpx、既定0 |
| 横・縦 | オーラ領域の幅・高さの倍率。画像本体の大きさは変えない | 各0.05〜5倍、既定1 |
| 角度（度） | オーラ領域を中心の周りで回す | −180〜180度、既定0 |
| 形状マスク・マスクを選ぶ | オーラを発生させる輪郭画像。選んだテクスチャを対象モジュールへ設定する | 未指定なら表示画像のアルファを使用 |
| 透過画像：アルファを使う／白黒画像：白を生成元にする | マスクの不透明部か、白い部分を生成領域にする。透明部はどちらも使わない | 2方式、既定はアルファ |
| マスク解除（旧表示の確認用） | 専用マスクを外して表示画像のアルファへ戻す | 明示保存で確定 |
| オーラをベイクして保存 | 現在のマスクと調整値からゲーム用の前後2枚のアトラスを作る | マスク指定が必要。256×186 px、32フレーム、8列、8fpsの既定設定 |

「設定だけ保存」はモジュールの数値を保存する操作。ゲームで使うオーラ画像は「オーラをベイクして保存」で別に生成する。生成プレビューの見た目だけで完成扱いにせず、「ベイク再生」でも確かめる。

## 後光タブの項目

後光も選択中の `LegendaryModuleDef` へ保存する。表の「既定」はモジュールに個別値がないとき演出シーンが使う値で、選択中モジュールの保存値とは限らない。

| 画面の項目 | 作用と増減 | 入力範囲・既定 |
|---|---|---|
| 光条の太さ | 後光の線の幅を増減する | 0.5〜2倍、既定1.1 |
| 主光条の本数 | 太い光条を増減する | 4〜64本、既定18 |
| 細光条の本数 | 細い光条を増減する | 8〜256本、既定96 |
| 光条の長さ | 中心から伸びる距離の倍率 | 0.3〜2倍、既定1 |
| 動きの速さ | 後光の時間変化を速める。0で時間変化を止める | 0〜3倍、既定1 |
| 長さ・幅・明滅の変動幅 | 光条の呼吸する動きの振れ幅 | 0〜1、既定0.85 |
| 後光の明るさ | 後光全体の強さ | 0〜1、既定0.8 |
| 主光条の強さ・細光条の強さ | それぞれの線の寄与を増減する | 各0〜4、既定1.2／0.9 |
| 白い芯の強さ | 中心の白い光を強める | 0〜4、既定2.6 |
| 白い芯の広さ | 白い中心領域を広げる | 0.08〜0.35、既定0.14 |
| 後光の色 | 後光の色調を選ぶ | RGB色。対象モジュールの保存値を確認 |
| 後光を既定値に戻す | 選択モジュールの後光の個別設定を消し、演出シーンの既定値を使う | 上部「保存」で確定 |

## マップタブの項目

「再生 / マップを開く」で演出を再確認する。変更はプレビューへ即時反映し、上部「保存」で `res://data/map_reveal_settings.tres` に保存する。通常ゲームは次の起動から保存値を使う。表の既定値は現在の設定リソースのスクリプト初期値で、保存済み値があれば画面表示を優先する。

| 画面のまとまり・項目 | 作用と増減 | 入力範囲・初期値 |
|---|---|---|
