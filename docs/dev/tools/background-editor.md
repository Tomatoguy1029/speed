# 背景編集

[ツール一覧](index.md)

**開く：** Godot「プロジェクト → ツール → 背景編集」。別のプレビューウィンドウが開く。

1. ステージを選び、素材一覧から背景画像を追加する。
2. キャンバスで配置を選択・ドラッグし、位置・大きさ・回転・不透明度・視差・色を調整する。
3. 前後関係や複製・削除を確認し、プレビューで動きを見る。必要なら元に戻す／やり直すを使う。
4. 「保存」で対象ステージへ反映し、[本番ラン](stage-launch.md)で確認する。

保存先は選択した `res://data/stages/stage_<番号>.tres` の背景配置。素材画像自体は書き換えない。保存前に別の編集でステージが変わったときは競合表示を確認し、読み直してから操作する。
