# 背景編集

[ツール一覧](index.md)

**開く：** Godot「プロジェクト → ツール → 背景編集」。別のプレビューウィンドウが開く。

1. ステージを選び、右欄上部の「背景の地色」で画面全体の色を調整する。「星を表示」は初めからONで、地色・星・背景素材を同時に確認できる。
2. 素材一覧から背景画像を追加する。
3. キャンバスで配置を選択・ドラッグし、位置・大きさ・回転・明るさ・視差・色を調整する。
4. 前後関係や複製・削除を確認し、プレビューで動きを見る。必要なら元に戻す／やり直すを使う。
5. 「ステージへ保存」で対象ステージへ反映し、[本番ラン](stage-launch.md)で確認する。

保存先は選択した `res://data/stages/stage_<番号>.tres` の地色と背景配置。「星を表示」はプレビューだけの切替。素材画像自体は書き換えない。保存前に別の編集でステージが変わったときは競合表示を確認し、読み直してから操作する。

## 配置と表示の操作

素材一覧は `res://assets/pixel/background/*.png` を表示する。素材を追加した後、配置一覧またはキャンバスで選ぶ。左ドラッグは位置変更、中ボタンドラッグは表示の移動、ホイールは表示倍率（0.02〜8倍）の変更。「開始地点へ」は表示中心を原点・表示倍率0.65へ、「選択を拡大」は選択配置へ表示を合わせる。「ガイド表示」は目安線の表示だけを切り替える。「視差プレビュー」は画面移動時の見え方を確認するモードで、ONの間はキャンバス上の位置ドラッグを止める。

| 画面の項目 | 何を変えるか | 入力範囲・単位 |
|---|---|---|
| 背景の地色 | 星と背景素材の背後に描く画面全体の色。配置を選ばずに編集できる | RGB色 |
| 星を表示 | 本番と共通の星の表示をプレビューで切り替える | 初期ON、保存対象外 |
| 位置 X・位置 Y | ステージ開始地点を基準にした背景の中心。増やすと右・下へ動く | 各−100000〜100000、ゲーム内距離単位、刻み1 |
| サイズ倍率 | 元画像の表示寸法。大きいほど画面で広く占める | 0.05〜10倍、刻み0.05 |
| 回転（度） | 背景画像の向き | −180〜180度、刻み1 |
| 明るさ（0＝黒、1＝元の明るさ） | 画像RGBへ掛ける明るさ。透明度ではなく、元画像のアルファは保持する | 0〜1、刻み0.01 |
| 移動倍率（0＝固定、1＝通常） | カメラ移動に対する画面上の追従。0は画面固定、1は通常の背景移動 | 0〜1、刻み0.05 |
| 重ねる色 | 画像RGBに重ねる色調。明るさの値とは独立して選ぶ | RGB色 |
| 奥へ・手前へ | 配置配列の順番を1段動かす。重なったときの描画順に作用 | 選択配置があるときだけ有効 |
| 複製・削除 | 選択配置を40×40ずらして複製、または配置を除去 | 素材ファイル自体は変更しない |
| 元に戻す・やり直す | 地色と配置操作の履歴を戻す・進める | 履歴は最大50操作 |

新しく追加した配置の初期値は位置0、倍率1、回転0度、移動倍率1、重ねる色 `#8ca6bf` 相当・明るさ0.7。選択した配置の値は右欄で確認する。変更は「ステージへ保存」を押したときだけ確定する。外部でステージファイルが変わっていれば保存を止める。
