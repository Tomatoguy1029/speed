# 敵描画ベンチ

[ツール一覧](index.md)

**開く：** Godot「プロジェクト → ツール → 敵描画ベンチ」。計測用ウィンドウが開く。

大量の簡易な敵を一定の条件で動かし、敵の更新・描画の負荷を調べる開発用ベンチ。計測終了後、Godotの「出力」に `[perf]` で始まる処理時間・フレーム時間などの数値を出す。

1. ほかの負荷条件をそろえて起動する。
2. 計測が終わったら「出力」の数値を読む。変更前後は同じ環境・条件で比較する。

ステージ配置や敵定義を保存する画面ではない。普段の遊び心地は[通常ランの録画](../stage-production.md#6-記録と感想で調整する)で確かめる。
