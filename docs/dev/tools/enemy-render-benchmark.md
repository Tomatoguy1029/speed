# 敵描画ベンチ

[ツール一覧](index.md)

**開く：** Godot「プロジェクト → ツール → 敵描画ベンチ」。計測用ウィンドウが開く。

大量の簡易な敵を一定の条件で動かし、敵の更新・描画の負荷を調べる開発用ベンチ。計測終了後、Godotの「出力」に `[perf]` で始まる処理時間・フレーム時間などの数値を出す。

1. ほかの負荷条件をそろえて起動する。
2. 計測が終わったら「出力」の数値を読む。変更前後は同じ環境・条件で比較する。

ステージ配置や敵定義を保存する画面ではない。普段の遊び心地は[通常ランの録画](../stage-production.md#6-記録と感想で調整する)で確かめる。

## 計測条件と結果

メニューからの起動では、敵1300体、固定更新120回/秒、計測10秒が既定。最初の1秒は集計から外す。敵は1種類の簡易データで、決まった乱数から配置し、追跡・近傍探索・接触・なぞり判定・MultiMesh描画を測る。実ステージの敵AI全種類を再現する試遊ではない。

コマンドラインで直接起動する場合だけ、Godot引数の `--` より後に次を指定できる。メニュー内に入力欄はない。

| 引数 | 作用・既定値 |
|---|---|
| `--count=数` | 簡易敵の体数。既定1300。大きいほど更新・描画の負荷を増やす |
| `--ticks=数` | 1秒あたりの固定更新回数。既定120。大きいほど1秒の更新回数が増える |
| `--seconds=秒` | 計測の長さ。既定10秒、先頭1秒を除いて集計 |
| `--layers` | 層別SubViewportとHDRの光のにじみを追加。指定しないと無効 |
| `--shot=パス` | 終了直前の画面を指定PNGへ保存。指定しないと画像保存なし |

出力の `tick_avg_ms`・`tick_p95_ms` は固定更新1回の平均・95パーセンタイル、`per_second_ms` は更新分の毎秒換算。`frame_avg_ms`・`fps`・`gpu_avg_ms` は画面1フレームの時間・速度・GPU時間。`path_hits`・`contact_hits` は計測中の判定件数で、同条件比較の確認に使う。環境と描画方式も先頭の `[perf]` 行に出る。
