# データ編集

[ツール一覧](index.md)

**開く：** Godot「プロジェクト → ツール → データ編集」。エディター内の別ウィンドウが開く。

1. 左側でデータの種類と項目を選ぶ。検索や比較表で対象の値を確認する。
2. 項目の説明と現在値を見て変更する。必要なら読み直しボタンで外部編集を取り込む。
3. 変更した値を通常ランや対応するプレビューで確認する。

値を変えると、対象の `res://data/` 配下の `.tres` へ**その場で保存**される。別の「保存」操作は不要。共通データの変更は参照するステージ全体に及ぶ。ボスの共通数値もここで見られるが、区間・技のつながりは[ボスAI](boss-ai.md)で編集する。ステージだけの敵上書きには[ステージ敵調整](stage-enemy-tuning.md)を使う。
