# データ編集

[ツール一覧](index.md)

**開く：** Godot「プロジェクト → ツール → データ編集」。エディター内の別ウィンドウが開く。

1. 左側で種類と項目を選ぶ。検索で内部名や説明も探せる。種類の見出しでは全件の比較表が開く。
2. 値と単位・説明を確認して変更する。数字は直接入力、整数のボタンは±1、小数のボタンは現在値の±10%（0なら±0.1）。
3. 編集は `res://data/` 内の選択リソースへ**即保存**。外部で編集したら「読み直す」を押す。実行中のランには自動反映されない値があるので、試遊を起動し直して確認する。

**入力の制約：** この画面は数値の意味上の上限・下限を一律には検証しない。型として読めない文字列は元へ戻す。下表の「0〜1」などはデータ定義の意味上の範囲で、必ずしも入力欄が強制する範囲ではない。整数配列はカンマ区切りで編集できる。リソース参照の配列・位置配列などはこの画面では読み取り／参照先を開く用途で、要素の追加や配置編集は専用画面またはGodot Inspectorを使う。IDを変えると参照が切れる可能性がある。

**調整先：** 敵種類の `params` は[ステージ敵調整の項目表](stage-enemy-tuning.md#敵固有の数値項目)、ボスの区間・技の接続は[ボスAI](boss-ai.md)、ステージ内の出現クリップは[出現タイムライン](spawn-timeline.md)を参照。この画面の敵定義・ボス定義は全ステージ共通。ステージ敵調整は選択ステージだけの上書き。

## 画面に出る項目

以下は現行 `res://data/` の直下と1階層下を走査し、各定義の画面用説明から作った一覧。**同じ種類でも選ぶリソースによって現在値・辞書キーが異なる。** 単独設定の値もGodotの現在値を確認してから変更する。`—` は定義に単位がない欄。`参照表示` はこの画面で要素を直接追加・変更できない配列・参照欄。`visuals/` は異なる設定クラスが同じフォルダにあり、データ編集はフォルダ先頭のクラスから欄を組み立てるため、個別の表示が一致しない可能性がある。炎・マップは各専用の[ビジュアル編集](visual-editor.md)を使う。

### 調整値

対象：`res://data/config.tres`。

#### ラン

| 画面の欄（内部名） | 何を変えるか | 単位・入力上の注意 |
|---|---|---|
| ボスが出る時刻 (`boss_time`) | ボスは、ラン開始からこの時間と「ボスが出る時刻の幅」の間のどこかで1体現れる。 | 実秒 |
| ボスが出る時刻の幅 (`boss_time_spread`) | ボスが出る時刻を、ランごとにこの幅の中でずらす。 | 実秒 |
| ボスの HP (`boss_hp`) | ボスの最大 HP。敵の HP 倍率も掛かる。 | HP |
| ボスの装甲 (`boss_armor`) | これより低い攻撃力の体当たりは弾かれる。敵の装甲倍率も掛かる。 | 攻撃力 |
| クリア報酬の部品 (`clear_bonus`) | ボスを倒してクリアしたとき、獲得した部品に足す数。 | 個 |
| 速度表示の換算 (`speed_to_kms`) | 画面の速度メーターで km/s を出すときに、ゲーム内の速さに掛ける値。見た目だけで、ゲームの動きは変わらない。 | 倍 |

| Lv別の発射間隔 (`interval_by_level`) | 後方ブラスター・迎撃ドローンのLv1から順の発射間隔。共通の頻度係数は適用しない。 単位：世界秒。 |
| 吹き飛ばし (`knock`) | 当たった敵を押し出す強さ。 単位：単位/秒。 |
| 寿命 (`life`) | 弾・機雷が消えるまでの時間。 単位：世界秒。 |
| 最大数 (`max`) | 同時に置いておける機雷の数。 単位：個。 |
| 発動する最短の距離 (`min_length`) | 双極ビーム：発射器と機体がこの距離より近いと撃たない。 単位：単位（距離）。 |
| 回る半径 (`orbit`) | ドローンが機体の周りを回る距離。 単位：単位（距離）。 |
| 編隊の回転速度 (`orbit_speed`) | 迎撃ドローン：自機の周りを周回する角速度。 単位：ラジアン/秒。 |
| 範囲 (`radius`) | 波動・爆発の半径。性能段階が上がると広がる。 単位：単位（距離）。 |
| 届く距離 (`range`) | ドローン：狙う敵を探す距離。接触電撃：電撃が隣の敵へ届く距離。 単位：単位（距離）。 |
| 復帰の速さ (`return_rate`) | 突進範囲ドローン：待機位置へ戻る補間の速さ。 単位：1/秒。 |
| 弾の半径 (`shot_radius`) | 迎撃ドローン：弾の当たり判定の半径。 単位：単位（距離）。 |
| 撃ち出す速さ (`shot_speed`) | 質量牽引砲：機体の速さに加える船体弾の速さ。迎撃ドローン：弾の速さ。 単位：単位/秒。 |
| Lv別の弾数 (`shots_by_level`) | 後方ブラスターのLv1から順の同時発射数。共通の性能係数は適用しない。 単位：発。 |
| 吹き飛ぶ時間 (`shove_time`) | 吹き飛ばした敵が飛んでいく時間。この間にほかの敵へぶつかるとダメージを与える。 単位：世界秒。 |
| 大きさの基準 (`size_ref`) | 質量牽引砲：船体の半径がこの値より大きいほど威力が上がる（半径 ÷ この値 倍、1倍未満にはしない）。 単位：単位（距離）。 |
| 置く間隔 (`spacing`) | 通った線に、この距離ごとに機雷を置く。性能段階が上がると狭まる。 単位：単位（距離）。 |
| 吹き飛ばす速さ（基本） (`speed_base`) | 触れた敵を吹き飛ばす速さ ＝ 基本 ＋ 段階ごとの増加 × 性能段階。 単位：単位/秒。 |
| 吹き飛ばす速さ（段階ごと） (`speed_per_tier`) | 性能段階が1上がるごとに足す、吹き飛ばす速さ。 単位：単位/秒。 |
| 弾の間隔の角度 (`spread_step`) | 弾を複数撃つとき、弾同士の角度の間隔。 単位：ラジアン。 |
| Lv別の光跡の長さ (`tail_by_level`) | 突進範囲ドローン：実際の経路へ残す演出の長さ。character_scale を掛ける。 単位：単位（距離）。 |
| 照準を分散する間隔 (`target_interval`) | 迎撃ドローン：射撃後に同じ敵への新たな照準を保留する時間。 単位：世界秒。 |
| 衝撃波の進む時間 (`travel`) | 衝撃波が機体と一緒に進路を進む時間。 単位：実秒。 |
| 反応する距離 (`trigger`) | 敵がこの距離に入ると機雷が爆発する。 単位：単位（距離）。 |
| 見せる数 (`visible`) | 質量牽引砲：機体の後ろの塊に見せる船体の数。弾の数そのものには上限がない。 単位：体。 |
| 幅 (`width`) | 双極ビーム：ビームの幅。性能段階が上がると広がる。 単位：単位（距離）。 |
