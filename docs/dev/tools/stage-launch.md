# 編集中のステージを起動

[ツール一覧](index.md)／[ステージ制作の流れ](../stage-production.md)

**開く：** Godot「プロジェクト → ツール → 編集中のステージを起動」または上部「▶ ステージ」。

1. 起動したい `res://scenes/stages/stage_<番号>.tscn` を開き、編集を保存する。
2. メニューから起動し、出現順・成長・ボスまで通常のランとして確かめる。
3. 別のステージを試すときは、開く対象を切り替えて再度起動する。

この操作は制作データを保存しない。**保存済みの内容**でメインシーンを起動するため、直前の未保存編集は先に保存する。ステージのシーン以外を開いている場合は、直前に直接起動したステージ、記録がなければステージ1が選ばれる。起動番号はGodotの「出力」で確認できる。
