# ビジュアル編集：炎

[ツール一覧](index.md)／[ビジュアル編集](visual-editor.md)

**開く：** Godot「プロジェクト → ツール → ビジュアル編集（炎・オーラ・後光・マップ）」から「炎」を選ぶ。エディターで `res://gyms/pixel_fire_preview.tscn` を直接開いた場合も、同じ調整項目をInspectorで編集できる。

1. 炎タブ上部の操作部で保存済み設定を選んで「読込」。炎の形・動きは主要項目で調整し、粒子・層・輪郭は折りたたみを開く。
2. ⏮・▶・⏸・⏹・⏭で先頭から再生、一時停止、停止、コマ送りを行う。⏩は1倍・2倍・4倍を切り替える。
3. 残す設定は「保存」。別の用途に分けるときは、新しい `res://data/visuals/*.tres` のパスを入力して「複製」を押す。

設定値と配置、参照PNGの追加・削除は `Cmd+Z`（Windows/Linuxでは `Ctrl+Z`）で取り消し、`Cmd+Shift+Z`（Windows/Linuxでは `Ctrl+Shift+Z`）でやり直す。InspectorではGodotの編集履歴を使い、独立画面では炎タブの履歴を使う。保存やPNG書き出しを取り消す操作ではない。文字入力中は入力欄自身の履歴を使う。

## 合成を見ながら配置する

「場面・配置」を開き、ステージ1〜5と背景配置を選ぶ。参照したいプロジェクト内PNGは「追加」で複数読み込める。炎や参照絵をクリックして選び、ドラッグで移動する。重なって選びにくいときは選択欄を使う。「倍率」「回転」でも選択物を調整できる。ホイールは表示ズーム、Shift＋ホイールは選択物の回転、中ボタンドラッグは表示位置の移動。「戻す」は選択物の配置を初期値に戻す。

**参照PNGとその配置は制作中の合成確認用。** 炎の `.tres` と書き出すPNGには入らない。ステージに使うときは炎設定を先に「保存」し、「選択背景へ配置保存」または用途名を付けて「固定位置へ配置保存」を押す。どちらも選択ステージの `res://data/stages/stage_<番号>.tres` に炎設定パス・位置・倍率を保存する。回転と表示ズームはステージ配置へ保存しない。動くシーンに個別設置する場合は `res://scenes/fx/pixel_fire.tscn` をNode2Dの子に置き、保存済み設定を指定する。

## 透明PNGを書き出す

プロジェクト内の `.png` パスを指定して「出力確認」を押す。確認画面には**実際に保存する現在の1コマ**が透明背景で表示される。「この画像を書き出す」で確定する。参照PNG、炎の配置移動・回転・倍率、表示ズームは出力に含まれない。炎そのものの形や出力サイズは「形・動き」「輪郭・発光」などの設定で調整する。

設定の保存先は選択した `res://data/visuals/*.tres`。未保存の調整をやり直す「読込」は保存済み設定を読み直す。炎の編集画面を開くこと自体では、通常ステージへ炎を追加しない。鳳凰専用炎など別方式の表現は独立している。

## 炎の調整値

次の「初期値」は `pixel_fire.tres` が値を個別指定していないときの設定値。画面で選んだ別の `.tres` は、それぞれ保存済みの値を使う。変更はプレビューに反映し、「保存」または「複製」で `.tres` へ確定する。

| 画面の項目 | 作用と増減 | 入力範囲・初期値 |
|---|---|---|
| 形 | 発生元を点・線・箱から選ぶ。線は横幅、箱は幅と高さを使う | 点／線／箱、初期は線 |
| 発生源幅・発生源高 | 粒子が生まれる範囲を広げる。点では寸法を使わない | 各0〜1024 px、初期52・6 |
| 発生/秒 | 各層の粒子を出す基準頻度。増やすと密度が上がり、粒上限で頭打ちになる | 1〜160、初期28 |
| 寿命 | 粒子の生存時間。伸ばすと炎が残りやすい | 0.1〜2.5秒、初期1.1 |
| 上昇 | 粒子が上がる速度。増やすと上へ速く伸びる | 20〜240 px/秒、初期108 |
| 横揺れ | 上昇中の左右の揺れを強める | 0〜80、初期24 |
| 発生秒 | 発生を続ける時間。0は連続燃焼 | 0〜3秒、初期0 |
| seed | 同じ設定の粒子乱数を再現する値。変更後は先頭から再実行する | 0〜99999、初期42 |
| 粒半径 | 各粒子の基準半径。大きいほど密度の塊が広がる | 8〜50 px、初期27 |
| 粒上限 | 同時に残せる粒子の合計。発生頻度を増やしてもここで制限される | 32〜384個、初期192 |
| 発生量 外・内・芯 | 3層それぞれの基準発生頻度に掛ける倍率。0の層は新しい粒子を出さない | 各0〜4倍、初期1／0.85／0.7 |
| 寿命比 外・内・芯 | 各層の粒子寿命に掛ける倍率。0の層は発生しない | 各0〜4倍、初期1／0.62／0.3 |
| 大きさ比 外・内・芯 | 各層の粒半径に掛ける倍率。0の層は発生しない | 各0〜4倍、初期1／0.7／0.44 |
| 外炎・内炎・芯 | 密度を色面にしたときの各層の色 | RGB色、初期 `#e95624`／`#ffbc40`／`#ffe9a0` |
| 描画域幅・描画域高 | 炎の生成領域とPNG出力の幅・高さ | 幅32〜1024、高さ64〜1024 px、初期220×280 |
| 密度解像 | 密度を作る画像の1画素の大きさ。大きいほど粗い密度場になる | 1〜4 px、初期2 |
| 結合 | 密度を炎の色面として採用する閾値。大きくすると薄い部分が減る | 0.05〜0.9、初期0.32 |
| 縁 | 閾値付近の境界のぼかし幅。大きいほど縁が柔らかい | 0.01〜0.2、初期0.04 |
| 変形 | 密度の参照位置を揺らして輪郭を崩す強さ | 0〜12、初期4.5 |
| ドット | 完成した炎の画素ブロックの大きさ。大きいほど粗い見た目 | 1〜8 px、初期4 |
| 更新FPS | 密度と輪郭を更新する回数。少ないほどコマ送り感が増える | 6〜60回/秒、初期12 |
| 発光量 | 完成した炎へ重ねる発光の強さ | 0〜0.7、初期0.16 |
| 発光径 | 発光が広がる半径 | 1〜18 px、初期7 |

「粒子詳細」「炎の層・色」「輪郭・発光」は折りたたみを開いて編集する。発生秒とseedを変更した後は、先頭から再実行して差を見る。

## 場面・配置の入力値

| 画面の項目 | 作用と制約 |
|---|---|
| ステージ・背景配置 | 合成表示するステージ1〜5と背景。選択背景への保存先にもなる。背景がないステージでは背景への割当ては使えない |
| 参照PNG・選択 | プロジェクト内PNGを複数追加し、炎または参照絵を選ぶ。参照絵は制作中の表示のみ |
| X・Y | 選択物の表示位置。各−2048〜2048 px。炎をステージへ配置保存するときは、その位置に反映 |
| 倍率 | 選択物の配置倍率。0.1〜8倍。炎のステージ配置に保存できるが、PNG出力の寸法は変えない |
| 回転 | 選択物の表示角度。−360〜360度。ステージ配置とPNG出力には保存しない |
| 表示 | 編集キャンバスのズーム。0.1〜8倍。PNG出力とステージ配置に影響しない |
| パンX・パンY | 編集キャンバスの移動。各−2048〜2048 px。保存する炎の位置は変えない |
| 用途名 | 固定位置へ保存する炎の識別名。保存済み設定パス・位置・倍率を選択ステージの `fire_uses` にまとめる |
| PNGのパス | 現在の1コマを書き出すプロジェクト内 `.png` パス。`.tres` の保存先とは別 |
