# ラン処理・描画ベンチ

[ツール一覧](index.md)

**開く：** Godot「プロジェクト → ツール → ラン処理・描画ベンチ」。計測用ウィンドウが開く。

ランを自動で進め、処理・描画の時間を計測する開発用ベンチ。Godotの「出力」に `PROFILE_RESULT` の計測結果を出す。

1. 起動して自動計測を待つ。
2. 「出力」の結果を保存し、変更前後を同じ条件で比べる。

ゲーム中の操作や感想を残すF9録画とは用途が異なる。ステージや敵の制作データは保存しない。通常ランでの手応えは[録画と振り返り](../stage-production.md#6-記録と感想で調整する)を使う。

## 計測条件

メニュー起動ではステージ1、ラン時計10秒から、実時間6秒を既定で計測する。入力と機体の無敵状態を固定し、計測結果を `PROFILE_RESULT` のJSONでGodot「出力」へ出す。メニュー内に調整欄はない。画面PNGも既定では保存しない。

直接コマンドライン起動するときはGodot引数の `--` より後へ指定する。変更前後は同じ条件を使う。

| 引数 | 作用・既定値 |
|---|---|
| `--stage=番号`・`--time=秒` | 計測ステージと開始するラン時計。既定1・10秒 |
| `--seconds=秒`・`--size=横x縦` | 測る実時間（既定6秒）とウィンドウ画素数。後者は指定したときだけ変更 |
| `--enemies=数`・`--types=ID,ID` | 簡易敵の追加体数、または指定種類を各2体生成。未指定なら追加なし |
| `--attack=on`・`--weapons=W01:5,T03:2` | 攻撃と負荷を有効化し、またはIDとレベルを指定して装備を入れ替える。未指定の装備はW01 Lv1 |
| `--sparks=off`・`--glow=off`・`--background=off` | 火花・発光・背景の描画を個別に切る。既定は各on |
| `--hazards=on` | 障害物を定期追加。既定off |
| `--hz=数`・`--fps=数` | 固定更新回数/秒と最大描画FPSを指定。未指定ならプロジェクト設定 |
| `--overlay=compact\|detail`・`--trace=on` | 性能表示を出す／区間トレースを結果へ追加。既定は表示指定なし・trace off |
| `--body_benchmark=on`・`--capture=パス` | 身体描画の比較を結果へ追加／終了時PNGを指定先に保存。既定はいずれもなし |

結果はFPSだけでなく処理区間・描画・GPUなどの測定値を含む。`--capture` は静止画1枚で、F9のプレイ録画とは別。
