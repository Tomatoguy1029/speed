# ラン処理・描画ベンチ

[ツール一覧](index.md)

**開く：** Godot「プロジェクト → ツール → ラン処理・描画ベンチ」。計測用ウィンドウが開く。

ランを自動で進め、処理・描画の時間を計測する開発用ベンチ。Godotの「出力」に `PROFILE_RESULT` の計測結果を出す。

1. 起動して自動計測を待つ。
2. 「出力」の結果を保存し、変更前後を同じ条件で比べる。

ゲーム中の操作や感想を残すF9録画とは用途が異なる。ステージや敵の制作データは保存しない。通常ランでの手応えは[録画と振り返り](../stage-production.md#6-記録と感想で調整する)を使う。
