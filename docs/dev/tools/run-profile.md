# ラン処理・描画ベンチ

[ツール一覧](index.md)

**開く：** Godot「プロジェクト → ツール → ラン処理・描画ベンチ」。計測用ウィンドウが開く。

ランを自動で進め、処理・描画の時間を計測する開発用ベンチ。Godotの「出力」に `PROFILE_RESULT` の計測結果と、要点をまとめた `PROFILE_SUMMARY` を出す。

1. 起動して自動計測を待つ。
2. 「出力」の結果を保存し、変更前後を同じ条件で比べる。

ゲーム中の操作や感想を残すF9録画とは用途が異なる。ステージや敵の制作データは保存しない。通常ランでの手応えは[録画と振り返り](../stage-production.md#6-記録と感想で調整する)を使う。

## 計測条件

メニュー起動ではステージ1、ラン時計10秒から、実時間6秒を既定で計測する。入力と機体の無敵状態を固定し、計測結果を `PROFILE_RESULT` のJSONでGodot「出力」へ出す。メニュー内に調整欄はない。画面PNGも既定では保存しない。

直接コマンドライン起動するときはGodot引数の `--` より後へ指定する。変更前後は同じ条件を使う。

| 引数 | 作用・既定値 |
|---|---|
| `--stage=番号`・`--time=秒` | 計測ステージと開始するラン時計。既定1・10秒 |
| `--seconds=秒`・`--size=横x縦` | 測る実時間（既定6秒）とウィンドウ画素数。後者は指定したときだけ変更 |
| `--enemies=数`・`--type=ID` | 画面内に出す敵の体数と種類。種類を指定しないと、試せる種類から無作為に選ぶ。未指定なら追加なし |
| `--mix=biter:8,splitter:1,bomber:1` | `--enemies` を目標に、出現指示を指定比率で実行。群れ・部位の生成で目標を超える場合があるため、実際の個体数は結果の `counts` と `enemy_count_range` を使う。`--type` と同時指定はできない。`--keep=on` の補充でも比率の続きを使う |
| `--bonus=on` | 通常のボーナス開始処理を通し、残り時間を結果に記録。既定off |
| `--keep=on` | 倒された分を補い、`--enemies` の体数を保つ。既定off |
| `--types=ID,ID` | 指定種類を機体の周りに各2体生成。未指定なら追加なし |
| `--levels=off`・`--hitstop=off` | 結晶の生成・回収・描画を保ち、取得する経験値だけを0にしてレベルアップを止める／ヒットストップを切る。大量に倒しても世界の更新を止めずに測る。既定は各on |
| `--rewards=off` | 付与済みの報酬表示を自動で閉じ、戦闘を続けて測る。報酬の付与は維持する。既定on |
| `--gpu=off` | GPU時間の計測を切る。GPU時間を取れない環境（macOSのMetalなど）では結果の `gpu_viewport_ms` が `available: false` になる。既定on |
| `--drive=circle`・`--draw=秒` | 機体を決まった円で回し続ける／その間隔で機体の前へジグザグの線を描いて駆け抜ける。実際の装備（`--weapons`）と合わせて、速さ・向き・駆け抜けで働く武器も動かす。既定はどちらもなし（機体は止まったまま） |
| `--attack=on`・`--weapons=W01:5,T03:2` | 攻撃と負荷を有効化し、またはIDとレベルを指定して装備を入れ替える。未指定の装備はW01 Lv1 |
| `--sparks=off`・`--glow=off`・`--background=off` | 火花・発光・背景の描画を個別に切る。既定は各on |
| `--hazards=on` | 障害物を定期追加。既定off |
| `--hz=数`・`--fps=数` | 固定更新回数/秒と最大描画FPSを指定。未指定ならプロジェクト設定 |
| `--overlay=compact\|detail`・`--trace=on` | 性能表示を出す／区間トレースを結果へ追加。既定は表示指定なし・trace off |
| `--body_benchmark=on`・`--capture=パス` | 身体描画の比較を結果へ追加／終了時PNGを指定先に保存。既定はいずれもなし |

初期配置・装備の準備と天体の再配置は、乱数シード1029を使う。初期カードの候補と準備待ちを解放してから指定装備を入れる。`initial_weapons`・`initial_traits` と終了時の `weapons`・`traits`、準備開始後の変更回数 `loadout_changes` で条件を確認し、装備変更を含む結果は固定装備の比較から外す。`ui_pause_frames` とフレーム別の `ui_paused` は、報酬・メニューでゲームが止まった観測を示す。停止を含む結果は連続戦闘の比較から外す。固定更新回数が上限に達した場面ではゲーム内時計が実時間より遅れるため、FPSと更新回数・進んだ時計を合わせて読む。

結果はFPSだけでなく処理区間・描画・GPUなどの測定値を含む。`frame_ms` は平均・最小・p95・p99・最大と、30fpsの1フレーム（1000/30ms）を超えた回数 `over_33_33ms` を含む。百分位はソート後の `(要素数−1)×割合` の小数を切り捨てた位置から取る。`measure_start_clock`・`measure_start_world` は計測開始時のラン時計・世界時計、各フレームの `run_clock`・`world_clock` と実時間から進行速度を確認する。`enemy_count_range` は計測フレームの敵数の平均・最小・p95・p99・最大、`enemy_capacity` はフレームごとの確保済みの行数を示す。

`view_ms` は表示側（`RunPresentation`）の処理と描画の層ごとの1フレームあたりの時間、`view_enemy_rows` は敵の描画1回あたりの行の数。`PROFILE_SUMMARY` は、ゲーム処理・出来事の受け渡し・表示側・残り（描画エンジン・GPU・待ち）の時間と、重い処理の上位、敵の行動・武器・弾などの種類ごとの内訳の上位を並べる。`--capture` は静止画1枚で、F9のプレイ録画とは別。

`PROFILE_BEGIN.session_ready_ms` はベンチ開始からSession準備までの時間。アプリのプロセス起動やタイトル画面の時間は含まない。`bonus_remaining` は計測開始時と各フレームのボーナス残り時間を表す。
