# F4 ステージ敵調整パネル

[ツール一覧](index.md)

**開く：** GodotエディターからF5でステージを実行し、ゲーム画面でF4を押す。プレイ中の画面に「ステージ敵調整」が重なる。

1. 敵を選び、分類・検索から値を探す。
2. 共通値とステージ上書きを見比べ、試したい項目を上書きして値を動かす。現在の通常敵と次の行動・出現で手応えを確認する。
3. 残すなら「Save」。試行を捨てるなら「再読込」。項目の上書きだけを消すなら「↶」またはチェックOFFを使う。

「Save」は実行中ステージの `res://data/stages/stage_<番号>.tres` にある `enemy_tuning` を保存する。パネルを閉じても未保存の試行値は残るため、捨てるときは再読込を使う。ゲームはパネルを開いても進み続ける。既に発射した攻撃は変わらないので、次の攻撃でも確認する。ボス本体と技は[ボスAI](boss-ai.md)・[実験場](enemy-lab.md)で扱う。

## 編集できる項目

F4とエディターのドックは同じ敵種類・同じステージ上書きの項目を扱う。[基礎7項目と現在の敵固有数値の一覧](stage-enemy-tuning.md#項目の読み方と保存範囲)で、項目名・作用・単位を確認できる。敵ごとに `params` の存在するキーだけ表示され、F4で変更した値は現在出現している同種と次の出現へ反映する。HPの変更時は残HPの割合を保ち、発射済みの弾はそのまま残る。

| F4の操作 | 対象と結果 |
|---|---|
| ステージ | 実行中ステージの `enemy_tuning`。プレイ中はステージ選択を固定する |
| 敵・分類・検索 | 選択敵に存在する数値を絞る。「変更した項目」は上書き中の項目だけ |
| このステージで上書き | ONで項目のステージ値を入力、OFFで共通値を継承 |
| 「共通値（参照）」と「実効値・状態」 | 共通の元値と、現在試している上書き後の値を比較する |
| ↶／共通値へ ↶ | 1項目、選択敵、または全敵の上書きを解除する。保存前は試行状態 |
| Save／再読込 | Saveでステージへ保存、再読込で未保存変更を破棄する |

共通定義自体の値やボス技はF4から編集しない。[実験場のヒットストップ](enemy-lab.md#ヒットストップと保存範囲)では選択敵・ボスに合わせて試せる。
