# ボスAI

[ツール一覧](index.md)

**開く：** Godot「プロジェクト → ツール → ボスAI」、上部「ボスAI」、またはCmd/Ctrl＋Alt＋B。エディターの専用画面が開く。

1. 左上のボス選択欄で、調整するボスを選ぶ。候補はステージ1〜5の `boss_id` 順で並び、未配置のボスは末尾に置く。
2. 上段の戦闘区間で、使う条件選択ノード・分類の確率・攻撃回数と間隔を調整する。区間同士の線が次の区間を決める。技ノードでは公開された攻撃値や動きを調整する。
3. 「変更を保存」し、「保存して戦闘を試す」で通常AIの動きを確認する。技を選んで試遊すると、その技を実行した状態で実験場が開く。実験場の「技を再生」では、登録済みの全ボスで技を選んで実行できる。[ボス技は実験場で画面を見ながら調整できる](enemy-lab.md#ボス技を見ながら調整)。

保存先は選択ボスの `res://data/bosses/ai/<ボスID>_flow.tres`、`<ボスID>_action_rules.tres` と参照する技の `.tres`。これらはボス共通の定義で、ステージ固有値ではない。技の新しい動作や判定そのものはスクリプト実装が必要。既存技の条件・順番・組み合わせはこの画面で調整できる。技の登録や内部構造が必要なら[AI向け参照](../stage-production-ai.md#ボスの区間フロー攻撃値タイムライン)を見る。

ボス選択の横の「同時攻撃あり」は、複数の通常技を同時に選ぶ機能をボス単位で切り替える。OFFは登録なしとして扱う。うみへび座の登録はONで、ほかのボスはOFF。区間の「同時攻撃の割合」はONのときだけ働き、条件・消費・参加部位を満たす技の組を選ぶ。コンボ内部の並列実行は別の設定。

うみへび座・いっかくじゅう座・りゅう座・ケンタウルス座・おおいぬ座が区間／技の編集対象になる。ボス選択欄の候補と、試遊ボタンの有効状態を確認する。

## 技を追加・名前と見た目を変える

「＋ 技を追加」で、重複しないID・表示名を入力し、既存の技スクリプトを選ぶか、ひな形から作る。作った技は条件の線がつながっていないノードとして置く。条件選択ノードへつなぎ、使わせる区間から選ぶと、通常AIの候補になる。単独再生は実験場の「技を再生」で行う。

技ノードの「表示名」は技のデータへ保存する。「見た目」では、その技が公開する技シーン・弾・ビーム・着弾のシーンを選ぶ。「開く」でGodotのシーン編集へ進み、「専用に複製」で共通シーンのコピーを作って選択技へ割り当てる。「新規作成」は空の技シーンか弾のひな形を作る。同名ファイルがある場合は別の名前を指定する。全体の設定の「ボスの表示を開く」は体の表示シーンを開く。

技シーンでは原点をボス中心、正面を+Xとし、`Telegraph` に予告の形を置く。`AnimationPlayer` の `windup`・`active`・`recover`・`hit` は技の段階に合わせて使う。弾シーンでは `Flight` が飛行中、`Hit` が着弾、`Fade` が消えるときの固定図形を持つ。固定図形を変えたら正規生成後に試遊する。動的な絵はシーンに付く描画スクリプトで作る。[構成と生成の契約](../../architecture.md#61-敵とボスの-ai)を参照する。

## 戦闘の区間と共通設定

選択ボスの区間フローは攻撃の回数・間隔・分類の確率・休息・遷移を決める。右欄は進行・攻撃選択・選択確率・スタミナに分かれ、条件選択ノードを一覧から個別に複数指定できる。距離・向き・予測射程・形態・再使用待ちは技ごとの成立条件が判定し、選択側が成立候補と区間の確率を合わせる。**今開いているボスの保存値が現在値**で、ほかのボスには波及しない。ノードは種類ごとに色を分け、攻撃の区間を青、休息の区間を緑、条件選択を黄、技（コンボ内の技を含む）を紫で表示する。

| 画面の項目 | 作用・増減 |
|---|---|
| 区間名 | 制作画面で区間を見分ける名前。ゲーム中の表示名ではない |
| ＋ 休息を追加 | 攻撃しない休息の区間を最後に足す。直前の最後の区間から線をつなぐ |
| 休息の区間にする | 区間を休息と攻撃で切り替える。休息の区間は攻撃せず、「スタミナ・休息」の時間だけ休んで次の区間へ進む。攻撃の設定は残り、切り替えて戻すと使える |
| 区間同士の線 | 攻撃を終えた後に進む区間。自身へつなぐとループする |
| 条件選択ノード | 区間の右側詳細欄で一覧から個別に複数選ぶ。選んだノードが区間の攻撃候補になる。区間グラフには配置しない |
| 使わない技 | 指定した技を候補から除く。旧データの許可リストは、編集時に同等の除外へ移す |
| 攻撃回数（`action_count`） | 次の区間へ進むまでに実行する回数。1以上の整数。省略時は1回 |
| 攻撃間隔（`action_interval`） | 同じ区間で次の攻撃を選ぶまでの秒数。省略時は0秒 |
| この区間で使える力（`section_budget`） | ONのとき区間内の消費を合計して制限し、使い切ると次へ進む。OFFなら共有スタミナだけを使う。既存データの技1回上限（`cap`）は内部で維持する |
| 候補なしで次へ（`no_candidate_timeout`） | ONのとき成立候補がない秒数の上限。OFFなら既存の不成立時遷移があれば即座に移り、なければ候補を待つ |
| 通常技・コンボ技・大技の確率 | 区間で選んだノード内で成立する分類の相対値。成立しない分類は分母に入れない。同時攻撃ありのボスだけ同時攻撃の確率も使える |
| 連発を抑える | 正の確率を持つ別候補があれば、直前と同じ技の組み合わせを外す。ほかに候補がなければ繰り返す |
| 同時攻撃の禁止 | 「同時攻撃あり」がONのとき、選んだ2技を同時候補から外す。選択欄は「登録なし」から始め、両方選んだペアだけ保存する |
| 最大スタミナ | ボス全区間で共有するスタミナの上限。定義の初期値6 |
| 残量ありの休息（秒）・枯渇時の休息（秒） | 休息が必要になったときの待ち時間。定義の初期値1秒・3秒 |

「条件選択」ノードでは「基本」にノード名と通常技・コンボ技・大技の単一分類、「つながっている技」に接続技の有効／無効を並べる。技がつながっていなければ、その旨を表示する。技をほかの条件選択へ移すときは、グラフ上で条件選択から技へ線を引き直す。分類間の確率は区間で編集する。発動範囲の確認欄（分離形態、残りスタミナ、表示半径、首の生存数）は**範囲図だけ**に使う仮の戦闘状況で、保存する発動条件にはならない。技・発動条件の詳細欄の範囲図は、左に発動条件（青）、右に間を空けて攻撃範囲（橙）を同じ縮尺・同じ塗りで並べる。扇の判定は扇形、直線の判定は判定の幅を持つ帯で示す。攻撃範囲は各ボスの技の当たり方から描き、自機を狙う技は発動条件内の代表距離にいる自機を狙った形にする。発動距離に上限がない場合は代表距離までを発動条件の図に描き、上限なしと表示する。画面外から入り直す技や自機のまわりに出る技も、ボスの正面を基準に、狙った自機の位置に対して出る向きと範囲で描く。うみへび座の技は、攻撃を出す首の頭を中心にして描く。各図の中央の三角形がボスで、尖った先が正面を向く。

## 技の発動条件と共通の欄

| 画面の項目 | 作用・範囲 |
|---|---|
| 技後の隙（秒） | 通常技・大技が終了してから次を選ぶまでの追加時間。コンボ技には追加しない。技中の予告や回復動作は変えない |
| 予告の間、自機を追う | 全ボスの単体技に出るチェック。ONでは予告の間に自機を追って狙いと向きを直し、OFFでは予告を始めた時の自機の位置へ撃つ。りゅう座は画面外からの配置を終えて最初に狙った時点で固定し、渦の中心移動は対象外。うみへび座は通常攻撃の首の狙いと連続攻撃の狙いを固定する。技のデータの `track_during_warn` に保存する |
| 最小距離・最大距離 | 技を候補にする自機との距離範囲。最小0〜100000、最大0〜100000の入力欄 |
| 中心角度（度）・半角（度） | 技を候補にする方向の中心と左右の広さ。中心−180〜180度、半角0〜180度 |
| 消費スタミナ | 技1回、またはコンボ全体1回の消費。0〜100000。区間の消費上限・残量により候補が変わる |
| コンボ：待機（秒） | 次の要素へ進むまでの時間。0〜100000秒 |
| コンボ：実行する技／順番／同時／条件分岐 | 登録技を順次または同時に実行し、分岐では距離・角度条件を設定する。実行制約を満たす組み合わせで試遊する |
| 彗星弾の弧：位置 X・Y、半径、中心角度、広がり、弾数 | 竜の吐出技に登録された弧ごとの位置・大きさ・向き・弾数。弧の追加・削除が可能。位置と中心角度の下限は−10000、ほかは1 |

技ノードの欄は「表示名」「見た目」「タイミング」「威力と範囲」「狙いと消費スタミナ」「この技へ進む条件」に分ける。数値欄は技スクリプトの `@export` から作り、`@export_range` の範囲・刻み・単位と `##` の説明を表示する。技が読む値だけを公開する。角度は `radians_as_degrees` を指定した欄で度として入力し、データへはラジアンで保存する。りゅう座の渦の内部時計 `warn` は表示対象から外す。初期値と保存値は `res://data/bosses/<ボス>_moves/*.tres` を参照する。
