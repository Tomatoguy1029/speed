# 実験場

[ツール一覧](index.md)／[ステージ制作の流れ](../stage-production.md)

**開く：** Godot「プロジェクト → ツール → 実験場」または上部「▶ 実験場」。別の試遊ウィンドウが開く。

1. 「試遊対象」で通常敵・強敵・分裂体・召喚体・ボスから対象を選び、「試遊」する。自由配置では敵の配置やルートも試せる。
2. ボスはまず通常AIで試す。「ボス技」が表示される対応ボスでは技を選んで実行し、予告から攻撃終了まで見る。
3. 画面上部の「ヒットストップ」で、**いま選択中または試遊中の対象**を確認して倍率を動かす。現在の同種と次に出現する同種へ試遊値が反映される。
4. 残すときだけ適用範囲を選んで「設定を保存」を押す。0は停止なし、1は共通の停止時間を使う値。

敵の「敵種類の定義（全ステージ）」は `res://data/enemies/<種類ID>.tres`、 「このステージのみ」は選択した `res://data/stages/stage_<番号>.tres` の敵上書きへ保存する。ボスは `res://data/bosses/<ボスID>.tres` の共通値へ保存する。ステージ上書きは「ステージ設定を継承へ戻す」で解除できる。

「試遊値を戻す」や実験のリセットは、未保存の試遊値を戻す。通常の「保存」は実験用JSONの保存であり、ヒットストップの本番設定には「設定を保存」を使う。ステージを選ぶだけでは、既存の敵上書き全項目を再現しないため、ステージ固有値の最終確認は[本番ラン](stage-launch.md)で行う。

## 試遊対象・再生

「試遊対象」は敵定義とボス定義から作られ、雑魚・強敵・分裂体・召喚体と登録済みボスを選べる。敵名検索、星数、区分で左の配置パレットを絞り、配置数を1〜10000体で指定する。選択中の個体があればその種類がヒットストップ対象になる。ボスの通常AI試遊は登録済み全種類が対象。「ボス技」の単技実行は対応するボス・技だけで使い、自律行動に戻すときは「通常AIへ戻す」を押す。技が未登録または実行条件を満たさないときは実行ボタンが無効になり、理由が表示される。ケンタウルス座・おおいぬ座では現状、単技指定の試遊UIは表示しない。

| 画面の項目 | 作用と範囲 |
|---|---|
| フィールド／Seed | ステージ1〜5の地形条件と乱数を選ぶ。Seedは0〜2147483647、初期932 |
| 空のフィールド・通常の自動出現・地形・岩・仕掛け | 実験開始時に置くものを選ぶ。空のフィールドをONにすると地形・岩・仕掛けをOFFにする |
| 再生・一時停止・1コマ・速度 | 試行の時間を進める／止める。速度は0.25・0.5・1・2・4倍 |
| 試遊中の無敵 | 操作中の機体への被弾条件。初期ON、実験中だけ |
| 自機レベル | 試遊中のレベル。1〜1000、初期1 |
| 充填率 | 自機を置き直す際のゲージ。0〜1、初期1 |
| ステージ経過（実秒） | 実験のラン時計を指定して適用。0〜10000秒 |
| 基礎攻撃力・最高速度・線の長さ・なぞりの当たり判定の太さ・描画中の世界の速さ・描画の確定待ち時間 | 実験中の共通設定の試行値。各0.01〜100000。現在の基準値を画面に表示し、元の `config.tres` へはこの欄から保存しない |
| ボスの基礎HP・ボスの基礎装甲 | 同じく実験中の共通ボス基準値。各0.01〜100000。個別ボス定義を保存する操作ではない |
| 装備・英雄 | メタ強化0〜100、武器・特性の選択とレベル1〜100、英雄を実験中の自機へ適用する。実験用の選択値 |

「新しい実験」やリセットは試行を作り直す。一般の数値試行、位置、装備は実験セッション内の値で、[本番の敵・ボスデータを保存する操作](#ヒットストップと保存範囲)と区別する。

## ヒットストップと保存範囲

| 画面の項目 | 作用と制約 |
|---|---|
| 対象 | 選択個体・配置予定の敵種類、または試遊中のボスIDを示す。対象を切り替えると保存先も切り替わる |
| 倍率 | 停止実時間に掛ける。0は停止なし、1は共通時間。入力0〜100000・刻み0.05だが、停止には共通の累積上限がある |
| 敵種類の定義（全ステージ） | 敵の `res://data/enemies/<ID>.tres`、ボスの `res://data/bosses/<ID>.tres` へ「設定を保存」で書く |
| このステージのみ | 通常敵の選択ステージ `enemy_tuning` にだけ書く。ボス選択中は使えない |
| 試遊値を戻す | 未保存の試行倍率を読み直す。保存操作はしない |
| ステージ設定を継承へ戻す | この敵種類・このステージの倍率上書きキーを消し、共通定義へ追従させる明示操作 |
| 設定を保存 | 画面に示す対象と適用範囲だけへ確定保存する。外部変更を検出した場合は保存を止める |

試遊値は現在の同種と次に出現する同種へ反映する。ボスの選択中に別の敵種類の倍率を保存しないよう、**対象の表示を見てから**保存する。実験を閉じる・リセットするだけでは未保存の試遊値は元データに残らない。

## 配置・攻撃・ルートの実験値

これらは実験セッション／実験用JSONの条件で、本番への敵数値の保存とは別。画面には選択中の種類・編成だけに対応する項目もある。

| 画面の項目 | 何を変えるか | 範囲・単位 |
|---|---|---|
| 全体の重み付き上限 | 同時に攻撃を許す重み合計の上限 | 0〜100、初期4 |
| 待ち方のばらつき（秒） | 攻撃候補の待機時間の揺れ | 0〜3秒、初期0.3 |
| 攻撃の重さ（強敵と大物） | 種類ごとの攻撃重み。全体上限と組み合わせて攻撃の重なりを調べる | 対象の種類だけ0〜20、刻み0.25。初期は各敵定義の値 |
| 開始（実秒）・終了（実秒） | 自動出現の対象時間帯 | 各0〜3600秒、初期0・30 |
| 間隔（実秒） | 自動出現を試みる周期 | 0.1〜300秒、初期2 |
| 出現する確率（0〜1） | 周期ごとに出現させる確率 | 0〜1、初期1 |
| 出現領域の半径 | 自動出現位置を散らす半径 | 0〜2000距離単位、初期0 |
| 敵の組み合わせ | 既存の編成シーン、並び、出現位置候補を選んで実験に置く | `data/formations/*.tscn` から選択 |
| 線を描く時間（実秒） | ルート検証で想定する描画時間 | 0.05〜20秒、初期0.5 |
| ルートに残す余裕幅 | ルートの周囲に確保する距離 | 0〜1000、初期20 |
| 抜けた先に残す余裕の半径・敵中心どうしの最小距離 | 出口の余裕と配置候補間の距離条件 | 各0〜1000、初期0 |
| 開始時間の幅（対応モデルのみ） | 複数の開始時刻を許す検証幅 | 0〜20秒、初期0 |
| 敵が動いてよい領域の半径 | ルートから配置候補の領域を作る広さ | 0〜1000、初期60 |
| 選んだ領域の最小数・最大数 | 選択領域に置く敵数の下限・上限 | 各0〜100、初期1 |
| ランダムに回す角度（度） | 候補編成の回転の広さ | 0〜180度、初期180 |
| 長さの最小倍率 | 候補ルート長を縮める下限 | 0.1〜1、初期0.8 |
| ルート上で貫く弱い敵の最小数 | 候補の採用条件 | 0〜10000体、初期1 |

「配置・条件のプリセットを保存」は条件と配置を、「再生履歴と分岐を保存」は操作履歴を `user://enemy_lab/` のJSONへ書く。「AI用フォルダを書き出す」は対象ステージ・時間帯・敵を選び、分析用資料を同じ場所の `exports/` へ出す。これらは本番の敵定義・ステージ定義へ反映しない。

## 外観の項目

選択した通常敵の見た目を実験中に確認する。画面の「この種類の設定をステージへ保存」は、実際にはその敵種類の共通 `EnemyDef.visual_settings`／装甲色を保存し、**全ステージの同種へ作用**する。

| 画面の項目 | 作用と入力範囲 |
|---|---|
| サイズ倍率（見た目・当たり判定） | 敵の全体サイズ。0.1〜5倍、初期1 |
| 当たり判定のみの倍率 | 見た目に対する接触半径。0.1〜5倍、初期1 |
| 敵の回転（度） | 実験中に選択敵の向きを変える。−180〜180度、初期0。種類別外観の保存値には含めない |
| 主光の強さ（左上）・補助光の強さ（右下） | 2方向からの照明の寄与。各0〜3。画面は保存済み外観値または共通照明値を表示 |
| 主光の角度（度）・補助光の角度（度） | 照らす方向。各−180〜180度 |
| 光の高さ（0=横、1=正面） | 照明の高さ。0〜1 |
| 環境光（影の明るさ） | 暗い面の明るさ。0〜1 |
| 法線の強調度（0=平面） | 表面の立体感。0〜3 |
| 装甲の上側・下側と色 | 装甲片の領域ごとにRGB色を設定する。選択中の敵種類にだけ使用 |

外観は「保存状態へ戻す」で未保存値を破棄できる。回転と照明の適用対象、装甲色の保存結果は対象敵のプレビューでも確認する。
