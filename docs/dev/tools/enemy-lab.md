# 実験場

[ツール一覧](index.md)／[ステージ制作の流れ](../stage-production.md)

**開く：** Godot「プロジェクト → ツール → 実験場」または上部「▶ 実験場」。別の試遊ウィンドウが開く。

1. 「試遊対象」で通常敵・強敵・分裂体・召喚体・ボスから対象を選び、「試遊」する。自由配置では敵の配置やルートも試せる。
2. ボスは「ボス技」で技を選び、実行して予告から攻撃終了まで見る。
3. 画面上部の「ヒットストップ」で、**いま選択中または試遊中の対象**を確認して倍率を動かす。現在の同種と次に出現する同種へ試遊値が反映される。
4. 残すときだけ適用範囲を選んで「設定を保存」を押す。0は停止なし、1は共通の停止時間を使う値。

敵の「敵種類の定義（全ステージ）」は `res://data/enemies/<種類ID>.tres`、 「このステージのみ」は選択した `res://data/stages/stage_<番号>.tres` の敵上書きへ保存する。ボスは `res://data/bosses/<ボスID>.tres` の共通値へ保存する。ステージ上書きは「ステージ設定を継承へ戻す」で解除できる。

「試遊値を戻す」や実験のリセットは、未保存の試遊値を戻す。通常の「保存」は実験用JSONの保存であり、ヒットストップの本番設定には「設定を保存」を使う。ステージを選ぶだけでは、既存の敵上書き全項目を再現しないため、ステージ固有値の最終確認は[本番ラン](stage-launch.md)で行う。
