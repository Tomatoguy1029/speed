# ステージ敵調整

[ツール一覧](index.md)

**開く：** Godot「プロジェクト → ツール → ステージ敵調整」。エディター右側のドックが開く。ステージの `.tres` を選ぶと、そのステージも表示される。

1. ステージと敵を選び、分類・検索から項目を探す。
2. 「共通値（参照）」を見て、ステージだけで変える項目を「上書きする」にする。
3. 値を調整して「保存」し、ステージを起動して確かめる。共通値へ戻す項目は「解除」を使う。

保存先は選択した `res://data/stages/stage_<番号>.tres` の `enemy_tuning`。上書きしていない項目は共通の敵定義を継承する。ボス本体と技は対象外。ゲームを遊びながら試すなら[F4パネル](f4-enemy-tuning.md)、ヒットストップを敵・ボスごとに試して保存するなら[実験場](enemy-lab.md)を使う。


## 項目の読み方と保存範囲

画面には**選択した敵の定義に実在する数値項目だけ**が出る。共通値は読み取り専用で、チェック「このステージで上書き」をONにした項目だけ入力できる。上書きOFFまたは「↶」はその項目を共通値へ戻す。「共通値へ ↶」は選択敵または全敵の上書きを解除する。ドックの「保存」で選択したステージの `enemy_tuning` に確定し、「再読込」は未保存の試行を破棄する。実際の敵への確認はステージを起動して行う。

数値欄の上限は100000。標準HPの下限は0.01。`volley`・`beams`・`layers`・`strikes` などの個数は最低1、予告・持続・再使用などの時間は通常最低0.01秒、その他は通常0。逆回転や位置関係を表す一部の値は負値も扱う。**項目ごとの現在の共通値は敵種類によって異なるため、画面の「共通値（参照）」を正とする。** 敵固有の整数項目は整数のみ入力できる。

| 基礎項目 | 作用・単位 |
|---|---|
| 標準HP | 星とHP属性から計算したHPを、サイズ・エリート補正の前に上書きする。HP。上げるほど倒しにくい |
| 装甲 | これより低い攻撃力の体当たりを弾く。攻撃力。上げるほど防ぎやすい |
| 移動速度 | 追跡時の標準速度。距離/秒。上げるほど移動が速い |
| 加速 | 目標速度へ近づく強さ。毎秒の割合。上げるほど速度が早く追従する |
| 旋回速度 | 機体へ向き直る速さ。ラジアン/秒。上げるほど早く向く |
| 背面の弱点角度 | 背面クリティカルの半角。ラジアン。0で弱点なし、広げるほど当てやすい |
| ヒットストップ時間倍率 | 一撃撃破・体当たりクリティカルの停止時間の倍率。0で停止なし、1で共通時間。共通の累積上限内で作用。**選択対象を見ながら試す・明示保存する操作は[実験場](enemy-lab.md)でも可能** |
