# 演出の試作の移植

承認済みのHTML試作（`prototypes/fx/` など）を本番へ移すときは、試作の見た目と動きを正とし、削らず減らさずに再現する。試作は1つのcanvasへコード順に描き、本番はC++の戦闘・GDScriptの表示・shader・描画の層に分かれて描く。この分かれ目で見た目がずれるため、技ごとに次の6点を確かめる。

| 確かめること | ずれ方 | 確かめ方 |
|---|---|---|
| 色の計算 | 色が薄く白っぽくなる | 本番は2DをHDRの線形色で合成する。色を数値で持つshaderは、色をsRGBで受けてsRGBで計算し、HDRの画面へ描くときだけ最後にリニアへ直す。変換の有無は描画先の `use_hdr_2d` から決める |
| 前からある描画 | 試作にない線・輪・模様が重なる | 対象の技が今出している描画（線・輪・マーク・別shaderの見た目・敵としての表示）を全部洗い出し、試作にないものを外す。新しい描画を足すときは、置き換える古い描画を同じ作業で消す |
| 共通処理の既定値 | 弾が途中で止まる・曲がる・遅れる | 弾・敵の共通の動き（減速・追尾など）を使うときは、その既定値が試作の動きと合うかを読む |
| 表示へ渡す値 | 何も描かれない・予兆の時間がずれる | 表示が使う時間・幅・位置などの値が、C++の状態から表示まで届いているかを確かめる。届かない値は0になり、エラーを出さずに消える |
| 重なり順 | 弾や岩が奥に隠れる | 試作の描く順と、本番のzと層の順を照らし合わせる |
| 本番だけの条件 | 技が始まらない・途中で止まる | 画面外での中止・時間切れ・配置待ちなど、試作にない条件で止まらないかを確かめる |

移したあとは、[一時作業場所](../../AGENTS.md#検証)で起動を1回にして全部の技を続けて撮り、同じ場面の試作と並べて比べる。実験場の範囲表示（赤い帯や円）は試作にないので、隠して撮る。
