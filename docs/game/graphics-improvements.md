# グラフィック改善ポイント

shaderや表示処理で扱う、画面のレイアウト・色・アニメーション・エフェクトの改善要件をまとめる。shaderとは別に絵が必要なものは[共有アート素材リスト](catalog/art-assets.md)で管理する。両方が必要な項目は素材と表現実装を分けて相互参照し、境界が不明なものは要確認とする。

この文書は改善内容と狙う見た目の正本とする。担当・進捗・実施履歴は作業管理側で扱う。見た目の基本方針は[アートスタイル](art-style.md)に従う。ID は文書間の参照に使い、`ART-` の参照IDも維持する。

### ワールドマップの表示制御

分離する画像・透過・原点・レイヤーは[絵の依頼書の周辺装飾の部品分け](catalog/art-assets.md#周辺装飾の分離素材art-041)を正本とする。下表は絵を組み合わせる表示側の責務を示す。静止部品も、所属する情報群の点灯時にはフェードする。

| 対象 | 固定する部分 | コードで制御する部分・現行の根拠 |
|---|---|---|
| 接続線と情報の点灯（GFX-002） | 装飾線の完成形、周辺の文字・印・情報の配置 | 星座の回転・画面遷移が完了してから接続線を伸ばし、伸長後に情報をフェードインさせる。[表示処理](../../speed/scripts/ui/constellation_map.gd)の `_reveal_details()` と[情報shader](../../speed/assets/ui/map/information_reveal.gdshader)で制御する。選択中の星座から右側情報欄への線は `_draw()` が描き、原画上の4本の装飾線はshaderで根元から現す。再選択・非表示・画面遷移では進行中の点灯を取り消す |
| 左下の波形 | 土台と棒の表示領域 | 情報shaderで16本の棒を描く。持続する「ゴォー」という広帯域の音に、ときどき大きな反応が重なる擬似信号を表し、信号はshaderの時間から生成する。各棒・帯域は異なる間隔でアタック・保持・減衰し、速度は周期全体を伸縮させる。通常の高さを中心に、全体の活動量・帯域の強弱・個々の振幅が別の時間スケールで変わる。通常の高さ・振幅の変化量・大きな反応の頻度と強さ・帯域の同期を独立して調整する |
| 左上の天動説の図 | 中心と元の偏心した3本の軌道 | 情報shaderが軌道上の小さな光だけを異なる周期でわずかに巡らせる。図全体の位置と向きは保つ |
| 右側情報欄 | UI枠・表示窓の形と配置 | 選択に応じて星座画像・見出し・解放状態・出撃可否を差し替え、情報の点灯と合わせて表示する。[枠shader](../../speed/assets/ui/map/selection_frame.gdshader)は見本の星座を覆って表示窓を空ける。ART-036 の星座絵の追加表示は未実装 |
| 中央の円と星座ボタン | 各画像の絵柄 | 表示処理の `_apply_rotation()` が選択・ドラッグに応じた内円の回転と位置、星座の位置・奥行き・明度を制御する。外周の円は[背景shader](../../speed/assets/ui/title/radar.gdshader)が同じ角度に追従させる。左上の天球図の小さな動きと分けて扱う |
| モニター効果（ART-039） | 絵の輪郭とドットの芯 | [モニターshader](../../speed/assets/ui/map/monitor.gdshader)が背景を含む合成画面へ表の効果を重ねる。追加の効果画像は不要 |

GFX-002・ART-039 と波形・天球図の視覚調整には[ビジュアル編集](../../speed/gyms/visual_editor.tscn)の「マップ」を使う。調整項目は「接続線と点灯」「波形」「天球図」「モニター効果」の4群で、右側にまとめる。[単体プレビュー](../../speed/gyms/map_reveal_preview.tscn)は効果別の4タブを使う。各項目に日本語の用途説明を付ける。プレビューはメモリ内の複製へ即反映し、上部の「保存」で[調整用リソース](../../speed/data/map_reveal_settings.tres)へ保存する。保存値は次の本番起動から使う。項目の定義は[設定クラス](../../speed/scripts/ui/map_reveal_settings.gd)を参照する。完成表現と基準値は未決とし、細かな値はプレビューで本人が調整する。

参照：[ワールドマップの基本方針](art-style.md#32-ワールドマップステージ選択)、[ステージ選択の操作と遷移](../spec.md#3-画面の流れ)。
