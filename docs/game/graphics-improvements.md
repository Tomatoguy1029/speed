# グラフィック改善ポイント

shaderや表示処理で扱う、画面のレイアウト・色・アニメーション・エフェクトの改善要件をまとめる。shaderとは別に絵が必要なものは[共有アート素材リスト](catalog/art-assets.md)で管理する。両方が必要な項目は素材と表現実装を分けて相互参照し、境界が不明なものは要確認とする。

この文書は改善内容と狙う見た目の正本とする。担当・進捗・実施履歴は作業管理側で扱う。見た目の基本方針は[アートスタイル](art-style.md)に従う。ID は文書間の参照に使い、`ART-` の参照IDも維持する。

## ワールドマップ

回していて楽しいUIにする。

| ID | 対象 | 改善内容 |
|---|---|---|
| ART-034 | 下部の目盛り | 奥になるほどグラデーションで暗くする |
| ART-035 | 「中身の丸」 | 中身の丸の位置を上下左右に揃える |
| GFX-001 | 星座の絵の表示 | ステージマップの星座の部分に、対応する[星座の絵（ART-036）](catalog/art-assets.md#ワールドマップ)を重ねる |
| ART-037 | 周囲の情報 | 明度を下げて、目立ちにくくする |
| ART-038 | 背景 | 銀河らしくカラフルにする。新規の背景絵が必要かは未決 |
| ART-039 | モニター風エフェクト | ステージセレクト（ワールドマップ）の背景を含め、モニターらしい走査線・ノイズのエフェクトを加える |
| GFX-002 | 周囲の情報が出るとき | まず線がピーっと伸び、その後モニターにぽわっと映るように情報をフェードインさせる |

「中身の丸」が指す部品と位置の基準、目盛りのグラデーション範囲・色・濃さ、星座の絵の重ね方・透明度、周囲の情報の対象と明度、背景の配色、走査線・ノイズの強度と具体手法、線の伸び方とフェードインの時間・変化は未決。対象を確認してから具体化する。

GFX-002・ART-039 の視覚調整には[マップ演出プレビュー](../../speed/gyms/map_reveal_preview.tscn)を使う。左上の丸につながる線を含め、線の伸長後に周辺情報を点灯させる。背景を含む画面へ控えめな走査線・周辺減光・微量ノイズを重ねる。左下の棒は星から受ける擬似信号として、共通の急な立ち上がりと短い減衰に、各棒の強弱を混ぜる。時間・発光・モニター強度・信号の速さと変動・相関は[調整用リソース](../../speed/data/map_reveal_settings.tres)で扱う。プレビューはメモリ内の複製を調整する。完成表現と基準値は未決。

参照：[ワールドマップの基本方針](art-style.md#32-ワールドマップステージ選択)、[ステージ選択の操作と遷移](../spec.md#3-画面の流れ)。
