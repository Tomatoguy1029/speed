# ステージ2：ケンタウルス座の星系

守りの奥にいる敵へ届かせる道中、成長の到達目標、登場する敵とその役割、ケンタウルス座とのボス戦を定義する。

## 1. 狙う体験

遠くの敵が撃ってくるのに、手前の群れや守りに阻まれて届かない。阻むものごと一筆で突き抜け、奥の敵まで届かせる。

山は長めにし、山の中で「守りが厚くなる → 突き崩す」を2回ほど繰り返す。山は後ろほど長くする。

設定と元ネタは[世界観の星系の主](../world.md#6-星系の主と取り込まれた星座)、見た目は[アートスタイル](../art-style.md)を参照する。

## 2. フェーズと成長目標

### 成長の方針

**機体の強化が2割程度育った状態で、ステージ2に臨むものとする**（[ステージごとの想定](../../spec.md#141-機体の強化)）。

**ボス前に、装備した武器・特性が全てMAXになるか、あと少しでMAXになる程度まで育つことを目指す。** 配分の考え方は[ステージ4](stage-4.md#成長の方針)と同じ。

### フェーズの役割

| フェーズ | 内容 |
|---|---|
| 1回目の育成 | 雑魚を倒して経験値を集め、最初の強敵に備える |
| 1回目の山 | じょうぎ座とたて座が登場する |
| 2回目の育成 | 経験値を集め、次の山に備える |
| 2回目の山 | ぼうえんきょう座が登場する |
| 3回目の育成 | 同上 |
| 3回目の山 | かに座が登場する |
| 4回目の育成 | ボス前のラッシュに備える |
| ボス前のラッシュ | 全ての強敵が押し寄せる |
| ボス | ケンタウルス座との戦闘へ進む |

| 2:45 | 2回目の育成 | 12 |
| 4:15 | 2回目の山 | 15 |
| 4:45 | 3回目の育成 | 18 |
| 6:25 | 3回目の山 | 22 |

### レベルアップの仮ペース

## 3. 登場する敵と編成

| 区分 | 敵 | ステージ内の役割・対処の狙い |
|---|---|---|
| 雑魚 | 守る雑魚 | 噛みつく雑魚の代わりに出る。強敵やボスの前に並んで道をふさぐ。並んだ列ごと一筆で貫き、その先の強敵・ボスへ届く |
| 雑魚 | 分裂する雑魚・分裂体 | 育成区間の経験値供給を担う |
| 硬め | ビームの敵 | 構えて砲口に光を集めてから撃つ。射線を読んで外れるか、撃たれる前に倒す |
| 強敵 | じょうぎ座 | 二つに分かれて自機を挟む位置へ広がり、長い光の壁を出し続ける。倒した側の壁は消える |
| 強敵 | たて座 | ステージ1から再登場。正面の盾で攻撃を弾き返す前衛になる。回り込んで背面から貫く |
| 強敵 | ぼうえんきょう座 | ゆっくり回るサーチライトの帯で自機を探し、帯の中にいる間に狙いが溜まると撃つ。光は隕石で遮られる |
| 強敵 | かに座 | 自機へ横腹を向け、速い横歩きで寄ってきて、進む方向をハサミで薙ぐ。縦から突っ込めば貫ける |

大物は出ない。

### 守る雑魚

| 項目 | 内容 |
|---|---|
| 近くに強敵もボスもいない間 | 噛みつく雑魚と同じく自機へ寄ってきて、近づくと光ってから噛みつく（近距離・点） |
| 近くに強敵かボスがいる間 | 最も近い相手と自機を結ぶ線の上へ寄っていき、仲間と横に並んで道をふさぐ。並んでいる間は攻撃しない |
| 倒し方 | 普通に倒せる |
| 未決 | 並ぶ数、強敵からの距離、速さ、体力、見た目 |

### かに座

| 項目 | 内容 |
|---|---|
| 普段の動き | 横にしか動けないが、横には速い。自機へ横腹を向け、横歩きで常に自機へ寄っていく |
| 向き直り | 進む方向から自機が外れると、その場で一瞬で向きを変え、横腹を自機へ向け直して進む |
| 攻撃 | 自機の近くまで来ると止まり、短い予告のあとすぐに進む方向をハサミで薙ぐ（近距離・面）。薙いだあとは少し止まる |
| 対処 | 前後には動けないので、縦から突っ込めば貫ける。横へ大きく外れると向き直させられる。薙いだあとの停止中も狙える |
| 未決 | 速さ、向き直す角度、攻撃を始める距離、届く距離、体力、ダメージ |

各敵の行動・当たり判定などの詳細は[敵一覧](../catalog/enemies.md)と[共通仕様](../../spec.md#11-敵)に従う。

## 4. ボス戦

ケンタウルス座は、守りの群れの奥から弓を射る。矢はや座。近づくと走って距離を取る。攻撃は遠距離が中心。

戦闘の進行・技・攻めどき・行動判断の要件・素材と演出は[ケンタウルス座の仕様](../bosses/centaurus.md)に定義する。

ボス戦中も通常敵が出現する。
