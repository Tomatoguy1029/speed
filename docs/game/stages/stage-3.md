# ステージ3：おおいぬ座の星系

猟犬の群れに追われ続ける道中、成長の到達目標、登場する敵とその役割、おおいぬ座とのボス戦を定義する。

## 1. 狙う体験

足の速い猟犬の群れが、どこまでも追ってきて、群れで飛びかかってくる。追ってくる群れは自機の後ろに長く伸びるので、向きを変えてその列を一筆で貫く。

追われている緊張を切らさないよう、休憩を短くし、山を長めに続ける。山ごとに強敵・大物を足していく。

設定と元ネタは[世界観の星系の主](../world.md#6-星系の主と取り込まれた星座)、見た目は[アートスタイル](../art-style.md)を参照する。

## 2. フェーズと成長目標

### 成長の方針

**機体の強化が5割程度育った状態で、ステージ3に臨むものとする**（[ステージごとの想定](../spec.md#141-機体の強化)）。

**ボス前に、装備した武器・特性が全てMAXになるか、あと少しでMAXになる程度まで育つことを目指す。** 配分の考え方は[ステージ4](stage-4.md#成長の方針)と同じ。分裂する雑魚は出さず、経験値は猟犬の群れをまとめて倒して稼ぐ。

## 3. 登場する敵と編成

| 区分 | 敵 | ステージ内の役割・対処の狙い |
|---|---|---|
| 雑魚 | 猟犬 | 噛みつく雑魚の代わりに出る。群れごと向きを変えて追ってくる。まとまって追ってくる群れを、正面から一筆で丸ごと貫く |
| 雑魚 | 自爆する雑魚 | 明滅し終わる前に貫いて、爆発させずに倒す |
| 強敵 | やまねこ座 | 距離を保ち、3本の爪痕の斬撃を左右交互に飛ばす。爪痕の内側の端を交互によけて、真ん中をS字に抜ける |
| 強敵 | ぎょしゃ座 | 光の戦車が猛スピードで飛び回り、通った跡に炎の帯を残す。帯がつながって自機のまわりに囲いができる。囲いの中で固まった群れを、切れ目から飛び込んで刈り、反対側へ抜ける |
| 強敵 | かじき座 | ステージ1から再登場。速く突っ込んできて、猟犬の群れと一緒に追ってくる |
| 大物 | みなみのかんむり座 | 雑魚を渦で率いて近づき、予告のあと投げる。猟犬の群れを率いる頭になる |
| 大物 | ほうおう座 | 遠くへ飛び去ったあと、火の粉と影で落ちる場所を見せてから飛び込んでくる。飛び込んだ所で、体より広い範囲に炎が弾ける（遠距離・面）。飛び込んだ直後は止まっているので、まわりの群れごと貫く |

硬めの敵は出ない。

### 猟犬

| 項目 | 内容 |
|---|---|
| 区分 | 雑魚（星1） |
| 普段の動き | 自機を追いながら、近くの仲間と向きと速さをそろえて、ひとかたまりで走る。噛みつく雑魚より少し速い |
| 予告と攻撃 | 噛みつく雑魚と同じ。近づくと一瞬光り、その場で短く噛みつく（近距離・点） |
| 群れの作り方 | 数体の群れで出現する。仲間が倒されても、残りでまとまって走り続ける |
| 倒し方 | 普通に倒せる |
| 未決 | 速さ、群れの数、仲間と動きをそろえる強さ、体力、ダメージ、見た目 |

各敵の行動・当たり判定などの詳細は[敵一覧](../catalog/enemies.md)と[共通仕様](../spec.md#11-敵)、冠の投擲は[敵一覧](../catalog/enemies.md#みなみのかんむり座)に従う。

## 4. ボス戦

おおいぬ座は、猟犬の群れを率いて、群れと一緒に追ってくる。ボスと群れが一体になって追ってきて、まわりを囲む。群れごとボスを一筆で貫くか、群れを崩してボスをむき出しにする。

技・攻めどき・形態の数は制作者が決める。例：

- 通常技：飛びかかり、号令で群れを一斉に飛びかからせる、口元のシリウスから焼き払う光。
- 大技：遠吠えで新しい群れを呼び、四方から囲ませる。シリウスの光で通った跡を焼きながら走り回る。
- 攻めどき：群れが一列になって走る瞬間に、ボスごと貫く。群れが減るとボスが自分で飛びかかってくるので、着地して止まったところを狙う。

ボス戦中も通常敵が出現する。
