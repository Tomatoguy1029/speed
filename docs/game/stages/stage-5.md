## 4. ラスボス戦

ラスボスは巨体のりゅう座で、核はこぐま座の北極星。多様な敵のピカロを出し、竜の本体も攻撃する。

本体は手前の戦闘空間にいる間、ピカロの残数にかかわらず基本的に全身へ攻撃が通る。背景奥へ退いている間は攻撃対象外とする。本体を攻撃できる間は、ピカロを減らすか、避けながら本体を狙うかを選び、本体へ突進する軌道にピカロも巻き込める。竜の大技の後は本体を狙う好機とする。1突進あたりのヒット上限は未決。

戦闘の数値、寄り道（ピネウスを助けて攻略の手がかりを得る）の中身は未決。撃破後の締めは[仕様書 12.4](../../spec.md#124-ラスボス戦と締め)に従う。

### ピカロと攻撃の重なり

戦闘の途中にピカロを使う行動を挟む。候補は敵の全種類とし、制作・試遊で不要な種類を除外できる。各回に出す種類の選出規則と体数は制作・試遊で決める。見た目は[ピカロの表現方針](../graphics-improvements.md#ピカロの見た目)に従う。

本体の技は1つずつ使う。ピカロ同士の攻撃は重なってよく、ケンタウルス座由来の隊列越しの遠距離攻撃を除いて、新しい攻撃を出す担当を本体とピカロで切り替える。同時攻撃の制御は予算システムで管理する。

ピカロを相手にする間、竜は背景奥へ退き、小さく薄い姿で見せる。本体攻撃へ切り替えるときは、ピカロの新規攻撃を止め、照射中のビームなど継続中の攻撃動作が終わるのを待つ。発射済みの弾は残し、全て消えるまでの待機は挟まず、竜が手前へ復帰して予兆を出し、本体攻撃へ進む。接近に伴い竜を大きく明瞭に見せ、攻撃対象への復帰を伝える。復帰の間も、残った弾を避ける時間とする。

ケンタウルス座由来の技では、竜の遠距離攻撃も隊列ピカロと共通の攻撃予算で管理し、予算内で隊列ピカロの迎撃と同時に使用できる。残る亀裂など、持続する障害物の切替時の扱いは未決。

### 攻撃方向と画面基準

| 攻撃 | 使用する方向 |
|---|---|
| 突進・複製攻撃・ピカロの隊列越しの遠距離攻撃 | さまざまな方向から使う |
| 飛びかかり・空間引き裂き・吸い込み | 画面の左右から使う |

飛びかかり・突進・渦巻き・空間引き裂きは、一度画面外へ退場してから、スクリーンの位置を基準に攻撃する。

カメラ追従中の画面基準位置の取り方と、攻撃軌道を固定する時点は未決。

### 通常攻撃

軽い通常攻撃2つのうち、1つは尾の薙ぎ払いとする。自機の位置にかかわらず選択できる範囲攻撃として使う。具体的な攻撃範囲・追尾・方向・予兆・数値は未決。もう1つの通常攻撃の内容も未決。

### 過去のボスを想起させる技

過去の4体のボスを想起させる技を使い、星の組み替えや竜本体の動きで表す。

| オマージュ元 | 対応する攻撃 | りゅう座の動作 |
|---|---|---|
| いっかくじゅう座 | 突進 | 頭の星が角の形に集まり、予告した直線へ突進する |
| ケンタウルス座 | ピカロの隊列越しの遠距離攻撃 | 接近を阻むピカロを並べた隊列の奥から遠距離攻撃を行う |

| うみへび座 | 複製攻撃 | 周囲に星でできた複数の顎が現れ、時間差で噛みつく |

### ピカロの隊列越しの遠距離攻撃

ケンタウルス座由来の隊列は、接近を阻むピカロを並べて作る。この技で使う種類は、一般の全種類候補とは別に、接近阻止に向く敵から調整できるようにする。候補の例は、ぼうえんきょう座のビームや、やまねこ座の3本の爪痕の斬撃とする。各敵の攻撃は[敵一覧](../catalog/enemies.md)に従う。

自機は隊列のピカロを突進で貫き、竜本体まで攻め込める。隊列の配置・体数と、竜が使う遠距離攻撃の具体的な形は未決。

### 渦を巻く接近と収縮

螺旋の中心は発動時の自機の位置に固定する。軌道の初期配置と向きは画面基準で作り、画面全体を覆う大きさから反時計回りに巻き始め、胴体同士が重ならないよう半径を小さくしながら近づく。収縮してくる姿で、急いで逃げる必要を感じさせる。1周目は高速、2周目は少し低速で巻く。

約2周した巻き終わりの形は、発動時の自機位置を原点、画面の右を+x、上を+yとする座標で、尾が180度（左）、頭が90度（上）にあり、頭が原点を向く形とする。この形で短い待機を挟み、逃げ出す余裕を持たせる。体の間は逃げ道だと分かる幅を確保する。

直進の前に攻撃予兆を出し、-y（画面下）へ一気に直進する。そのタイミングで巻いた胴体が一気に収縮し、体の間の隙間が閉じる。

螺旋中は胴体に炎状のオーラを纏わせる。オーラは機体の通り抜けを止める壁として扱い、危険な範囲を示す。

自機は体の間をくるっと回り込むようになぞって抜け出す。脱出が間に合わず、収縮する胴体に挟まれるとダメージを受ける。

炎状オーラの色・強度・判定幅、接触ダメージの扱いと具体値、弾の通過、具体的な軌道計算、速度の値、待機・予兆の時間は未決。

### 三本爪による空間の亀裂

竜が左右から三本爪で引っ掻き、空間に長い亀裂を刻む。亀裂は機体の通過を止める障害物として残り、自機は空間が裂けていない隙間を縫って本体へ攻め込む。

左右の攻撃を同時に出すか交互に出すか、亀裂の配置・持続時間・接触ダメージの有無と接触効果・弾の通過・破壊可能性は未決。

### 吸引大技

非常に広い範囲から自機を口へ強く引き寄せる。高速移動を繰り返して、かろうじて同じ位置を維持できる程度の感触を目指す。演出は既存のピクセル調を保ち、口へ重力が集まる様子をリッチに描く。

残っているピカロも吸い込む。吸引後は太いブレスを吐き、吸収したピカロを構成する星の合計数が多いほど、周囲に散る星弾が増える。ブレスを避けることを軸に、残したピカロの星の分だけ逃げ道が狭くなる。

星弾は並びを制御できる方式とし、制作者が出方・並び方を調整して、なぞる移動でかわすのが楽しい配置を作れるようにする。

自機が口に到達すると、ブレスとは別の噛みつき系の専用攻撃を受ける。この攻撃のダメージや、拘束・吐き出し等の効果は未決。

星数から弾数への換算方法・上限、星弾の具体的なパターン・編集UI・吸収星数に応じた配置の変化方法、射角、攻撃時間、予兆、吸引時間は未決。
