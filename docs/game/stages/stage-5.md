## 4. ラスボス戦

ラスボスはりゅう座で、核はこぐま座の北極星。多様な敵のピカロを出し、竜の本体も攻撃する。

本体には常に攻撃が通り、ピカロの残数にかかわらず攻められる。ピカロを倒すと攻撃の重なりが減り、本体に攻め込みやすくなる。ピカロを減らすか、避けながら本体を狙うかを選び、本体へ突進する軌道にピカロも巻き込める。竜の大技の後は本体を狙う好機とする。

ピカロの出現数・選出規則、戦闘の数値、寄り道（ピネウスを助けて攻略の手がかりを得る）の中身は未決。撃破後の締めは[仕様書 12.4](../../spec.md#124-ラスボス戦と締め)に従う。

### 吸引大技

非常に広い範囲から自機を口へ強く引き寄せる。高速移動を繰り返して、かろうじて同じ位置を維持できる程度の感触を目指す。演出は既存のピクセル調を保ち、口へ重力が集まる様子をリッチに描く。

残っているピカロも吸い込む。吸引後は太いブレスを吐き、吸収したピカロを構成する星の合計数が多いほど、周囲に散る星弾が増える。ブレスを避けることを軸に、残したピカロの星の分だけ逃げ道が狭くなる。

星弾は並びを制御できる方式とし、制作者が出方・並び方を調整して、なぞる移動でかわすのが楽しい配置を作れるようにする。

自機が口に到達すると、ブレスとは別の噛みつき系の専用攻撃を受ける。この攻撃のダメージや、拘束・吐き出し等の効果は未決。

星数から弾数への換算方法・上限、星弾の具体的なパターン・編集UI・吸収星数に応じた配置の変化方法、射角、攻撃時間、予兆、吸引時間は未決。ほかの具体的な技も未決。
