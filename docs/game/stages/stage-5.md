# ステージ5：元凶の待つ星系

倒した敵が生まれ直す道中、登場する敵、りゅう座とのラスボス戦を定義する。

## 1. 狙う体験

倒した敵の星が光の流れになって竜へ運ばれ、強くなった敵として生まれ直す。

道中の快感の中身は未決。

設定と元ネタは[世界観の元凶](../world.md#9-元凶ラスボス)、見た目は[アートスタイル](../art-style.md)を参照する。

## 2. フェーズと成長目標

**機体の強化が9割程度育った状態で、ステージ5に臨むものとする**（[ステージごとの想定](../../spec.md#141-機体の強化)）。

道中のフェーズの構成、到達レベル、予算、ボスの登場時刻は未決。

## 4. ラスボス戦

道中で育てた装備を持って巨体のりゅう座に挑む。ピカロへの対処と本体への攻撃を選び、後半ほど広がる攻撃に対応する戦闘とする。

ボス戦は、本体だけで戦う序盤、複製とピカロ隊列を使う中盤、両方に吸い込み・吐き出しを加える終盤の3段階で進む。段階の配分と移行は[りゅう座仕様の戦闘進行](../bosses/draco.md#2-戦闘の進行)に従う。

竜のHPを0にすると核のこぐま座が解放され、伝説のモジュールが組み合わさって最終入力へ進む。自由になぞる入力からフィニッシュ攻撃へつなぎ、竜を貫いてコズミックな破砕・爆発とともにクリアする。[核の解放から最終決着まで](../bosses/draco.md#23-hp0から最終決着)を、ステージの締めとする。

各技・判定・攻めどき・行動判断・素材と演出の詳細は[りゅう座仕様](../bosses/draco.md)に定義する。
