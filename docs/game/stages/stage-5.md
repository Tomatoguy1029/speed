# ステージ5：元凶の待つ星系

道中の構成、登場する敵、りゅう座とのラスボス戦を定義する。

## 1. 狙う体験

育成区間を挟んで5回の山を置く。前半は既出の強敵の組み合わせに対処し、後半は大物を中心とする軍勢や広範囲攻撃を突破する。最後に混成のラッシュで育てた装備を使い、静かな星空から竜との対面へつなぐ。

星から敵を生成する仕組みは、[ボス戦のピカロ](../bosses/draco.md#3-本体とピカロ)で扱う。

設定と元ネタは[世界観の元凶](../world.md#9-元凶ラスボス)、見た目は[アートスタイル](../art-style.md)を参照する。

## 2. フェーズと成長目標

**機体の強化が9割程度育った状態で、ステージ5に臨むものとする**（[ステージごとの想定](../../spec.md#141-機体の強化)）。

**竜との戦闘開始時に、装備した武器・特性がほぼMAXになり、上手く稼げば全てMAXに届くことを目指す。** 育成区間で経験値を多く稼ぎ、山では戦闘に集中する配分にする。具体的な到達レベルと選択間隔は未決。

### フェーズの役割

フェーズの進行は共通の仕組みに従う。前半2回の山は短め、ケフェウス座とわし座を主役とする山は長めに取る。各山の間に育成区間を置き、そのランの装備を育てる。

| フェーズ | 内容 |
|---|---|
| 最初の育成 | 雑魚をまとめて倒し、そのランの装備を揃え始める |
| 1回目の山 | 既出の強敵を少数の組み合わせで出し、連携への対処を楽しませる |
| 育成 | 圧力を落とし、まとめて倒して成長する |
| 2回目の山 | 1回目とは異なる強敵の組み合わせで、攻め込む経路や狙う順番を変える |
| 育成 | 大物に向けて装備を育てる |
| 3回目の山 | ケフェウス座の軍勢を突破し、王を倒して一気に崩す |
| 育成 | 軍勢を崩した後に十分な間を置く |
| 4回目の山 | わし座の広範囲攻撃をかわしながら、周囲の強敵ごと攻める |
| 最後の育成 | 装備を仕上げる機会を作る |
| 5回目の山 | それまでの敵を組み合わせた最終ラッシュ。山の中でも編成を入れ替え、段階的に盛り上げる |
| 静けさ・ボス登場 | 戦闘の圧力を落とし、[星空から竜との対面](../bosses/draco.md#83-ラスボス戦の登場)へつなぐ |
| ボス | りゅう座との戦闘へ進む |

### 育成区間の強敵

育成区間にも強敵を少数ずつ出す。出現候補を常に全種類同時に揃えることはせず、出現数・補充間隔・同時攻撃を調整する。後半の育成ほど少しずつ難しくし、直前・直後の山より圧力を落とす。育成3以降は種類数を増やさず、補充間隔と攻撃の重なりで段階的に強める。

| 育成フェーズ | 強敵の出現候補 |
|---|---|
| 最初の育成 | ポンプ座、かに座 |
| 育成2 | かに座、みなみじゅうじ座 |
| 育成3 | ぎょしゃ座、いるか座、からす座 |
| 育成4 | ポンプ座、みなみじゅうじ座、からす座 |
| 最後の育成 | かに座、いるか座、からす座 |

からす座は2回目の山から道中の最後まで、育成区間を含めて継続して出現する。

### 試遊用の全編成

`data/stages/stage_5.tres` に8分15秒の仮タイムラインを置く。編成と攻撃予算は同じ出現タイムラインで編集する。数値は試遊用の初期値とし、成長の到達レベルは固定しない。

雑魚の曲線は区間内にも山と間を作る。育成では噛みつく雑魚の圧力を落とし、分裂型を厚くして経験値をまとめて稼ぐ機会を作る。戦闘の山では噛みつく雑魚を複数回増減させ、自爆型を山1から混ぜて後半ほど増やす。山5後半の編成切り替えを経て、道中の終端では雑魚の補充を0へ落とす。これらは装備の完成度を試遊で確認するための仮設定とする。

編成シーンは敵の種類ごとの再利用ライブラリとして持ち、各クリップから使う並びを選ぶ。配置・出現位置の重みは編成シーン、開始・長さ・群れ数・補充間隔・攻撃優先度と使う並びはクリップで編集する。単体配置の左右・前後は群れの正面を基準とする。既存クリップは単体配置を選び、位置を含む出現条件を保つ。複数体の並びを持つ編成では制作時に候補を選べる。採用時に出現数と攻撃の重なりを確認する。

| 編成シーン | 複数体の並び | 配置の狙い |
|---|---|---|
| `s5_pump.tscn` | 左右吸引・吸引三角 | 吸引点を離して置き、近くの雑魚を別々に固める |
| `s5_crab.tscn` | 横壁・前後二列 | 横歩きの接近を横へ広げる配置と、前後で到達をずらす配置を選ぶ |
| `s5_cross.tscn` | 段差射線・射線三角 | レーザーの構えに入る位置を左右・奥行きへ分散する |
| `s5_auriga.tscn` | 左右走路・追走 | 炎の軌跡の入口を左右へ離す配置と、奥行きへ連ねる配置を選ぶ |
| `s5_dolphin.tscn` | 波の横列・波の二列 | 波を撃つ敵の接近位置を横へ広げる配置と、後続を持つ配置を選ぶ |
| `s5_crow.tscn` | 横並び・前後横断 | 回収する群れの入口を横へ広げる配置と、前後へずらす配置を選ぶ |
| `s5_cepheus.tscn` | 単体配置のみ | 王の開始位置を3種類から選ぶ |
| `s5_aquila.tscn` | 単体配置のみ | 雷を残す大物の開始位置を3種類から選ぶ |

| 強敵 | からす座 | 倒された敵の星を拾い、竜へ運ぶ |
| 強敵 | ポンプ座 | ステージ1から再登場 |

## 4. ラスボス戦

戦闘前には、救ってきた星空を眺める静けさから空間の裂け目と竜の出現へつなぐ。[ラスボスの登場演出](../bosses/draco.md#83-ラスボス戦の登場)を経て戦闘を開始する。

道中で育てた装備を持って巨体のりゅう座に挑む。ピカロへの対処と本体への攻撃を選び、後半ほど広がる攻撃に対応する戦闘とする。

ボス戦は、本体だけで戦う序盤、複製とピカロ隊列を使う中盤、両方に吸い込み・吐き出しを加える終盤の3段階で進む。段階の配分と移行は[りゅう座仕様の戦闘進行](../bosses/draco.md#2-戦闘の進行)に従う。

竜のHPを0にすると核のこぐま座が解放され、伝説のモジュールが組み合わさって最終入力へ進む。自由になぞる入力からフィニッシュ攻撃へつなぎ、竜を貫いてコズミックな破砕・爆発とともにクリアする。[核の解放から最終決着まで](../bosses/draco.md#23-hp0から最終決着)を、ステージの締めとする。

各技・判定・攻めどき・行動判断・素材と演出の詳細は[りゅう座仕様](../bosses/draco.md)に定義する。

## 5. 未確定事項

からす座の竜へ運ぶ動きと到達レベルは未決。編成・予算の仮値は試遊で調整する。時間配分と出現量は試遊で調整する。寄り道はピネウスを助けて攻略の手がかりを得るものとし、中身は未決。

ボスの調整値・素材・未決事項は[専用仕様](../bosses/draco.md#10-調整素材の未完項目)を参照する。
