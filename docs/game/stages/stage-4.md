# ステージ4：うみへび座の星系

育成と強敵の山を繰り返す道中、成長の到達目標、登場する敵とその役割、ヒュドラとのボス戦を定義する。

## 1. 狙う体験

育成区間で力を得て、強敵と群れが押し寄せる区間でその力を使う。成長を実感しながら、異なる攻撃への対処を積み重ねてヒュドラへ挑む。

同じフェーズの中にも敵数の山と谷を作る。押し寄せる群れを高速移動と突進で突破する場面と、そのあとにできる間によって、道中に緩急をつける。

設定と元ネタは[世界観の星系の主](../world.md#6-星系の主と取り込まれた星座)と[難所](../world.md#7-ステージの難所)、見た目は[アートスタイル](../art-style.md)を参照する。

開始地点の周辺に、コロニーとソーラーパネルの残骸、小惑星2種、宇宙の瓦礫を背景として置く。接触判定を持たず、配置・倍率・回転・色と明るさは `stage_4.tres` の `backgrounds` で調整する。

## 2. フェーズと成長目標

### 成長の方針

**機体の強化（ランをまたいで残る強化）が7割程度育った状態で、ステージ4に臨むものとする**（[ステージごとの想定](../../spec.md#141-機体の強化)）。全項目の段の合計が最大の段の合計の7割になる状態を基準に、難易度と成長を調整する。開発版では調整パネルの機体の強化の段の「7割」でこの状態にできる（[仕様書](../../spec.md)20章）。

**ボス前に、装備した武器・特性が全てMAXになるか、あと少しでMAXになる程度まで育つことを目指す。** ボスへ持ち込む装備全体の完成度を起点に、各フェーズで増やすレベル数と、レベルアップの間隔を配分する。

育成と休憩の区間では短い間隔で選択を重ねて成長を感じさせる。山場では戦闘に集中する時間を長く取り、ボス前のラッシュでは回避の忙しさに合わせて選択の間隔をさらに空ける。ボス戦にも残りの成長機会を持たせる。

### フェーズの役割

| フェーズ | 内容 |
|---|---|
| 1回目の育成 | 雑魚を倒して経験値を集め、最初の強敵に備える |
| 1回目の山 | 望遠鏡がレチクルと組んで登場し、群れへの対処に射線の読み合いが加わる |
| 一旦減少（休憩・育成） | 敵の圧力をいったん落とし、短い間隔で成長しながら次の山に備える |
| 2回目の山 | いるかの波動と、望遠鏡・レチクルの組み合わせが登場する |
| 2回目の育成 | 経験値を集め、さらに装備を育てる |
| 3回目の山 | 雑魚の群れに、いるかと南十字の攻撃が重なる |
| 3回目の育成 | 成長を進めながら、次のラッシュへ備える |
| ボス前のラッシュ | 複数の強敵に冠と水瓶が加わり、育てた装備で押し寄せる敵に対処する |
| ボス | ヒュドラとの戦闘へ進む |

育成区間では、経験値を多く落とす分裂する雑魚を多めに出す。噛みつく雑魚は同じフェーズ内でも増減させ、単調な密度が続くことを防ぐ。

### レベルアップの仮ペース

| 段階 | レベルアップの間隔 | この間にレベルアップで選ぶ回数 |
|---|---|---:|
| 最初の育成（0〜1:00） | 約10秒に1回 | 6回 |
| 休憩・育成（各30秒） | 約10秒に1回 | 各3回 |
| 山場（各1分15秒） | 約25秒に1回 | 各3回 |
| ボス前のラッシュ | 約35秒に1回。回避に集中できるよう、選択の間を空ける | 3回 |

到達レベルと選択の間隔を、成長を配分する二つの基準とする。レベル目標に加え、ボス前に装備全体がどこまで育つかを満たすものとする。

## 3. 登場する敵と編成

| 敵 | ステージ内の役割・対処の狙い |
|---|---|
| 噛みつく雑魚 | ヘビの群れで道中の密度とウェーブを作る。群れの中で止まる危険と、まとめて駆け抜ける快感を担う |
| 分裂する雑魚・分裂体 | 育成区間の経験値供給を担う。分裂後の小さい敵も含めて群れを処理する |
| 自爆する雑魚 | 群れの中で爆発までの猶予を意識させる。予告中に倒して爆発を防ぐ |
| ぼうえんきょう座 | 遠くから狙う射線の脅威を作る。照準を振り切る、岩陰を使う、本体へ攻め込む判断を求める |
| レチクル座 | 望遠鏡と組み、岩陰の安全を崩す。本体を倒して遮蔽物を守るか、望遠鏡を先に倒して連携を崩す |
| いるか座 | 波動の射線と群れの位置を意識させる。敵を射線に挟み、自分は離れて波動を敵に当てさせる |
| みなみじゅうじ座 | 十字の射線で位置取りに圧力をかける。停止して構えている間に攻め込む |
| みなみのかんむり座 | 雑魚を率いる渦と投擲で圧力を作る。周囲の群れを突破して投げる弾薬を減らす |
| みずがめ座 | 広がる水流の射線で周囲を脅かす。予告を読んで攻撃範囲を避け、本体を狙う |

望遠鏡とレチクルは連携する組み合わせとして登場する。ほかの強敵も雑魚の群れと重なり、攻撃を避ける経路と群れを倒す経路を選ぶ場面を作る。

各敵の行動・当たり判定などの詳細は[敵一覧](../catalog/enemies.md)と[共通仕様](../../spec.md#11-敵)、冠の投擲は[敵一覧](../catalog/enemies.md#みなみのかんむり座)に従う。

## 4. ボス戦

道中で育てた装備を持ってヒュドラに挑む。複数の首が生む脅威を読み、高速移動と突進で攻める経路を選ぶ戦闘とする。

戦闘は合体形態から分離形態へ進み、羅針盤を抱える不死の蛇の撃破で決着する。ボス戦中も通常敵が出現する。各形態・技・攻めどき・戦闘エリアの詳細は[ヒュドラ仕様](../bosses/hydra.md)に定義する。
