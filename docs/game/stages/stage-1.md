# ステージ1：いっかくじゅう座の星系

近距離で攻撃してくる敵を相手にする道中、成長の到達目標、登場する敵とその役割、いっかくじゅう座とのボス戦を定義する。

## 1. 狙う体験

近づいてきた敵が、すぐそばで攻撃してくる。予告を見て、攻撃される前に、または攻撃の届かない向きから飛び込み、まとめて貫く。

最初のステージとして、敵の攻撃を近距離に限り、危ないものを自機のまわりに集める。短い山をテンポよく繰り返し、新しく登場する強敵を主役にしながら、既に出た強敵と組み合わせる。

設定と元ネタは[世界観の星系の主](../world.md#6-星系の主と取り込まれた星座)、見た目は[アートスタイル](../art-style.md)を参照する。

## 2. フェーズと成長目標

### 成長の方針

**機体の強化が育っていない状態（0割）で、ステージ1に臨むものとする**（[ステージごとの想定](../../spec.md#141-機体の強化)）。

**ボス到達時に、装備した武器・特性が8〜9割育ち、プレイ次第でMAXに届く程度を目指す。** 育ち具合の割合の分母と、具体的な到達レベル・選択間隔は未決。

### 道中の長さ

ボスはラン開始から8分を目安に出現する。具体的な秒数と各区間への配分は調整する。

### フェーズの役割

育成区間を挟んで6回の山を置き、下表の強敵構成を使う。構成は強敵の種類と相対的な配分を示す。区間時刻・体数・補充間隔・XP倍率は試遊用の仮設定とし、育成区間の強敵の有無も含めて調整する。

| 仮の区間 | フェーズ | 内容 |
|---|---|---|
| 0:00〜0:45 | 1回目の育成 | 雑魚を倒して経験値を集め、最初の強敵に備える |
| 0:45〜1:30 | 1回目の山 | 強敵はたて座のみ |
| 1:30〜2:00 | 2回目の育成 | 経験値を集め、次の山に備える |
| 2:00〜2:45 | 2回目の山 | 最初はポンプ座を出し、同じ山の後半からたて座も加える |
| 2:45〜3:15 | 3回目の育成 | 同上 |
| 3:15〜4:00 | 3回目の山 | 強敵はかじき座のみ |
| 4:00〜4:30 | 4回目の育成 | 同上 |
| 4:30〜5:15 | 4回目の山 | みなみのさんかく座を主役に、ポンプ座・たて座も出す |
| 5:15〜5:45 | 5回目の育成 | 同上 |
| 5:45〜6:30 | 5回目の山 | かじき座を多めに、ポンプ座を少し混ぜる |
| 6:30〜7:00 | 6回目の育成 | ボス前のラッシュに備える |
| 7:00〜8:00 | 6回目の山（ボス前のラッシュ） | たて座・ポンプ座・かじき座・みなみのさんかく座を混ぜる |
| 8:00〜8:15 | ボス前の静けさ | 雑魚と強敵の補充を止める |
| 8:15〜 | ボス | いっかくじゅう座との戦闘へ進む |

### 調整する場所

編集元は [`stage_1.tres`](../../../speed/data/stages/stage_1.tres)。`phases` で区間・XP倍率・攻撃予算、`zako_curves` で雑魚の種類別目標数、`clips` で強敵の補充を調整する。育成区間は分裂する雑魚を厚くし、同じ区間内でも雑魚の曲線に山と間を作る。成長の到達目標と仮設定の比較は、通常開始の試遊で行う。

強敵の編成は [`data/formations/`](../../../speed/data/formations/) の `s1_*.tscn` を使う。単体・二体並びの候補と、クリップの `groups`・`interval` で出現量を変える。三角は中心1体から3つの星を生成する。1種類だけの山でも、複数の群れを補充する。

強敵のHPは `stage_1.tres` の `enemy_tuning` に試遊用の仮値を持つ。かじき座・ポンプ座・たて座の本体と、みなみのさんかく座の破壊対象である `triangle_star` を個別に上書きする。共通定義と他ステージのHPはそれぞれの設定を使う。

育成区間では強敵の新しい補充を休止する。クリップの終了で補充が止まり、生き残った敵は次の区間へ残る。ボス戦中の通常敵は曲線の末尾とボス戦フェーズで調整する。実測の装備完成度と成長速度は試遊で確認する。

### 攻撃の予算の仮目標

| フェーズ | 予算 |
|---|---:|
| 育成 | 1 |
| 1〜5回目の山 | 2・2・3・3・3 |
| 6回目の山 | 3 |

強敵1体のvalueを1とした目安。valueは同時に発生する攻撃の重さで、`enemy_attack_values` で種類ごとに調整する。出現量は曲線・編成・群れ数・補充間隔で調整する。

## 3. 登場する敵と編成

| 区分 | 敵 | ステージ内の役割・対処の狙い |
|---|---|---|
| 雑魚 | 噛みつく雑魚 | 道中の密度とウェーブを作る |
| 雑魚 | 突進する雑魚 | 群れで寄ってきて、そばで次々に突っ込んでくる。光っている間に貫き、突進させずに倒す |
| 雑魚 | 自爆する雑魚 | 明滅し終わる前に貫いて、爆発させずに倒す |
| 雑魚 | 分裂する雑魚・分裂体 | 育成区間の経験値供給を担う |
| 硬め | 波動の敵 | 止まって短い輪を出す。輪の合間を突く |
| 強敵 | たて座 | 正面の盾で攻撃を弾き返す。回り込んで背面から貫くと倒れ、盾を奪える |
| 強敵 | ポンプ座 | 周りの敵を吸い込んで固め、巨大な弾を一発撃つ。倒すと、固めた敵が飛び散って周りの敵を倒す |
| 強敵 | かじき座 | 高速で泳ぎ回り、止まってキランと光ると、その時の自機の位置へまっすぐ突っ込む。先読みはせず、進む先の敵や隕石を壊して進む。惑星は地形として保持する |
| 強敵 | みなみのさんかく座 | 3つの星が三角の辺に沿って回る。動く星の後ろの赤いレーザーに触れると被弾する。星が頂点で止まった間に、三角をなぞる一筆でまとめて貫く |

大物は出ない。

### 突進する雑魚

| 項目 | 内容 |
|---|---|
| 普段の動き | 噛みつく雑魚と同じく、自機へまっすぐ寄ってくる |
| 予告 | 自機が一定の距離まで近づくと、その場で止まり、体が光る。光っている間に、突進する向き（自機の方）を決める |
| 攻撃 | 光り終わると、決めた向きへ短い距離をまっすぐ突進する（近距離・線）。突進中の体に触れると被弾する。追尾はしない |
| 攻撃の後 | 突進し終えると少しの間止まり、また普段の動きに戻る |
| 倒し方 | 普通に倒せる。予告で止まっている間がいちばん狙いやすい |
| 自爆する雑魚との違い | 自爆は自分のまわりの面が危ない。突進する雑魚は自分の前の線が危なく、突進の向きから外れれば安全 |
| 未決 | 反応する距離、光っている時間、突進の距離と速さ、突進後に止まる時間、体力、ダメージ、見た目 |

### みなみのさんかく座

| 項目 | 内容 |
|---|---|
| 体 | 3つの星。中心は見えず、当たり判定もない |
| 普段の動き | 三角の形と向きを保ったまま、ゆっくり自機へ寄ってくる。3つの星は、三角の辺に沿って回る |
| 移動 | 星は頂点で止まり、止まる時間が終わると、次の頂点へ辺を動く。動いている間、星の後ろに赤いレーザーの軌跡が伸びる。軌跡は星に近いほど太く、後ろほど細い（細くなりすぎない）。輪郭のはっきりしたピクセルアートらしい見た目にする |
| 攻撃 | 赤いレーザーの軌跡は通り抜けられるが、触れると被弾する（近距離・線） |
| 倒し方 | 星が頂点で止まっている間だけ攻撃が通る。動いている間の星には攻撃が通らない（体当たりは貫通する）。止まった3つの星を、三角をなぞる一筆でまとめて貫く。星が全部倒れると倒れる |
| 減ったとき | 残った星は、元の三角の軌道のまま回り続ける |
| 未決 | 動く時間、止まる時間、三角の大きさ、軌跡の太さとダメージ、星の体力 |

各敵の行動・当たり判定などの詳細は[敵一覧](../catalog/enemies.md)と[共通仕様](../../spec.md#11-敵)に従う。

## 4. ボス戦

いっかくじゅう座は、突進と角で一気に距離を詰めて攻撃する。危ないのは角が向いている正面で、攻撃は近距離が中心。

戦闘の進行・技・攻めどき・行動判断の要件・素材と演出は[いっかくじゅう座の仕様](../bosses/monoceros.md)に定義する。

ボス戦中も通常敵が出現する。
