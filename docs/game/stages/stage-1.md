# ステージ1：いっかくじゅう座の星系

近距離で攻撃してくる敵を相手にする道中、成長の到達目標、登場する敵とその役割、いっかくじゅう座とのボス戦を定義する。

## 1. 狙う体験

近づいてきた敵が、すぐそばで攻撃してくる。予告を見て、攻撃される前に、または攻撃の届かない向きから飛び込み、まとめて貫く。

最初のステージとして、敵の攻撃を近距離に限り、危ないものを自機のまわりに集める。短い山をテンポよく繰り返し、山ごとに強敵を1種類ずつ足していく。

設定と元ネタは[世界観の星系の主](../world.md#6-星系の主と取り込まれた星座)、見た目は[アートスタイル](../art-style.md)を参照する。

## 2. フェーズと成長目標

### 成長の方針

**機体の強化が育っていない状態（0割）で、ステージ1に臨むものとする**（[ステージごとの想定](../../spec.md#141-機体の強化)）。

**ボス前に、装備した武器・特性が全てMAXになるか、あと少しでMAXになる程度まで育つことを目指す。** 配分の考え方は[ステージ4](stage-4.md#成長の方針)と同じ。

## 3. 登場する敵と編成

| 区分 | 敵 | ステージ内の役割・対処の狙い |
|---|---|---|
| 雑魚 | 噛みつく雑魚 | 道中の密度とウェーブを作る |
| 雑魚 | 突進する雑魚 | 群れで寄ってきて、そばで次々に突っ込んでくる。光っている間に貫き、突進させずに倒す |
| 雑魚 | 自爆する雑魚 | 明滅し終わる前に貫いて、爆発させずに倒す |
| 雑魚 | 分裂する雑魚・分裂体 | 育成区間の経験値供給を担う |
| 硬め | 波動の敵 | 止まって短い輪を出す。輪の合間を突く |
| 強敵 | たて座 | 正面の盾で攻撃を弾き返す。回り込んで背面から貫くと倒れ、盾を奪える |
| 強敵 | ポンプ座 | 周りの敵を吸い込んで固め、巨大な弾を一発撃つ。倒すと、固めた敵が飛び散って周りの敵を倒す |
| 強敵 | かじき座 | 高速で泳ぎ回り、止まってキランと光ると、その時の自機の位置へまっすぐ突っ込む。先読みはせず、進む先の敵や隕石を壊して進む。惑星は地形として保持する |
| 強敵 | みなみのさんかく座 | 3つの星が三角の辺に沿って回る。動く星の後ろの赤いレーザーに触れると被弾する。星が頂点で止まった間に、三角をなぞる一筆でまとめて貫く |

大物は出ない。

### 突進する雑魚

| 項目 | 内容 |
|---|---|
| 普段の動き | 噛みつく雑魚と同じく、自機へまっすぐ寄ってくる |
| 予告 | 自機が一定の距離まで近づくと、その場で止まり、体が光る。光っている間に、突進する向き（自機の方）を決める |
| 攻撃 | 光り終わると、決めた向きへ短い距離をまっすぐ突進する（近距離・線）。突進中の体に触れると被弾する。追尾はしない |
| 攻撃の後 | 突進し終えると少しの間止まり、また普段の動きに戻る |
| 倒し方 | 普通に倒せる。予告で止まっている間がいちばん狙いやすい |
| 自爆する雑魚との違い | 自爆は自分のまわりの面が危ない。突進する雑魚は自分の前の線が危なく、突進の向きから外れれば安全 |
| 未決 | 反応する距離、光っている時間、突進の距離と速さ、突進後に止まる時間、体力、ダメージ、見た目 |

### みなみのさんかく座

| 項目 | 内容 |
|---|---|
| 体 | 3つの星。中心は見えず、当たり判定もない |
| 普段の動き | 三角の形と向きを保ったまま、ゆっくり自機へ寄ってくる。3つの星は、三角の辺に沿って回る |
| 移動 | 星は頂点で止まり、止まる時間が終わると、次の頂点へ辺を動く。動いている間、星の後ろに赤いレーザーの軌跡が伸びる。軌跡は星に近いほど太く、後ろほど細い（細くなりすぎない）。輪郭のはっきりしたピクセルアートらしい見た目にする |
| 攻撃 | 赤いレーザーの軌跡は通り抜けられるが、触れると被弾する（近距離・線） |
| 倒し方 | 星が頂点で止まっている間だけ攻撃が通る。動いている間の星には攻撃が通らない（体当たりは貫通する）。止まった3つの星を、三角をなぞる一筆でまとめて貫く。星が全部倒れると倒れる |
| 減ったとき | 残った星は、元の三角の軌道のまま回り続ける |
| 未決 | 動く時間、止まる時間、三角の大きさ、軌跡の太さとダメージ、星の体力 |

各敵の行動・当たり判定などの詳細は[敵一覧](../catalog/enemies.md)と[共通仕様](../../spec.md#11-敵)に従う。

## 4. ボス戦

いっかくじゅう座は、突進と角で一気に距離を詰めて攻撃する。危ないのは角が向いている正面で、攻撃は近距離が中心。

戦闘の進行・技・攻めどき・行動判断の要件・素材と演出は[いっかくじゅう座の仕様](../bosses/monoceros.md)に定義する。

ボス戦中も通常敵が出現する。
