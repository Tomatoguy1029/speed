# Godot 本番の課題

現在の実装と、仕上げ・追加制作・要確認の事項を分けて管理する。戦闘の実装状況は[敵一覧](catalog/enemies.md)、画像の依頼・組込状況は[絵の依頼書](catalog/art-assets.md)を正とする。

| 課題 | 状態・次に確認すること |
|---|---|
| 敵・武器・特性・英雄の星座、経験値と機体強化のバランス | 機能と調整用データを実装済み。単体・混成・通常進行の試遊で数値を調整する。数値の正は `speed/data/`。成長の規則は[仕様書](../spec.md#9-成長)を参照 |
| 各ステージの敵構成・出現量・配置とフィールドの広さ | 各ステージの個別仕様に沿って試遊調整する。ステージ4の後半は[ステージ4](stages/stage-4.md)の時間帯・出現クリップで確認する |
| 鉄のがれき・丸鋸の置き方と、ボーナスステージの敵の量 | 仮の配置と出現を実装済み。配置の手触りと出現量を調整する（[仕様書13.1](../spec.md#131-フィールドの要素)） |
| 5体のボス戦の仕上げ | 専用ボス・技・形態・決着を実装済み。詳細は[ボス一覧](catalog/enemies.md#ボス)。数値、見た目と判定の一致、通常開始から結果までの通し試遊を確認する |
| りゅう座・うみへび座の追加調整を本番へ反映する | `claude/sweet-feynman-wiewbo` の技の動き・演出・最終決着・実験場の変更は作業ブランチで実装済み。統合時に、mainのULT・導入・描画準備の変更と文書を照合する |
| 英雄の星座と目印の星の案内 | 発見通知・画面端の矢印・ミニマップ・獲得演出を実装済み（[仕様書13.1](../spec.md#131-フィールドの要素)）。初見で探索・解放・発動が分かるかを試遊で確認し、操作説明を仕上げる |
| 必要な正式画像の制作・差し替え | 優先する画像と、納品済み・共用・要照合の区別は[絵の依頼書](catalog/art-assets.md)に集約する |
| BGM・効果音と画面の仕上げ | [音](../spec.md#18-音)に記載した曲・効果音を接続済み。仮の合成音と個別演出の音、残る画面の見た目を確認する。見た目の要件は[グラフィック改善ポイント](graphics-improvements.md)を参照 |
| ゲーム本体の負荷計測・最適化 | 追加するエフェクトなどが一通り入った後に行う。高密度の敵・ボス・背景を含む現在の内容で測り、[性能目標](../spec.md#21-性能)に対する不足を整理する |
| 配布版の確認 | 統合対象の版を決めてMac・Windowsの配布物を作り、必要ファイルの同梱と起動を確認する。Windows実機・Intel Macの動作と、Windowsの開発用C++ビルド操作は要確認 |
| ステージ5のピネウスの寄り道 | 攻略の手がかりを得る寄り道の中身は未決（[ステージ5](stages/stage-5.md)） |
| エンドレスモード | [仕様書2.1](../spec.md#21-モード)の内容と制作範囲を確認する。通常の選択画面から遊べるモードとしては未実装 |
| 審査用の準備 | 提出するアセット画像の整理と、無制限モードの対象・範囲の確認が必要。エンドレスモードと区別する |

ブラウザ試作の課題は [demo の課題](../../demo/docs/backlog.md) を参照する。
