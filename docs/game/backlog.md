# Godot 本番の課題

| 課題 | 状態 |
|---|---|
| 敵・英雄の星座・うみへび座の仮の絵を、種類と予告が見分けられる素材にする | [アート方針](art-style.md)・[敵一覧](catalog/enemies.md)に沿って制作 |
| 敵の出現の重み、10:00以降の波、英雄の星座の力、うみへび座の頭と生え直しを調整する | 専用の[敵・ルート実験場](../spec.md#201-敵ルート実験場)で敵を一体ずつ調整し、混成で確認してから段階的に採用する。数値の正は `speed/data/` |
| 鉄のがれき・丸鋸・重力の置き方と、ボーナスステージの敵の量を決める | 仮の配置と出現で実装済み（[仕様書](../spec.md)13.1） |
| 英雄の星座と目印の星の存在を伝える | チュートリアルと一緒に決める |
| 被弾で失う勢い：敵を倒し続けて溜まる強さの中身 | 未決（[仕様書](../spec.md)7.2） |
| いっかくじゅう座・ケンタウルス座・おおいぬ座・りゅう座のボス戦 | 各ステージの個別仕様（[1](stages/stage-1.md#4-ボス戦)・[2](stages/stage-2.md#4-ボス戦)・[3](stages/stage-3.md#4-ボス戦)・[5](stages/stage-5.md#4-ラスボス戦)）に沿って実装する。今は仮のボスで遊べる |
| 高密度時のCPU負荷と背景の再描画 | 調査済み。最適化は保留 |
| ステージ3で猟犬が数百体いる間、フレームレートが落ちる（約900体で25FPS前後） | 調査済み。様子見。猟犬の仮表示の描画準備と、猟犬の群れの計算が主な負荷 |
| ステージ5でピネウスを助け、ラスボス攻略の手がかりを得る寄り道 | 中身は未決。ラスボスと一緒に決める（[仕様書](../spec.md)12.4） |

ブラウザ試作の課題は [demo の課題](../../demo/docs/backlog.md) を参照する。
