# SPEED 仕様書

## 1. 用語と単位

| 用語 | 意味 |
|---|---|
| 実秒 | 現実の時間。ランの時計、ゲージの充填、線をなぞる時間はこれで数える |
| 世界秒 | ゲーム世界の時間。描画中のスロー・なぞり中のスロー・ヒットストップで遅くなる。敵・弾・効果の寿命はこれで数える |
| 単位 | ゲーム内の距離。止まっているとき、画面の短い辺に `config.base_view` 単位が映る |
| 速度 | 単位/世界秒。画面の表示は km/s に換算する（× `config.speed_to_kms`） |
| A | 攻撃力（7.1） |
| L | レベル（機体・敵・武器の文脈による） |
| n | 特性の重ね数 |
| `config.xxx` | 調整値（`speed/data/config.tres`）の項目 |
| データ | `speed/data/` の `.tres`。値は Godot エディタの「プロジェクト → ツール → データ編集」で見て変える |

- ゲーム世界の更新は固定間隔で行う。
- ポーズ中と3択の選択中は、世界・ランの時計・ゲージのすべてが止まる。
- 武器・特性・敵の個別の効果は [武器一覧](catalog/weapons.md)・[特性一覧](catalog/traits.md)・[敵一覧](catalog/enemies.md)。

## 2. ゲームの構成

### 2.1 モード

| モード | 内容 | 未決 |
|---|---|---|
| ストーリー | 5つのステージを順に進む。中ボスのステージが4つと、ラスボスのステージ。ADV パートのようなものはあまり入れない | 各ステージの長さ、失敗したときにどこからやり直すか |
| エンドレス | ハイスコアを目指す。ハイスコアを保存する。ステージ選択の画面から選ぶ | スコアの計算方法、終わる条件、使うフィールド、時間とともにどう難しくなるか、中ボスが出るか |

### 2.2 ステージ

| 順 | 星系 | 星系の主（中ボス） | フィールドの仕掛け |
|---|---|---|---|
| 1 | いっかくじゅう座の星系 | いっかくじゅう座 | 風の流れ |
| 2 | ケンタウルス座の星系 | ケンタウルス座 | 歌の領域 |
| 3 | おおいぬ座の星系 | おおいぬ座 | 明るい光の塊 |
| 4 | うみへび座の星系 | うみへび座 | 渦の首が出す渦 |
| 5 | 元凶の待つ星系 | りゅう座（核は北極星） | 未決 |

- ステージの順は、中ボスの星の数（中ボスの星座と取り込んだ星座の合計。[世界観とストーリー](world.md) の6章）が少ない順。
- クリア条件はボスの撃破。前のステージをクリアすると、次のステージを選べるようになる。
- 各ステージは星系を舞台にした、広めのフィールド。広さは 13.1 のフィールドと同じ。
- ステージの背景とワールドマップは、クリアしたステージの数が増えるほど色鮮やかになる。プレイ中には変わらない。見た目は [デザインとアートスタイル](art-style.md) の3.1・3.2。
- フィールドの端の英雄の星座と、そこを指す目印の星を探して動き回る（13.1）。
- 武器・特性などプレイ中に手に入れたものは、ステージをまたいで持ち越さない。
- 通常ステージは共通の6時間帯を使う。追加版の時間帯と敵は調整用に保持する。出現状態は [敵一覧](catalog/enemies.md)。
- **未決**：敵を倒したとき、星に戻る様子をゲーム中で見せるか。

### 2.3 伝説のモジュール

- 中ボスを倒すと、その中ボスが取り込んでいた星座の伝説のモジュールを1つ手に入れる。全部で4つ。
- 機体の性能に効かない。能力値の計算（7.1、9.1、14.1）に含めない。
- 4体の中ボスをすべて倒すと、4つそろう。
- 入手済みかどうかを保存し、図鑑（14.3）に載せる。
- **未決**：入手したときの見せ方。

## 3. 画面の流れ

| 画面・状態 | 内容 | 次へ |

| メインメニュー | 「ステージ選択」「機体の強化」「図鑑」のボタン | ステージ選択／強化／図鑑。戻る：タイトル |

- タイトル以外のすべての画面に、前の画面へ戻る操作がある。

## 4. ランの進行

### 4.1 時計と勝敗

- 時計は、ラン開始からの経過時間を実秒で数え上げる。描画中・なぞり中も進み、ポーズ・3択・ヒットストップの間は止まる。
- ボスは、`config.boss_time` から `config.boss_time` ＋ `config.boss_time_spread` の間のどこかで1体現れる（12.2）。ランごとにずらす。
- **クリア**：ボスを撃破する。時計はトドメの時点で止まる。
- **失敗**：機体の HP が0になる。時間切れはない。
- 結果で、獲得した部品をセーブに加え、記録を更新する（14.2）。クリアなら部品に `config.clear_bonus` を足す。

### 4.2 時間帯

時間帯ごとの値は `speed/data/phases/*.tres`、ステージが使う時間帯の並びは `speed/data/stages/*.tres`。時間帯の名前は画面に出さない。

- 敵の数は、時間帯の開始と終了の値（`pop_from`・`pop_to`）を時間帯の中で直線補間し、`config.density_mult` を掛けたもの。敵レベル（`level_from`・`level_to`）も同様に補間する。
- 補充の速さは `rate` × `config.density_mult`（体/秒）。
- 出現する敵は `mix`（type ID → 重み）から選ぶ。
- `xp_bonus` があれば、その時間帯の経験値に掛ける。
- `wave_interval` があれば、その間隔で群れをまとめて出す（11.3）。
- `cores` が true の時間帯に出力コアが出る（10）。
- **10:00 以降の強まり**：`config.surge_start` から、`config.surge_interval` ごとに段が1つ上がる（始まった時点で1段）。1段ごとに、目標の敵の数を `config.surge_pop` の割合だけ増やし、敵レベルに `config.surge_level` を足し、撃つ敵（敵の定義の `ranged`）の出現の重みを `config.surge_ranged` の割合だけ増やし、エリートになる確率に `config.surge_elite` を足す。最後の時間帯は、ボスを倒すまで続く。

## 5. 機体

| 項目 | 値 |
|---|---|
| 当たり判定の半径 | `config.ship_radius` |
| 最大 HP | `config.base_hp`。レベル・強化で増える |
| 被弾後の無敵 | `config.invuln_time` |
| 最高速度 | `config.base_max_speed`。レベル・特性・出力コア・強化で伸びる |
| 回収範囲 | `config.pickup_radius`。特性・強化で伸びる |

### 5.1 通常の移動

- **マウス**：機体はカーソルの方向へ進む。カーソルが機体から `config.mouse_dead_zone` 以内なら向きを変えない。向きは毎秒 `config.steer_rate` ラジアンで回る。最高速度 × `config.steer_cruise` に達するまで、毎秒 `config.steer_accel` ずつ加速する。
- **タッチ**：押した点を中心とする仮想スティック。`config.stick_dead_zone`（px）未満のずれは無視し、`config.stick_radius`（px）で最大。倒し具合に応じて巡航速度が最高速度 × `config.steer_cruise` から × `config.stick_cruise_max` まで変わる。
- 速さが `config.pivot_speed` より遅いときは、機体の向きを最後に操作した向きのままにする。

### 5.2 速さの減り方

- 発射（なぞりの開始）から `config.boost_duration` の間は減速しない。その後、残す速さを `config.energy_cut` まで落とす。
- 普段は弱い抵抗（`config.cruise_drag`）で減速するが、最高速度 × `config.cruise_floor` より下には落ちない。最高速度を超えた分は毎秒 `config.overcap_decay` の割合で減る。
- 宇宙塵の雲（13.1）の中では抵抗 `config.dust_drag` がかかる。
- なぞり終えたあとの勢い（6.6）がある間は、どの減速もかからない。

## 6. ゲージと描画

### 6.1 充填

- ゲージは**容量**と**充填率**（0〜100%）で表す。ラン開始時は満タン。
- 容量 ＝ 1 ＋ 大容量チャージ（T08）による増加。容量は回数のストックではなく、1回で描ける長さと勢いを増やす。
- 1単位の充填にかかる時間は `config.dash_charge_time` 実秒。急速充填（T07）と強化「充電効率」で短くなる。満タンまでの時間は、容量 × 1単位の充填時間。
- 描画中・なぞり中・ポーズ中・3択の間は溜まらない。経験値や撃破では溜まらない。

### 6.2 描き始め

- 充填率が `config.draw_min_charge` 以上のとき、クリックした位置から描き始められる。補助として Space でも開始でき、タッチでは「描く」ボタンを使う。描き始めの点は、惑星・月の外へ押し出す。
- 描ける長さの上限 ＝ `config.draw_length` × 開始時の充填率 × 容量 ×（最高速度 ÷ `config.base_max_speed`）× 軌跡延長（T14）の倍率。
- 描画中は、ボタンを押し続けずにカーソルを動かすだけで線が伸びる。点は `config.draw_step` 単位ごとに記録する。描く時間に制限はない。
- 描画中、世界の速さは `config.draw_time_scale` 倍。カメラはその場で固定する。
- 描画中・なぞり中の攻撃範囲の半透明帯は、経路が交差・折り返しても同じ濃さを保つ。帯の始点・終点と曲がり角は丸くつなぎ、幅は `config.wave_radius` に合わせる。中心線は帯と別に重ねる。
- 自機・通常敵・ボス・ドローンの描画には `config.character_scale` を適用する。敵・ボス・ドローンの判定も同倍率、自機の判定は調整した `config.ship_radius` を使う。隕石・月・惑星は対象外で、カメラ倍率は従来どおり。
- カーソル近くのリングに、描画前は充填率を、描画中は残りの長さを表示する。リングは0から充填率のとおりに伸びる。使える充填率（`config.draw_min_charge`）の位置に目盛りを置き、それ未満は暗い緑、以上で明るい緑、満タンで金。使えるようになった瞬間に、リングから広がる輪を出す。

### 6.3 確定

次のどれかで線が確定し、なぞりが始まる。

- もう一度クリックする（描き始めてから `config.draw_confirm_delay` 実秒たち、線ができているときだけ。それ以外のクリックでは描き続ける）
- 描ける長さを使い切る
- 線が惑星・月に届く（その位置で線を切り詰める）

線ができないまま惑星・月に届いたときは、描くのをやめ、ゲージは減らない。

### 6.4 消費

- 消費する割合 ＝ 開始時の充填率 × 実際に描いた長さ ÷ 今回の上限。例：満タンから上限の40%だけ描くと、60%残る。
- 確定したら、途中で敵に止められても消費は戻らない。
- 残りが使える充填率以上なら、なぞり終えたあとすぐ次の線を描ける。足りなければ、残りから充填を再開する。

### 6.5 なぞり

- 機体は線の始点へ移動し（ワープ）、線全体を `config.draw_run_time` 実秒でなぞる（ヒットストップの分だけ延びる）。
- 突進の速さ ＝ 最高速度 × `config.launch_ratio` × 充填の量 ＋ 同じ向きの今の速さ × `config.carry`（最高速度 × max(1, 充填の量) が上限）。
- なぞり中の世界の速さ ＝ `config.draw_run_slow_ref` ÷ 突進の速さ。ただし `config.draw_run_scale_min` 倍より遅くしない。カメラは固定。
- 機体は常に実際の進行方向へ向く。炎・火花のアニメーションは描画中・ヒットストップ中は停止し、移動中は速さに応じて再生する（なぞり中は線上の移動速度を使う）。
- 機体本体（半径 `config.ship_radius`）が触れた敵には体当たりの判定（7.2）を行う。貫いた敵は吹き飛び、機体は減速しない。
- 線の左右 `config.wave_radius` 単位の帯に、装甲を無視する波動（威力 A × `config.wave_damage`）が出る。帯から一度外れて再び重なった敵には、もう一度当たる。実際に再貫通したときは「×2」「×3」と表示する。
- 装甲を突破できない敵や障害物に当たると、その場で止まる（弾かれ）。
- 満タンから始めた線をなぞっている間は「満タン突撃」（T04）の効果がかかる。

### 6.6 なぞり終えたあとの勢い

- なぞり終えても速度を保ち、カーソル／スティックで向きを変えられる。この間は5.2の減速をかけない。
- なぞり終了時の速さが描画開始前より低ければ、終了時の進行方向のまま描画開始前の速さを引き継ぐ。弾かれて途中終了した場合も、弾かれた方向を保って同じ下限を適用する。
- 雑魚を貫いても減速しない。
- 次のときに通常の移動へ戻る：装甲を突破できない敵・惑星・月への衝突、敵の弾を受けたとき。
- この間、無敵にはならない。

## 7. 戦闘の計算

### 7.1 攻撃力

- A ＝ `config.base_attack` × 攻撃力倍率 × `config.atk_scale` × 満タン突撃の倍率。
- 攻撃力倍率は、レベル（1ごとに `config.level_atk_growth`）・特性「攻撃力」（T11）・強化「衝角素材」で上がる。
- 威力は移動の速さと関係しない。

### 7.2 接触

敵に触れると、こちらの攻撃になる。機体が被弾するのは、敵の攻撃（弾・ビーム・波動など）に当たったときだけ。

- **高速の接触**：なぞり中、なぞり終えたあとの勢いがある間、または最高速度 × `config.ram_speed_ratio` 以上で動いているとき。敵への体当たり攻撃になる。
  - A ≥ 敵の装甲 なら貫通し、ダメージを与える。貫いたあとの減速は、勢いがない普段の高速の接触のときだけ（敵の大きさに応じて少し落ちる）。
  - A < 敵の装甲 なら弾かれて止まる（失敗）。跳ね返り、速さを `config.bounce_keep` の割合だけ残す（最低 `config.bounce_min_speed`）。敵には A の 1/4 を与える。被弾はしない。
- **普段の接触**：上記以外。弱い攻撃になり、A × `config.touch_damage` を与える。
- **特殊な倒し方**：倒し方の条件を持つ敵（敵の定義の `gate`）には、条件を満たさない攻撃ではダメージが通らない。体当たりは貫通する（止まらない）。ただし、たて座・かに座の前面と、みなみのかんむり座の輪の星への体当たりは弾かれる（失敗）。条件ごとの扱いは [敵一覧](catalog/enemies.md)。
- 同じ敵には `config.contact_cooldown` の間、続けて当たらない。
- **隕石**は固い障害物。普段の速さで触れると押し出されて跳ね返り、A の 1/4 を与える（同じ隕石には0.25世界秒に1回）。上は通り抜けられない。高速で装甲を破れなければ弾かれる。
- 惑星・月にぶつかると、`config.crash_restitution` の反発で跳ね返る。

### 7.3 クリティカル

- 確率は `config.base_crit_chance`（T09 で上がる）。威力は × `config.crit_mult`。体当たりでは装甲の判定に × `config.crit_armor` の値を使う。
- 背面の弱点を持つ敵（敵の `weak_arc` が0より大きい種類）は、背面に当てると必ずクリティカル。背面を黄色い弧で示す。
- 大型の敵の破片（11.6）、吹き飛ばし衝角で吹き飛ばした敵と飛ばした死体がほかの敵に当たったときは、クリティカルにならない。

### 7.4 ヒットストップ

- 敵を一撃で倒したとき `config.kill_hitstop` 止まる。大型の敵は × `config.hitstop_big_mult`、クリティカルは × `config.hitstop_crit_mult`。
- 一撃かどうかは、その突進で最初に触れた時点の HP で判定する。体当たり・なぞり中の波動の両方が対象。
- 1回の突進で合計 `config.kill_hitstop_cap` まで。突進していない間、この上限は毎秒 `config.kill_hitstop_regen` ずつ戻る。
- 設定でヒットストップを切ると、ヒットストップは起きない。

### 7.5 敵の狙い

- 敵は機体の実際の位置ではなく、遅れて追いかける位置を狙う。`config.enemy_aim_lag` 秒遅れで、その位置は毎秒 `config.enemy_aim_speed` より速く動かない。射撃・誘導・追跡・突進の構えのすべてに使う。
- 遅れて追う位置は、画面の半径の55%（最低300）より機体から離れないように補正する。

## 8. 武器と特性

- **枠**：武器 `config.weapon_slots` 個、特性 `config.trait_slots` 個。
- **上限**：武器は Lv `config.weapon_max_level`、特性は同じものを `config.trait_max_stacks` 回まで重ねる。
- **最初の武器**：ラン開始時に選ぶ（9.2）。
- **武器の強さ**：表示 Lv を性能段階 P（武器の `level_steps`）に対応させる。威力係数 D ＝ 1 ＋ 0.3（P−1）、頻度係数 F ＝ 1 ＋ 0.12（P−1）、範囲係数 R ＝ 1 ＋ 0.1（P−1）。
- **彗星限定の武器**：質量牽引砲（W21）と双極ビーム（W22）は、レアな彗星（13.1）を壊したときだけ手に入る。3択には出ず、強化もない。手に入れたときから Lv の上限（`config.weapon_max_level`）の強さで装備する。
- **彗星限定の武器の受け取り**：カプセルを拾ったら、描画中・なぞり中が終わってから受け取る。空き枠があれば装備する。枠が満員なら、外す武器を選ぶカード（持っている武器と「今の装備を残す」）を出す。レベルアップの回数は使わず、リロールはできない。
- **後方ブラスター（W23）の例外**：共通係数は使わず、定義のLv別配列を適用する。Lv2・5は弾数、Lv3は連射速度、Lv4は威力のみを強化する。
- **色**：段階1＝白、2＝緑、3＝青（#3989ff）、4＝紫、5＝金。武器の Lv と特性の重ね数に共通。カードは取得後の段階、装備一覧は現在の段階で色を決める。
- 味方の弾と攻撃する破片は、惑星・月に当たると消える（敵を貫く弾も地形は貫かない）。波動・範囲攻撃・ビームは地形に遮られない。

### 8.1 英雄の星座の力

- **特別な枠**：武器・特性とは別の1枠。英雄の星座（13.1）を解放すると、その星座の力が入る。Q（キー設定で変えられる）で発動する。
- **クールダウン**：発動してから次に使えるまでの時間と、効いている時間は、星座ごとに決める（`speed/data/heroes/<ID>.tres` の `cooldown`・`duration`）。クールダウンは効いている時間を含み、実秒で進む。
- 力はそのステージの間だけ使える。ランの状態と一緒に、ステージが終わると無くなる。
- エンドレスモードでは、新しい星座を解放すると、特別な枠の力が入れ替わる。

| 英雄の星座 | 捕らわれているステージ | 力 |
|---|---|---|
| しし座 | 1 | 線が太くなる |
| ペルセウス座 | 2 | メドゥーサの首 |
| ふたご座 | 3 | 線を2本 |
| ヘルクレス座 | 4 | 火の隕石 |

- **しし座（線が太くなる）**：効いている間の突進は、なぞり中の波動の帯（6.5、線の左右に `config.wave_radius`）が `width_mult` 倍に太くなる。太い帯に入った敵は、体当たりと同じ扱い（攻撃力 A のダメージ、特殊な倒し方の条件は体当たりと同じ）で、装甲に関係なく貫く。帯は金色になる。
- **ペルセウス座（メドゥーサの首）**：発動した瞬間に、画面の中の敵（ボスと障害物のほか）と敵の弾が、効いている時間だけ石になって止まる（石の時間は世界秒で進む）。石になった敵は、突進でも普段の速さでも、触れると装甲や特殊な倒し方に関係なく一撃で砕ける。石になった弾は、触れると砕けて被弾しない。画面の中のボスは石にならず、`boss_stun` 実秒だけ止まる。
- **ふたご座（線を2本）**：効いている間は、1本目の線を確定すると、すぐに2本目を好きな所から描ける（長さの上限は1本目と同じ。ゲージは1本目のぶんだけ減る）。2本目を確定すると、機体は1本目を、双子のもう1機は2本目を、同じ速さで同時に駆け抜ける。双子の機体は、通った敵に体当たりと同じように当たり（装甲に届かなければ当たらない）、波動の帯も出す。弾かれず、被弾もしない。
- **ヘルクレス座（火の隕石）**：効いている間、`interval` 実秒ごとに、機体の周り（画面の半分くらいの範囲）に火の隕石を1つ落とす。落ちる場所はランダムで、範囲に敵がいればその敵の所に寄せる（うみへび座との戦いでは12.3）。`fall_time` 実秒の影のあと、半径 `radius` の範囲の敵を、装甲に関係なく A × `power` で焼く。落ちた跡は `burn_time` 実秒燃え、入ってきた敵を 0.25 秒ごとに A × `power` × `burn_power` で焼く。
- 力の値（`width_mult` など）は `speed/data/heroes/<ID>.tres` の `params`。

## 9. 成長

### 9.1 経験値とレベル

- レベルは0から始まる。レベル L から次へ必要な経験値 ＝ `config.xp_base` ＋ `config.xp_growth` × L ＋ `config.xp_curve` × L²。
- レベルが1上がるごとに：最高速度 × (1 ＋ `config.level_speed_growth`)、攻撃力 × (1 ＋ `config.level_atk_growth`)、最大 HP ＋ `config.level_hp_growth`、最大 HP × `config.level_heal` を回復。
- ゲージの充填時間はレベルでは短くならない。

### 9.2 カードの選択

**最初の武器**：狙ったビルドを組みやすくするために、ラン開始時に最初の武器を選ぶ。

- 全武器からランダムに `config.start_weapon_choices` 種類を出し、1つを選んで Lv1 で始める。選ぶまで時計は止まる。

**レベルアップの3択**

- レベルが1上がるごとに3枚のカードを出し、1枚を選ぶ。
- カードは「新しい武器」「武器の強化」「特性（新規または重ね）」を混ぜて抽選する。同じ候補を1画面に重複させない。
- 持っているものは × `config.owned_card_bias` の重みで出やすくする。枠が埋まったら新規取得のカードは出さない。上限に達したものは出さない。
- 候補が3枚に足りないときは、「HP 回復（最大 HP × `config.fallback_heal`）」のカードで埋める。
- 複数のレベルが一度に上がったら、1レベルにつき1回ずつ選ぶ。選択画面同士の間に待ち時間はない。

どちらもクリックまたは数字キー1〜3で選ぶ。

### 9.3 リロール

狙ったビルドを組みやすくするために、表示中のカードを引き直せる。

- 最初の武器の選択と、レベルアップの3択の両方で使える。新しいカードは、それぞれ9.2と同じ決まりで抽選する。
- 回数は1回のランで `config.reroll_count` 回。強化「演算予備」（14.1）で増える。
- 選択画面のボタン、または R キー。ボタンに残りの回数を表示し、残り0回では押せない。

### 9.4 保留

- 描画中・なぞり中に上がったレベルの3択は、なぞりが終わってから出す（弾かれて止まった場合も終わってから）。
- 3択を閉じたら、直前の速度を引き継いで再開する。

## 11. 敵

種類ごとの基礎値・行動の値は `speed/data/enemies/*.tres`。

### 11.1 見た目と強さ

- 区分は敵の定義の `rank`（取り込んでいる星の数）。星1が雑魚、星2が硬めの敵、星3〜5が強敵、星6〜10が大物。強敵と大物は星座をモチーフにする。種類と星の数は [敵一覧](catalog/enemies.md)。
- 星の数を強さの目安にし、HP・装甲などの基礎値は種類ごとの定義で調整する。見た目は [デザインとアートスタイル](art-style.md) の4.2。

### 11.2 強さの補正

敵レベル L（最低1）、サイズ比 z ＝ 実際の半径 ÷ 標準の半径（エリートの補正前）について：

| 項目 | 式 | エリート |
|---|---|---|
| HP | 基礎 × z² ×（1 ＋ 0.6（L−1））× `config.enemy_hp_mult` | さらに3倍 |
| 装甲 | 基礎 × z ×（1 ＋ 0.35（L−1））× `config.enemy_armor_mult` | さらに1.3倍 |
| 弾のダメージ | 基礎 ×（1 ＋ 0.25（L−1）） | — |
| 経験値 | 基礎 × z ×（1 ＋ 0.5（L−1）） | さらに4倍 |
| 速度 | 基礎 ×（1 ＋ 0.04（L−1）） | — |
| 半径 | — | 1.25倍 |

- エリートになる確率 ＝ 1% ＋ 6% × 危険度 ＋ 10:00 以降の強まり（4.2）。同時に出る数の上限を持つ種類（強敵）はエリートにならない。
- 出現地点の危険度（13.1）に応じて、敵レベルに最大 `config.danger_level` を足す。
- 大きさが変わる種類（`size_var`）は、標準の0.85〜1.30倍で生成する。

### 11.3 出現と補充

- 敵は画面の四辺の外（余白 `config.spawn_margin` ＋ 0〜80）に出す。外周にいる敵が少ない辺を優先し、辺の長さも考慮する。
- 目標の数に足りないときは、時間帯の補充の速さと「不足数 ÷ `config.spawn_refill_time`」の大きい方で補充する。出現に失敗した試行は数えない。
- 群れ：時間帯の `wave_interval` ごとに、`wave_type` の敵を画面を囲む輪か、一方向からの流れでまとめて出す。
- 敵の定義に同時に出る数の上限（`max_alive`）がある種類は、その数までしか出さない。強敵を一度に出しすぎないために使う。
- 分裂で増える敵は、その時点の目標数 ×（1 ＋ `config.enemy_split_overflow`）まで。
- ボス戦の間も、時間帯と10:00以降の強まり（4.2）に従って雑魚を含む通常敵を補充する。
- ボスと隕石は目標数に含めない。目標数が下がっても、すでにいる敵は消さない。

### 11.4 遠くの敵の再配置

- 画面の中心から、画面の半幅・半高 × `config.spawn_recycle_scale` ＋ 200 より離れた敵は、画面外の出現地点へ移す。HP・レベル・個体は保ち、撃破・経験値・ドロップは発生しない。
- ボスは移さない。

### 11.5 動き

- 追ってくる敵は `config.enemy_approach_cycle` 秒の周期で「接近」と「広域移動」を切り替える。敵ごとに開始をずらし、`config.enemy_approach_time` 秒は機体の遅れた位置（7.5）へ向かう。その前後 `config.enemy_approach_blend` 秒で進路を切り替える。残りの時間は、画面の45〜95%の広がり（`config.enemy_pursuit_spread` で調整）を持つ、時間とともに回る移動先（`config.enemy_roam_turn`）を追う。
- 距離の維持、構えて撃つまでの時間、爆発、分裂などは、それぞれの種類の行動の値（`params`）を使う。ボスは常に直接追う。
- 移動中の敵は、進む向きと機体（の遅れた位置）への向きを混ぜた向きを向く。進む向きの割合は `config.enemy_face_move` で、遅いときほど機体の方を向く。向きは敵の種類ごとの速さまでしか回らない。撃つ前の予告の間は機体の方を向き、構えて撃つ敵は撃つ向きで止まる。
- 敵同士の押し合い（間隔の補正）は行わない。
- 敵は惑星・月をすり抜けない。表面で止まり、横方向の速度は残す。敵の弾も、惑星・月に最初に当たった時点で消える。
- ソニックブーム・クリティカルランスを受けて生き残った雑魚は、0.3世界秒だけ追跡をやめて吹き飛んだ勢いを保つ（ボスを除く）。

### 11.6 大型の敵を倒したときの破片

- 半径 `config.hull_debris_min_radius` 以上の通常の敵を倒すと、ceil（半径 ÷ 12）個（6個以上、`config.hull_debris_max_pieces` 個まで）の攻撃する破片が飛ぶ。
- 初速 `config.hull_debris_speed`（ソニックブーム・クリティカルランスでの撃破は `config.hull_debris_force_speed`、吹き飛ばし衝角での接触撃破は W03 の値）。攻撃の方向がある場合はその方向へ `config.hull_debris_spread` 度の扇状に、方向がない場合は全周へ飛ぶ。
- 破片は `config.hull_debris_life` 世界秒残り、威力 A × `config.hull_debris_damage`、敵を貫き、吹き飛ばし `config.hull_debris_knock` で周りを巻き込む。
- 破片で倒した敵からは破片を出さない。隕石とボスは対象外。クリティカルは乗らない。

### 11.7 敵の攻撃の形

敵の攻撃は、弾（敵の弾・ミサイル）と、次の形を組み合わせて作る。どれも予告のあとに当たり判定を持つ。残る線のほかは、1つの攻撃は機体に1回だけ当たる。地形では止まらない。

| 形 | 中身 | 予告の見せ方 |
|---|---|---|
| ビーム | 撃った位置から、決まった長さと幅の線。予告のあと少しの間当たる。十字は4方向のビーム | 砲口に光が集まっていく |
| 遅れて弾ける範囲 | 円の範囲が、予告のあと一瞬弾ける | 照準の模様（照準・落雷）、または中心の点滅（爆発） |
| 広がる波 | 1点から輪や扇が広がる。切れ目を空けられる。何層もの輪は、層ごとに少し遅れて広がり、切れ目の向きが少しずつずれる | 中心に光が集まる |
| 残る線 | 決まった長さと幅の線が、しばらく残る。触れている間は危ない（被弾後の無敵の間は当たらない） | 線が薄く現れてから濃くなる |

- 予告は、攻撃する敵の側の光・模様・点滅で見せる。当たる範囲そのものは画面に出さない。
- 画面の外で画面から離れていく敵の弾（ホーミングしない弾）は、消える。
- 吸い寄せ（ポンプ座）と押し流し（みずがめ座の水流）は、敵と遅い機体を動かす力で、ダメージはない。高速の機体には効かない。
- ビームの長さはゲーム内の距離で決め、画面の端の少し先まで届く長さを目安に調整する。
- 長さ・幅・予告の時間・ダメージは、その攻撃を使う敵の定義（`speed/data/enemies/<type ID>.tres` の行動の値）で決める。

### 12.1 見た目

### 12.2 仮のボス

今のステージ1〜3・5には、このボスが出る（ステージ4はうみへび座、12.3）。値は `speed/data/bosses/provisional.tres`（HP・装甲・出現時刻は `config.boss_hp`・`config.boss_armor`・`config.boss_time`・`config.boss_time_spread`）。

- ボスが出ても通常の敵は湧き続ける。ボスは画面外へ離れても消えず、再配置もしない。

### 12.3 中ボス

| うみへび座 | 首を複数生やして、同時に複数の場所を攻撃する。巨大な敵 | 下記 | 下記 |

**うみへび座**

調整用に保持するステージ4のボス。通常出現は [敵一覧](catalog/enemies.md) に従う。値は `speed/data/bosses/hydra.tres`（体力・出現時刻は12.2と同じく `config.boss_hp`・`config.boss_time`・`config.boss_time_spread`）、頭は `speed/data/enemies/hydra_<首の種類>.tres`。

- 本体は基本的にその場で構え、機体の方へゆっくり向き直る。機体が `engage` より離れると、機体の方へ泳いで近づく。
- 首は本体の周りに等しい間隔で生え、普段は機体の方へゆらゆら向く。首の本数は本体の体力で増える：75%より上は3本、50%より上は5本、25%より上は7本、それ以下は9本。
- 本体と首は、体当たりも武器もすり抜ける（ダメージはなく、弾かれもしない）。ダメージが通るのは頭だけ。頭は敵と同じく、体当たり・武器・特性の攻撃で削れ、装甲に届かない体当たりは弾かれる。頭に与えたダメージの `head_share` の割合が、本体の体力を削る。
- 頭の HP は `head_hp`。落とした頭は `regrow` 世界秒で生え直す。1本の線（1回の突進）でまとめて落とした頭が1本増えるごとに、生え直す時間が `regrow_combo` の割合だけ延びる。
- 頭を落とすと、首の残骸が攻撃する破片になって飛び散る（敵に `debris_dmg` を与える）。
- 普段の頭が全部落ちると、真ん中の不死の首が `expose_time` 世界秒むき出しになる。むき出しの間に不死の首の頭を貫くと（体当たりだけが通る）、本体の最大体力の `immortal_dmg` の割合を削る。むき出しが終わると、普段の首がすぐ生え直す。次にむき出しになれるのは3世界秒後から。
- 首の本数が増えるとき（段階が変わるとき）は、全部の首が生え直し、新しい首も加わる。
- 首の種類と本数：3本は噛みつく首・渦の首・瓦礫の首。5本でビームの首と噛みつく首、7本でホーミング弾の首とビームの首、9本で渦の首と瓦礫の首が加わる。
- 首ごとに、`attack_cd` 世界秒（±20%）の間隔で、機体が `engage` × 1.3 より近いとき、その種類の2つの攻撃のどちらかを出す。普段の首の攻撃は羅針盤で予告しない（首の引き・頭の光で見せる）。

| 首 | 攻撃1 | 攻撃2 |
|---|---|---|
| 噛みつく首 | 首を後ろに引いて（頭が光る）から、前へ `bite_reach` まで伸びて噛みつく（頭の位置の半径 `bite_radius`、`bite_dmg`）。噛みついた直後は伸びきって止まる | 短く3回、続けて噛みつきながら前へ出てくる |
| 渦の首 | 頭の先に渦を1つ置く（半径 `vortex_radius`、`vortex_life` 世界秒で縮んで消える。13.1の重力と同じく、敵・敵の弾・遅い機体を引き寄せる） | 首を振りながら、渦を3つ並べて置く |
| 瓦礫の首 | 瓦礫を `rubble_count` 個吐き出し、ほかの首の頭の周りに漂わせる。瓦礫に体当たりすると弾かれる（失敗）。武器では壊せる。6世界秒で消える | 瓦礫を固めた塊（半径 `lump_r`、`lump_dmg`）を、機体の方へ投げつける |
| ビームの首 | 首を高く持ち上げて光を溜め（1世界秒）、太いビーム（長さ `beam_len`、`beam_dmg`）を出したまま首を振り、本体の周りを薙ぐ | 細いビームを、機体の方へ3回続けて撃つ（予告 0.45世界秒） |
| ホーミング弾の首 | ホーミング弾を4発吐き出す | 自分の周りに弾を12発、輪のように浮かべ、0.9世界秒のあと全部を外へ放つ |

- むき出しの不死の首は、0.9世界秒ごとに、周りへ短い衝撃（半径 `shock_radius` の輪）を出して暴れる。

**強めの技と羅針盤**

- 本体に羅針盤が埋め込まれている。普段の針は北を指す。強めの技の前だけ、針が 1.2世界秒くるくる回り、どの技かを方位で指して止まる（画面の上が北）。
- 強めの技は、`tech_cd` 世界秒に1回、機体が `engage` × 1.3 より近く、不死の首がむき出しでないとき、必要な首がそろっている技からランダムに1つ出す。技の間は、普段の首の攻撃を止める。
- 技の途中で必要な首が落ちると、技は崩れて終わる。

| 方位 | 技 | 必要な首 | 流れ |
|---|---|---|---|
| 北 | 全方向の噛みつき | 噛みつく首 | 首を全部引っ込めて体を丸め、少しすると全部の首が一斉に付け根の向き（周りのあらゆる方向）へ `bite_reach` まで伸びて噛みつく。伸びきったあとは全部の首が止まる。ホーミング弾の首がいれば、伸びきったところからホーミング弾を3発吐く |
| 東 | 砕ける瓦礫 | 瓦礫の首、ビームの首 | 瓦礫の首が本体の周りに瓦礫を10個漂わせたあと、ビームの首が光を溜め、太いビームで薙ぎ払う。ビームに当たった瓦礫は砕けて、破片（敵の弾 6発、`shard_speed`・`shard_dmg`）が飛び散る |
| 南 | 瓦礫の渦 | 渦の首、瓦礫の首 | 渦の首が機体の方に大きな渦を置いたあと、瓦礫の首が瓦礫を8個吐く。瓦礫は渦に吸い込まれて回り、渦が消えるときに外へ破片を飛び散らせる |
| 西 | はさみ薙ぎ | ビームの首2本 | 2本のビームの首が機体の左右へ首を上げて光を溜め、太いビームで同時に、間を閉じるように薙ぎ払う |

**火の隕石（ヘルクレス座、8.1）との関係**

- 火（火の隕石の爆発と、燃えている跡）でダメージを受けてから 0.5世界秒以内に落ちた頭は、首の本数が次の段階に増えるまで生え直さない。段階が変わると、焼いた首も含めて全部が生え直し、新しい首も加わる。
- 不死の首は、火では焼けない（ダメージが通らない）。
- ボス戦の間、火の隕石は35%の確率で、範囲の中のボスの頭に寄せて落ちる。

### 12.4 ラスボス戦と締め

ラスボスはりゅう座、核はこぐま座の北極星（設定は [世界観](world.md) の9章）。戦いの仕掛け・攻撃・数値は未決。ステージ5の寄り道は、ピネウスを助けて攻略の手がかりを得るものとし、中身をラスボスと一緒に決める。

| 段階 | 内容 | 操作 | 未決 |
|---|---|---|---|
| 1. 通常の戦い | ラスボスと普通に戦う | 通常 | ラスボスの攻撃と数値 |
| 2. 倒したと思わせる | ラスボスを倒したように見せる | — | どう見せるか（HP が0になる、撃破の演出を途中まで出す など） |
| 3. 最後の抵抗 | ラスボスが、捌ききれない強敵と共に襲ってくる | 通常 | 強敵の種類と数、この段階の長さ、ここで負けることがあるか |
| 4. 伝説の機体の完成 | 4つの伝説のモジュールが組み合わさり、制限が外れる | なし（演出） | 演出の長さ |
| 5. 止まった世界で描く | 描ける長さが無限になり、時間も大きく伸び、その間は世界が止まる（世界の速さ0）。敵を通る軌跡を描きまくる | 描画（6.2） | 何の時間をどれだけ伸ばすか、描き終える条件、ゲージを使うか |
| 6. 叩き込む | 超加速した機体がラスボスに攻撃を叩き込みまくり、最後に自動でまっすぐ貫く | なし（自動の演出） | 描いた軌跡をなぞるのか、別の動きか。描いた軌跡が敵に与える効果 |
| 7. 決着 | ラスボスが大爆発と共に散り、クリア | — | クリア後の見せ方 |

5の段階では、6.2の長さの上限と6.3の「長さを使い切ると確定」が働かず、描画中の世界の速さが `config.draw_time_scale` ではなく0になる。

### 13.1 フィールドの要素

| 宇宙塵の雲 | `config.dust_count` 個。中では抵抗 `config.dust_drag`（6.6の勢いの間は無効） |
| 危険度 | 中心から `config.zone_outer` までは0。外縁に向かって1まで上がる |
| 重力 | 下記 |
| 隕石 | 下記 |
| 鉄のがれき | 下記 |
| 回る丸鋸 | 下記 |
| ワープホール | 下記 |
| 英雄の星座 | 下記 |

**隕石**

- ラン開始時に、世界の決まった位置へ配置する：隕石地帯（各8個）と、まばらに漂う岩。数は `config.meteor_count` を基準にする。惑星の中やフィールドの外に入る岩は除く。
- 漂流隕石の軌道と回転は世界秒で進む。描画中・なぞり中は敵と同じ倍率で遅くなり、停止中に実時間の分だけ軌道が先へ飛ぶことはない。

**彗星**

- `config.comet_interval_min`〜`config.comet_interval_max` 世界秒ごとに1つ現れ、画面の端の近くを `config.comet_speed` でまっすぐ横切る。惑星を通らない向きを選ぶ。画面を抜けたら消える。
- 隕石と同じく壊せる（基礎値は隕石と同じで、大きさに応じて HP が増える）。見た目は [デザインとアートスタイル](art-style.md) の3.6。
- ランの時計が `config.rare_comet_after` 実秒を過ぎたあと、確率 `config.rare_comet_chance` でレアな彗星になる。レアな彗星は、まだ持っていない彗星限定の武器（8章）のどれか1つを持ち、壊すとそのカプセルを必ず落とす。彗星限定の武器をすべて持っていれば、レアな彗星は出ない。
- 隕石の基礎値は `speed/data/enemies/meteor.tres`。
- 画面の近くに入ったら有効にし、離れたら無効にする。
- 壊した隕石はそのランの間は戻らない。追跡・再配置・補充はしない。

**重力**

- `config.gravity_interval_min`〜`config.gravity_interval_max` 世界秒ごとに、画面の中の機体から少し離れた位置に1つ現れる。置き方は仮。
- 現れたときの届く半径は `config.gravity_radius`、中心の引き寄せる加速は `config.gravity_pull`。中心から離れるほど弱く、`config.gravity_life` 世界秒かけて縮んで消える。
- 敵・敵の弾・遅い機体を引き寄せ、敵や弾の進路を曲げる。高速の機体（7.2の高速の接触と同じ条件）には効かない。ボス・障害物・部位には効かない。

**鉄のがれき**

- ラン開始時に、`config.iron_count` 個の塊（1つの塊に3〜5個）を世界の決まった位置へ置く。動かない。置き方は仮。
- 隕石と同じく固い障害物で、普段の速さで触れると押し出されて跳ね返る。装甲がとても高く（`speed/data/enemies/iron.tres`）、十分な攻撃力の体当たりなら割れる。ぶつかると火花が出る。

**回る丸鋸**

- ラン開始時に、`config.saw_count` 個を世界の決まった位置へ散らして置く。その場で回る。置き方は仮。
- 機体が触れると（速さによらない）、機体の進んでいた向きへ、`config.saw_speed` と機体の速さの速い方で飛んでいく。飛ぶ丸鋸は敵を貫いて巻き込み、攻撃力 × `config.saw_power` を与え、`config.saw_life` 世界秒で壊れる。1回使うと戻らない。
- 武器や敵の攻撃では壊れない。

**英雄の星座**

- ステージ1〜4に、そのステージに捕らわれた英雄の星座（8.1）が1つある。ラン開始時に、フィールドの端のほう（中心から `config.field_radius` の72%〜外縁の600手前）の、機体から離れたランダムな位置とランダムな向きに置く。星の位置は `speed/data/heroes/<ID>.tres` の形に `config.hero_scale` を掛ける。
- エンドレスモードでは、最初に4つのうちランダムに1つが現れる。解放すると、`config.hero_next_time` 実秒あとに、別の星座（ランダム）が別の場所に現れる。
- 星座線は、うっすらと点線で見える。機体が星座の中心から `config.hero_glow_range` より近いと、星が恒星のように強く光る（近いほど強い）。
- 機体が星座の中心から `config.hero_guard_range` より近づくと、周りにそのステージの強敵（大物を除く）を `config.hero_guards` 体出して守らせる。1つの星座に1回だけ。
- **解放**：1回の突進（なぞり）の中で、星座線でつながった2つの星を続けて通ると、その間の線が光る。星を通るとは、機体が星の半径 `config.hero_star_radius` の中を通ること。全部の線が光ると解放され、特別な枠（8.1）にその星座の力が入る。何回の突進に分けてもよい。

**目印の星**

- 英雄の星座がまだ解放されていない間、`config.landmark_interval` 実秒ごとに確率 `config.landmark_chance` で、機体の近く（画面の対角の半分 × 1.3 の範囲）の強めの敵（星2〜5、部位を除く）から1体に目印の星を持たせる。目印の星を持つ敵が生きている間と、線が2本そろったあとは選ばない。
- 選ぶ敵は、英雄の星座と、前に取り戻した目印の星の位置から `config.landmark_spacing` より離れた敵に限る（フィールドに散らばるように）。
- 目印の星を持つ敵は、金色とも白ともつかない特別な光を放つ。倒すと目印の星を取り戻し、その位置から英雄の星座を通る線が1本、ミニマップに出る。2本目で2本の線が交わり、場所がわかる。英雄の星座が入れ替わると（エンドレスモード）、線は消える。

**ワープホールとボーナスステージ**

- ワープホールは、彗星が現れる時刻に、確率 `config.warp_chance` で彗星の代わりに現れる。ランの時計が `config.rare_comet_after` を過ぎてから、ボスが出るまでの間だけ。同時に1つまで。
- 画面の端の近くに現れ、`config.warp_life` 世界秒で消える。半径は `config.warp_radius`。機体が触れるとボーナスステージに入る。
- ボーナスステージは `config.bonus_time` 実秒。入るとき、周りの敵（ボスと障害物のほか）と敵の攻撃を消す。背景の色が変わる。
- 中では、そのステージの時間帯の出現の割り振りから、雑魚と硬めの敵だけを `config.bonus_pop` × `config.density_mult` 体保つ。強敵は出ない。中身は仮。
- ゲージは無制限：1本の線の長さは普段の上限のままで、放つとすぐに満タンに戻る。
- ボーナスステージの間は、ランの時計（4.1）が止まる。終わると、ボーナスステージの敵と敵の攻撃を消し、その場で通常の出現に戻る。

### 13.2 ステージの仕掛け

風・歌・光の仕掛けは、自機の移動（5）や線（6）に作用するフィールドの領域として検討する。数値は未決。うみへび座の渦は、ボスの渦の首の攻撃（12.3）として扱う。

| 仕掛け | 作用 | 未決 |
|---|---|---|
| 風の流れ（いっかくじゅう座） | 自機の移動と描いた軌跡を、風の向きに押し流す | 軌跡が流れるのは描いている間か、なぞる間か。風の強さと範囲 |
| 歌の領域（ケンタウルス座） | 自機を引き寄せる。弦や糸で自機の動きが縛られる場面と組み合わせる | 引き寄せる強さ、縛りの内容と解き方 |
| 明るい光の塊（おおいぬ座） | 触れてはいけない。軌跡で触れると爆発する | 爆発が自機・敵に与える影響、普段の移動で触れたときの扱い、塊の数と再生 |
| 渦の首の攻撃（うみへび座） | 渦の首が出す渦と、噛みつく首の攻撃で挟み撃ちになる。作用は12.3・13.1 | 難しさの調整 |

- 風・歌の領域の引き寄せは、5.1の通常の移動と6.6の勢いに力を加える。なぞり（6.5）の間に効くかは未決。
- 光の塊は、6.3の「線が惑星・月に届くと確定」と同じく、線との接触を判定する。

| ソニックブーム | 機体と一緒に進路を進む。画面のフラッシュと揺れ、衝撃波の歪み |
| 普段の被弾 | 機体を `config.ship_hurt_time` 実秒赤くし、機体だけを横に最大 `config.ship_hurt_shake` px 震わせる。カメラは揺らさない |
| 敗北 | 最後の被弾の瞬間、カメラを固定し、HUD を消す。世界を `config.death_freeze_time` 実秒止め、機体以外を `config.death_world_dim` の割合で暗くする。機体を消して爆発・破片を `config.death_explosion_time` 秒、GAME OVER を `config.death_game_over_time` 秒表示して結果画面へ。暗さは結果画面まで保つ |
| ボス撃破 | 直前 `config.boss_finish_replay_window` 秒の機体の動きを記録し、`config.boss_finish_zoom` 倍に寄って `config.boss_finish_slow_time` 秒かけてスローで再生。通常の速さに戻ってボスが爆発し、残りの敵と敵の弾を消す。`config.boss_finish_blast_time` 秒のあと CLEAR! を `config.boss_finish_clear_time` 秒表示し、結果画面へ。演出中は操作・被弾・時間切れ・3択・新しい出現を止める。部品と記録の保存は演出の最後に1回だけ |

- 演出は攻撃力・装甲・ヒットストップに影響しない。ポーズ中・3択の間は止まる。

## 20. 調整機能

開発版では、プレイ中に値を変えて試せる調整パネル（P）と、性能の表示（F3）を使える。

- ステージ選択：クリア状況に関係なくステージ1〜5を選び、各ステージを最初からプレイできる。開発版で全ステージを選べる旨を画面に表示する。ステージの解放とクリアの記録は通常の進行として保存する。
- 時間：+30秒／+60秒、ボス出現の時刻へ進める、ボスを倒す
- 機体：無敵、HP 全快、レベルアップ、ゲージ満タン、被弾・致命傷の演出を確認
- 装備：武器・特性を指定した段階で直接入手、装備のリセット
- 敵：すべて消す、指定数のランダムな通常敵を画面内に追加（負荷計測用。通常の出現上限を超えて生成可能）、密度、追跡の広がり、ボスの HP・装甲・出現時刻、隕石の密度と各ドロップ率、彗星・レアな彗星・重力・ワープホールを出す
- ゲージ：充填時間、使える最低の充填率、描画中の世界の速さ（0〜1）
- 成長：必要経験値、武器・特性の枠の数
- 部品+100、強化のリセット
- 調整パネルで変えた値はそのランの間だけ有効で、データは変えない。「既定値に戻す」でデータの値に戻る。

性能の表示（F3）は、押すたびに簡易表示 → 詳細表示 → 非表示と切り替わる。初期位置は画面の右上（ボスの HP バーの下）で、つかんで動かせる。表示の段階と位置は、同じ起動の間は次のランにも引き継ぐ。数値は1秒に4回更新し、その間の平均と最大を出す。

- 簡易表示：FPS、フレーム時間の平均と最大、1フレームに実行した物理更新の回数（2回を超えると赤）、敵・敵弾・味方の弾・経験値の結晶・部品の数
- 詳細表示：簡易表示に加えて次を出す
  - 処理時間：1フレームあたりのゲーム処理と、それ以外（描画・待ち）の時間、ゲーム更新1回の時間、処理ごとの時間（世界側の更新1回あたり）
  - 描画：描画命令・オブジェクト・頂点の数、シェーダーのコンパイル数（累計と直近の増加）
  - メモリ：RAM・VRAM、オブジェクト・ノード・どこにもつながっていないノードの数
  - 表の行：敵・弾・結晶・部品の使用中の行と、空きを含む行数（設計書 6）
  - 直近120フレームのフレーム時間のグラフ（16.7ms と 33.3ms に線、25ms を超えたフレームは赤）

### 20.1 敵・ルート実験場

開発版のメインメニューから専用の実験場を開く。通常の敵と調整用に保持する敵・ボスを同じパレットから配置する。通常ステージの出現は敵一覧の通常構成を使い、全ステージを最初から選べる。

中央には本番のランの画面（描画・カメラ）をそのまま映し、その上に編集用の層を重ねる。編集用の層は、選択・攻撃の発生元と範囲・ID・編集する線・配置の目印だけを描く。左の敵一覧は画像と名前を表示し、種類の絞り込みと検索を使う。右の調整パネルは敵の選択時に開き、姿・HP・撃破可否・基本値を優先して表示する。名前とHPの下に、その種類の「動き」（どう動いて攻撃するか）と「倒し方」を短く出す。文章は `speed/data/text/strings.csv` の `lab.enemy.<type ID>.move`・`.kill`。攻撃・行動の詳細、個体の条件、実効値と待機理由は折りたたみから開く。

実験条件・ランダム配置・保存は上部から専用パネルを開く。下部に再生操作と時間バーを置く。再生操作の「リセット」は配置・線・履歴を消して、実験条件の最初の状態に戻し、「最初の時刻へ戻す」は配置を残して時刻0に戻す。履歴から攻撃などの時間軸と分岐を開く。

左右の一覧は境界をドラッグして幅を変え、画面端の矢印で折りたたみ・再展開する。下部の境界でトラックの高さを変え、履歴を開き直すと調整した高さに戻す。下向き矢印で再生操作を含む下部バー全体を隠し、画面下端の上向き矢印で元の表示と高さに戻す。時間軸の目盛りは、切りのいい間隔（0.1・0.2・0.5・1・2・5・10秒…）で、ちょうどの時刻に打つ。時間軸はホイールと＋／−で拡大縮小し、中ドラッグ・Shift＋ホイール・横スクロールバーで表示範囲を動かす。全体表示ボタンで時間軸を全範囲に戻す。

再生・停止・取り消しなどは操作アイコンを使い、独自の道具は短い名前を添える。名前・IDの一括表示と攻撃範囲は表示メニューで切り替える。本番の HUD（HP・装備など）、ミニマップ、背景の星は初めは出さず、表示メニューで選んだときだけ出す。

数値変更は同じ種類の実験用定義に、レベルとエリートは選択個体に反映する。HP の基礎値を変えると残り HP の割合を保つ。

| 操作 | 内容 |
| --- | --- |
| 敵を配置 | 敵一覧の画像をフィールドへドラッグする。画像をクリックしてからフィールドをクリックすると連続配置できる。数は一覧下部、レベルは配置オプションで選ぶ |
| 選択・移動 | ドラッグで動かす。Shift で複数選択、Alt で重なった敵を選び直す。Q/E で回転、Ctrl+D で複製、Delete で削除する |
| 範囲・向き | 選択した敵からドラッグし、対応する攻撃の射程と方向を変える |
| 線を編集 | 「自由に描く」はクリックで描き始め、マウスの軌跡を線にし、もう一度クリックで確定する。ドラッグして離す操作でも描ける。新しい線で現在の線を置き換え、描画中の右クリック・Escで元に戻す。「点を編集」はクリックで点を追加し、点をドラッグする。右クリックで近くの点を削除する。Alt＋ドラッグで線全体を動かす。「線を消す」で線を消す（取り消しで戻せる） |
| ルートを試す | 描いた線を、今の場面のまま本番の描画と同じ処理（描画の時間・長さの上限・地形・角の補正・始点へのワープ）で描いて確定し、駆け抜けさせる。そのまま普通に再生し、カメラは機体を追う。ホイール・中ドラッグで視点を動かすと追うのをやめる。操作の履歴に記録するので、巻き戻しても同じに再生される |
| 取り消す・やり直す | 配置・数値は命令履歴から、線は編集履歴から戻す。Ctrl+Z / Ctrl+Shift+Z も使える |
| 再生・停止・1コマ | 固定更新で進める。時間軸は再生済みの任意 tick へ戻す。過去で編集すると元の履歴を分岐として残す |
| 中ボタン・ホイール | 試遊以外のとき、描画のカメラだけを動かすパン・ズーム。ゲームの表示範囲と狙いは変えない |
| 自機で試遊 | 試遊を選ぶと再生が始まり、ほかのモードへ切り替えると止まる。本番と同じ入力・カメラで操作する（カーソルで移動、クリック／Space で線を描く、Q で英雄の星座の力）。毎回の入力を操作の履歴に記録し、シードと固定の時間刻みで同じ展開を再生する。記録済みの時刻を再生している間は記録どおりに進み、クリックなどの押す操作をすると、そこから新しい分岐になる。HUD は表示だけで、ポーズ・3択の入力は受けない。ウィンドウのフォーカスを外すと停止する |

空の実験と、ステージの地形・装備を使った実験を切り替える。天体、隕石・がれき、フィールドの仕掛け、自動出現を個別に選べる。出現レーンは敵・数・開始・終了・間隔・確率・領域を持ち、手動配置と併用できる。部位は親の配置と動きに従う。手動配置は地形や外縁と重なる例外も許し、選択情報に表示する。

攻撃管理は狙い弾、誘導弾、突進、ビーム、遅延範囲、広がる輪、残留範囲を分類し、分類ごとの枠・重み・開始間隔と全体上限を使う。予告の前に必要な分類をまとめて取得する。画面内の敵と待った時間で優先順位を決める。撃破時の受動効果はその場で発生させ、残った弾と範囲が消えるまで危険として数える。攻撃の発生元、待機理由、時間軸を対応付けて表示し、管理の有効・無効を比較できる。

調整パネルの「描いた線を隔離して再生」は、編集元から隔離した本番ランで描画の時間、始点ワープ、長さ制限、なぞり、装備、地形、敵、攻撃の判定を実行する。元の敵・時刻・乱数は保つ。線を実行している途中は、開始前へ巻き戻して別の線を評価する。結果に撃破、被ダメージ、弾かれ・停止の印、終点、残り充填を示し、線を複製して比較する。

| 評価の表示 | 対象と条件 |
| --- | --- |
| 静止配置で成立 | 線分全体と機体の半径・余裕幅・入力点補正の余裕を掃引し、長さ、地形、確実に貫く弱い敵、装甲、現在の危険範囲を検査する |
| この再生条件で成立 | 指定 seed・開始 tick・描画時間・装備で、終点到達と無被弾を隔離した本番処理で確認する |
| 指定時間幅で成立 | 開始時間幅に描画・なぞり・ヒットストップの猶予を加えた保守的な包絡を検査する。停止した非攻撃の通常敵、直進する通常弾、位置と向きが固定されたビーム・円・輪・壁に対応する |
| 未対応 | 動く敵・地形、ストリーミングされる岩、追尾・入力への反応、付着して動く範囲、複合ボス技、受動効果や条件付き能力など、保守的な時間モデルを持たない対象を含む。隔離再生で個別に試す |
| 再確認が必要 | 配置、時刻、装備、線、基準データが変わった結果。新しい条件で検査する |
| 未発見 | 限定した探索範囲で成立候補が見つからない。条件や探索範囲を変えて試す |

配置からルートと敵の移動領域を取得し、領域の中心と半径、巻き込む群れ・避ける対象、種類と数の範囲、回転・長さ・余裕幅・時間幅を指定する。生成はルートを先に変形し、許可領域内で配置を変え、検査した候補だけを提示する。候補の小さな配置図とフィールドへの重ね表示で比較し、現在状態との一致を確認して追加する。認証した開始時間幅を保護する間は新しい能動攻撃と自動出現を見送る。成立区分は指定条件の範囲を示し、本番の見つけやすさと蹂躙の楽しさは単体・混成の試遊で判断する。

保存先は `user://enemy_lab/`。プリセットは初期条件・現在配置・定義差分・出現レーン・攻撃枠・ルート条件を、記録は seed・命令履歴・分岐・再生位置・結果・基準ハッシュを保存する。実験は専用設定を複製し、通常の部品・クリア・強化を保存する出口から独立して動く。

AI 用の書き出しは `user://enemy_lab/exports/<実験名>/` に `record.json`、`preset.json`、`changes.json`、`adoption.json`、`overview.png` をまとめる。書き出す対象ステージ・時間帯・敵 ID を明示する。AI は基準ハッシュと対象を照合し、指定した敵の `.tres` と `StageDef.encounter_profile` の採用設定へ反映し、反映後の依存データのハッシュを採用設定へ記録する。採用設定自身を含むステージのファイルは依存ハッシュから除く。採用設定は指定したステージ・時間帯で攻撃管理と候補生成を有効にする。通常5ステージの既定の採用設定は空で、実験から段階的に採用する。「本番データを再読込して新しい実験」で敵・ボス・時間帯・共通値を新しいリソースとして読み直し、プリセットと同じ線で確認する。

## 21. 性能

- 目標は60fps。最も敵が多い無双期（1300体前後）でも保つ。
- PC を最優先し、最終的にはスマホでも同じ目標を満たせるようにする。ブラウザは最低限動けばよい。
