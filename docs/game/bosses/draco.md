# ドラコ（りゅう座）仕様

ステージ5のラスボス、りゅう座の戦闘・行動判断の要件・素材と演出・最終決着を定義する。

**ピカロは、竜が集めた星から作る既存敵のコズミック版で、竜自身の全身複製も含む。** 既存敵のピカロは元の敵のギミックで攻撃する。見た目は元の敵・竜本体の絵を流用し、全種類に共通するshaderで統一する。

巨体の竜は自ら攻撃するとともに、ピカロへの攻撃担当の切替や共同攻撃、星の採集と再生成を使って戦う。ピカロの[候補と生成サイクル](#3-本体とピカロ)、[本体との攻撃の組合せ](#6-攻撃の重なりと共同攻撃)、[見た目と生成演出](#82-ピカロの表現と生成)は各章に定義する。

ステージでの位置づけは[ステージ5](../stages/stage-5.md#4-ラスボス戦)、採用・実装状況は[敵一覧](../catalog/enemies.md)、設定と核の元ネタは[世界観](../world.md#9-元凶ラスボス)、共通のAI基盤と編集方法は[設計書6.1](../../architecture.md#61-敵とボスの-ai)を参照する。

## 1. 狙う体験と攻撃の整理

巨体の竜の攻撃とピカロの脅威を読み、高速移動と突進で攻める経路を選ぶ。ピカロの処理と本体への攻撃を選び、同じ突進の軌道で両立させる。大技後やピカロの再生成中には、本体を攻める機会を作る。

距離や状況に応じた軽い通常攻撃と、4体のボスを想起させる4技・螺旋収縮・空間の亀裂・吸引吐き出しを持つ。大段階による技の広がりと、攻撃区間内の候補選択を分ける。

## 2. 戦闘の進行

### 2.1 HPによる大段階

HPゲージは1本を戦闘全体で使い、移行後も閾値の残HPから戦闘を続ける。残りHPに応じて次の3段階へ進む。配分は調整可能な初期設定として3:3:4とし、残りHP70％・40％を切替の目安にする。

| 大段階 | 全体HPの配分 | 戦い方 |
|---|---|---|
| 前半 | 最初の約3割（開始〜残りHP70％） | 本体だけで成立する技で戦う |
| 中盤 | 次の約3割（残りHP70％〜40％） | 複製攻撃とピカロ隊列を使う |
| 終盤 | 残り約4割（残りHP40％〜撃破） | 前半・中盤の技全体と吸い込み・吐き出しを組み合わせる |

HPは現在の段階の下限となる閾値で止める。閾値を越える一撃は、閾値に達する分までダメージを反映して超過分を切り捨て、段階移行の完了後にHPの減少を再開する。各段階を順に通る。

後半ほど使う攻撃の幅を増やし、撃破後はクライマックスへ進む。ピカロ主体の中盤への移行は、[初回生成](#33-初回生成と再生成)のカットシーンとして見せる。

本体技は、本書に定める技のうち竜本体だけで成立するものを使う。終盤のピカロ連携や吸収を利用した攻撃をさらに増やすか、その具体内容は未決。

### 2.2 段階移行と中断

この大きな戦闘展開と、順番に巡る攻撃区間内の技選択を分けて扱う。段階のHP閾値に達したら、攻撃中でも技をキャンセルして段階移行へ入る。HP段階移行時のキャンセルでは、残っている攻撃を次のように扱う。

| 対象 | HP段階移行時の扱い |
|---|---|
| 発射済みの弾 | そのまま飛び続ける。新規発射は止める |
| 照射中のビーム | 放射元を止め、高速に減衰して消える |
| ピカロ | 個体を残し、攻撃モーションをキャンセルする |
| 空間の亀裂 | 技終了時と同じように閉じて消える |
| ブレス用に配置した隕石 | ブレスの開始前・途中とも、その場で崩して消す |

段階移行の演出中はダメージを発生させず、咆哮・画面揺れ・ポストエフェクトで切替を伝える。[初回ピカロ生成](#33-初回生成と再生成)の移行だけはプレイヤーの操作と攻撃を止め、画面上下の黒帯とUI非表示でシネマスコープ風に見せる。それ以外の段階移行中は、自機を動かせる状態で進める。

段階移行後のピカロの行動は、移行先の[行動フロー](#71-攻撃区間と技の選択)と[攻撃担当の制御](#6-攻撃の重なりと共同攻撃)に従う。

### 2.3 HP0から最終決着

| 段階 | 内容 | 操作 | 未決 |
|---|---|---|---|
| 1. 通常の戦い | ラスボスと戦い、HPを0にする | 通常 | 戦闘の数値 |
| 2. 核の解放 | 核のこぐま座が解放され、吠える | なし（演出） | 解放と咆哮の具体的な見せ方 |
| 3. 伝説の機体の完成 | こぐま座の咆哮をきっかけに4つの伝説のモジュールが組み合わさり、プレイヤーの武器欄に並ぶ。機体の制限が外れ、トドメへつながる | なし（演出） | 演出の長さ |
| 4. 最終姿勢 | 竜が円内にうねって収まる姿勢を取る | なし（演出） | 具体的な姿勢・配置は指定図で定める |
| 5. 止まった世界で描く | 薄い任意のガイドを見せ、プレイヤーが自由になぞる。描ける長さは無限で、世界の速さは0になる | 自由描画。離すと次へ進む | ガイドの具体形、描画時間・ゲージの扱い |
| 6. 叩き込む | 入力を離した瞬間に、下記の固定フィニッシュとカメラ演出を始める | なし（自動の演出） | 連撃の回数・個々の進入位置・各動作とカメラの尺 |
| 7. 決着 | 下記の発光と視界の回復を経て、二つに切断された竜を見せ、次の瞬間にコズミックな破砕・爆発で散らしてクリアする | — | クリア後の見せ方 |

最終決着の5の段階では、[共通仕様6.2・6.3](../../spec.md#62-描き始め)の長さの上限と「長さを使い切ると確定」が働かず、描画中の世界の速さが `config.draw_time_scale` ではなく0になる。

ガイドは自由描画の参考として示し、描画した軌跡にかかわらず6の固定アニメーションへ進む。

固定フィニッシュでは、自機がさまざまな角度に瞬間移動するように姿を現し、そのたびに直進して竜を貫く。この出現と直線の貫通を繰り返し、連撃に合わせてカメラを徐々に寄せる。最後の一撃の直前にカメラを一気に引き、画面の下から上へ一直線に突き抜ける。

最後の貫通では、その直線が突出して強く発光し、相対的に周囲が暗く見える。目が明るさに慣れてくるように周囲の見え方を徐々に戻し、二つに切断された竜の姿を見せる。その姿が見えた次の瞬間に竜が爆発する。直線の発光・周囲との明るさの差・視界の回復・切断の露出・爆発を順に見せる。

## 3. 本体とピカロ

### 3.1 本体と命中対象

ラスボスは巨体のりゅう座で、核はこぐま座の北極星。

本体は手前の戦闘空間にいる間、ピカロの残数にかかわらず基本的に全身へ攻撃が通る。背景奥へ退いている間は攻撃対象外とする。本体を攻撃できる間は、ピカロを減らすか、避けながら本体を狙うかを選び、本体へ突進する軌道にピカロも巻き込める。竜の大技の後は本体を狙う好機とする。

体長・胴幅・頭の倍率・胴の分割数は`data/bosses/draco.tres`の共通寸法で管理する。渦巻きの画面を囲む有効長は`data/bosses/draco_moves/spiral.tres`で管理する。頭の通過経路を後続の胴体が一定間隔でたどり、技の固有姿勢も背骨の点列で変える。描画と全身の命中形状は同じ点列と幅を使う。背景奥への遠近縮小は判定も同じ倍率に揃え、攻撃対象外の保護とともに扱う。

蛇体に沿って判定形状を複数置く場合も、命中対象とダメージ受付は「りゅう本体」一体にまとめ、共通の敵命中処理へ渡す。往復して当て直す攻撃は、他の敵と同じ[なぞり](../../spec.md#65-なぞり)・[接触](../../spec.md#72-接触)の共通ルールで再命中する。

### 3.2 ピカロの候補

戦闘の途中にピカロを使う行動を挟む。候補は敵の全種類とし、制作・試遊で不要な種類を除外できる。各回に出す種類の選出規則と体数は制作・試遊で決める。見た目は[ピカロの表現方針](#82-ピカロの表現と生成)に従う。

### 3.3 初回生成と再生成

初めてピカロ主体の段階へ入るときは、咆哮から奥への飛行・星の採集・前景への帰還・ピカロの連続生成までをカメラで追う。操作・画面表示・ダメージ保護は[段階移行の規則](#22-段階移行と中断)に従う。

ピカロへ攻撃を任せる区間では、戦闘が始まると竜は再び奥へ飛び、長めに飛行して星を採集する。一定時間で帰還し、ピカロを全て倒すと早期に帰還する。2回目以降の帰還では、短い待機の後、口を長めに開け、溜めた星からピカロを順々に生成する。この間は通常戦闘の操作・被弾ルールで進め、手前にいる本体へ攻撃できる。一定数を生成すると、再び奥へ飛ぶ。隊列越しの遠距離攻撃・複製攻撃の共同攻撃は、それぞれの技の規則に従う。

生成の見た目は[ピカロの表現方針](#82-ピカロの表現と生成)に従う。復帰をリセットの区切りとし、対象となる具体的な資源・残留物、採集と生成の時間・生成数は未決。

## 4. 通常攻撃

通常攻撃は、距離や状況ごとの役割に応じて軽い技を組み合わせる。正面・側面・後方、近距離・中距離・遠距離など、異なる範囲を受け持つ技を揃え、自機の位置に応じて使い分ける。種類数は必要な役割に合わせて増やせる構成とする。

| 技 | 動作と役割 | 未決 |
|---|---|---|
| 尾の薙ぎ払い | 体をひねって尾を振り、側面から後方を広く掃く。尾を振る側を構えで知らせる。尾の根元から先まで当たり、先ほど大きく振れるので、当たる範囲は根元が細く先が広い1つの扇になる。予兆はその扇全体を薄く塗り、本体から外へ濃い塗りを広げて、端へ届くと尾を振る | 攻撃範囲の広さ・追尾と方向固定・判定・各動作の時間・数値 |
| 星弾 | 頭の周りの前方へ開く扇に複数の星弾を等間隔で並べ、一斉に発射する。扇の広がりは左右それぞれ約60〜70度を設計上の目安とする。撃ち終わりに攻める隙を作る | 照準・方向固定・弾数・速度・配置半径・予兆と隙の時間 |
| 噛みつき | 口を開いて首を引く予兆の後、近距離の自機へ首を伸ばして一度噛む。頭を戻す間に隙を作る。自機は横へかわし、噛み終えた頭を攻める | 攻撃範囲・追尾と方向固定・判定・各動作の時間・数値 |
| 隕石投射 | 盤面に障害物を残し、[薙ぎ払いブレスの予兆と遮蔽物](#41-隕石投射と薙ぎ払いブレス)を作る | 飛行軌道・飛行中の接触・配置・数・大きさ・数値 |
| 薙ぎ払いブレス | 幅のある炎を吐きながら首を横に振り、前方から側面の中距離を掃く。[隕石の裏に隠れて避ける](#41-隕石投射と薙ぎ払いブレス) | 炎の具体的な見た目・射程と幅・予兆・追尾と方向固定・各動作の時間・数値 |
| 尾の叩きつけ | 尾を持ち上げ、自機付近の予告した場所へ叩きつける。叩いた場所の周囲へ小さな衝撃波を出す | 直撃と衝撃波の範囲・狙いを固定する時点・予兆・判定・各動作の時間・数値 |

### 4.1 隕石投射と薙ぎ払いブレス

口から隕石を吐き出して盤面に遮蔽物を作ってから、薙ぎ払いブレスへ進む。隕石を吐く動きそのものをブレスの予兆として見せ、自機は隕石の裏へ移動して炎を避ける。この順序は[共通の行動ノード](#71-攻撃区間と技の選択)で組み立てる。

投射した隕石は、通常の隕石と同じようにプレイヤーの攻撃で破壊でき、壊れにくさを通常の隕石より高めに調整する。ブレスに対しては攻撃を最後まで防ぎきり、ブレスの攻撃判定が終わってから、その攻撃で破壊された様子で崩れる。ブレスによる崩壊まで持ちこたえる姿で、遮蔽物が攻撃を受け止めたことを伝える。

炎は隕石に遮られた方向だけ途中で切れ、隕石の裏には安全な影ができる。炎の表示とダメージ判定に同じ遮蔽結果を使い、見えている炎と被弾する範囲を揃える。首の動きによる炎の向きと、隕石の位置・残存状態を遮蔽へ反映する。

ブレスの威力は通常のダメージ値として調整する。

HP段階移行時の配置済み隕石は[段階移行時の扱い](#22-段階移行と中断)に従う。隕石の飛行軌道・配置・投射からブレスまでの間隔、ブレス以外の敵攻撃の影響、炎が当たらなかった隕石の残存と回収、ドロップ、HP段階移行時の飛行中の隕石と、撃破時の隕石の扱いは未決。

## 5. 主な技

過去の4体のボスを想起させる技を使い、星の組み替えや竜本体の動きで表す。

### 5.1 突進（いっかくじゅう座）

頭の星が角の形に集まり、予告した直線へ突進する。

### 5.2 隊列越しの遠距離攻撃（ケンタウルス座）

接近を阻むピカロの隊列の奥で、口から光の矢を上向きに何発か続けて発射する。矢はいったん画面外へ消え、その後、自機の居場所を狙って着弾する。着弾地点は攻撃予告を出した瞬間の自機の位置に固定し、予告がだんだん小さくなってから矢が着弾する。着弾時には小さな光の爆発が周囲に広がり、その範囲にダメージを与える。自機は予告地点から離れて避ける。矢はコズミック版の配色とし、形や発射時の見た目を[ケンタウルス座](centaurus.md)の光の矢と揃える。

ケンタウルス座由来の隊列は、接近を阻むピカロを並べて作る。この技で使う種類は、一般の全種類候補とは別に、接近阻止に向く敵から調整できるようにする。候補の例は、ぼうえんきょう座のビームや、やまねこ座の3本の爪痕の斬撃とする。各敵の攻撃は[敵一覧](../catalog/enemies.md)に従う。

自機は隊列のピカロを突進で貫き、竜本体まで攻め込める。隊列の配置・体数、矢の発射数・間隔・着弾の順序、光の爆発の具体的な範囲と威力、上下の飛行軌道・予告の形と時間、共通の見た目の細部は未決。

### 5.3 飛びかかり（おおいぬ座）

竜本体が踏み込んでから自機へ飛びかかり、噛みついて攻撃する。

### 5.4 全身複製（うみへび座）

竜の全身をピカロとして複製し、本体と全身複製が共同で攻撃する。編成の基準は本体1体と複製2体の合計3体とする。この技の間、各個体が使う攻撃はヒュドラの専用技に限る。共同攻撃の参加者の扱いは[攻撃の重なりと共同攻撃](#6-攻撃の重なりと共同攻撃)に従う。

流用する動きと仕組みは、次の2つとする。

- [多方向からの連続飛びかかり](hydra.md#55-分離多方向からの連続飛びかかり)：本体と複製がさまざまな方向から順番に飛びかかる。
- [首ごとの攻撃分担](hydra.md#4-通常攻撃)：本体・複製をそれぞれの首に相当する攻撃者として扱う。噛みつき・渦・瓦礫・ビーム・雷の5系統から担当を選び、異なる攻撃を各個体から出す。1回に出す体数と、候補となる5系統の数は分けて設定する。

竜の全身複製の見た目は[ピカロの表現方針](#82-ピカロの表現と生成)に従う。複製は本体よりずっと少ない独立したHPを持ち、攻撃して倒せる。複製を倒すと攻撃する数が減って戦いやすくなる。複製へのダメージはその複製のHPへ反映し、ボスの撃破を進めるには本体を攻撃する。

技の通常終了時に残った複製は、回収専用の「吸い込むだけ」のモーションで全て吸い込まれて消える。この回収は[吸引大技](#57-吸引大技)の吐き出し攻撃と別に扱う。HP段階移行でキャンセルする場合は[段階移行時の扱い](#22-段階移行と中断)に従う。吸収量を体数へ反映するか、各個体が使う攻撃の具体的な選定と割当・連続飛びかかりの細かな動作・予算配分・HPの具体値は未決。

### 5.5 渦を巻く接近と収縮

発動すると頭から退場し、カメラの範囲から胴体の最後尾まで消えてから画面外で渦の進入姿勢へ移る。頭から再入場する間は螺旋の中心が自機の移動を速度制限付きで追い、巻き終わりの予告開始時にワールド座標で固定する。カメラを滑らかに少し引き、外周は画面の短辺から少しはみ出しても、縦横の半径比を抑えて円に近い形で自機を囲む。半径は外周半径から内周半径まで、2周かけて少しずつ縮める。隣の周回との間には胴幅を考慮した逃げ道を取る。巻きの外径と周回・離脱の時間は技リソースで調整し、胴の太さと頭の大きさは通常時と同じ共通寸法を使う。頭が反時計回りに進み、胴体は頭が通った経路を一定間隔でたどる。1周目は高速、2周目は少し低速で巻く。

渦を巻く短い構築中だけ機体の操作と位置を固定し、他の敵からの被害も防ぐ。約2周した巻き終わりには、終端の胴体を左へ曲げ、頭を構築開始時の自機がいた渦の中心へ向ける。頭の中心は自機の少し上で接触半径と余白を残す。この時点で操作を戻し、直進する道と中心へ収束する光・音を見せる溜めを挟み、逃げ出す時間を確保する。操作復帰直後には短い接触猶予を与える。中断時も操作と被害保護を元へ戻す。外周半径・内周半径・縦横比・2周の所要時間・頭の終点・溜め・退場時間・渦を巻く間の体長は[ボスAI](../../dev/tools/boss-ai.md#技の発動条件と共通の欄)から調整する。

直進の前に攻撃予兆を出し、その時点でワールド座標の照準を固定する。頭は自機の真上で巻き終わり、真下へ一気に直進し、胴体は頭側から紐をほどくように順番に動き、先行する部位の軌跡をたどって渦から抜ける。発進後の軌道は自機を追尾せず、離脱後にカメラは通常の追従へ滑らかに戻る。

螺旋中は胴体に青〜紫系の光のオーラを纏わせ、触れるとダメージを受ける危険な範囲として見せる。オーラは機体と味方・敵の弾を遮る壁として扱い、機体が触れるとダメージを与える。巻いている途中の胴に触れて被弾したら、離れて抜け出せるよう `touch_invuln` 秒の無敵にする。

自機は体の間をくるっと回り込むようになぞって抜け出す。脱出が間に合わず、直進する頭や追従する胴体に触れた場合は1回のダメージを受け、一定時間無敵になる。無敵中は機体の透明度を素早く切り替えて点滅させ、被弾と保護中の状態を伝える。その間に竜が画面下へまっすぐ飛び去り、自機を囲んでいた胴体が順に離れる。被弾・点滅・竜の離脱を一連の動きとして見せる。

オーラの具体的な光の形・青〜紫系の配色・強度・判定幅、ダメージ値、具体的な軌道計算、速度、待機・予兆・点滅と無敵・離脱の時間は調整対象とする。

### 5.6 三本爪による空間の亀裂

竜が左右を片側ずつ素早く続けて三本爪で引っ掻き、空間に長い亀裂を刻む。爪は口の前から自機の少し先まで伸び、外側へ少し開く。片側の爪の数・間隔・中心からの横のずれ・開く角度・自機の先まで伸ばす長さ・長さの上限は、技の値として調整する。左右2回の引っかきを合わせて約0.7〜0.9秒に収めるテンポを設計上の目安とする。

ダメージは引っかきの動作に限り、攻撃判定を引っかきのアニメーションへ同期する。残る亀裂は機体・味方と敵の弾を止める障害物として扱い、接触は押し戻しで処理する。亀裂の生成位置に重なった自機は通行可能な側へ押し出す。

引っかいた後は亀裂を一定時間残し、本体が隙を見せる区間を設ける。自機は空間が裂けていない隙間を縫い、本体へ攻め込む。亀裂は攻撃を受けても保たれ、この区間が終わると修復して消える。HP段階移行による中断は[段階移行時の扱い](#22-段階移行と中断)に従う。

空間が紙のように破れていく様子を引っかきとともに描き、裂け目の奥をブラックホールのような暗い空洞として見せる。修復時は裂けた空間が滑らかにくっついて元に戻り、亀裂が閉じて消える。修復の見た目と機体・弾を遮る範囲を揃え、次の技は亀裂が消えた状態で始める。

亀裂の配置と幅、引っかきの予兆・攻撃判定の範囲と威力、攻め込める隙の長さ、修復の細かな時間、ビームや範囲攻撃の扱いは未決。

### 5.7 吸引大技

非常に広い範囲から自機を口へ強く引き寄せる。高速移動を繰り返して、かろうじて同じ位置を維持できる程度の感触を目指す。演出は既存のピクセル調を保ち、口へ重力が集まる様子をリッチに描く。

画面の横から入ったあと、予告の後半で自機の方を向き、体を頭の後ろへまっすぐ伸ばしてうねらせる。吸い込みの間は口を大きく開けたまま、自機の方へゆっくり向き直る。

残っているピカロも吸い込む。吸引後は太いビームを吐き、吸収したピカロがゼロならビームだけを放つ。吐く前に口元へ光の粒と縮む輪が集まり、撃ち始めは光線の先が口から射程の端まで `beam_extend` 秒で伸びる。光線は口元で細く先へ向かって太くなるピクセル調の光で、白い芯・薄紫の内側・紫の縁と、口から先へ流れる光の筋で描く。判定も伸びた長さに合わせる。吸収した場合は、そのピカロを構成する星の合計数に応じて、ビームの左右へ隕石・彗星のような点状弾を追加する。ビームを避けることを軸に、左右の追加弾が逃げ道を狭める。この吸収効果は直後の吐き出し1回で使い切る。

左右の点状弾は複数の弧に並べ、弧ごとに半径を前後させ、角度も少しずつずらした配置とする。弧の数・各弧の半径と角度・弾の配置をエディターで編集できるようにする。制作者が出方・並び方を後から調整して保存し、再読込と試遊へ反映できる構成とする。配置は、なぞる移動でかわす楽しさを試遊しながら調整する。

自機が口に到達すると、ビームとは別の噛みつき系の専用攻撃でダメージを受け、即座に口の外へ弾き出される。ボスから離れる方向へ慣性を付けて吹き飛ばし、短時間の操作不能を経て操作へ復帰する。噛みつきのダメージ、吹き飛ばしの距離・速度、操作不能時間は調整値とする。

この操作不能期間は、竜を含む敵の攻撃による追加ダメージから自機を保護する。竜は操作復帰まで待機し、次の攻撃モーションの開始も待たせる。

星数から追加弾数への換算方法・上限、編集UIの具体的な操作方法・吸収星数に応じた配置の変化方法、弾の速度、射角、攻撃時間、予兆、吸引時間は未決。弧の具体的な配置はエディターで調整する。

## 6. 攻撃の重なりと共同攻撃

本体の技は1つずつ使う。通常の敵のピカロ同士の攻撃は重なってよく、ケンタウルス座由来の隊列越しの遠距離攻撃を除いて、新しい攻撃を出す担当を本体と通常の敵のピカロで切り替える。同時攻撃の制御は予算システムで管理する。

ケンタウルス座由来の技では、竜の遠距離攻撃も隊列ピカロと共通の攻撃予算で管理し、予算内で隊列ピカロの迎撃と同時に使用できる。

複製攻撃は、本体と竜の全身複製を等価な攻撃者として扱い、一緒に攻撃する共同行動とする。

## 7. 攻めどきと行動判断の要件

### 7.1 攻撃区間と技の選択

順番に巡る攻撃区間ごとに、使用可能な技のリストを持たせる。各区間のリストは共通の技定義を参照し、その区間の候補から発動条件と攻撃予算に応じて技を選ぶ構成を実装要件とする。

各技の攻撃が届く範囲に合わせて、既存の条件ノードへ距離・方向の発動条件を設定する。条件の編集と候補選択は[共通のボス行動編集](../../dev/stage-production.md#56-ボス行動を調整する)に従う。

「ボス行動」画面の対象にりゅう座を加え、使う技・区間の順序と選択条件・既存技の組み合わせ・技の数値を編集できるようにする。技固有の動作と演出はスクリプトと表示シーンで作り、戦闘の組み立ては[共通のノード編集](../../dev/stage-production.md#56-ボス行動を調整する)を使う。編集した組み合わせにも、[HPによる段階と中断](#2-戦闘の進行)・[攻撃の重なり](#6-攻撃の重なりと共同攻撃)の規則を適用する。

区間と候補は `data/bosses/ai/draco_flow.tres`、距離・方向・HP段階の条件は `draco_action_rules.tres` で編集する。仮フローは本体攻撃区間を巡り、中盤から複製と隊列、終盤から吸引を候補へ加える。区間の最終的な構成・順序・配分は試遊で調整する。

### 7.2 攻撃方向と画面基準

| 攻撃 | 使用する方向 |
|---|---|
| 突進・複製攻撃・ピカロの隊列越しの遠距離攻撃 | さまざまな方向から使う |
| 飛びかかり・空間引き裂き・吸い込み | 画面の左右から使う |

飛びかかり・突進・渦巻き・空間引き裂きは、一度画面外へ退場してから、スクリーンの位置を基準に再配置する。攻撃は基本的に画面内にいる状態から予兆を出して始め、突進は画面外から来る攻撃とする。

画面基準の攻撃は、構えで現在の自機位置や短い予測位置へ狙いを合わせ、予告を確定した後は自機やカメラの移動を追って軌道を変えない。狙い・予告・攻撃判定の点列はワールド座標で共用し、描画時に一度だけ変換する。画面基準で退場・再登場する技は、元の本体が自機から遠ざかっていても候補に残す。近距離の噛みつきや尾の技は、それぞれの距離条件を保つ。螺旋は[渦を巻く接近と収縮](#55-渦を巻く接近と収縮)で定める中心の固定と巻き・収縮の動作を保つ。

### 7.3 通常の攻撃担当の切替

通常の敵のピカロへ攻撃を任せる間、竜は次のピカロを作る星を採集するため、背景奥へ飛ぶ。背景奥では小さく薄い姿で見せる。通常の攻撃担当の切替では、ピカロの新規攻撃を止め、照射中のビームなど継続中の攻撃動作が終わるのを待つ。発射済みの弾は残し、全て消えるまでの待機は挟まず、竜が手前へ復帰して予兆を出し、本体攻撃へ進む。接近に伴い竜を大きく明瞭に見せ、攻撃対象への復帰を伝える。復帰の間も、残った弾を避ける時間とする。

## 8. 素材と演出

### 8.1 竜本体と核

巨体の竜本体と、こぐま座の北極星の核を見せる。頭は胴幅との釣り合いを保つ細長い輪郭とし、口先・角の位置と命中形状を合わせる。必要な絵・サイズ・分割・納品条件は[共有アート素材リスト](../catalog/art-assets.md#りゅう座)で管理する。

飛びかかりのアニメーションは、[技の動作](#53-飛びかかりおおいぬ座)に合わせて構成する。

段階移行の演出と操作・ダメージの扱いは[段階移行](#22-段階移行と中断)、核の解放から決着までは[最終決着](#23-hp0から最終決着)に従う。

### 8.2 ピカロの表現と生成

外観のshaderでは全身フィルターやオーラを重ねる。shaderの表現と調整は[グラフィックス側の課題](../graphics-improvements.md#ピカロの見た目)で管理する。具体的な配色・オーラ・フィルターの見え方や調整値は未決。

ピカロの生成時は、星が集まって塊になり、柔らかな半透明の球状の膜がスライム状にうねる。膜の表面に渦模様と明るい縁を見せ、細いリボン状の帯を周囲に旋回させる。塊が変形した後、膜が帯状に裂け、素早くらせん状にほどけて開き、中から敵が現れる。膜・星・粒の余韻を残して消し、生成を終える。形状のうねり・裂開・ほどけ・敵の露出を、連続したアニメーションとして見せる。

星集合から敵の出現・余韻まで、輪郭・色の階調・帯・粒を含むアニメーション全体をピクセル調にする。配色も共通の表現方針に合わせる。各段階の尺・変形量・帯の動き・余韻の長さは調整可能とする。

### 8.3 ラスボス戦の登場

ゲーム冒頭の登場は[導入演出](../art-style.md#38-導入)に従う。ラスボス戦への導入は、旅で救った星々の美しさと失われた北極星への気づきを通して、主人公と竜の対面を見せる。台詞の量と本文は[演出用の台詞](../text.md#演出用の台詞)に従う。

| 場面 | 見せ方 |
|---|---|
| 静かな星空 | 主人公が竜のいる星系へたどり着くが、対面の場には竜の姿が見えない。背景では救ってきた星々が生き生きと煌めき、主人公はその美しさに感慨を抱く。上下の黒帯を入れたシネマスコープで見せる |
| 違和感と裂け目 | 星空に何かが足りないと感じた瞬間、空間が急に破れるように引き裂ける。裂け目の奥には深淵が広がり、二つの赤い目が煌めく |
| 北極星への気づき | 竜の出現とともに、主人公はこの星空に北極星とこぐま座が欠けていることをはっきりと思い出す。無数の星々の中でも、航海の目印の不在を認識する |
| 対面 | 竜が裂け目から姿を現す。体内に取り込んだ北極星が強い光を放ち、胸元が強く発光している。手前に小さな自機を背後から映し、その奥に胸元が輝く巨竜を置く。機体と竜の大きさの差を強く見せ、登場演出の見せ場として特に重視する |
| 戦闘開始 | 対面の構図を見せてからシネマスコープの黒帯を外し、戦闘を開始する |

対面時の竜のポーズは未決。カメラの細かな位置と動き、各場面の尺、音と台詞の提示方法、気づきの映像表現は未決。静かな星空から裂け目・赤眼・発光する胸元・戦闘開始までの仮演出を実装する。正式ポーズと構図は差し替える。

## 9. 実装・調整・接続

### 9.1 一戦を試遊できる完成ライン

本体・行動AI・通常攻撃・主な7技・ピカロ・段階移行と、登場から最終決着までの演出をつなぎ、ステージ5で一戦を試遊できる状態にする。絵素材は仮素材を使い、技の動き・予兆・エフェクト・カメラ演出まで確認できるようにする。正式アートと戦闘バランスの最終調整は、試遊できる状態から仕上げる。

| 確認する範囲 | 到達条件 |
|---|---|
| 本番への接続 | ステージの出現設定から登場し、[戦闘の進行](#2-戦闘の進行)を経て最終決着・結果へ進める |
| 技とAI | [通常攻撃](#4-通常攻撃)・[主な技](#5-主な技)をそれぞれ単独で確認でき、一戦ではHP段階・区間・発動条件に従って選択し、予告から終了・次の行動まで進む |
| 命中とピカロ | [本体とピカロ](#3-本体とピカロ)の命中対象、初回生成と再生成、帰還条件を確認できる。本体との共同攻撃と担当切替は[攻撃の重なり](#6-攻撃の重なりと共同攻撃)・[通常の切替](#73-通常の攻撃担当の切替)に従う |
| 中断 | 大きな一撃も[各HP閾値](#21-hpによる大段階)で止め、[段階移行時の残留物・操作とダメージ保護](#22-段階移行と中断)を適用して順に次段階へ進む |
| 見た目 | [素材と演出](#8-素材と演出)を実際の予告・判定・生成・消滅に同期させ、一戦を通して画面で確認できる |
| 最終決着 | [HP0からの各段階](#23-hp0から最終決着)を、操作・世界時間・カメラ・UIの切替とともにつなぎ、自由描画の入力を離すとフィニッシュからクリアへ進む |
| 編集と再試遊 | [行動編集](#71-攻撃区間と技の選択)の内容を保存・再読込し、正規生成後の単独試遊と本番の一戦に反映できる |

通常攻撃を含む未決の動作・演出は、具体案を相談してから定める。試遊の完成ラインは本書の対象全体に適用し、未決項目は各節で保持する。

HP0を[最終決着](#23-hp0から最終決着)への接続点とする。決着後のCLEAR! 表示・結果画面への遷移・部品と記録の保存は[共通の演出処理](../../spec.md#16-演出)へ接続する。

ボスの登録・編集・単独試遊への接続は[AI向けの追加手順](../../dev/stage-production-ai.md#新しい技調整項目ボスを追加する手順)、実行用データの生成と資源の寿命は[設計書15.1](../../architecture.md#151-ビルドと実行時の境界)に従う。自動テストは依頼時に実行し、生成・読み込み・短い画面確認と区別する。

ブレスの遮蔽は、ぼうえんきょう座の`speed/scripts/enemies/sniper.gd`にある、障害物で方向ごとの光線の長さを切り、表示と視線判定で共有する処理を応用する。共通の `scripts/common/beam_occlusion.gd` へ方向ごとの遮蔽距離を渡し、炎の表示とダメージ判定で同じ光線を共有する。

螺旋収縮の被弾は`speed/scripts/runtime/systems/ship_system.gd`の共通ダメージ処理と無敵状態へ接続し、点滅は`speed/scripts/render/ship_visual.gd`の透明度による表示を利用する。1回の収縮によるダメージを一度にまとめ、点滅・無敵と竜の離脱の時間を合わせる。

## 10. 調整・素材の未完項目

戦闘の数値と各技の細かな動作は未決。個別の未決事項は、段階移行・初回生成と再生成・通常攻撃・各技・素材と演出の節に記載する。

戦闘開始時の登場演出は[ラスボス戦の登場](#83-ラスボス戦の登場)に従い、構図と演出の細部を相談して定める。

最終決着の竜の姿勢・配置は指定図で定める。通常攻撃の細かな動作、区間の構成・順序・各区間の候補、リセット対象は、それぞれの節で未決として扱う。
