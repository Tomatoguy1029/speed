# いっかくじゅう座の仕様

ステージ1のボス、いっかくじゅう座の戦闘・行動判断・素材と演出を定義する。正面の角と直線突進をかわし、横や背後から本体を貫く戦闘とする。

ステージでの位置づけは [ステージ1](../stages/stage-1.md#4-ボス戦)、実装状況は [敵一覧](../catalog/enemies.md)、設定の元ネタは [世界観](../world.md#いっかくじゅう座--とも座)、共通のAI基盤は [設計書 6.1](../../architecture.md#61-敵とボスの-ai) を参照する。

## 1. 狙う体験と攻撃の整理

正面の角と直線突進をかわし、横や背後から本体を貫く戦闘とする。

通常技の終了後に、静止して息を整える隙を作る。惑星への角刺さりは、既存の惑星を利用できたときに追加の攻撃機会を与える。

## 2. 戦闘の進行

| 形態 | 内容 |
|---|---|
| 第1形態 | 通常突進、往復突進、角の薙ぎ払い、後ろ蹴りを使う |
| 第2形態 | 第1形態の技に、光の槍への踏み込み突きを加える。形態変化の見た目は[素材と演出](#8-素材と演出)に従う |

本体の残HPが `params.phase_threshold` 以下になると、第2形態への移行を予約する。現在の攻撃、往復や連携、その後の隙、角刺さりから角抜きまでを完了してから移行する。移行中も本体への攻撃を受ける。外観は角を中心に変化させ、船尾の装甲を保つ。

撃破は共通のHP表示・ボス撃破演出と、とも座の伝説モジュール獲得へ渡す。ボス戦中の通常敵と道中の進行はステージ側が管理する。

## 3. 本体と命中対象

四足の馬の体、角、たてがみ、とも座の船尾の部品を持つ。本体を一体の攻撃対象とし、全方向から共通のダメージを受ける。横や背後への貫通経路は、正面の角を避ける攻め方として有効にする。

## 4. 通常攻撃

| 技 | 動作と対処 |
|---|---|
| 通常突進 | 脚を開いて踏ん張り、角と直線の進路を光らせる。自機の現在位置と速度から接触位置を見積もって向き直り、発進直前に方向を固定して直進する。通過後は静止して隙を作る |
| 往復突進 | 複数回の突進を繰り返す。各突進の間で脚を踏み替え、再び予告・向き直り・方向固定を挟む。最後に長い隙を作る |
| 角の薙ぎ払い | 首を横へ引いて前方の扇を予告し、角でその扇を薙ぐ。角の線分を掃引して判定する。振り切った後に隙を作る |
| 後ろ蹴り | 背後の近距離にいる自機に対し、後脚を畳んで背後の自機へ線を予告し、その方向へ蹄を伸ばす。序盤から使い、独立した長めの再使用待ち時間で背後からの攻めを保つ |

## 5. 大技と連携

| 技 | 動作と対処 |
|---|---|
| 光の槍 | 第2形態で角を長大な光の槍にし、遠めから予告・方向固定の後に踏み込んで突く。終了時に槍の光が消え、長い隙を作る |

連携は、AIが距離・方向・状態に応じて既存技を選んだ結果として生じる攻撃のつながりとして扱う。各技の予告と、攻撃後に反撃できる隙を保つ。

## 6. 惑星を使う攻めどき

発進直前に、本体の幅を含めて目の前から狙いまでの地形を確認する。惑星や月が塞ぐ場合は発進を見送り、横へ位置を変える。狙いを越えた突進の残りの経路には、かわされた先の惑星に当たる余地を残す。

通常突進・往復突進で角先が惑星に当たると連撃を中断し、その場所でしばらくもがく。自力で角を引き抜き、後退してから復帰する。惑星の配置・大きさを保ったまま判定し、角刺さり中も本体への攻撃を受ける。月や側面の地形接触は突進を終了して通常の隙へ進む。光の槍の地形接触は通常の隙へ進む。

## 7. 攻めどきと行動判断の要件

### 7.1 移動と攻撃開始

画面外へ出た場合はプレイヤーの現在位置へ向き直り、`params.approach_speed` で近くへ戻り、攻撃可能な範囲に入ったら攻撃を開始する。旋回中の移動量は進行方向と自機方向の一致度に合わせる。通常突進・往復突進の開始距離は、ボス行動の距離条件で接近先の `params.approach_range` に合わせる。各技は編集した距離・角度条件と、実際の角・蹄と移動量の到達範囲を両方満たす自機を候補にする。予告中も一定速で進む相手には、予告後の接触位置まで届く技を選び、届く距離まで接近を続ける。距離条件はエディターから変更できる。

### 7.2 狙いの捕捉と固定

通常突進・往復突進・光の槍は、各回の予告中に自機の現在位置と速度、技の移動速度と角の長さから接触位置を見積もる。`params.lock_lead` だけ発進より前にその狙いを一度固定し、表示と発進方向を一致させる。往復の切り返し中にも向き直り、各回の予告へつなぐ。発進後は固定した向きへ直進する。薙ぎ・蹴りも予告中に狙いを捕捉し、固定後は予告した形状で攻撃する。固定した狙いが到達範囲を越えた場合は、攻撃後と同じ隙へ進む。

### 7.3 行動選択と形態

近距離の正面には薙ぎ、背後には蹴りを優先し、それぞれの再使用待ち中は他の届く技を候補にする。予告中に向き直れる角度へ入ってから攻撃を選ぶ。技の選択は共通フローで行い、`ai/monoceros_flow.tres`が区間の割合・消費上限・共有スタミナ・休息を持つ。`ai/monoceros_action_rules.tres`が距離・方向・必要形態を持ち、個別の再使用待ちを満たす候補から選ぶ。形態の予約と確定は役者が管理する。

## 8. 素材と演出

登場時は画面外から船尾ブースターを噴射して飛び込み、停止して角を構え、戦闘へ入る。進入方向・停止位置・カメラと各動作の尺は調整する。

仮アートは既存の落ち着いた船体色とシアンの光を用い、輪郭と座標をピクセル単位にそろえる。四肢の根元・膝・蹄を個別に動かし、旋回時の踏み替え、構えの踏ん張り、突進の足運び、薙ぎの首振り、後ろ蹴り、刺さった角のもがきと後退を見せる。攻撃の太い光は実際の角・蹄の判定線から描く。突進・光の槍の前の薄い直線は移動後の角先まで、薙ぎ前の弧は角が通る範囲を示す。

突進時は、取り込んだとも座の船尾ブースターから噴射を出し、その勢いで加速して突っ込む様子を見せる。通常突進・往復突進・連携内の突進に共通する演出として、既存の発進・移動に合わせて再生する。攻撃判定は既存の突進と角の判定を使う。

外観は、尻尾位置の船尾部品をブースター状にし、そこから出る青白い炎が尻尾の形を作る。普段は短く揺らめき、突進時に後方へ大きく噴き出す。絵素材の依頼・分割・納品条件は[共有アート素材リスト](../catalog/art-assets.md#いっかくじゅう座)で管理し、噴射の動きと発進への同期は演出側で扱う。炎の形状の細部・噴射の強さや時間は調整する。

第2形態への移行では、足を止めて踏ん張り、角と目へ光を集めて強く輝かせる。角は通常の角の形から、光り輝く剣のような形へ変わる。

光の槍は、角を芯に長大な槍状の光を伸ばして突く。突き終わると槍の光の形を一瞬固定し、全体がぱっと飛び散るように消える。わずかに残る粒子をフェードアウトさせ、技の余韻を見せる。静止・飛散・粒子の消失の尺は調整する。

`scenes/bosses/monoceros_presentation.tscn` を差し替えて、役者の `presentation_scene` に指定する。シーンは `bind_monoceros(actor)` で以下を接続する。

- `presentation_event`：予告、方向固定、発進、隙、角刺さり、角抜き、形態変化、被弾、撃破、制限時間演出。`cue`・`technique`・`phase`・`mode`・`position`・`angle`・`world_time` を渡す。
- `presentation_advanced`：世界時間の進行。停止中はアニメーションも止まる。
- `horn_points()`：ワールド座標の判定線。薙ぎ払いでは引数で扇内の位置を取得できる。

実際にHPが減った被弾では本体を薄く白く光らせ、短い減衰する揺れを描画へ加える。連続命中では演出時間と揺れ幅を上限内へ戻す。本体座標・照準・予告線・攻撃判定は戦闘状態をそのまま使う。

仮表示の `body_texture`・`head_texture`・`hoof_texture` には正式アートを指定できる。姿勢の構成を変える場合は表示シーンを差し替える。

## 9. 実装・調整・接続

### 9.1 一戦を試遊できる完成ライン

本体・行動AI・全技・形態移行と、登場から撃破までの演出をつなぎ、ステージ1で一戦を試遊できる状態にする。絵素材は仮素材を使い、技の動き・予兆・エフェクト・カメラ演出まで確認できるようにする。正式アートと戦闘バランスの最終調整は、試遊できる状態から仕上げる。

| 確認する範囲 | 到達条件 |
|---|---|
| 本番への接続 | ステージの出現設定から登場し、[戦闘の進行](#2-戦闘の進行)を経て撃破演出・報酬・結果へ進める |
| 技とAI | [通常攻撃](#4-通常攻撃)・[大技と連携](#5-大技と連携)をそれぞれ単独で確認でき、一戦では[行動判断の条件](#7-攻めどきと行動判断の要件)に従って開始・終了・次の行動へ進む |
| 地形と形態 | [惑星との接触](#6-惑星を使う攻めどき)と形態移行の予約が、技の途中や終了後でも定義どおりにつながる |
| 見た目 | [素材と演出](#8-素材と演出)の動きが、実際の予告・判定・隙に同期する。登場・形態変化・撃破を含め、一戦を通して画面で確認できる |
| 編集と再試遊 | 下記の編集内容を保存・再読込し、正規生成後の単独試遊と本番の一戦に反映できる |

### 9.2 調整と実装の接続

「ボス行動」画面で、使う技・区間の順序と選択条件・既存技の組み合わせ・技の数値を調整できるようにする。技固有の動作と演出はスクリプトと表示シーンで作り、戦闘の組み立ては[共通のノード編集](../../dev/stage-production.md#56-ボス行動を調整する)を使う。組み合わせは本体を共有する技の実行制約と[連携の方針](#5-大技と連携)に従う。

本体の数値の正は [`speed/data/bosses/monoceros.tres`](../../../speed/data/bosses/monoceros.tres)、技別の性能は [`monoceros_moves/`](../../../speed/data/bosses/monoceros_moves/) のリソースとする。HP・装甲・移動速度・旋回速度、距離・角度、技別の予告・実行・硬直・ダメージ・再使用待ち時間、突進回数、角刺さり・角抜き時間、形態移行のHP閾値は試遊調整用の仮値とする。`use_def_stats` を有効にしてHP・装甲を専用データから読み、共通の敵HP・装甲倍率を掛ける。

現仮実装の `combo` は、通常突進の後に自機が薙ぎの範囲にいる場合、短い切り返しから予告付きの薙ぎ払いへ進む実装例とする。範囲を離れた場合は突進後の隙へ進む。技の並びは仮置きとし、戦闘のつながりは[連携の方針](#5-大技と連携)に従う。

`monoceros_boss_timeline.tres` の `attack` は方向固定・発進・終了のメソッドトラックを持つ。役者ごとに複製し、技の開始時に専用データの時間へ合わせて手動更新する。表示は戦闘イベントへ接続する。技の性能・時間・再使用待ちは`monoceros_moves/*.tres`を使う。制限時間の一撃は`boss_final_strike.gd`の共通演出を使う。

短い受け入れ確認は `tests/monoceros.tscn`、静止・等速移動・予告後の回避と距離別の技選択・被弾表示の確認は `tests/monoceros_combat_quality.tscn`、描画付きの技の見本は同じシーンへ `-- --capture` を付けて実行する。実験場では `monoceros` を配置して試遊できる。ボス行動画面で作るコンボも共通の順次・待機・条件分岐を使い、各技の開始時に距離・形態・再使用待ちを確認する。

保存・生成・試遊は[AI向けの確認手順](../../dev/stage-production-ai.md#保存生成試遊録画)、実行時期と資源の寿命は[設計書15.1](../../architecture.md#151-ビルドと実行時の境界)に従う。自動テストは依頼時に実行し、生成・読み込み・短い画面確認と区別する。

## 10. 調整・素材の未完項目

船尾ブースターから青白い炎の尻尾を描き、突進時と登場飛行で噴射を強める。登場飛行の尺は本体の `params.entrance_time` で調整する。第2形態の角は光る剣状になり、光の槍は突き終わりに一瞬固定してから全体で飛散し、粒子が減衰する。固定と減衰の尺は `params.lance_hold`・`params.lance_fade` で調整する。

戦闘バランスの確定値、正式な馬・角・船尾のアート、剣状の角と光の槍の輪郭の細部、個別の音、カメラ演出の細部は未決。演出の細部は具体案を相談して定め、数値は試遊用の仮値として調整する。
