# いっかくじゅう座の仕様

ステージ1のボス、いっかくじゅう座の戦闘・行動判断・素材と演出を定義する。正面の角と直線突進をかわし、横や背後から本体を貫く戦闘とする。

ステージでの位置づけは [ステージ1](../stages/stage-1.md#4-ボス戦)、実装状況は [敵一覧](../catalog/enemies.md)、設定の元ネタは [世界観](../world.md#いっかくじゅう座--とも座)、共通のAI基盤は [設計書 6.1](../../architecture.md#61-敵とボスの-ai) を参照する。

## 1. 狙う体験と攻撃の整理

正面の角と、船尾ジェットで一気に詰める動きをかわし、横や背後から本体を貫く戦闘とする。技はツノとジェットを軸に組む。

- 攻撃するのは角だけで、本体に触れても自機は傷つかない。
- 予告は体の動き（首の捻り・身構え・角の光・ジェットの噴射）で見せる。
- 動きは生き物として見せ、溜めと振り抜き、止まる所と動く所の強弱をはっきりさせる。
- 技の終わりには、静止して息を整える隙を作る。
- 惑星への角刺さりは、既存の惑星を利用できたときに追加の攻撃機会を与える。

## 2. 戦闘の進行

| 形態 | 内容 |
|---|---|
| 第1形態 | 通常突進・連続突進・踏み込み薙ぎ・角の衝撃波・後ろ蹴りを使う。大技はない |
| 第2形態 | 角が光の剣になって長くなり、通常突進と連続突進が速くなり、連続突進の回数が増える。第1形態の技に、光の剣の連撃を加え、大技に光の槍と光角の乱舞を使う。形態変化の見た目は[素材と演出](#8-素材と演出)に従う |

本体の残HPが `params.phase_threshold` 以下になると、第2形態への移行を予約する。現在の攻撃、連続した突進や斬撃、その後の隙、角刺さりから角抜きまでを完了してから移行する。移行中も本体への攻撃を受ける。外観は角を中心に変化させ、船尾の装甲を保つ。

撃破は共通のHP表示・ボス撃破演出と、とも座の伝説モジュール獲得へ渡す。道中の進行はステージ側が管理する。ボス戦中は通常敵を出さない（[仕様書](../../spec.md#113-出現と補充)）。

## 3. 本体と命中対象

四足の馬の体、角、たてがみ、とも座の船尾の部品を持つ。本体を一体の攻撃対象とし、全方向から共通のダメージを受ける。横や背後への貫通経路は、正面の角を避ける攻め方として有効にする。

## 4. 通常攻撃

| 技 | 形態 | 動作と対処 |
|---|---|---|
| 通常突進 | 第1形態から | 脚を開いて踏ん張り、ジェットを溜めて角と直線の進路を光らせる。共通の遅延照準へ向き直り、発進直前に方向を固定して直進する。通過後は静止して隙を作る |
| 連続突進 | 第1形態から | 通常突進を決めた回数続ける。突き抜けるたびにジェットを逆に吹いて止まり、自機の今の位置へ向き直って、また自機へ突っ込む。向き直りは回り始めと終わりをゆっくりにし、頭が先に自機を向いて体が追いつく。発進の少し前に向きを固定する。各回の突進は自機の位置の決めた距離先までで止まる。最後に長い隙を作る |
| 踏み込み薙ぎ | 第1形態から | 遠目からジェットで加速して自機へ突っ込みながら、首を片側へ捻る（体の動きが予告）。自機の決めた距離まで寄るか、決めた時間が過ぎると、逆噴射でぴたりと止まり、捻りきった姿勢で一瞬静止する。そこから角を逆側へ一気に振り抜き、振り切った姿勢でぴたりと止まる。止まったあと、ゆっくり正面へ戻す。振る側は使うたびに左右を入れ替える。当たりは振り抜いている間の角 |
| 角の衝撃波 | 第1形態から | 首を片側へ引いて角を光らせて溜め、反対側へ振り抜きながら三日月形の衝撃波を飛ばす。振り終わりで一瞬止まって溜め直し、今度は逆向きに振り抜いてもう1発飛ばす。衝撃波は振っている角の向き（正面から振る側へ決めた角度ずれた向き）へ飛ぶので、1発目と2発目で中心が左右に分かれる。振りは始めと終わりがゆっくり。衝撃波はボスを中心に広がる弧で、弧の帯に触れると当たる。地形を通り抜け、決めた半径まで広がると消える |
| 光の剣の連撃 | 第2形態 | 光の剣になった角で、閃光斬を決めた回数続ける。1回ごとに、自機の今の位置へ向き直りながら角を片側へ引いて光を溜め、発動の少し前に向きと狙う位置を固定する。角を逆側へ素早く振り抜くと、その瞬間に狙った位置へ直線の斬撃が走る。斬撃は両端の尖った針状の光で、向きは振りに合わせて正面に対して横向きを振る側の前へ決めた角度傾ける。当たりは斬撃が走った瞬間だけ、線の上。地形を通り抜ける。振るたびに左右が入れ替わる。最後に角を正面へ戻して隙を作る |
| 後ろ蹴り | 第1形態から | 背後の近距離にいる自機に対し、後脚を畳んで後方の線を予告し、蹄を伸ばす。背後の範囲攻撃として、予告を始めた時の自機の位置へ蹴り、予告の間は狙いを動かさない。序盤から使い、独立した長めの再使用待ち時間で背後からの攻めを保つ |

## 5. 大技

大技はどちらも第2形態で使う。大技の後は長い隙を作る。

| 技 | 動作と対処 |
|---|---|
| 光の槍 | 後ろへ少し下がって身を沈め、角へ光を集める。角は伸びず、光をまとって太くなり、先に穂先ができて槍の形になる（形が予告）。発進の少し前に向きを固定し、ジェットを全開にして、通常突進よりずっと速く一直線に突き抜ける。突き抜ける間、先端の前にソニックブームの輪が次々に出て後ろへ流れる（見た目だけで当たりはない）。止まると槍の光が砕け散る。当たりは槍の形の角 |
| 光角の乱舞 | その場で自機を向いて角を光らせ、自機を貫くように突進する。突き抜けて自機の決めた距離先まで進むと、止まらずに減速しながら、いつも左回り（画面で反時計回り）に旋回する。旋回中は頭が少し先に自機を向き、機首の向きが自機に合うほど角が光る。機首が自機に向いた瞬間、そのまま自機へ突っ込む。これを決めた回数続け、最後は止まって角を掲げる。旋回の速さには上限があり、旋回の内側に入ると向きが合わないので、決めた時間が過ぎると旋回を小さくする。決めた時間旋回しても向きが合わなければ技を終える |

## 6. 惑星を使う攻めどき

発進直前に、本体の幅を含めて目の前から狙いまでの地形を確認する。惑星や月が塞ぐ場合は発進を見送り、横へ位置を変える。狙いを越えた突進の残りの経路には、かわされた先の惑星に当たる余地を残す。

通常突進・連続突進・光角の乱舞の突進で角先が惑星に当たると技を中断し、その場所でしばらくもがく。自力で角を引き抜き、後退してから復帰する。惑星の配置・大きさを保ったまま判定し、角刺さり中も本体への攻撃を受ける。月や側面の地形接触は突進を終了して通常の隙へ進む。光の槍の地形接触は、その場で止まって槍の光が砕け、通常の隙へ進む。

## 7. 攻めどきと行動判断の要件

### 7.1 移動と攻撃開始

画面外へ出た場合はプレイヤーの近くへ戻り、攻撃可能な範囲に入ったら攻撃を開始する。接近は自機から `params.approach_range` の距離で止め、その内側では位置を変えずに向きだけを自機へ合わせる。接近の速さ `params.approach_speed` は自機の基本の最高速より遅くし、離れた自機へは突進で距離を詰める。通常突進・連続突進の開始距離は、ボス行動の距離条件で接近先の `params.approach_range` に合わせる。距離条件はエディターから変更できる。

### 7.2 狙いの捕捉と固定

通常突進と連続突進の1回目は、予告中に `enemy_aim` を追い、`params.lock_lead` だけ発進より前に向きを固定する。発進後はその向きへ直進する。連続突進の2回目以降・踏み込み薙ぎ・光の剣の連撃・光の槍・光角の乱舞は、自機の今の位置を狙い、技ごとに決めた時間だけ前に向きを固定する。角の衝撃波は溜めと振りの間、`enemy_aim` へ向き直る。

### 7.3 行動選択と形態

技の選択は共通フローで行い、`ai/monoceros_flow.tres`が区間の割合・消費上限・共有スタミナ・休息を持つ。`ai/monoceros_action_rules.tres`が距離・方向・必要形態を持ち、個別の再使用待ちを満たす候補から選ぶ。通常技は通常突進・踏み込み薙ぎ・角の衝撃波・光の剣の連撃・後ろ蹴り、コンボは連続突進、大技は光の槍と光角の乱舞とする。形態の予約と確定は役者が管理する。

## 8. 素材と演出

`scenes/bosses/monoceros_parts.tscn` は、納品されたパーツ画像を組み立てた表示シーンとする。胴体、頭の上下、四肢の根元と脚先、尻尾のブースターを個別ノードで保持する。各パーツの切り出し範囲と配置はシーンへ保存し、表示時は元画像を参照する。

このパーツ画像は仮絵として組み込む。`assets/pixel/monoceros/unicorn_source.aseprite` のBaseとArmorを分け、Armorを含む7レイヤーと脚の根元・金色のブースターに、装甲の区切りを少数の平面で表す法線を付ける。平面内の傾きを一定にし、塗装のディザを凹凸に変えない。重なる装甲レイヤーは同じ位置に同じ法線を使う。装甲は主光と補助光で照らし、塗装の色と濃淡を保つ。頭・胴体・脚・ブースターは同じ法線の規則で表示し、左右反転したパーツは法線の左右も反転する。

`scenes/bosses/monoceros_parts_preview.tscn` をGodotで開き、F6で走りの確認画面を表示する。脚先の4差分を長い・中間・短い・真下・短い・中間の順で往復させ、対角の脚を半周期ずらす。6コマそれぞれの表示時間はスライダーで10〜600msに調整でき、再生の停止と時間の初期化を備える。設定は確認画面の実行中だけ保持する。ゲームと確認画面は共通の脚アニメーション処理を使い、初期の表示時間と画像は `data/visuals/monoceros_gait.tres` を参照する。

敵実験所の「外観」から「一角獣の外観・パーツ編集」を開く。パーツ全体とBase／Armorを選び、色と元の配置からのX/Y位置補正を調整する。走り・向き・法線の強さを見本で確認し、色と配置を `BossDef.part_appearance` へ明示的に保存する。見本の向きと法線の強さは確認画面だけに適用する。編集は実験所の履歴と条件保存に含み、当たり判定と攻撃性能は戦闘データを使う。

戦闘中は移動に合わせて走りを再生し、停止・予告・角刺さりでは脚を止める。旋回では頭先端、胴体側の頭、胴体の順に戦闘方向へ追従させ、頭の2パーツは接続部を支点に回す。胴体の表示中心は判定円の中心に保つ。角を使う技の間は、頭を判定線（角）の向きへ合わせる。首の捻りと振りは頭の回転で見せる。アニメーションは役者の世界時間で進み、世界時間の停止中は姿勢を保持する。移動と当たり判定は表示の追従角を使わない。後ろ蹴りでは予告中に両後脚を畳み、攻撃時に判定線の先端まで伸ばす。踏み込み薙ぎと後ろ蹴りは攻撃後に姿勢を保持してから正面へ戻す。攻撃の太い光は実際の角の判定線から描き、後ろ蹴りは伸ばした脚で範囲を示す。通常突進と連続突進の1回目の予告では、薄い直線で移動方向を示す。

登場時は画面外から船尾ブースターを噴射して飛び込み、停止して角を構え、戦闘へ入る。進入方向・停止位置・カメラと各動作の尺は調整する。

突進時は、取り込んだとも座の船尾ブースターから噴射を出し、その勢いで加速して突っ込む様子を見せる。通常突進・連続突進・踏み込み薙ぎの踏み込み・光の槍・光角の乱舞に共通する演出として、発進・移動に合わせて再生する。速く動くときは、噴射の炎が途切れて点線に見えないよう、1回の更新で進んだ間を炎で埋める。連続突進の止まりと踏み込み薙ぎの止まりでは、ジェットを前へ逆に吹く。攻撃判定は突進と角の判定を使う。

外観は、尻尾位置の船尾部品をブースター状にし、そこから出る青白い炎が尻尾の形を作る。普段は短く揺らめき、突進時に後方へ大きく噴き出す。ブースターは接続部を支点に胴体より遅れて旋回する。炎の根元は噴出口へ接続し、先端ほど向きの追従を遅らせ、ピクセル単位の矩形で曲がった尾を描く。追従時間と角度の上限は `monoceros_presentation.gd` の `Turning` エクスポート項目で調整する。絵素材の依頼・分割・納品条件は[共有アート素材リスト](../catalog/art-assets.md#いっかくじゅう座)で管理し、噴射の動きと発進への同期は演出側で扱う。炎の形状の細部・噴射の強さや時間は調整する。

第2形態への移行では、足を止めて踏ん張り、角と目へ光を集めて強く輝かせる。角は通常の角の形から、光り輝く剣のような形へ変わり、長くなる。剣の長さは判定の長さと同じ。

光の槍の溜めでは、まわりから光の粒が角へ集まり、角が光をまとって太くなり、先端に菱形の穂先ができる。角の長さは変えない。発進の瞬間に本体から光の輪が広がり、画面が一瞬白く光る。止まると槍の光が粒になって飛び散り、角は剣の形へ戻る。

角の衝撃波は、白く光る三日月形の弧として描き、広がるほど薄くなる。放つ瞬間に角先から小さな光の輪を出す。

光の剣の連撃の斬撃は、両端の尖った針状の光（白い芯と紫の縁）として描く。出た瞬間に全長で現れ、少しの間そのまま保ってから細くなって消える。まわりに細い光の筋を数本、斬撃の向き寄りに交差させて出す（見た目だけ）。

光角の乱舞では、角を光らせる間と旋回で向きが合っていく間、角の光を強める。最後に止まると角を掲げて光らせる。

針状の光・衝撃波・ソニックブームなどのエフェクトは shader で作る。作れないものはテクスチャを描いてもらう。

`scenes/bosses/monoceros_presentation.tscn` を差し替えて、役者の `presentation_scene` に指定する。シーンは `bind_monoceros(actor)` で以下を接続する。

- `presentation_event`：予告、方向固定、発進、隙、角刺さり、角抜き、形態変化、被弾、撃破、制限時間演出と、技の段ごとの合図（止まる、振り抜く、衝撃波を放つ、斬撃を放つ、槍が砕ける、旋回を始める）。`cue`・`technique`・`phase`・`mode`・`position`・`angle`・`world_time` を渡す。
- `presentation_advanced`：世界時間の進行。停止中はアニメーションも止まる。
- `horn_points()`：ワールド座標の判定線。首の捻り・振りを含めた今の角の向きと長さを返す。

パーツの構成は `monoceros_parts.tscn`、戦闘との同期と攻撃の光は `monoceros_presentation.gd` で扱う。 実際にHPが減った被弾では本体を薄く白く光らせ、短い減衰する揺れを描画へ加える。連続命中では演出時間と揺れ幅を上限内へ戻し、本体座標・照準・予告線・攻撃判定は戦闘状態を使う。

## 9. 実装・調整・接続

### 9.1 一戦を試遊できる完成ライン

本体・行動AI・全技・形態移行と、登場から撃破までの演出をつなぎ、ステージ1で一戦を試遊できる状態にする。絵素材は仮素材を使い、技の動き・予兆・エフェクト・カメラ演出まで確認できるようにする。正式アートと戦闘バランスの最終調整は、試遊できる状態から仕上げる。

| 確認する範囲 | 到達条件 |
|---|---|
| 本番への接続 | ステージの出現設定から登場し、[戦闘の進行](#2-戦闘の進行)を経て撃破演出・報酬・結果へ進める |
| 技とAI | [通常攻撃](#4-通常攻撃)・[大技](#5-大技)をそれぞれ単独で確認でき、一戦では[行動判断の条件](#7-攻めどきと行動判断の要件)に従って開始・終了・次の行動へ進む |
| 地形と形態 | [惑星との接触](#6-惑星を使う攻めどき)と形態移行の予約が、技の途中や終了後でも定義どおりにつながる |
| 見た目 | [素材と演出](#8-素材と演出)の動きが、実際の予告・判定・隙に同期する。登場・形態変化・撃破を含め、一戦を通して画面で確認できる |
| 編集と再試遊 | 下記の編集内容を保存・再読込し、正規生成後の単独試遊と本番の一戦に反映できる |

### 9.2 調整と実装の接続

技の動きと公開値は `scripts/bosses/monoceros/techniques/`、技の見た目は `scenes/bosses/monoceros/`、保存値は `data/bosses/monoceros_moves/` に置く。追加・名前・見た目の操作は[ボスAIの操作ガイド](../../dev/tools/boss-ai.md#技を追加名前と見た目を変える)、共通の構成は[設計書](../../architecture.md#61-敵とボスの-ai)を参照する。

「ボス行動」画面で、使う技・区間の順序と選択条件・既存技の組み合わせ・技の数値を調整できるようにする。技固有の動作と演出はスクリプトと表示シーンで作り、戦闘の組み立ては[共通のノード編集](../../dev/stage-production.md#56-ボス行動を調整する)を使う。組み合わせは本体を共有する技の実行制約に従う。

本体の数値の正は [`speed/data/bosses/monoceros.tres`](../../../speed/data/bosses/monoceros.tres)、技別の性能は [`monoceros_moves/`](../../../speed/data/bosses/monoceros_moves/) のリソースとする。HP・装甲・移動速度・旋回速度、距離・角度、技別の予告・実行・硬直・ダメージ・再使用待ち時間、突進回数、角刺さり・角抜き時間、形態移行のHP閾値は試遊調整用の仮値とする。`use_def_stats` を有効にしてHP・装甲を専用データから読み、共通の敵HP・装甲倍率を掛ける。

連続突進・踏み込み薙ぎ・角の衝撃波・光の剣の連撃・光の槍・光角の乱舞は、段（止まる・向き直る・振る・旋回するなど）を持つ。これらは技の Runner が世界時間で段を進め、段の時間・速さ・角度はすべて技の値として公開してボス行動画面で調整できるようにする。第2形態で変える値は、同じ名前に `_p2` を付けた値で持つ。通常突進と後ろ蹴りは、`monoceros_boss_timeline.tres` の `attack` で進める。`attack` は方向固定・発進・終了のメソッドトラックを持つ。役者ごとに複製し、技の開始時に専用データの時間へ合わせて手動更新する。表示は戦闘イベントへ接続する。技の性能・時間・再使用待ちは`monoceros_moves/*.tres`を使う。制限時間の一撃は`boss_final_strike.gd`の共通演出を使う。

短い受け入れ確認は `tests/monoceros.tscn`、描画付きの技の見本は同じシーンへ `-- --capture` を付けて実行する。実験場では `monoceros` を配置して試遊できる。ボス行動画面で作るコンボも共通の順次・待機・条件分岐を使い、各技の開始時に距離・形態・再使用待ちを確認する。

保存・生成・試遊は[AI向けの確認手順](../../dev/stage-production-ai.md#保存生成試遊録画)、実行時期と資源の寿命は[設計書15.1](../../architecture.md#151-ビルドと実行時の境界)に従う。自動テストは依頼時に実行し、生成・読み込み・短い画面確認と区別する。

## 10. 調整・素材の未完項目

船尾ブースターから青白い炎の尻尾を描き、突進時と登場飛行で噴射を強める。登場飛行の尺は本体の `params.entrance_time` で調整する。第2形態の角は光る剣状になる。光の槍の穂先の形・砕けるまでの時間、衝撃波・斬撃・ソニックブームの見た目は、技の値と表示シーンで調整する。

戦闘バランスの確定値、仮絵の仕上げ、剣状の角と光の槍の輪郭の細部、首を捻る・振るポーズの正式な絵、エフェクトの shader、個別の音、カメラ演出の細部は未決。演出の細部は具体案を相談して定め、数値は試遊用の仮値として調整する。
