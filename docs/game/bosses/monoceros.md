# いっかくじゅう座の仕様

ステージ1のボス、いっかくじゅう座の戦闘・行動判断の要件・素材と演出の雛形を定義する。1章の核に沿って、2章以降の進行・技・攻めどき・演出を制作者が決める。2章以降に挙げる内容は例で、技の中身と数・形態の数は変えてよい。

ステージでの位置づけは [ステージ1](../stages/stage-1.md#4-ボス戦)、実装状況は [敵一覧](../catalog/enemies.md)、設定の元ネタは [世界観](../world.md#いっかくじゅう座--とも座)、敵とボスの考え方は [設計の進め方](../../dev/stage-production.md#4-敵とボスを設計する)、役者・BT・演出の編集方法は [設計書 6.1](../../dev/architecture.md#61-敵とボスの-ai) を参照する。

## 1. 狙う体験と攻撃の整理

- 突進と角で、一気に距離を詰めて攻撃する。
- 危ないのは角が向いている正面。正面を外して、横や背後から貫く。
- 攻撃は近距離が中心。

## 2. 戦闘の進行（例）

| 形態 | 内容 |
|---|---|
| 第1形態 | 突進と角の攻撃で戦う |
| 第2形態 | HPが半分を切ると、たてがみが燃える。突進が速くなり、続けて突っ込んでくる |

撃破は共通のボス撃破演出と、とも座の伝説モジュール獲得演出へ渡す。ボス戦中も通常敵が出現する。

## 3. 通常攻撃（例）

| 技 | 分類 | 動作と対処 |
|---|---|---|
| 突進 | 近距離・線 | 前脚で踏み込み、角が光ってから、まっすぐ駆け抜ける。抜けたあとで止まって向き直る。進路から外れ、向き直る間に攻める |
| 角の突き | 近距離・点 | 近くで、短く鋭く突く。角の先から横へ外れる |
| 角の薙ぎ | 近距離・面 | 首を振って前方を扇形に薙ぐ。扇の外へ抜け、振り切った後に攻める |
| 後ろ蹴り | 近距離・面 | 背後に長くいると、後ろ脚で蹴る。背後にとどまらず、貫いて抜ける |

## 4. 大技（例）

大技は複数用意する。大技の後は攻めどきを作る。

### 4.1 往復突進

場を何度も往復して突進する。突進と突進の間の隙を読んで抜ける。終わると息を切らして止まる。

### 4.2 隕石すくい

角で隕石をすくい上げ、自機へ投げつける（遠距離・点）。投げた後は角を振り上げた姿勢で止まる。

### 4.3 暴走（第2形態）

続けて突っ込みながら、進む先の隕石や鉄のがれきを砕く。砕けた破片が周りへ飛び散る。

## 5. 攻めどきと行動判断の要件（例）

### 5.1 状態の区別

| 状態 | 意味と扱い |
|---|---|
| 攻撃可能 | 距離・向き・再使用待ち時間などの条件を満たせば行動できる |
| 攻撃中 | 予告・狙い固定・実行を進める |
| 向き直り | 突進の後、止まって向きを変える。攻める対象になる |
| 角が刺さる | 突進の先の障害物に角が刺さり、数秒動けない。背後ががら空きになる |
| 息切れ | 大技の後に止まる。攻める対象になる |

### 5.2 共通ルール

- 自機との距離で技を選ぶ。離れていれば突進、近ければ角の突き・薙ぎを使う。
- 自機の向こうに障害物があっても突進を選ぶ。プレイヤーは障害物の前に立って角を刺させられる。
- 背後に長くいる自機には後ろ蹴りを使う。
- 大技の後は、全体で攻めどきを作る。

## 6. 素材と演出（例）

- 四足の獣の体、長い角、たてがみ、取り込んだとも座（船尾）の部品を描く。
- 突進の予告は、前脚の踏み込みと角の光で見せる。
- 角が刺さる・抜ける、向き直る、息を切らすを、連続した動作として見せる。
- 第2形態への移行で、たてがみが燃えるアニメーションを入れる。
- エフェクトはシェーダーを使い、ピクセルアートらしい輪郭・色の階調・粒子の見え方を持つ表現にする。

## 7. 実装・調整・接続

- 調整値の正は `speed/data/bosses/` の `.tres` とする。
- 段階進行、BehaviorTree、攻撃と判定、素材差し替えの編集方法は [設計書 6.1](../../dev/architecture.md#61-敵とボスの-ai) に従う。
- 撃破を最終勝利の接続点とし、共通のボス撃破演出と伝説モジュール獲得演出へ渡す。
