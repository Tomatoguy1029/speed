# ケンタウルス座の仕様

ステージ2のボス、ケンタウルス座の戦闘・行動判断の要件・素材と演出を定義する。1章の核に沿って、進行・技・攻めどき・演出を制作者が決める。第1形態の速射の矢・貫く強弓・離脱・位置取りは決まった決まりで、見出しに「例」を付けた内容は雛形の例である。例の技の中身と数・形態の数は変えてよい。

ステージでの位置づけは [ステージ2](../stages/stage-2.md#4-ボス戦)、実装状況は [敵一覧](../catalog/enemies.md)、設定の元ネタは [世界観](../world.md#ケンタウルス座--ほ座)、敵とボスの考え方は [設計の進め方](../../dev/stage-production.md#4-敵とボスを設計する)、役者・BT・演出の編集方法は [設計書 6.1](../../architecture.md#61-敵とボスの-ai) を参照する。

## 1. 狙う体験と攻撃の整理

- 守りの群れの奥から弓を射る。矢はや座。
- 近づくと走って距離を取る。走る速さは自機の高速移動より遅く、突進で届く。
- 攻撃は遠距離が中心。守りの群れと矢ごと一筆で突き抜け、本体に届かせる。

## 2. 戦闘の進行

| 形態 | 内容 |
|---|---|
| 第1形態 | 距離を取りながら、速射の矢と貫く強弓を射る。近づかれると走って離れる |
| 第2形態（例） | HPが半分を切ると、取り込んだほ座（帆）を広げる。走る速さが上がり、矢の数が増える |

撃破は共通のボス撃破演出と、ほ座の伝説モジュール獲得演出へ渡す。ボス戦中も通常敵が出現する。

## 3. 通常攻撃

| 技 | 分類 | 動作と対処 |
|---|---|---|
| 速射の矢 | 遠距離・点 | 止まって弓を引く予告のあと、矢を一定の間隔で続けて射る。1本ごとに、射る瞬間の[機体の遅れた位置](../../spec.md#75-敵の狙い)を狙う。動き続けて矢の間を抜ける |
| 貫く強弓 | 遠距離・線 | 止まって大きく弓を引き絞る。引き絞りの前半は自機の方へ向き直り、後半は向きを止めて射線を示し、その向きへ太い矢を射る。太い矢は敵をすり抜け、守りの群れの後ろまで届く。向きが止まってから射線の外へ出る。構えている間と射終わりの硬直が攻めどき |
| 矢の雨（例） | 遠距離・面 | 空へ矢を放ち、落ちる場所を影で見せてから降らせる。影の外へ抜ける |
| 後ろ脚の蹴り（例） | 近距離・面 | 背後に回った自機を後ろ脚で蹴る。背後にとどまらず、貫いて抜ける |

矢は光の矢（`scripts/attacks/light_arrow.gd`）で飛び、惑星・月で止まる。貫く強弓は光の矢のコズミック色で描く。

## 4. 大技（例）

大技は複数用意する。大技の後は攻めどきを作る。

### 4.1 一斉射撃

守る雑魚の列を前に並ばせ、その後ろから広い範囲に矢の雨を降らせる。列と矢の雨の切れ目を一筆で突き抜け、本体まで届かせる。

### 4.2 走りながらの連射（第2形態）

自機のまわりを大きく回るように走りながら、矢を射続ける。矢の切れ目から飛び込む。走り終えると止まって息を整える。

## 5. 攻めどきと行動判断の要件

### 5.1 状態の区別

| 状態 | 意味と扱い |
|---|---|
| 待機 | 好む距離を保って歩き、自機の方を向く。距離と再使用待ち時間の条件を満たした技を共通フローが選ぶ |
| 攻撃中 | 止まって予告・狙い固定・発射を進める |
| 引き絞り | 貫く強弓の構え。止まっていて、攻める対象になる |
| 硬直 | 射終わりに止まる。攻める対象になる |
| 離脱 | 走って距離を取る。終わると止まって向き直る |
| 息を整える（例） | 大技の後に止まる。攻める対象になる |

### 5.2 共通ルール

- 待機中に自機が近づくと、自機と反対の方向へ走る。決めた距離まで離れるか、決めた時間が過ぎると止まり、自機の方へ向き直る。そのあと一定時間は走らない。フィールドの外縁では縁に沿って走る。攻撃中・硬直中は走らない。
- 待機中は、自機から決めた範囲の距離を保つ。近くに守る雑魚が一定数以上集まっていると、自機から見てその集まりの奥へ回る。守る雑魚は[敵一覧](../catalog/enemies.md)の行動に従い、ボスの前に並ぶ動きは未決。
- 背後に回った自機には後ろ脚の蹴りを使う（例）。
- 大技の後は、全体で攻めどきを作る（例）。

## 6. 素材と演出

仮表示は図形で描く。馬の胴・4本の脚・尾・人の上半身・弓を描き、走る間は脚を大きく振る。弓を引くほど弦が後ろへ下がり、矢の光が伸びる。貫く強弓の引き絞りは自機への射線を細く示し、向きが止まると矢の太さの赤い射線に変える。硬直中は縁を青く光らせる。

`scenes/bosses/centaurus_presentation.tscn` を差し替えて、役者の `presentation_scene` に指定する。シーンは `bind_centaurus(actor)` で以下を接続する。

- `presentation_event`：登場、予告、向きの固定、発射、硬直、離脱、被弾、撃破、制限時間演出。`cue`・`technique`・`phase`・`mode`・`position`・`angle`・`world_time` を渡す。
- `presentation_advanced`：世界時間の進行。停止中はアニメーションも止まる。

雛形の例：

- 半人半馬の体、弓、や座の矢、取り込んだほ座（帆）の部品を描く。
- 矢の雨は落ちる場所の影で見せる。
- 走る・止まる・向き直る・弓を引き絞るを、連続した動作として見せる。
- 第2形態への移行で、帆を広げるアニメーションを入れる。
- エフェクトはシェーダーを使い、ピクセルアートらしい輪郭・色の階調・粒子の見え方を持つ表現にする。

## 7. 実装・調整・接続

- 本体の数値（HP・装甲・歩く速さ・旋回・好む距離・離脱・位置取り）の正は [`speed/data/bosses/centaurus.tres`](../../../speed/data/bosses/centaurus.tres)、技別の性能（予告・矢の数と間隔・速さ・半径・射程・ダメージ・硬直・再使用待ち、強弓の向きを止める時間）は [`centaurus_moves/`](../../../speed/data/bosses/centaurus_moves/) とする。どれも試遊調整用の仮値。`use_def_stats` を有効にしてHP・装甲を専用データから読み、共通の敵HP・装甲倍率を掛ける。
- 技の選択は共通フローで行う。`ai/centaurus_flow.tres` が区間・消費上限・共有スタミナ・休息を、`ai/centaurus_action_rules.tres` が技ごとの距離条件と消費を持つ。「ボス行動」画面のボスの選択に、ケンタウルス座がある。
- `centaurus_boss_timeline.tres` の `attack` は、向きの固定・発射・終了のメソッドトラックを持つ。役者ごとに複製し、技の開始時に専用データの時間へ合わせて手動更新する。制限時間の一撃は `boss_final_strike.gd` の共通演出を使う。
- ステージ2の `boss_id` が `centaurus` を参照し、`boss_time` の時刻に登場する。撃破を最終勝利の接続点とし、共通のボス撃破演出と伝説モジュール（`legendary_sail`）獲得演出へ渡す。
- `gyms/centaurus_trial.tscn` をF6で起動すると、敵・ルート実験場がステージ2の設定で開き、ケンタウルス座と守る雑魚を置いた試遊ができる。シーンのInspectorで、開始位置・無敵・試遊用の攻撃倍率・守る雑魚の数・繰り返す技を変える。実験場の配置からも `centaurus` を置ける。

## 8. 未決事項
