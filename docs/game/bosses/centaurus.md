# ケンタウルス座の仕様

ステージ2のボス、ケンタウルス座の戦闘・行動判断の要件・素材と演出を定義する。1章の核に沿って、進行・技・攻めどき・演出を制作者が決める。第1形態の速射の矢・貫く強弓・矢の雨・背後攻撃・離脱・位置取りと第2形態への移行は決まった決まりで、見出しに「例」を付けた内容は雛形の例である。例の技の中身と数・形態の数は変えてよい。

ステージでの位置づけは [ステージ2](../stages/stage-2.md#4-ボス戦)、実装状況は [敵一覧](../catalog/enemies.md)、設定の元ネタは [世界観](../world.md#ケンタウルス座--ほ座)、敵とボスの考え方は [設計の進め方](../../dev/stage-production.md#4-敵とボスを設計する)、役者・BT・演出の編集方法は [設計書 6.1](../../architecture.md#61-敵とボスの-ai) を参照する。

## 1. 狙う体験と攻撃の整理

- 守りの群れの奥から弓を射る。矢はや座。
- 近づくと走って距離を取る。走る速さは自機の高速移動より遅く、突進で届く。
- 攻撃は遠距離が中心。守りの群れと矢ごと一筆で突き抜け、本体に届かせる。

## 2. 戦闘の進行

| 形態 | 内容 |
|---|---|
| 第1形態 | 距離を取りながら、速射の矢・貫く強弓・矢の雨を使う。近づかれると走って離れ、背後に回られると背後攻撃を使う |
| 第2形態 | HPが決めた割合を切ると、今の技を終えて待機へ戻ったところで、決めた時間だけ止まって取り込んだほ座（帆）を広げる。広げると、走る速さが上がり、速射の矢の数・貫く強弓の本数・矢の雨のトレースの回数が増える |

撃破は共通のボス撃破演出と、ほ座の伝説モジュール獲得演出へ渡す。ボス戦中も通常敵が出現する。

## 3. 通常攻撃

| 技 | 分類 | 動作と対処 |
|---|---|---|
| 速射の矢 | 遠距離・点 | 止まって弓を引く予告のあと、矢を一定の間隔で続けて射る。1本ごとに、射る瞬間の[機体の遅れた位置](../../spec.md#75-敵の狙い)を狙う。動き続けて矢の間を抜ける |
| 貫く強弓 | 遠距離・線 | 止まって大きく弓を引き絞る。引き絞りの間は自機の今の位置へ向きを合わせ続け、発射の直前に射線で警告し、発射の瞬間の自機の位置へ太い矢を射る。複数本のときは、真ん中の1本を自機へ向け、残りを左右へ決めた角度ずつ開いて同時に射り、射線の警告も本数だけ示す。太い矢は敵をすり抜け、守りの群れの後ろまで届く。矢が届くまでの間に射線の横へ動くか、矢と矢の間へ抜ける。構えている間と射終わりの硬直が攻めどき |
| 矢の雨 | 遠距離・面 | 止まって空へ射る予告のあと、トレースを決めた回数だけ続けて走らせる。トレースは、円が弧の道すじを滑らかに走った跡の帯で、自機の進む向きの前方から自機の位置を通るように走る。円を追ってその中へ矢が降り、決めた時間ののちに着く。着いた矢の円に自機が入ると当たり、1本のトレースで当たるのは1回まで。トレースは1本ごとに、その時の自機の位置と向きから置き直し、走り終えて決めた間隔ののちに次を始める。曲がる向きは1本ごとに左右を入れ替える。トレースの間、ボスは好む距離を保って歩く。帯の横へ抜ける |
| 背後攻撃 | 近距離・面 | 自機が背後の決めた範囲へ回ると、背中を向けたまま止まり、体を赤く明滅させて構える。構えのあと決めた時間だけ、背中の後ろの円に当たりが有効になり、1回の攻撃で1回だけ当たる。背後にとどまらず、貫いて抜ける。動作の見た目は未決 |

速射の矢と貫く強弓の矢は光の矢（`scripts/attacks/light_arrow.gd`）で飛び、惑星・月で止まる。貫く強弓は光の矢のコズミック色で描く。矢の雨は地形に関わらず降り、敵には当たらない。

## 4. 大技（例）

大技は複数用意する。大技の後は攻めどきを作る。

### 4.1 一斉射撃

守る雑魚の列を前に並ばせ、その後ろから広い範囲に矢の雨を降らせる。列と矢の雨の切れ目を一筆で突き抜け、本体まで届かせる。

### 4.2 走りながらの連射（第2形態）

自機のまわりを大きく回るように走りながら、矢を射続ける。矢の切れ目から飛び込む。走り終えると止まって息を整える。

## 5. 攻めどきと行動判断の要件

### 5.1 状態の区別

| 状態 | 意味と扱い |
|---|---|
| 待機 | 好む距離を保って歩き、自機の方を向く。距離と再使用待ち時間の条件を満たした技を共通フローが選ぶ |
| 攻撃中 | 止まって予告・発射前の警告・発射を進める。矢の雨は予告のあと、トレースが終わるまで歩きながら続ける。背後攻撃は向き直らずに構える |
| 引き絞り | 貫く強弓の構え。止まっていて、攻める対象になる |
| 硬直 | 射終わりに止まる。攻める対象になる |
| 帆を広げる | 第2形態への移行で止まる。攻める対象になる |
| 離脱 | 走って距離を取る。終わると止まって向き直る |
| 息を整える（例） | 大技の後に止まる。攻める対象になる |

### 5.2 共通ルール

- 待機中に自機が近づくと、自機と反対の方向へ走る。決めた距離まで離れるか、決めた時間が過ぎると止まり、自機の方へ向き直る。そのあと一定時間は走らない。フィールドの外縁では縁に沿って走る。攻撃中・硬直中は走らない。背後攻撃を共通フローが選べる間は、走らずに背後攻撃を優先する。
- 待機中は、自機から決めた範囲の距離を保つ。近くに守る雑魚が一定数以上集まっていると、自機から見てその集まりの側へ回る。近くの守る雑魚は、[敵一覧](../catalog/enemies.md)の行動に従ってボスと自機の間に並ぶ。
- 背後攻撃の発動条件は、自機の今の位置で測る。ほかの技は共通の遅延照準で測る。
- 大技の後は、全体で攻めどきを作る（例）。

## 6. 素材と演出

仮表示は図形で描く。馬の胴・4本の脚・尾・人の上半身・弓を描き、走る間は脚を大きく振る。弓を引くほど弦が後ろへ下がり、矢の光が伸びる。貫く強弓の引き絞りは自機への射線を細く示し、発射前の警告で矢の太さの赤い射線に変える。硬直中は縁を青く光らせる。第2形態では、馬の背の帆桁から左右へ帆を広げ、後ろへふくらませて描き、四隅の星を瞬かせる。移行の間は帆を広げながら、まわりへ光の輪を広げる。背後攻撃の構えの間は体全体を赤く明滅させ、当たりが有効な間は赤く光らせ続ける。攻撃範囲の円は本番の画面に描かず、敵・ルート実験場の攻撃範囲の表示で描く。

矢の雨は、まだ矢が着いていない帯を薄い色と縁の線で描き、走っている円を輪で描く。帯は円の走りに合わせて伸び、矢が着いた所から消える。矢は着弾点から画面の上方向へずらした位置から、落ちるほど速く下りて着き、同じ間に透明から不透明へキリっと変わる。着いた矢は決めた時間だけ刺さって残り、短く消える。

`scenes/bosses/centaurus_presentation.tscn` を差し替えて、役者の `presentation_scene` に指定する。シーンは `bind_centaurus(actor)` で以下を接続する。

- `presentation_event`：登場、第2形態への移行、予告、発射前の警告、発射、矢の雨の開始と各トレースの開始、背後攻撃の当たりの開始、硬直、離脱、被弾、撃破、制限時間演出。`cue`・`technique`・`phase`・`mode`・`position`・`angle`・`world_time` を渡す。
- `presentation_advanced`：世界時間の進行。停止中はアニメーションも止まる。

雛形の例：

- 半人半馬の体、弓、や座の矢、取り込んだほ座（帆）の部品を描く。
- 走る・止まる・向き直る・弓を引き絞るを、連続した動作として見せる。
- 第2形態への移行で、帆を広げるアニメーションを入れる。
- エフェクトはシェーダーを使い、ピクセルアートらしい輪郭・色の階調・粒子の見え方を持つ表現にする。

## 7. 実装・調整・接続

- 本体の数値（HP・装甲・歩く速さ・旋回・好む距離・離脱・位置取り・第2形態へ移るHPの割合と帆を広げる時間）の正は [`speed/data/bosses/centaurus.tres`](../../../speed/data/bosses/centaurus.tres)、技別の性能（予告・矢の数と間隔・速さ・半径・射程・ダメージ・硬直・再使用待ち、強弓の本数と矢どうしの角度・発射前の警告の時間、矢の雨のトレースの回数・前方への距離・円の半径・長さ・速さ・曲がり具合・間隔、矢を落とす間隔と数、降りる時間・不透明になる時間・降りる高さ・刺さって残る時間、背後攻撃の背中から範囲の中心までの距離・範囲の半径・当たりが有効な時間）は [`centaurus_moves/`](../../../speed/data/bosses/centaurus_moves/) とする。第2形態の値は、同じファイルの同じ名前に `_p2` を付けた項目に置き、第2形態では置いた項目だけを置き換える。「ボス行動」画面では、その項目の名前に「（第2形態）」を添えて示す。どれも試遊調整用の仮値。`use_def_stats` を有効にしてHP・装甲を専用データから読み、共通の敵HP・装甲倍率を掛ける。
- 技の選択は共通フローで行う。`ai/centaurus_flow.tres` が区間・消費上限・共有スタミナ・休息を、`ai/centaurus_action_rules.tres` が技ごとの距離条件と消費を持つ。「ボス行動」画面のボスの選択に、ケンタウルス座がある。
- `centaurus_boss_timeline.tres` の `attack` は、発射前の警告・発射・終了、矢の雨の開始、背後攻撃の当たりの開始のメソッドトラックを持つ。役者ごとに複製し、技の開始時に専用データの時間へ合わせて手動更新する。制限時間の一撃は `boss_final_strike.gd` の共通演出を使う。
- ステージ2の `boss_id` が `centaurus` を参照し、`boss_time` の時刻に登場する。撃破を最終勝利の接続点とし、共通のボス撃破演出と伝説モジュール（`legendary_sail`）獲得演出へ渡す。
- `gyms/centaurus_trial.tscn` をF6で起動すると、敵・ルート実験場がステージ2の設定で開き、ケンタウルス座と守る雑魚を置いた試遊ができる。シーンのInspectorで、開始位置・無敵・試遊用の攻撃倍率・守る雑魚の数・繰り返す技・第2形態から始めるかを変える。役者の `lab_ranges()` が返す攻撃範囲を、実験場の攻撃範囲の表示が描く。ボスを選ぶと、構えていない間の背後攻撃の範囲も描く。実験場の配置からも `centaurus` を置ける。
