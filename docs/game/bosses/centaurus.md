# ケンタウルス座の仕様

ステージ2のボス、ケンタウルス座の戦闘・行動判断の要件・素材と演出を定義する。

ステージでの位置づけは [ステージ2](../stages/stage-2.md#4-ボス戦)、実装状況は [敵一覧](../catalog/enemies.md)、設定の元ネタは [世界観](../world.md#ケンタウルス座--ほ座)、敵とボスの考え方は [設計の進め方](../../dev/stage-production.md#4-敵とボスを設計する)、役者・BT・演出の編集方法は [設計書 6.1](../../architecture.md#61-敵とボスの-ai) を参照する。

## 1. 狙う体験と攻撃の整理

- 守る雑魚を壁にして、その後ろから弓を射る。矢はや座。
- 近づかれると走るか跳び退いて距離を取り、自機との間に矢を降らせて壁を作る。走る速さは自機の高速移動より遅く、突進で届く。
- 攻撃は遠距離が中心。守りの群れと矢の間を一筆で突き抜け、本体に届かせる。
- 第2形態では帆を張って壁の後ろから走り出し、自機のまわりを回りながら射る。

## 2. 戦闘の進行

| 形態 | 内容 |
|---|---|
| 第1形態 | 距離を取りながら、速射の矢・貫く強弓・矢の雨・降り注ぐ矢（追いかける）を使い、大技に一斉射撃を使う。近づかれると離脱と跳び退きで距離を取り、正面に来られると前脚の踏みつけ、背後に回られると背後攻撃を使う |
| 第2形態 | HPが決めた割合を切ると、今の技を終えて待機へ戻ったところで、決めた時間だけ止まって取り込んだほ座（帆）を広げる。広げると、走る速さが上がり、速射の矢の数・貫く強弓の本数・矢の雨のトレースの回数が増える。降り注ぐ矢（進む先を塞ぐ）と、大技の帆走の連射を加える |

画面外から駆け込み、止まって弓を構えて戦闘を始める。撃破は共通のボス撃破演出と、ほ座の伝説モジュール獲得演出へ渡す。

### 2.1 守る雑魚

- ボス戦中は通常敵を出さず、守る雑魚はケンタウルス座が出す。登場時に決めた数を連れて出る。
- 待機中に守る雑魚が決めた数より少ないと、決めた間隔で1体ずつ自分の後ろへ呼ぶ。技の間は呼ばない。
- 守る雑魚は[敵一覧](../catalog/enemies.md)の行動に従ってボスと自機の間に並ぶ。一斉射撃の矢と貫く強弓の矢は守る雑魚をすり抜ける。
- 帆走の連射の間は、守る雑魚もボスを追って速く走る。走る速さはボスより遅く、個体ごとにばらつかせるので、追いつききれずにばらけて後を追う。

### 2.2 命中・画面・地形

- 全身を1つの命中対象とし、弓と帆も含める。弱点は持たない。被弾と撃破の見せ方は、ほかのボスと同じ共通処理を使う。
- 攻撃は画面内に入ってから予告を始める。画面外へ出たら自機の近くへ戻る。離脱は画面の端で止まり、端に沿って走る。
- 離脱・跳び退き・帆走の途中で惑星・月に当たったときは、表面に沿って回り込む。

## 3. 通常攻撃

| 技 | 分類 | 動作と対処 |
|---|---|---|
| 速射の矢 | 遠距離・点 | 止まって弓を引く予告のあと、矢を一定の間隔で続けて射る。1本ごとに、射る瞬間の[機体の遅れた位置](../../spec.md#75-敵の狙い)を狙う。動き続けて矢の間を抜ける |
| 貫く強弓 | 遠距離・線 | 止まって大きく弓を引き絞る。引き絞りの間は自機の今の位置へ向きを合わせ続け、発射の直前に射線で警告し、発射の瞬間の自機の位置へ太い矢を射る。複数本のときは、真ん中の1本を自機へ向け、残りを左右へ決めた角度ずつ開いて同時に射り、射線の警告も本数だけ示す。太い矢は敵をすり抜け、守りの群れの後ろまで届く。矢が届くまでの間に射線の横へ動くか、矢と矢の間へ抜ける。構えている間と射終わりの硬直が攻めどき |
| 矢の雨 | 遠距離・面 | 止まって空へ射る予告のあと、トレースを決めた回数だけ続けて走らせる。トレースは、円が弧の道すじを滑らかに走った跡の帯で、自機の進む向きの前方から自機の位置を通るように走る。円が通った所には、決めた時間ののちに円の中へ矢が降り始め、さらに決めた時間ののちに着く。着いた矢の円に自機が入ると当たり、1本のトレースで当たるのは1回まで。トレースは1本ごとに、その時の自機の位置と向きから置き直し、走り終えて決めた間隔ののちに次を始める。曲がる向きは1本ごとに左右を入れ替える。トレースの間、ボスは好む距離を保って歩く。帯の横へ抜ける |
| 降り注ぐ矢 | 遠距離・面 | 止まって空へ矢を射上げる予告のあと、矢の落ちる場所に円の予告を出す。円の内側は縮みながら満ち、満ちきると矢が降る。降っている間に円へ入ると当たる（被弾後の無敵の間は当たらない）。置き方は[3.1](#31-降り注ぐ矢の置き方)の3つ。円の外へ出るか、列の切れ目を抜ける |
| 前脚の踏みつけ | 近距離・面 | 自機が正面の決めた範囲にいると、止まって前脚を高く上げる予告のあと、踏み下ろして前方の扇の範囲に衝撃を出す。1回の攻撃で1回だけ当たる。扇の外へ抜けるか、踏み下ろした後の停止を攻める。動作の見た目は未決 |
| 背後攻撃 | 近距離・面 | 自機が背後の決めた範囲へ回ると、背中を向けたまま止まり、体を赤く明滅させて構える。構えのあと決めた時間だけ、背中の後ろの円に当たりが有効になり、1回の攻撃で1回だけ当たる。背後にとどまらず、貫いて抜ける。動作の見た目は未決 |

速射の矢と貫く強弓の矢は光の矢（`scripts/attacks/light_arrow.gd`）で飛び、惑星・月で止まる。貫く強弓は光の矢のコズミック色で描く。矢の雨と降り注ぐ矢は地形に関わらず降り、敵には当たらない。

### 3.1 降り注ぐ矢の置き方

| 置き方 | 使う形態 | 置く場所と降らせ方 |
|---|---|---|
| 追いかける | 第1形態から | 決めた間隔で、自機の今の速さと向きから決めた時間後にいる位置へ、円を1つずつ置く。決めた数だけ置き、各円は短い時間だけ降る |
| ボスへの道を塞ぐ | 第1形態から | ボスと自機を結ぶ線の上、ボスから距離の決めた割合（上限と下限あり）の所に、その線と直角な列で円を並べる。真ん中から外へ順に降らせ、各円は長く降り続けて壁になる |
| 進む先を塞ぐ | 第2形態から | 射上げた時の自機の進む先の決めた距離に、進む向きと直角な列で円を並べる。端から順に降らせ、各円は長く降り続けて壁になる |

## 4. 大技

大技の後は攻めどきを作る。

### 4.1 一斉射撃

止まって弓を引き絞る予告のあと、矢を扇形にまとめて射る。扇は射る瞬間の自機の遅れた位置を中心にし、決めた本数を決めた角度の範囲へ等間隔に並べる。決めた間隔で決めた回数射り、毎回その時の自機の遅れた位置を中心に置き直す。矢の当たり判定は遅く進む長い線で、見た目は光の矢とする。矢は守る雑魚をすり抜け、惑星・月で止まる。

扇なので、ボスに近いほど矢の間隔が狭い。離れて広い隙間で避けるか、狭い隙間を通って射ているボスを貫くかを選ばせる。射ている間は止まっていて、射終わりに硬直する。

### 4.2 帆走の連射（第2形態）

止まって、これから走る向きへ体を向け、帆を張る。帆がふくらみきると走り出す。走る向きは体の向きで示し、道すじの線は出さない。

帆を張った時の自機の位置を中心に、決めた角度の弧を決めた時間で走る。弧の半径は、その時の自機との距離を決めた範囲に収めた値とし、帆を張る間に弧の上へ寄る。回る向きは使うたびに入れ替える。走りながら決めた間隔で矢を射り、1本ごとに射る瞬間の自機の遅れた位置へ向ける（追尾しない）。矢の当たり判定は遅く進む長い線で、見た目は光の矢とする。

走っている間、ボスは守る雑魚の壁から離れる。弧の先へ一筆を描いて、走ってくるボスを貫く。走り終えると帆をたたんで止まる（攻めどき）。

## 5. 攻めどきと行動判断の要件

### 5.1 状態の区別

| 状態 | 意味と扱い |
|---|---|
| 待機 | 好む距離を保って歩き、自機の方を向く。条件を満たした技を共通フローが選ぶ |
| 攻撃中 | 止まって予告・発射前の警告・発射を進める。矢の雨は予告のあと、トレースが終わるまで歩きながら続ける。背後攻撃は向き直らずに構える |
| 引き絞り | 貫く強弓と一斉射撃の構え。止まっていて、攻める対象になる |
| 硬直 | 射終わりと踏みつけの後に止まる。攻める対象になる |
| 帆を広げる | 第2形態への移行で止まる。攻める対象になる |
| 離脱 | 走って距離を取る。終わると止まって向き直る |
| 跳び退き | 後ろへ一気に跳ぶ。着地するとすぐ降り注ぐ矢（ボスへの道を塞ぐ）へ進む |
| 帆走 | 帆走の連射で弧を走る。攻める対象になる |
| 息を整える | 大技の後に止まる。攻める対象になる |

### 5.2 攻撃の流れ

いっかくじゅう座と同じく、区間を「牽制 → 圧力 → 大技 → 反撃の間」の順に回す。

| 区間 | 使う技 |
|---|---|
| 牽制 | 速射の矢・貫く強弓・矢の雨・降り注ぐ矢（追いかける）を単発で使う |
| 圧力 | 降り注ぐ矢や矢の雨で動かした先を、貫く強弓や速射の矢で狙う組み合わせを使う |
| 大技 | 第1形態は一斉射撃、第2形態は一斉射撃か帆走の連射 |
| 反撃の間 | 止まる |

次の行動は区間に関係なく、条件を満たしたときに使う。

| 条件 | 行動 |
|---|---|
| 自機が近づいた | 自機を向いたまま短く後ろへ跳んで離脱し、着地から降り注ぐ矢（ボスへの道を塞ぐ）へつなぐ。さらに近い距離では跳び退きの再使用待ちで判断する |
| 自機が正面の近くにいる | 前脚の踏みつけ |
| 自機が背後に回った | 背後攻撃 |
| 第2形態で、自機がボスのまわりを横切るように動き続けた | 降り注ぐ矢（進む先を塞ぐ）。自機の進む向きとボスへの向きがほぼ直角で、決めた距離の範囲にいる状態が決めた時間続いたときに使う |

### 5.3 共通ルール

- 待機中に自機が近づくと、自機を向いたまま素早く後ろへ跳ぶ。離脱にも跳び退きの距離・時間を使い、着地から矢の壁へつなぐ。離脱と壁の再使用待ちが終わっているときに行う。攻撃中・硬直中は離脱せず、背後攻撃を選べる間は背後攻撃を優先する。
- 待機中は、自機から決めた範囲の距離を保つ。近くに守る雑魚が一定数以上集まっていると、自機から見てその集まりの側へ回る。
- 背後攻撃と前脚の踏みつけの発動条件は、自機の今の位置で測る。ほかの技は共通の遅延照準で測る。
- 跳び退き・ボスへの道を塞ぐ・進む先を塞ぐは、それぞれ再使用待ちを持つ。

### 6.2 ポーズ・アニメーションの編集

`scenes/bosses/centaurus_parts_preview.tscn` をGodotで開き、F6でポーズ・アニメーション編集画面を開く。`centaurus_parts.tscn` を単独実行しても同じ画面を開く。画像のクリックまたは一覧で部位を選び、ドラッグ・位置・回転・拡大率・重なり順・表示状態を編集する。プレビュー上のマウスホイールで表示倍率を変え、中ドラッグまたはSpace＋左ドラッグで視点を移動する。「視点・倍率をリセット」で表示を中央へ戻す。設定欄とコマ操作欄では各欄のスクロールを優先する。肩と肘を親子の支点として動かし、Base・Armor・法線をまとめて追従させる。部位の重なり順を編集しても全BaseをArmorの下へ描く。弓はBase・Rotate Bow・Bow Upの差分を部位の選択欄から切り替える。Rotate Bowは横向きから幅を縮めて縦向きへ至る回転順に並べ、画像差分を切り替えても握り位置を保つ。既存のコマの差分番号を保持し、弓法線は各差分の透過形状と一致させる。パーツの複製とプロジェクト内PNGの追加にも対応する。追加パーツは作成した姿勢で表示し、ほかの姿勢では表示を切り替えて使う。

「腕の操作」の「関節位置を設定」で右腕・左腕を選び、肩・肘・手首・握りの目印をドラッグして接続点を決める。設定中は絵の配置を保ち、接続点を全ポーズ・コマで共用する。「関節を動かす（握りはIK）」では肩をドラッグして腕全体を移動し、肘で肩を中心にした上腕、手首で肘を中心にした前腕の向きを変える。握りのドラッグは腕全体のIKを使う。いずれも接続と腕の長さを保つ。肩・肘・手首の数値で支点を中心に回転し、肘の曲がる向きを反転できる。接続状態はポーズ・コマごとに持ち、既存の姿勢は手先操作か接続チェックを有効にしたコマから接続する。

頭は内部パス `LowerBody` を保持し、一覧では「頭（LowerBody）」と表示する。頭の回転支点は上端中央を初期位置とする。頭などの部位を選んで「支点を固定して回転」を有効にし、「支点の位置を編集」で首元などへ置く。支点編集をOFFにすると、絵または回転ハンドルのドラッグと回転の数値変更で、支点の位置を保って回す。支点の部位内座標は全ポーズで共用し、各コマは親座標系の支点位置を保存する。支点設定時に既存のコマの絵の配置を保ち、コマ間の補間でも支点位置を基準に変形する。腕と弓は専用の接続操作を使う。

「手に接続する弓」で本来の弓または複製した弓を選び、選択中の腕の握り位置へ接続する。弓の差分を切り替えても握り位置を保つ。接続中の弓を通常の部位編集で動かすと、手からの相対位置・回転をそのコマに保存する。接続解除後も現在の見た目を保つ。コマ間を補間するときも、接続中の腕の肘・手首と弓の握り位置を補正する。

「基礎ポーズを編集」で姿勢を用意し、名前を入力して別の基礎ポーズとして追加する。「基本姿勢」は通常時の基準とする。動作を選ぶと画面下にコマの一覧が開く。「基礎ポーズをこのコマに適用」で姿勢を取り込み、コマの複製・削除・並べ替えと表示時間を編集する。取り込んだ姿勢はコマごとに独立して編集できる。「構え・引き絞り」の最初のコマは攻撃開始時の姿勢を持ち、通常・待機の姿勢は別に編集する。基礎ポーズの変更を既存のコマへ反映するには、そのコマへ再度適用する。補間を有効にしたコマは、位置・回転・拡大率を次のコマへつなぐ。表示状態と弓の差分はコマの境界で切り替える。

通常・待機、射撃の構え・引き絞り、発射・引き直し、戻し、矢の雨の構え・発射中・戻しを個別に編集・再生する。通常と矢の雨の発射中は繰り返し、構えは技の予告時間、射撃の発射・引き直しは矢の間隔へコマの時間比率を保って合わせる。技の性能と発射時刻は技データを正とする。初期のコマは配置済みの姿勢と弓の差分を持ち、腕・脚の手付けは制作対象とする。

「すべて保存」で `data/visuals/centaurus_animation.tres` に全ポーズ・コマ・追加パーツ・関節設定を保存する。保存先が外部で更新されている場合は上書きを止める。保存後は戦闘を起動し直して同じデータを表示へ反映する。部位の基準シーンは `centaurus_parts.tscn`、元画像は `assets/pixel/centaurus/centaurus_source.aseprite`、書き出しは `tools/art/export_centaurus.lua` とする。箱と参考画像を除き、各部位をBaseとArmorの両方を含む範囲で切り出す。装甲と金色の弓の法線はパーツの回転・左右反転へ追従する。

貫く強弓の引き絞りは自機への射線を細く示し、発射前の警告で矢の太さの赤い射線に変える。硬直中は縁を青く光らせる。第2形態では馬の背から帆を広げ、四隅の星を瞬かせる。移行中は光の輪を広げる。背後攻撃の構えの間は体全体を赤く明滅させ、当たりが有効な間は赤く光らせ続ける。攻撃範囲の円は敵・ルート実験場の攻撃範囲の表示で描く。

矢の雨は、まだ矢が着いていない帯を薄い色と縁の線で描き、走っている円を輪で描く。帯は円の走りに合わせて伸び、矢が着いた所から消える。矢は着弾点から画面の上方向へずらした位置から、落ちるほど速く下りて着き、同じ間に透明から不透明へキリっと変わる。着いた矢は決めた時間だけ刺さって残り、短く消える。

`scenes/bosses/centaurus_presentation.tscn` を差し替えて、役者の `presentation_scene` に指定する。シーンは `bind_centaurus(actor)` で以下を接続する。

- `presentation_event`：登場、第2形態への移行、予告、発射前の警告、発射、矢の雨の開始と各トレースの開始、背後攻撃の当たりの開始、硬直、離脱、被弾、撃破、制限時間演出、守る雑魚の補充（`guard_called`）、降り注ぐ矢の射上げ・円の出現・降り始め（`shower_launched`・`shower_mark`・`shower_landed`）、跳び退きと着地（`leap`・`leap_landed`）、踏みつけの予告と当たり（`stomp_windup`・`stomp`）、一斉射撃の予告と各発射（`fan_windup`・`fan_released`）。`cue`・`technique`・`phase`・`mode`・`position`・`angle`・`world_time` を渡す。
- `presentation_advanced`：世界時間の進行。停止中はアニメーションも止まる。

表現の方針：

- 半人半馬の体、弓、や座の矢、取り込んだほ座（帆）の部品を描く。
- 走る・止まる・向き直る・弓を引き絞るを、連続した動作として見せる。
- 第2形態への移行で、帆を広げるアニメーションを入れる。
- エフェクトはシェーダーを使い、ピクセルアートらしい輪郭・色の階調・粒子の見え方を持つ表現にする。

## 7. 実装・調整・接続

- 降り注ぐ矢は `techniques/arrow_shower.gd` と `centaurus_moves/shower_chase.tres`・`shower_wall.tres`、踏みつけは `techniques/stomp.gd` と `centaurus_moves/stomp.tres`、一斉射撃は `techniques/fan_volley.gd` と `centaurus_moves/fan_volley.tres` に置く。技スクリプトの基点は `scripts/bosses/centaurus/`、保存値の基点は `data/bosses/`。
- 連携は `scripts/bosses/centaurus/techniques/combo_shower_shot.gd`・`combo_rain_volley.gd` と、同じIDの `data/bosses/centaurus_moves/*.tres` に置く。
- 追加技の見た目は `scenes/bosses/centaurus/arrow_shower_visual.tscn`・`stomp_visual.tscn`・`fan_volley_visual.tscn` と `scripts/bosses/centaurus/additional_technique_visual.gd`、ポーズの差し替え口は `data/visuals/centaurus_animation.tres` に置く。

技の動きと公開値は `scripts/bosses/centaurus/techniques/`、技の見た目は `scenes/bosses/centaurus/`、保存値は `data/bosses/centaurus_moves/` に置く。追加・名前・見た目の操作は[ボスAIの操作ガイド](../../dev/tools/boss-ai.md#技を追加名前と見た目を変える)、共通の構成は[設計書](../../architecture.md#61-敵とボスの-ai)を参照する。

- 本体の数値（HP・装甲・歩く速さ・旋回・好む距離・離脱・位置取り・跳び退きの発動距離と跳ぶ距離・時間・再使用待ち、連れて出る守る雑魚の数・呼ぶ間隔・帆走の間の守る雑魚の速さとばらつき、第2形態へ移るHPの割合と帆を広げる時間）の正は [`speed/data/bosses/centaurus.tres`](../../../speed/data/bosses/centaurus.tres)、技別の性能（予告・矢の数と間隔・速さ・半径・射程・ダメージ・硬直・再使用待ち、強弓の本数と矢どうしの角度・発射前の警告の時間、矢の雨のトレースの回数・前方への距離・円の半径・長さ・速さ・曲がり具合・間隔、円が通ってから矢を落とし始めるまでの時間、矢を落とす間隔と数、降りる時間・不透明になる時間・降りる高さ・刺さって残る時間、背後攻撃の背中から範囲の中心までの距離・範囲の半径・当たりが有効な時間、降り注ぐ矢の置き方ごとの円の数・間隔・半径・予告の時間・降り続ける時間・置く距離と割合、一斉射撃の本数・扇の角度・回数・間隔・矢の速さと長さ、帆走の連射の弧の角度・走る時間・半径の範囲・射る間隔・矢の速さと長さ、前脚の踏みつけの範囲・予告・停止、進む先を塞ぐ発動条件の角度・距離・時間、各技の再使用待ち）は [`centaurus_moves/`](../../../speed/data/bosses/centaurus_moves/) とする。第2形態の値は、同じファイルの同じ名前に `_p2` を付けた項目に置き、第2形態では置いた項目だけを置き換える。「ボス行動」画面では、その項目の名前に「（第2形態）」を添えて示す。どれも試遊調整用の仮値。`use_def_stats` を有効にしてHP・装甲を専用データから読み、共通の敵HP・装甲倍率を掛ける。
- 技の選択は共通フローで行う。`ai/centaurus_flow.tres` が区間・消費上限・共有スタミナ・休息を、`ai/centaurus_action_rules.tres` が技ごとの距離条件と消費を持つ。「ボス行動」画面のボスの選択に、ケンタウルス座がある。
- `centaurus_boss_timeline.tres` の `attack` は、発射前の警告・発射・終了、矢の雨の開始、背後攻撃の当たりの開始のメソッドトラックを持つ。役者ごとに複製し、技の開始時に専用データの時間へ合わせて手動更新する。制限時間の一撃は `boss_final_strike.gd` の共通演出を使う。
- ステージ2の `boss_id` が `centaurus` を参照し、`boss_time` の時刻に登場する。撃破を最終勝利の接続点とし、共通のボス撃破演出と伝説モジュール（`legendary_sail`）獲得演出へ渡す。
- `gyms/centaurus_trial.tscn` をF6で起動すると、敵・ルート実験場がステージ2の設定で開き、ケンタウルス座と守る雑魚を置いた試遊ができる。シーンのInspectorで、開始位置・無敵・試遊用の攻撃倍率・守る雑魚の数・繰り返す技・第2形態から始めるかを変える。役者の `lab_ranges()` が返す攻撃範囲を、実験場の攻撃範囲の表示が描く。ボスを選ぶと、構えていない間の背後攻撃の範囲も描く。実験場の配置からも `centaurus` を置ける。
