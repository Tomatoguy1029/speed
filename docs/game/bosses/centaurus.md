# ケンタウルス座の仕様

ステージ2のボス、ケンタウルス座の戦闘・行動判断の要件・素材と演出の雛形を定義する。1章の核に沿って、2章以降の進行・技・攻めどき・演出を制作者が決める。2章以降に挙げる内容は例で、技の中身と数・形態の数は変えてよい。

ステージでの位置づけは [ステージ2](../stages/stage-2.md#4-ボス戦)、実装状況は [敵一覧](../catalog/enemies.md)、設定の元ネタは [世界観](../world.md#ケンタウルス座--ほ座)、敵とボスの考え方は [設計の進め方](../../dev/stage-production.md#4-敵とボスを設計する)、役者・BT・演出の編集方法は [設計書 6.1](../../architecture.md#61-敵とボスの-ai) を参照する。

## 1. 狙う体験と攻撃の整理

- 守りの群れの奥から弓を射る。矢はや座。
- 近づくと走って距離を取る。走る速さは自機の高速移動より遅く、突進で届く。
- 攻撃は遠距離が中心。守りの群れと矢ごと一筆で突き抜け、本体に届かせる。

## 2. 戦闘の進行（例）

| 形態 | 内容 |
|---|---|
| 第1形態 | 距離を取りながら弓を射る |
| 第2形態 | HPが半分を切ると、取り込んだほ座（帆）を広げる。走る速さが上がり、矢の数が増える |

撃破は共通のボス撃破演出と、ほ座の伝説モジュール獲得演出へ渡す。ボス戦中も通常敵が出現する。

## 3. 通常攻撃（例）

| 技 | 分類 | 動作と対処 |
|---|---|---|
| 速射の矢 | 遠距離・点 | 弓を引いて自機を狙い、矢を続けて射る。矢の間を抜ける |
| 貫く強弓 | 遠距離・線 | 止まって大きく弓を引き絞り、守りの群れごと貫く太い矢を射る。射線から外れ、構えている間に攻める |
| 矢の雨 | 遠距離・面 | 空へ矢を放ち、落ちる場所を影で見せてから降らせる。影の外へ抜ける |
| 後ろ脚の蹴り | 近距離・面 | 背後に回った自機を後ろ脚で蹴る。背後にとどまらず、貫いて抜ける |

## 4. 大技（例）

大技は複数用意する。大技の後は攻めどきを作る。

### 4.1 一斉射撃

守る雑魚の列を前に並ばせ、その後ろから広い範囲に矢の雨を降らせる。列と矢の雨の切れ目を一筆で突き抜け、本体まで届かせる。

### 4.2 走りながらの連射（第2形態）

自機のまわりを大きく回るように走りながら、矢を射続ける。矢の切れ目から飛び込む。走り終えると止まって息を整える。

## 5. 攻めどきと行動判断の要件（例）

### 5.1 状態の区別

| 状態 | 意味と扱い |
|---|---|
| 攻撃可能 | 距離・向き・再使用待ち時間などの条件を満たせば行動できる |
| 攻撃中 | 予告・狙い固定・実行を進める |
| 引き絞り | 貫く強弓の構え。止まっていて、攻める対象になる |
| 離脱 | 走って距離を取る。終わると向き直る |
| 息を整える | 大技の後に止まる。攻める対象になる |

### 5.2 共通ルール

- 自機が近づくと走って距離を取り、離れたら射る。
- 守る雑魚が並んでいる側から射るように位置を取る。
- 背後に回った自機には後ろ脚の蹴りを使う。
- 大技の後は、全体で攻めどきを作る。

## 6. 素材と演出（例）

- 半人半馬の体、弓、や座の矢、取り込んだほ座（帆）の部品を描く。
- 射撃の予告は、弓を引く動作と矢の光で見せる。矢の雨は落ちる場所の影で見せる。
- 走る・止まる・向き直る・弓を引き絞るを、連続した動作として見せる。
- 第2形態への移行で、帆を広げるアニメーションを入れる。
- エフェクトはシェーダーを使い、ピクセルアートらしい輪郭・色の階調・粒子の見え方を持つ表現にする。

## 7. 実装・調整・接続

- 調整値の正は `speed/data/bosses/` の `.tres` とする。
- 段階進行、BehaviorTree、攻撃と判定、素材差し替えの編集方法は [設計書 6.1](../../architecture.md#61-敵とボスの-ai) に従う。
- 撃破を最終勝利の接続点とし、共通のボス撃破演出と伝説モジュール獲得演出へ渡す。
