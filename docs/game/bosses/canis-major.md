# おおいぬ座の仕様

ステージ3のボス、おおいぬ座の戦闘・行動判断の要件・素材と演出を定義する。

ステージでの位置づけは [ステージ3](../stages/stage-3.md#4-ボス戦)、実装状況は [敵一覧](../catalog/enemies.md)、設定の元ネタは [世界観](../world.md#おおいぬ座--りゅうこつ座)、敵とボスの考え方は [設計の進め方](../../dev/stage-production.md#4-敵とボスを設計する)、役者・BT・演出の編集方法は [設計書 6.1](../../architecture.md#61-敵とボスの-ai) を参照する。

## 1. 狙う体験と攻撃の整理

- 猟犬の群れを率いて、群れと一緒に追ってくる。群れは獲物を囲み、足止めし、順に飛びかかる。
- 群れごとボスを一筆で貫くか、群れを崩してボスをむき出しにする。
- 第1形態は群れの狩りで戦う。第2形態ではシリウス（名の由来は「焼き焦がすもの」）が目覚め、青白い炎と強い光の技が加わる。

## 2. 戦闘の進行

| 形態 | 内容 |
|---|---|
| 第1形態 | 猟犬の群れを率いて追ってくる。飛びかかり・号令・順番の号令・吠え立て・追い立てと飛びかかり・呼び声を使い、大技に遠吠えを使う |
| 第2形態 | HPが決めた割合を切ると、今の技を終えて追跡へ戻ったところで、決めた時間だけ止まって口元のシリウスを強く輝かせる。輝かせると、追う速さが上がり、号令の猟犬が速く飛び出して再使用待ちが短くなり、飛びかかりの予告と再使用待ちが短くなる。第1形態の技に、シリウスの光・焼き焦がす光・燃える猟犬・光を継ぐ群れを加え、追い立てと飛びかかりを追い立てと狙撃に置き換え、大技にシリウスの閃光を加える |

群れを連れて画面外から駆け込み、一度吠えてから戦闘を始める。撃破は共通のボス撃破演出と、りゅうこつ座の伝説モジュール獲得演出へ渡す。率いる群れは[ステージ3の猟犬](../stages/stage-3.md#猟犬)を使う。

### 2.1 命中・画面・地形

- ボスは全身を1つの命中対象とし、弱点は持たない。被弾と撃破の見せ方は、ほかのボスと同じ共通処理を使う。
- 攻撃は画面内に入ってから予告を始める。画面外へ出たら自機の近くへ戻る。
- 飛びかかりの途中で惑星・月に当たったときは、その場で着地して止まる。

## 3. 群れの統率

- 登場すると、自分の群れの猟犬を決めた数だけ連れて出る。ボス戦中は通常敵を出さず、猟犬はおおいぬ座が呼び声と技で出す。
- まわりの決めた範囲にいる猟犬を、上限の数まで率いる。猟犬は弱く倒れやすいので、上限は多めに持つ。
- 率いる猟犬を、ボスの前から自機へ向けて広がるくさび形の隊形に並べる。1列目に2体、2列目に3体と、後ろの列ほど1体ずつ増やす。くさびの両端とボスは一直線に並び、群れごとボスを一筆で貫ける。ボスが自機へ近づくと、くさびの先端が自機を越えないよう列の間隔を縮め、群れが自機を包む。
- 隊形の位置は目安とし、猟犬ごとに位置のずれと揺らぎ、速さのばらつきを持たせる。群れは幅を持ったまま追う。
- 隊形の位置から遅れた猟犬は、自分の速さを上限の倍率まで上げて追いつく。率いられている間、猟犬は群れの仲間と向きをそろえず、間隔だけを保つ。噛みつきは通常の猟犬と同じ。
- ボスが光や炎を撃つ技の間は、隊形の真ん中を空けて左右へ寄り、射線に猟犬を入れない。
- 隊形を離れて動く技（吠え立て・燃える猟犬・シリウスの閃光）の間、猟犬は向いている方へだけ走る。曲がる速さと加減速に上限を持ち、持ち場に着くと止まって自機の方へ向き直る。
- 率いられている猟犬は、自機の体当たりを決めた回数受けると倒れる硬さになる。体当たりの基準の強さは、基本の攻撃力に攻撃の倍率と、満タンの突進の倍率（持っていれば）を掛けたもので、クリティカルは含めない。最大HPを、その強さで決めた回数目に倒れる値（強さ ×（回数 − 1）＋ 強さ ÷ 2）まで上げ、元の最大HPより下げない。群れから外れると元の最大HPへ戻す。どちらも今のHPの割合を保つ。
- 率いられている猟犬は見た目を変え、群れに加わっていることを示す。仮表示では色を決めた色に変え、群れから外れると元の色へ戻す。正式な見た目は未決。
- 撃破されると群れを解き、猟犬は通常の群れの追跡へ戻る。

## 4. 群れの技

| 技 | 形態 | 分類 | 動作と対処 |
|---|---|---|---|
| 飛びかかり | 第1形態から | 近距離・点 | 止まって身を低くし、自機の進む先を読んで着地点を決める。跳ぶ少し前に着地点を固定し、その少し先まで一気に跳ぶ。跳んでいる間に本体へ触れると、1回だけ当たる。着地した所で止まる。率いている猟犬が決めた数より少ない間は、決めた回数続けて跳び、2回目からは予告を短くする。横へかわし、着地後に攻める |
| 号令 | 第1形態から | 近距離・点 | 率いている猟犬が決めた数以上いるときに使う。吠える予告のあと、率いている猟犬が一斉に自機の方向へ、最初から全速でまっすぐ飛び出す。飛び出した猟犬に触れると、号令1回で1回だけ当たる。飛び出した猟犬の列を一筆で貫く。終わると猟犬は隊形へ戻る |
| 順番の号令 | 第1形態から | 近距離・点 | 吠える予告のあと、猟犬が1体ずつ白く光り、決めた時間ののちにその時の自機の位置へ全速でまっすぐ飛び出す。次の猟犬は決めた間隔で続く。飛び出した猟犬に触れると、その猟犬1体につき1回当たる。光った猟犬を見て飛び出す向きを読む |
| 吠え立て | 第1形態から | 近距離・点 | 獲物を足止めする猟犬の動き。猟犬が散って自機を遠巻きに囲み、自機に合わせて走りながらゆっくり回る。自機の進む向きの正面側の猟犬は距離を取って吠える（当たり判定なし）。背後側の猟犬は近く寄り、白く光ってから短く噛みつきに飛び込む。噛みつくのは同時に決めた数まで、1体ごとに決めた時間空ける。その間ボスは寄ってきて、決めた時間ののちに飛びかかりで仕留めにかかる。飛びかかりの間も猟犬は囲みと噛みつきを続け、ボスが着地すると隊形へ戻る。向きを変えて背後の猟犬を正面へ回すか、囲みを貫いて抜ける |
| 追い立てと飛びかかり | 第1形態 | 組み合わせ | 順番の号令で猟犬を次々に飛び出させ、最後の1体が出た直後にボスが飛びかかりの構えに入る。着地点は猟犬をよけて動いた先を読んで決める |
| 呼び声 | 第1形態から | — | 率いている猟犬が決めた数より少ないと、短く吠えて、自分の後ろへ決めた数まで猟犬を呼び足す。呼んだ猟犬はボスの群れの番号を持つ |

## 5. シリウスの技（第2形態）

シリウスの光は青白い炎として描く。まっすぐ撃つ光は、白い芯のまわりを青白い炎がゆらいで流れる炎のビームとする。どの光も猟犬などの敵をすり抜け、惑星・月で止まる。ボスが倒れると光も消える。

| 技 | 分類 | 動作と対処 |
|---|---|---|
| シリウスの光 | 近〜中距離・面 | 口元に青白い火を溜め、火の粉をこぼす予告のあと、炎を決めた時間吐き続ける。炎の粒は吐いた時の向きへ速く飛び出し、進むほど遅く・太くなって消える。吐く間、ボスは自機の今の位置へ決めた速さまでで向き直り、離れていれば詰めてくる。炎の粒は吐いた時の向きへ進むので、向き直ると流れが遅れて曲がる。曲がりの内側へ回り込むか、届かない所まで離れる。吐き終わりの硬直が攻めどき |
| 焼き焦がす光 | 遠距離・線 | 炎のビームを決めた回数続けて撃つ。1回ごとに溜めの間は自機の少し先へ向きを合わせ、発射の少し前に固定して射線を示す。ビームが通った跡は焼け跡として決めた時間燃え残り、触れている間は当たる（[残る線](../../spec.md#117-敵の攻撃の形)）。焼け跡で区切られた場所を群れが追ってくる |
| 燃える猟犬 | 近距離・面 | ボスが近い猟犬に口元の火を移す（決めた数）。火のついた猟犬は1回の体当たりで倒れる硬さになり、自機へ走り寄る。近くまで来るか決めた時間が過ぎると止まって明滅し、決めた時間ののちに決めた半径で爆発する。明滅し終わる前に貫けば爆発しない（ステージ3の自爆する雑魚と同じ対処） |
| 光を継ぐ群れ | 遠距離・線 | ボスが止まって吠え、口元のシリウスが強く瞬く。群れの猟犬の体全体がシリウスの色に光る（予告。当たり判定なし）。猟犬は時間をずらして1体ずつ白く強く光り、そのとき自機の今の位置へ向きを決めて止まる。決めた向きに細い線が出て濃くなり、線の上へ炎のビームを吐く。倒した猟犬は吐かない。最後にボスが溜めて炎のビームを撃つ。猟犬を刈ってビームの数を減らしてからボスを狙う |
| 追い立てと狙撃 | 組み合わせ | 順番の号令で猟犬を次々に飛び出させ、最後の1体が出た直後からボスが炎のビームを溜める。溜めの間は自機の少し先へゆっくり向き直り、発射の決めた時間前に固定して撃つ |

## 6. 大技

大技の後は攻めどきを作る。

### 6.1 遠吠え

第1形態から使う（近距離・点）。止まって決めた時間だけ吠えたあと、自機を中心にした輪へ猟犬を並べて囲む。

- 輪には決めた数の猟犬を等間隔に並べ、決めた数か所に、猟犬を決めた数だけ抜いた薄い所を作る。輪の向きは毎回変わる。
- 輪の猟犬は、率いている群れから先に、輪の位置に近い順で使う。足りない分は、輪の外の決めた距離へ新しい猟犬を呼んで補う。1回に呼ぶ数には上限がある。
- 猟犬は輪へ走る間、自分の速さを決めた倍率まで上げる。輪の中心は決めた時間だけ自機を追い、その間に輪を決めた半径まで縮める。
- 中心が止まると、輪の猟犬が輪を回る順に1体ずつ白く光り、決めた時間ののちにその時の自機の位置へ全速でまっすぐ飛び出す。次の猟犬は決めた間隔で続く。飛び出した猟犬に触れると、その猟犬1体につき1回当たる。
- 飛び出した猟犬は群れに戻り、呼んだ猟犬はボスの近くへ来ると群れに加わる。
- 輪を貫いて外へ抜ければ、飛び出しは一方向からだけになる。吠える間と囲む間、ボスは止まっていて、攻めどきになる。

### 6.2 シリウスの閃光（第2形態）

止まって、猟犬を決めた数だけ2体ずつ寄り添わせ、口元のシリウスのまわり決めた数か所に外を向いて立たせる。口元のシリウスを膨らませる（決めた時間）。光源は口元で、光が強まるにつれてまわりが照らされ、寄り添う猟犬の体の後ろにだけ影が伸びる。影の範囲は、口元から見て猟犬の体が光を遮る角度から決める。

最後に画面が白むほど強く光り、光が決めた数の輪になって速く広がる。輪は影の部分だけ欠け、影の中にいれば当たらない。輪は自機の巡航より速いので、光る前に影へ入っておく。影を作る猟犬を倒すと、その影もなくなる。光ったあとは息を整える（攻めどき）。

## 7. 攻めどきと行動判断の要件

### 7.1 状態の区別

| 状態 | 意味と扱い |
|---|---|
| 追跡 | 群れの先頭で、自機の遅れた位置を追う。条件を満たした技を共通フローが選ぶ |
| シリウスを輝かせる | 第2形態への移行で止まる。群れは隊形を保つ。攻める対象になる |
| 攻撃中 | 予告・狙い固定・実行を進める |
| 着地 | 飛びかかりの後に止まる。攻める対象になる |
| 硬直 | 号令・炎・ビームの後に止まる。炎とビームの後は攻める対象になる |
| 遠吠え・閃光の溜め | 吠える間、光を溜める間、止まる。攻める対象になる |
| 息を整える | 大技の後に止まる。攻める対象になる |

### 7.2 攻撃の流れ

いっかくじゅう座と同じく、区間を「牽制 → 圧力 → 大技 → 反撃の間」の順に回す。

| 区間 | 使う技 |
|---|---|
| 牽制 | 飛びかかり・号令を単発で使う。第2形態はシリウスの光・焼き焦がす光も使う |
| 圧力 | 順番の号令・吠え立て・追い立てと飛びかかり（第2形態は追い立てと狙撃）。第2形態は燃える猟犬・光を継ぐ群れも使う |
| 大技 | 第1形態は遠吠え、第2形態は遠吠えかシリウスの閃光 |
| 反撃の間 | 止まる |

呼び声は区間に関係なく、群れが決めた数より少ないときに使う。群れの数が技の条件に足りないときは、その技の前に呼び声を使う。

### 7.3 共通ルール

- 群れと一緒に自機を追う。号令で群れが一列になって走る瞬間を作り、ボスごと貫ける場面を作る。
- 群れが減ると、ボスが自分で飛びかかる回数を増やす。
- 呼び声と遠吠えで1回に呼ぶ猟犬の数に上限を持たせる。
- ボスが光や炎を撃つ間は、隊形の真ん中を空ける。

## 8. 素材と演出

### 8.1 技ごとのポーズと演出

絵担当には、基本の絵と次の動作のポーズを依頼する。エフェクトはシェーダーで描く。猟犬は見下ろしで小さく映るので、猟犬の予告は体全体の光り方と色で示す。

| 動作 | ポーズ・動き | エフェクト |
|---|---|---|
| 登場 | 群れを連れて駆け込み、止まって一度吠える | 口元から広がる輪 |
| 追跡 | 群れの先頭で走る。脚を振る | 口元のシリウスが小さく瞬く |
| 飛びかかり | 胴を短く太くして脚を開き、身を低くする。跳ぶ間は胴を伸ばす。着地して止まる | 着地点までの線と着地点の輪 |
| 号令・順番の号令・呼び声 | 吠える | 口元から広がる輪。飛び出す猟犬の赤い光と軌跡、順に光る猟犬の白い光 |
| 吠え立て | 群れを散らすように吠え、寄ってきて飛びかかる | 吠える猟犬の小さな輪、噛みつく猟犬の白い光 |
| 遠吠え | 首を上げて長く吠える | 口元から大きな弧の輪 |
| シリウスを輝かせる（第2形態への移行） | 止まって口元を強く輝かせる | シリウスの暈と十字の光芒、広がる光の輪 |
| シリウスの光 | 口元に火を溜めて、炎を吐き続けながら向き直る | 青白い炎の粒の流れ、火の粉 |
| 焼き焦がす光・追い立てと狙撃・光を継ぐ群れの締め | 口元に光を溜めて撃つ | 炎のビーム、射線の予告、焼け跡の燃え残り |
| 燃える猟犬 | 口元の火を猟犬へ移す | 火のついた猟犬の炎と火の粉、明滅、爆発 |
| 光を継ぐ群れ | 吠えて口元を瞬かせる | 猟犬の体の光、猟犬の予告線と炎のビーム |
| シリウスの閃光 | 止まって口元のシリウスを膨らませる | まわりを照らす光と猟犬の影、画面が白む閃光、影で欠ける光の輪 |
| 息を整える・硬直 | 止まって息を整える | 縁の青い光 |
| 被弾・撃破 | 共通処理に合わせた被弾と撃破 | — |

### 8.2 絵の組み込みと表示の接続

`assets/pixel/canis_major/wolf_source.aseprite` の頭・胴体・前脚・後脚・尾を組み込み、脚は左右へ複製して4本とする。`tools/art/export_canis_major.lua` は各部位のBase・Armor・金色のレイヤーを制作時に合成し、参考レイヤーを除いてPNGへ書き出す。青い装甲と金色の部分には、色数を限定した平面状の生成法線を適用する。制作時に `tools/art/generate_canis_major_normals.py` で装甲片を大きな面へ分け、通常画像と同じサイズの法線を生成する。`wolf_with_normals_planar.aseprite` は元レイヤーを保持し、非表示の法線グループを追加した編集用コピーとする。左右反転した脚は法線のX方向も反転する。`scenes/bosses/canis_major_parts.tscn` は頭と胴体の元の重なりを保ち、下向きの絵を戦闘方向へ向ける。走る間は対角の脚を振り、尾を小さく動かす。口元のシリウスは `star`・`large_star` の画像を使う。輪郭を拡大せず、明るさを段階的に切り替え、ときどき数度だけ向きを揺らす。通常は小さい星を表示し、溜め・合図・第2形態では大きい星を重ねる。星と同じ1〜2画素の光粒を少数出し、溜め中だけ内側へ集める。星の書き出しは `tools/art/export_canis_major_stars.lua` とする。飛びかかりの構えでは、胴を短く太くして脚を開き、身を低くする。着地点までの線と着地点の輪を描き、着地点が固定されると赤くする。跳んでいる間は胴を伸ばす。号令の構えでは、シリウスを強く瞬かせ、口元から輪を広げる。号令で飛び出している猟犬は、体のまわりを赤く光らせ、後ろに短い赤い軌跡を引く。シリウスの光の溜めでは、口元の光を大きくしながら射線を細く示し、向きが固定されると光の太さの赤い線に変える。光は白に近い水色で、先端を丸く描き、消える直前に短く薄れる。着地の後と号令の後の硬直中は、縁を青く光らせる。遠吠えの間は、口元から前へ大きな弧の輪を次々に広げる。遠吠えの囲みの間は、自機のまわりに今の囲みの半径を薄い円で示す。第2形態では大きい星の重なりと光粒の数を増やし、移行中は段階的に強める。飛びかかりの着地点と跳んでいる本体の範囲は、敵・ルート実験場の攻撃範囲の表示でも描く。

`scenes/bosses/canis_major_presentation.tscn` を差し替えて、役者の `presentation_scene` に指定する。シーンは `bind_canis_major(actor)` で以下を接続する。

- `presentation_event`：登場、第2形態への移行、予告、遠吠えの囲みの開始、着地点や向きの固定、飛びかかり、号令、順番の号令と吠え立ての猟犬ごとの予告、呼び声、シリウスの光（炎）と炎のビームの溜め・発射、燃える猟犬の点火と爆発、光を継ぐ群れの猟犬ごとの予告、シリウスの閃光の溜めと発光、硬直、被弾、撃破、制限時間演出。`cue`・`technique`・`phase`・`mode`・`position`・`angle`・`world_time` を渡す。
- `presentation_advanced`：世界時間の進行。停止中はアニメーションも止まる。

表現の方針：

- 大型の猟犬の体、口元のシリウス、取り込んだりゅうこつ座（竜骨）の部品を描く。
- 走る・飛びかかる・着地する・遠吠えするを、連続した動作として見せる。
- 第2形態への移行で、シリウスが強く輝くアニメーションを入れる。
- エフェクトはシェーダーを使い、ピクセルアートらしい輪郭・色の階調・粒子の見え方を持つ表現にする。

## 9. 実装・調整・接続

技の動きと公開値は `scripts/bosses/canis_major/techniques/`、技の見た目は `scenes/bosses/canis_major/`、保存値は `data/bosses/canis_major_moves/` に置く。追加・名前・見た目の操作は[ボスAIの操作ガイド](../../dev/tools/boss-ai.md#技を追加名前と見た目を変える)、共通の構成は[設計書](../../architecture.md#61-敵とボスの-ai)を参照する。

- 本体の数値（HP・装甲・追う速さ・旋回、連れて出る猟犬の数、率いる範囲と上限、隊形の列と横の間隔、追いつくときの速さの倍率、率いている猟犬を倒すのに要る体当たりの回数、率いている猟犬の仮表示の色、第2形態へ移るHPの割合・シリウスを輝かせる時間・第2形態の追う速さ、隊形の揺らぎと速さのばらつき、射線を空ける横の幅、隊形を離れて動く猟犬の最高速・旋回・加減速）の正は [`speed/data/bosses/canis_major.tres`](../../../speed/data/bosses/canis_major.tres)、技別の性能（予告・狙いを固定する時間・着地点の先までの距離・跳ぶ時間・猟犬が飛び出す速さと時間・号令に要る猟犬の数、群れが少ないとみなす猟犬の数と群れが少ないときの飛びかかりの再使用待ち、光の長さ・太さ・光を出す時間、遠吠えの囲みの猟犬の数・薄い所の数と抜く数・始めと終わりの半径・並ぶ時間・狭める時間・輪へ走る速さの倍率・呼び足す猟犬の上限と出る距離、順番の号令の光ってから飛び出すまでの時間と間隔、吠え立ての囲む距離・噛みつく猟犬の数と間隔・ボスが飛びかかるまでの時間、呼び声で保つ数、遠吠えの輪の中心が自機を追う時間と飛び出しの間隔、シリウスの光（炎）の溜め・吐く時間・炎の速さと寿命と太さ・向き直りの速さ、焼き焦がす光の回数・焼け跡の時間、燃える猟犬の数・走る速さ・明滅の時間・爆発の半径、光を継ぐ群れの間隔・予告線の時間、追い立ての締めの狙い、シリウスの閃光の猟犬の数と位置・溜め・輪の数と速さと間隔、ダメージ・硬直・再使用待ち）は [`canis_major_moves/`](../../../speed/data/bosses/canis_major_moves/) とする。第2形態の値は、同じファイルの同じ名前に `_p2` を付けた項目に置き、第2形態では置いた項目だけを置き換える。「ボス行動」画面では、その項目の名前に「（第2形態）」を添えて示す。どれも試遊調整用の仮値。`use_def_stats` を有効にしてHP・装甲を専用データから読み、共通の敵HP・装甲倍率を掛ける。
- 技の選択は共通フローで行う。`ai/canis_major_flow.tres` が区間・消費上限・共有スタミナ・休息と単発技と大技の重みを、`ai/canis_major_action_rules.tres` が技ごとの距離条件と消費を持つ。「ボス行動」画面のボスの選択に、おおいぬ座がある。
- `canis_major_boss_timeline.tres` の `attack` は、着地点や向きの固定・技の開始・終了のメソッドトラックを持つ。役者ごとに複製し、技の開始時に専用データの時間へ合わせて手動更新する。制限時間の一撃は `boss_final_strike.gd` の共通演出を使う。
- 率いる猟犬へは、猟犬の行動（`scripts/enemies/hound.gd`）の `follow()` で走る先と期限を渡す。期限が過ぎると、猟犬は通常の群れの追跡へ戻る。
- ステージ3の `boss_id` が `canis_major` を参照し、`boss_time` の時刻に登場する。撃破を最終勝利の接続点とし、共通のボス撃破演出と伝説モジュール（`legendary_keel`）獲得演出へ渡す。
- `gyms/canis_major_trial.tscn` をF6で起動すると、敵・ルート実験場がステージ3の設定で開き、おおいぬ座と群れを置いた試遊ができる。シーンのInspectorで、開始位置・無敵・試遊用の攻撃倍率・追加で置く猟犬の群れの数・繰り返す技・第2形態から始めるかを変える。実験場の配置からも `canis_major` を置ける。
