# おおいぬ座の仕様

ステージ3のボス、おおいぬ座の戦闘・行動判断の要件・素材と演出の雛形を定義する。1章の核に沿って、2章以降の進行・技・攻めどき・演出を制作者が決める。2章以降に挙げる内容は例で、技の中身と数・形態の数は変えてよい。

ステージでの位置づけは [ステージ3](../stages/stage-3.md#4-ボス戦)、実装状況は [敵一覧](../catalog/enemies.md)、設定の元ネタは [世界観](../world.md#おおいぬ座--りゅうこつ座)、敵とボスの考え方は [設計の進め方](../../dev/stage-production.md#4-敵とボスを設計する)、役者・BT・演出の編集方法は [設計書 6.1](../../architecture.md#61-敵とボスの-ai) を参照する。

## 1. 狙う体験と攻撃の整理

- 猟犬の群れを率いて、群れと一緒に追ってくる。
- ボスと群れが一体になって追ってきて、まわりを囲む。
- 群れごとボスを一筆で貫くか、群れを崩してボスをむき出しにする。

## 2. 戦闘の進行（例）

| 形態 | 内容 |
|---|---|
| 第1形態 | 猟犬の群れを率いて追ってくる。群れに号令して攻めさせる |
| 第2形態 | HPが半分を切ると、口元のシリウスが強く輝く。群れが減ると自分で飛びかかってくる |

撃破は共通のボス撃破演出と、りゅうこつ座の伝説モジュール獲得演出へ渡す。ボス戦中も通常敵が出現する。率いる群れは[ステージ3の猟犬](../stages/stage-3.md#猟犬)を使う。

## 3. 通常攻撃（例）

| 技 | 分類 | 動作と対処 |
|---|---|---|
| 飛びかかり | 近距離・点 | 身を低くしてから、自機へ飛びかかる。着地した所で止まる。横へかわし、着地後に攻める |
| 号令 | 近距離・点 | 吠えて、まわりの猟犬を一斉に飛びかからせる。飛びかかった猟犬の列を一筆で貫く |
| シリウスの光 | 遠距離・線 | 口元に光を溜めてから、まっすぐ焼き払う光を吐く。射線から外れる |

## 4. 大技（例）

大技は複数用意する。大技の後は攻めどきを作る。

### 4.1 遠吠え

遠吠えで新しい猟犬の群れを呼び、四方から囲ませる（近距離・面）。囲みが閉じる前に、群れの薄い所から突き抜ける。遠吠えの間、ボスは止まる。

### 4.2 焼き払いの疾走（第2形態）

シリウスの光で通った跡を焼きながら、場を走り回る（近距離・面）。焼けた跡は少しの間残る。走り終えると止まって息を整える。

## 5. 攻めどきと行動判断の要件（例）

### 5.1 状態の区別

| 状態 | 意味と扱い |
|---|---|
| 攻撃可能 | 距離・向き・再使用待ち時間・群れの数などの条件を満たせば行動できる |
| 攻撃中 | 予告・狙い固定・実行を進める |
| 着地 | 飛びかかりの後に止まる。攻める対象になる |
| 遠吠え | 群れを呼ぶ間、止まる。攻める対象になる |
| 息を整える | 大技の後に止まる。攻める対象になる |

### 5.2 共通ルール

- 群れと一緒に自機を追う。群れが一列になって走る瞬間を作り、ボスごと貫ける場面を作る。
- 群れが減ると、ボスが自分で飛びかかる回数を増やす。
- 遠吠えで呼ぶ群れの数に上限を持たせる。
- 大技の後は、全体で攻めどきを作る。

## 6. 素材と演出（例）

- 大型の猟犬の体、口元のシリウス、取り込んだりゅうこつ座（竜骨）の部品を描く。
- 飛びかかりの予告は身を低くする動作で、シリウスの光は口元の光の溜まりで見せる。
- 走る・飛びかかる・着地する・遠吠えするを、連続した動作として見せる。
- 第2形態への移行で、シリウスが強く輝くアニメーションを入れる。
- エフェクトはシェーダーを使い、ピクセルアートらしい輪郭・色の階調・粒子の見え方を持つ表現にする。

## 7. 実装・調整・接続

- 調整値の正は `speed/data/bosses/` の `.tres` とする。
- 段階進行、共通フロー、攻撃と判定、素材差し替えの編集方法は [設計書 6.1](../../architecture.md#61-敵とボスの-ai) に従う。
- 撃破を最終勝利の接続点とし、共通のボス撃破演出と伝説モジュール獲得演出へ渡す。
