# おおいぬ座の仕様

ステージ3のボス、おおいぬ座の戦闘・行動判断の要件・素材と演出を定義する。1章の核に沿って、進行・技・攻めどき・演出を制作者が決める。第1形態の群れの統率・飛びかかり・号令は決まった決まりで、見出しに「例」を付けた内容は雛形の例である。例の技の中身と数・形態の数は変えてよい。

ステージでの位置づけは [ステージ3](../stages/stage-3.md#4-ボス戦)、実装状況は [敵一覧](../catalog/enemies.md)、設定の元ネタは [世界観](../world.md#おおいぬ座--りゅうこつ座)、敵とボスの考え方は [設計の進め方](../../dev/stage-production.md#4-敵とボスを設計する)、役者・BT・演出の編集方法は [設計書 6.1](../../architecture.md#61-敵とボスの-ai) を参照する。

## 1. 狙う体験と攻撃の整理

- 猟犬の群れを率いて、群れと一緒に追ってくる。
- ボスと群れが一体になって追ってきて、まわりを囲む。
- 群れごとボスを一筆で貫くか、群れを崩してボスをむき出しにする。

## 2. 戦闘の進行

| 形態 | 内容 |
|---|---|
| 第1形態 | 猟犬の群れを率いて追ってくる。飛びかかりと、群れへの号令を使う |
| 第2形態（例） | HPが半分を切ると、口元のシリウスが強く輝く。群れが減ると自分で飛びかかってくる |

撃破は共通のボス撃破演出と、りゅうこつ座の伝説モジュール獲得演出へ渡す。ボス戦中も通常敵が出現する。率いる群れは[ステージ3の猟犬](../stages/stage-3.md#猟犬)を使う。

## 3. 群れの統率

- 登場すると、自分の群れの猟犬を決めた数だけ連れて出る。
- まわりの決めた範囲にいる猟犬を、上限の数まで率いる。ステージの通常の猟犬も、範囲へ入ると加わる。猟犬は弱く倒れやすいので、上限は多めに持つ。
- 率いる猟犬を、ボスの前から自機へ向けて広がるくさび形の隊形に並べる。1列目に2体、2列目に3体と、後ろの列ほど1体ずつ増やす。くさびの両端とボスは一直線に並び、群れごとボスを一筆で貫ける。ボスが自機へ近づくと、くさびの先端が自機を越えないよう列の間隔を縮め、群れが自機を包む。
- 隊形の位置から遅れた猟犬は、自分の速さを上限の倍率まで上げて追いつく。率いられている間、猟犬は群れの仲間と向きをそろえず、間隔だけを保つ。噛みつきは通常の猟犬と同じ。
- 撃破されると群れを解き、猟犬は通常の群れの追跡へ戻る。

## 4. 通常攻撃

| 技 | 分類 | 動作と対処 |
|---|---|---|
| 飛びかかり | 近距離・点 | 止まって身を低くし、自機の遅れた位置を追って着地点を決める。跳ぶ少し前に着地点を固定し、その少し先まで一気に跳ぶ。跳んでいる間に本体へ触れると、1回だけ当たる。着地した所で止まる。横へかわし、着地後に攻める |
| 号令 | 近距離・点 | 率いている猟犬が決めた数以上いるときに使う。吠える予告のあと、率いている猟犬が一斉に自機の方向へまっすぐ飛び出す。飛び出した猟犬に触れると、号令1回で1回だけ当たる。飛び出した猟犬の列を一筆で貫く。終わると猟犬は隊形へ戻る |
| シリウスの光（例） | 遠距離・線 | 口元に光を溜めてから、まっすぐ焼き払う光を吐く。射線から外れる |

## 5. 大技（例）

大技は複数用意する。大技の後は攻めどきを作る。

### 5.1 遠吠え

遠吠えで新しい猟犬の群れを呼び、四方から囲ませる（近距離・面）。囲みが閉じる前に、群れの薄い所から突き抜ける。遠吠えの間、ボスは止まる。

### 5.2 焼き払いの疾走（第2形態）

シリウスの光で通った跡を焼きながら、場を走り回る（近距離・面）。焼けた跡は少しの間残る。走り終えると止まって息を整える。

## 6. 攻めどきと行動判断の要件

### 6.1 状態の区別

| 状態 | 意味と扱い |
|---|---|
| 追跡 | 群れの先頭で、自機の遅れた位置を追う。距離・再使用待ち時間・率いている猟犬の数の条件を満たした技を共通フローが選ぶ |
| 攻撃中 | 止まって予告・狙い固定・実行を進める |
| 着地 | 飛びかかりの後に止まる。攻める対象になる |
| 硬直 | 号令の後に短く止まる |
| 遠吠え（例） | 群れを呼ぶ間、止まる。攻める対象になる |
| 息を整える（例） | 大技の後に止まる。攻める対象になる |

### 6.2 共通ルール

- 群れと一緒に自機を追う。号令で群れが一列になって走る瞬間を作り、ボスごと貫ける場面を作る。
- 群れが減ると、ボスが自分で飛びかかる回数を増やす（例）。
- 遠吠えで呼ぶ群れの数に上限を持たせる（例）。
- 大技の後は、全体で攻めどきを作る（例）。

## 7. 素材と演出

仮表示は図形で描く。大型の猟犬の胴・4本の脚・尾・頭・耳・口元を描き、走る間は脚を振る。口元のシリウスは常に小さく瞬く。飛びかかりの構えでは、胴を短く太くして脚を開き、身を低くする。着地点までの線と着地点の輪を描き、着地点が固定されると赤くする。跳んでいる間は胴を伸ばす。号令の構えでは、シリウスを強く瞬かせ、口元から輪を広げる。着地の後と号令の後の硬直中は、縁を青く光らせる。飛びかかりの着地点と跳んでいる本体の範囲は、敵・ルート実験場の攻撃範囲の表示でも描く。

`scenes/bosses/canis_major_presentation.tscn` を差し替えて、役者の `presentation_scene` に指定する。シーンは `bind_canis_major(actor)` で以下を接続する。

- `presentation_event`：登場、予告、着地点の固定、飛びかかり、号令、硬直、被弾、撃破、制限時間演出。`cue`・`technique`・`phase`・`mode`・`position`・`angle`・`world_time` を渡す。
- `presentation_advanced`：世界時間の進行。停止中はアニメーションも止まる。

雛形の例：

- 大型の猟犬の体、口元のシリウス、取り込んだりゅうこつ座（竜骨）の部品を描く。
- シリウスの光は口元の光の溜まりで見せる。
- 走る・飛びかかる・着地する・遠吠えするを、連続した動作として見せる。
- 第2形態への移行で、シリウスが強く輝くアニメーションを入れる。
- エフェクトはシェーダーを使い、ピクセルアートらしい輪郭・色の階調・粒子の見え方を持つ表現にする。

## 8. 実装・調整・接続

- 本体の数値（HP・装甲・追う速さ・旋回、連れて出る猟犬の数、率いる範囲と上限、隊形の列と横の間隔、追いつくときの速さの倍率）の正は [`speed/data/bosses/canis_major.tres`](../../../speed/data/bosses/canis_major.tres)、技別の性能（予告・狙いを固定する時間・着地点の先までの距離・跳ぶ時間・猟犬が飛び出す速さと時間・号令に要る猟犬の数・ダメージ・硬直・再使用待ち）は [`canis_major_moves/`](../../../speed/data/bosses/canis_major_moves/) とする。どれも試遊調整用の仮値。`use_def_stats` を有効にしてHP・装甲を専用データから読み、共通の敵HP・装甲倍率を掛ける。
- 技の選択は共通フローで行う。`ai/canis_major_flow.tres` が区間・消費上限・共有スタミナ・休息を、`ai/canis_major_action_rules.tres` が技ごとの距離条件と消費を持つ。「ボス行動」画面のボスの選択に、おおいぬ座がある。
- `canis_major_boss_timeline.tres` の `attack` は、着地点の固定・飛びかかりと号令の開始・終了のメソッドトラックを持つ。役者ごとに複製し、技の開始時に専用データの時間へ合わせて手動更新する。制限時間の一撃は `boss_final_strike.gd` の共通演出を使う。
- 率いる猟犬へは、猟犬の行動（`scripts/enemies/hound.gd`）の `follow()` で走る先と期限を渡す。期限が過ぎると、猟犬は通常の群れの追跡へ戻る。
- ステージ3の `boss_id` が `canis_major` を参照し、`boss_time` の時刻に登場する。撃破を最終勝利の接続点とし、共通のボス撃破演出と伝説モジュール（`legendary_keel`）獲得演出へ渡す。
- `gyms/canis_major_trial.tscn` をF6で起動すると、敵・ルート実験場がステージ3の設定で開き、おおいぬ座と群れを置いた試遊ができる。シーンのInspectorで、開始位置・無敵・試遊用の攻撃倍率・追加で置く猟犬の群れの数・繰り返す技を変える。実験場の配置からも `canis_major` を置ける。
