# SPEED 企画書

## 1. 概要

『SPEED』は、2D 見下ろし型のサバイバーアクション。プレイヤーは星を目印に星系間を航海するパイロットとなって、星座から生まれたモンスターの大群を、線を描いて駆け抜ける高速移動で吹き飛ばしていく。舞台は星系を行き来する未来の宇宙で、ギリシャ神話の星座をモチーフにしている。

| 項目 | 内容 |
|---|---|
| ジャンル | 2D 見下ろし型のサバイバーアクション（ローグライト要素あり） |
| 人数 | 1人 |
| 構成 | ストーリー（5ステージ）と、ハイスコアを目指すエンドレスモード |
| 対象 | 商用。PC を最優先し、最終的にはスマホとブラウザにも対応する |
| 入力 | PC はマウス、スマホはタッチ |
| 配布 | 最初は Steam。最終的に itch.io とスマホのストアにも出す |

## 2. 体験の目標

**迫り来る敵の大群に、高速移動で立ち向かい、一気に吹き飛ばして圧倒する。脅威を快感に変える。**

ゲームの中身は、次の3つの問いで確かめる。

1. 迫り来る敵の大群に脅威を感じるか
2. 自分の操作による高速移動で立ち向かう手応えがあるか
3. 一気に吹き飛ばして圧倒することで、脅威が快感に変わるか

**デザインの方針**

- ルートを思いついたら、それを楽に入力できるようにする。操作の存在を意識させない。
- うまく大量に倒すと、それが次の攻撃につながる。
- 「計画に工夫の余地がない」「工夫しても報われない」状態をつくらない。
- 高みを目指して実際にたどり着くことを楽しむゲーム。負けは明確に悪く、勝つことが目標。何かを犠牲にして戦う話にはしない。

## 3. 描いて、駆け抜ける

このゲームの中心のアクション。

1. **溜める**：ゲージは時間で溜まる。
2. **描く**：画面の好きな場所をクリックし、マウスを動かすだけで線を描く。描いている間、世界はほとんど止まるほどゆっくりになり、敵の動きを見ながら「どの群れをどう通すか」を考えられる。
3. **駆け抜ける**：もう一度クリックすると、機体は線全体を一瞬（約0.5秒）でなぞる。線上の敵は体当たりで貫かれ、線の周りの敵にも波動が当たる。
4. **勢いが残る**：なぞり終えても速さは落ちず、そのまま群れの中を突き進める。硬い敵に弾かれると止まる。

描く間の集中と、駆け抜ける一瞬の解放。この切り替えが、このゲームの緩急になる。

## 4. ゲームの流れ

```mermaid
flowchart LR
  A[動き回って<br>ゲージを溜める] --> B[線を描く<br>世界はゆっくり]
  B --> C[一瞬で駆け抜ける<br>敵を貫き吹き飛ばす]
  C --> D[経験値を拾う]
  D --> E[レベルアップ<br>3枚から1枚選ぶ]
  E --> A
```

- **1回のラン**：敵の量と強さが時間とともに波を打つ。弱い敵を吹き飛ばして育つ時間、硬い敵に押される時間、1000体を超える弱い群れをまとめて貫く時間を繰り返し、最後に星系の主（ボス）と戦う。
- **ストーリー**：5つの星系を順に進む。4つの星系には主（中ボス）がいて、それぞれの星系に、オデュッセイアの難所を元にした仕掛け（渦・風・光の塊・歌）がある。主を倒すと伝説のモジュールが手に入り、4つそろうとラスボス戦の最後で伝説の機体が完成する。止まった世界で敵を通る線を描きまくり、ラスボスを貫いて決着する。
- **ランの外**：ランで拾った部品で、機体の基礎性能を強化する。

## 5. 成長

- レベルが上がると、3枚のカードから1枚を選ぶ。武器（10種）と特性（14種）を組み合わせて、ラン中にビルドを組み上げる。
- 武器は「進む方向へ撃つ」「体当たりした敵をほかの敵にぶつける」「駆け抜けた線に機雷を残す」「進路ごと衝撃波」など。特性は「線の終点で爆発」「前の線と交わった点で爆発」「クリティカルのたびに前方へ貫くビーム」など、線の描き方に効くものが多い。
- 狙ったビルドを組みやすくするために、ランの最初に武器をランダムな候補から選び、カードはリロールで引き直せる。
- レベルアップで得た力は、星系の主を倒すと星空へ返す（借りていた星の力のため）。ステージごとに一から組み上げる。

## 6. 敵

- 敵は画面の外から絶えず押し寄せ、多いときは画面に1000体を超える。
- 追ってくるもの、構えて突進するもの、距離を取って撃つもの、硬い装甲を持つもの、分裂するもの、機体を遅くするものがいる。
- 攻撃力が敵の装甲に届かないと弾かれる。強くなるほど、貫ける敵が増えていく。

## 7. 判断と葛藤

| 観点 | 内容 |
|---|---|
| 迷うところ | 短い線ですぐ使うか、満タンまで待って硬い敵ごと抜くか。長く描いて多く巻き込むか、硬い敵や地形で止まる危険を避けるか。経験値を拾いに群れへ近づくか、距離を取るか。3択でどれを伸ばすか |
| 自然とやりたくなること | 一筆でできるだけ多く巻き込みたい。硬い敵を貫けるようになりたい |
| 感情の動き | 迫られる圧迫感 → 線を描く集中 → 一気に吹き飛ばす解放感 |

## 8. 世界観と見た目

- 星を目印に航海するパイロットが、星々をモンスターに変えている元凶を追って旅をする。倒したモンスターは元の星に戻る。
- 見た目は航海と星図が軸。取り戻した星が空に戻り、ステージを進めるほど背景が色鮮やかになっていく。
