# SPEED デザインとアートスタイル

## 1. 方向性

ゲーム全体のデザインは**航海と星図**を軸にする。

- 星図・航海図の見た目を土台にする。SF の未来という舞台と組み合わせてよい。
- 製図の器具や、天文学・航海の器具（大航海時代の道具など）を、デザインに組み込む。世界観に合うものだけを使い、詰め込みすぎない。
- 昔の地図はインクとペンで描かれていたので、インクの線やにじみを表現に使う。
- 見やすさを損なう装飾はしない。

イントロのストーリー本文と結果画面の動的な文字は `assets/ui/aseprite_font.tres` を使う。英数字はArial、日本語はYu Gothic UIを明示し、アンチエイリアスとサブピクセル配置を切ってピクセル格子へ合わせる。対象のLabelへフォントを指定し、その他の画面とイントロの操作案内・ボタンは共通テーマのフォントを使う。Windowsのシステムフォントを参照し、日本語フォントを取得できない環境ではOSの代替フォントを使う。

## 3. 画面

### 3.1 ステージの背景

- 背景は星空。星座の絵は描かない。
- 取り戻した星が背景の空に戻り、星雲や天の川が色鮮やかになっていく。いつ変わるかは [仕様書](../spec.md) の2.2。
- 敵や弾が見にくくならない範囲で鮮やかにする。

### 3.2 ワールドマップ（ステージ選択）

- 5つの星系を航路で結んだ海図として描く。
- 古い航海図と古い天球図を組み合わせた見た目にする。星座の絵を地図上に描く。
- ステージの背景と同じく、色鮮やかになっていく。
- 開くときに、地図を広げるような演出を入れる。

### 3.3 ミニマップ

- 見やすさを一番大事にする。円形の星図をオマージュした、レーダーのような画面にする：濃紺の円に、同心円と放射状の細い線、外周に目盛りの付いた円。
- 目印の星の線と英雄の星座は金色で描く。
- 戦闘HUDは独立したゲージ・円形レーダー・左下の装備枠を配置し、戦闘領域の周囲を開ける。装備枠は [combat_ui_components.png](../../speed/assets/ui/combat/combat_ui_components.png) を使う。彗星限定武器は元画像の枠線を赤（`#ff3b4e`）で表示し、輪郭・線幅・寸法・位置と枠内の背景を保つ。
- 戦闘HUDのプレイヤー体力ゲージは緑、残り半分未満で黄、残り10%以下で赤にする。枠は元の水色で表示する。
- 彗星武器の交換画面は、上段中央に通常カードと同じ形・寸法の新武器カードを赤系で置き、下向きの矢印の下に所持武器のアイコンと名前を囲う四角枠4つを並べる。下段の枠と破棄ボタンも既存のカード画像の線・角を使う。背景とHUDを半透明の黒で少し暗くし、選択UIを明るく保つ。
- 表示するものは [仕様書](../spec.md) の17章。

### 3.4 線を描く仕組み（描画・なぞり）

- 製図と絡めた雰囲気にする。

### 3.5 アイコン・エフェクト・画面の切り替え

- 製図の器具や、ペンで書く・消すといった描くことを意識したものにする。無理にすべてに当てはめない。
- インクがにじむ演出を使う。例：ワールドマップからタイトル画面へ戻るときにインクがにじむように消える、Esc でメニューを開いたときににじむように出てくる。

### 終了時のHUD演出

- ステージクリアは、中央の閃光から同心円と二重の菱形が広がり、暗い帯の上に白い文字が収まる。シアンの円弧や目盛りと金色の四芒星を添え、終了時は装飾が外へ分かれ、文字が縦に縮んで消える。
- ゲームオーバーは、白とシアンの文字と走査線を出し、上下から画面を閉じる。中央に残った横線を光点へ縮め、結果画面まで暗転を保つ。

結果画面は `assets/ui/results/` のクリア用・ゲームオーバー用の原画を使う。640×360の絵と焼き込み文字を縦横同じ倍率で拡大し、画面中央へ配置する。記録の数値と取得モジュール名を共通フォントで重ね、原画下部の2つの枠をメニュー・再挑戦のボタンにする。

### 3.6 彗星

- 隕石とは別の見た目。光る核と、進む向きの反対へ長く伸びる尾。
- 通常は青白い手描きの核と青い冷気の尾、レアは金色の核と尾・光の粒で描く。彗星限定の武器のカプセルも金色にする。
- 専用の絵は未決。今は光と尾を描いた仮の見た目。

### 3.7 雷撃

- 雷撃は距離に応じた折れと短い枝を持つピクセル雷で描く。アークフィールドは黄（`#ffcf3a`）の外光と薄い黄白（`#fff8d6`）の芯、敵の落雷は白い芯と白に近い水色（`#e1f7ff`）の枝・周辺光を使う。整数グリッド上のドットで階段状の輪郭を作る。
- ゲーム内のドット幅はカメラのズームに合わせて補正し、画面上の太さを保つ。短い区間は折れと枝を減らす。アークフィールドは実際につながった枝ごとに対象間を結ぶ。
- 放電は弱い発光・強い発光・短い減光・再発光と減衰の順に進み、短い間隔で形を切り替える。各演出の経過時間に合わせて進める。
- 落雷は既存の照準・収束する輪・着弾円を淡い水色で描き、発動時に着弾点の上から雷を落とす。枝と縦の雷は外観の装飾とする。
- 武器プレビューも同じ生成処理を使い、停止中は静止した雷、未入手時はシルエットで表示する。

### クリティカル命中

接触点で小さな白い星状の閃光を出し、黄へ冷める短い光筋・欠ける弧・少数の火花へ素早く抜ける。敵の頭上には小さなピクセル文字の「CRIT」を添える。画面上の大きさをカメラ倍率で保ち、機体と命中した敵の近くに収める。専用のコマ画像と再生値は `data/visuals/critical_hit.tres` が持つ。

### 3.8 導入

640×360の原画の配置を保ち、画面の縦横比に合わせて全体を等倍比で拡大・中央配置する。全場面の絵と星の上に共通のoutlineレイヤーを重ね、原画の表示枠を保つ。各場面の文章は[ゲーム内文言](text.md)の段落を画面下部に表示する。再生の入口と視聴済み保存は[仕様書](../spec.md#3-画面の流れ)に従う。

| 場面 | 見せ方 |
|---|---|
| Scene1 | 航海中のイラストと対応する文章 |
| Scene1-2 | Scene1を残し、scene1-2altの竜をフェードインして文章を切り替える |
| Scene2・Scene3 | 瓦礫の集合、怪物の襲来を順に見せる |
| Scene4 | scene4とscene4_effectsを重ね、戦闘後の機体へ光が宿る場面を見せる |
| Scene5 | scene5に三つの星レイヤーを重ね、文章の後にscene5_stars1、2、3を一枚ずつフェードアウトする |
| Scene6・Scene7 | 銀河の危機、旅立ちを順に見せ、タイトルへ進む |

編集元は `speed/assets/ui/intro/template.aseprite`。制作時に `speed/tools/art/export_intro.lua` で各レイヤーを原寸キャンバスのPNGへ書き出し、再生時は `scripts/ui/intro_story.gd` の固定参照を使う。場面のフェード時間・文字速度・全文表示後の待機時間・星の消える速さは導入シーンのInspectorで調整する。

### 3.9 経験値の結晶

| 種類 | 基調色 |
|---|---|
| 低経験値 `low` | 水色 `#08DEFF` |
| 中経験値 `mid` | 紫 `#945CFF` |
| 高経験値 `high` | 黄色 `#FFB609` |

3種類とも、先端の尖った共通の欠片形に色を満たしたピクセル結晶として描く。三面の整理された明暗と少数の白い反射で澄んだ質感を表す。基調色の面に指定RGBを使い、種類と保持XPにかかわらず通常結晶の共通の基準寸法を保つ。

経験値は背景より手前、通常敵と自前描画する全ボスより奥へ置く。重なった場所は敵の不透明な部分が経験値を隠す。集約先も同じ形・寸法・黄色を使い、保持量の表示は結晶の外観へ加えない。報酬と回収の規則は[共通仕様](../spec.md#10-ドロップと回収)に従う。

### 3.10 ワープホールとボーナスステージ

- ワープホールは、金色の銀河を奥へ続くトンネルとして描く。筒の壁にオレンジとピンクの2本の腕がらせん状に巻きつき、奥のもう1層が違う巻きで回る。金の輪が奥へ流れ、奥ほど暗く、出口だけが金と白に光る。奥の中心がゆっくり揺れて筒が曲がって見える。腕の縁と輪はノイズで崩す。
- 星の粒がらせんを描いて縁から吸い込まれ、縁のまわりで金色の四芒星がときどき光る。出現時は0.6世界秒で開き、消える前の1世界秒は点滅しながら縮む。ドットは機体の絵と同じ大きさにそろえる。
- 機体が触れると、穴が画面中央へ寄りながら広がり、速度の筋とともにトンネルを潜って金白の閃光になる（1.2実秒）。ゲームはこの間も進む。
- ボーナス中の背景は、金とマゼンタの星雲に画面の上の外から柔らかい光の筋が差し、金の粒が上へ流れ、星がまたたく。画面全体に光のにじみ・色収差・周辺減光を掛ける。終わる直前に白く飛ばし、出たあと0.8実秒で通常の画面へ戻す。
- ボーナス中の敵の金色の縁取りと機体の金の軌跡は未実装。

### 4.2 敵

重ねた絵の登録とステージごとの外観指定は[設計書の描画](../architecture.md#10-描画と演出)に従う。

| 対象 | 見た目 |
|---|---|
| 雑魚 | 単純な形状で、星を一つ取り込んでいる |
| 硬めの敵 | 星を2つ取り込んでいる |
| 強敵と大物 | [敵一覧](catalog/enemies.md) の星座と星の数をモチーフにする |

- 取り込んでいる星は、基本的に赤く光る。
- 輪郭で種類を見分けられるようにする。
- その種類の特性を示す主な特徴は一つに絞る。
- 小型の敵ほど細部を減らす。
- 世界観の装飾は控えめにする。

エリートは船体の異なる接点に、黒い縁と赤い芯を持つ短いピクセル状の放電を不規則に走らせる。同時の放電は3本を中心に増減し、少数の火花を接点から散らす。個体ごとの発生時刻をずらし、本体の輪郭・可動部位・変形へ追従させる。目印の星と併存するときは、金色の輪郭オーラへ赤黒い局所放電を重ねる。

自爆型（`bomber`）・ぼうえんきょう座（`telescope`）・レチクル座（`reticle`）・みなみのさんかく座の星（`triangle_star`）・みずがめ座（`aquarius`）・かに座（`crab`）・いるか座（`dolphin`）・かじき座（`marlin`）・みなみのかんむり座（`corona`）・みなみじゅうじ座（`cross`）・わし座（`aquila`）は、`assets/pixel/` 内の各専用フォルダのベース画像に装甲画像を重ね、装甲の法線マップで陰影を付ける。専用フォルダへ追加する敵画像は、画像全体の幅・高さを基準に、自機と共通の `config.character_scale` と、敵データの `visual_settings.scale` によるサイズ倍率を掛けた寸法で描く。当たり判定は敵データの半径を使う。左上からの主光と右下からの補助光を使い、敵の回転に応じて装甲面の明るさを変える。ベースの赤い光と、攻撃・自爆の予告は発光として見せる。装甲片ごとの塗装は元の濃淡と透過を保って色を置き換え、同じ法線画像で陰影を付ける。

やまねこ座（`lynx`）は、元画像の寸法を保ち、Base → Decorations → Armorの順に重ねる。Normalは装甲の法線マップに使う。ディテールは装甲片の塗装時にも元の色を保つ。

噛みつく雑魚（`biter`）の専用外観は、本体と左右の顎を分け、構える間に少し開き、素早く噛み閉じてから元の姿勢へ戻す。口が閉じる瞬間に、口先から長短の異なる6本の先細りの火花が走る。白熱した芯から黄・橙へ薄まり、遠目でも噛む瞬間が分かる大きさにする。攻撃の予告は顎の動き、被弾は船体の白いフラッシュで示す。ステージ4の蛇は固有の船体を使い、噛み閉じる時機の火花を共用する。

たて座（`shield`）は、`assets/pixel/shield/` の `scutum_base.png`・`scutum_armor.png`・`scutum_normal.png` を使う。BaseにArmorを重ね、Normalで装甲の陰影を付ける。原画の上側の盾を敵の正面へ向け、盾の見た目は原画の装甲で表す。奪って機体へ装備した盾は[敵一覧の装備表示](catalog/enemies.md#たて座から奪った盾)を使い、転送中は盾の移動演出を使う。

じょうぎ座（`ruler`）は上下各58×46ピクセルの共通キャンバスを同じ位置に重ねる。分離後もキャンバスの中心と寸法を保ち、それぞれの装甲へ対応する法線画像を使う。

ケフェウス座（`cepheus`）は、中央の赤い星から左右へ湾曲した厚い装甲を広げ、下方へ細い装甲の軸を伸ばす。青灰色の大小の装甲片と暗い内部構造を重ね、左右の装甲の隙間に赤い発光部を置く。本体は `assets/pixel/cepheus/`、兵は `assets/pixel/cepheus_soldier/` のBase・Armor・Normalを使う。兵は左右へ小さな装甲を張り出した細い輪郭を持つ。

分裂する雑魚（`splitter`）と分裂体（`splitling`）は、各専用フォルダのBase・Armor・Normalを重ねる。元画像の寸法と透明な余白を保ち、本体の赤い発光と装甲の陰影を分ける。

ほうおう座（`phoenix`）は `assets/pixel/phoenix/` の元画像の寸法と透明な余白を保ち、Base → Decoration → Armorの順に重ねる。Normalは装甲へ適用する。翼と尾の炎のディテールは元の色を保つ。

### 4.5 英雄の星座と目印の星

- 英雄の星座は、星座全体を包む淡い光の雲で、遠くからも特別なものと見分けられる。まだつないでいない星は残り火のように弱く光り、星どうしを弱い金色の点線で結ぶ。なぞってつないだ線は、何層にも重ねた光線として明るく光り、つないだ星は輝きを取り戻す。線の描き方は操作線と共通。
- 目印の星を持つ敵は、船体の輪郭に沿って濃い金色のオーラを放つ。明るい金の芯から橙寄りの暗い金へ外側を薄くし、ドット状の幅と濃さを揺らす。分離・移動する部位と膨らむ船体にも輪郭を追従させる。ミニマップでの見せ方は3.3。
- 特別な枠のアイコンは、借りている英雄の星座を表す。配置とクールダウンの表示は [仕様書](../spec.md) の17章。

### 4.6 みなみのかんむり座

- 本体は青い装甲と赤い中心の星を持つ冠。`speed/assets/pixel/corona/` の `crown_base.png`・`crown_armor.png`・`crown_normal.png` を使い、[敵の共通の描画](#42-敵)に従って陰影を付ける。
- 渦は淡い紫の短い弧が中心の周りを回り、保持した敵本体を見せる。予告は冠の周囲にたまる赤い弧と、選ばれた個体の明滅する赤い輪で示す。
- 投擲中は敵本体より大きい赤い頭に橙の前縁と後ろへ伸びる尾を付け、小さな彗星のように見せる。赤は既存の敵弾、橙は敵の爆発と同系統の攻撃色を使う。頭の中央を薄くして元の敵の種類を見せる。尾は装飾とする。
- 渦・予告・投擲は `scripts/enemies/corona_vortex.gd` の `draw()` にまとめた仮の図形。動きと当たり判定を保って描画だけ差し替えられる。頭の大きさは [敵一覧](catalog/enemies.md#みなみのかんむり座) に従う。

### 図鑑の投影と機体の演出

図鑑の実演は機体と武器のパーツを白に近い水色、敵を濃い青のベタ塗りにする。炎と攻撃の色、命中時の白い閃光を保つ。投影はたる型の歪み、粗い格子、段階色、ゆっくり流れる暗い線、間隔と速さが異なる明るい走査線、ときどき横へずれる細い線、ディザのにじみと縁を重ねる。通常は水色、彗星の遺物は金で統一し、下端の投影口と四隅の括弧を添える。

機体の武器・特性は段階的な色と市松でピクセルの粗さをそろえ、1ドットを機体と同じ比率で拡大する。赤は敵の攻撃に使い、自機の演出は青・青緑・黄・紫を使い分ける。ギアアップの炎の終わりの赤褐色と、元の敵の色を持つ破片は、その色を保つ。
