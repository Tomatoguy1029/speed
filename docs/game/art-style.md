# SPEED デザインとアートスタイル

## 1. 方向性

ゲーム全体のデザインは**航海と星図**を軸にする。

- 星図・航海図の見た目を土台にする。SF の未来という舞台と組み合わせてよい。
- 製図の器具や、天文学・航海の器具（大航海時代の道具など）を、デザインに組み込む。世界観に合うものだけを使い、詰め込みすぎない。
- 昔の地図はインクとペンで描かれていたので、インクの線やにじみを表現に使う。
- 見やすさを損なう装飾はしない。

## 2. 参考にするもの

| 参考 | 見た目の特徴 | 使う所 |
|---|---|---|
| 円形の星図 | 濃紺の地に白い点の星（明るい星ほど大きい）。星座は細い線で結ぶ。天の川は点描。同心円と放射状の線が入り、外周は目盛りの付いた何重かの円 | ミニマップ |
| 古い航海図 | 古い紙の色の地。方位を示す放射状の線、コンパスローズ、天球儀、装飾の枠に入った題字、帆船の絵、手描きの文字 | ワールドマップ |
| 古い天球図 | 円形の2つの半球に、手彩色の星座の絵（動物・人物）を描く。四隅に天体の運行を示す図、周りに雲、上に帯状の題字 | ワールドマップ |

## 3. 画面

### 3.1 ステージの背景

- 背景は星空。星座の絵は描かない。
- 取り戻した星が背景の空に戻り、星雲や天の川が色鮮やかになっていく。いつ変わるかは [仕様書](spec.md) の2.2。
- 敵や弾が見にくくならない範囲で鮮やかにする。

### 3.2 ワールドマップ（ステージ選択）

- 5つの星系を航路で結んだ海図として描く。
- 古い航海図と古い天球図を組み合わせた見た目にする。星座の絵は、このワールドマップでだけ描く。
- ステージの背景と同じく、色鮮やかになっていく。
- 開くときに、地図を広げるような演出を入れる。

### 3.3 ミニマップ

- 見やすさを一番大事にする。円形の星図をオマージュした、レーダーのような画面にする：濃紺の円に、同心円と放射状の細い線、外周に目盛りの付いた円。
- 目印の星の線と英雄の星座は金色で描く。
- 表示するものは [仕様書](spec.md) の17章。

### 3.4 線を描く仕組み（描画・なぞり）

- 製図と絡めた雰囲気にする。

### 3.5 アイコン・エフェクト・画面の切り替え

- 製図の器具や、ペンで書く・消すといった描くことを意識したものにする。無理にすべてに当てはめない。
- インクがにじむ演出を使う。例：ワールドマップからタイトル画面へ戻るときにインクがにじむように消える、Esc でメニューを開いたときににじむように出てくる。

### 3.6 彗星

- 隕石とは別の見た目。光る核と、進む向きの反対へ長く伸びる尾。
- レアな彗星は金色の核と尾で、周りを光の粒が回る。彗星限定の武器のカプセルも金色にする。
- 専用の絵は未決。今は光と尾を描いた仮の見た目。

### 3.7 雷撃

- 接触電撃と敵の落雷は、距離に応じた折れと短い枝を持つピクセル雷で描く。整数グリッド上のドットで階段状の輪郭を作り、白い芯と白に近い水色（`#e1f7ff`）の枝・周辺光を重ねる。
- ゲーム内のドット幅はカメラのズームに合わせて補正し、画面上の太さを保つ。短い区間は折れと枝を減らす。接触電撃は実際につながった枝ごとに対象間を結ぶ。
- 放電は弱い発光・強い発光・短い減光・再発光と減衰の順に進み、短い間隔で形を切り替える。各演出の経過時間に合わせて進める。
- 落雷は既存の照準・収束する輪・着弾円を淡い水色で描き、発動時に着弾点の上から雷を落とす。枝と縦の雷は外観の装飾とする。
- 武器プレビューも同じ生成処理を使い、停止中は静止した雷、未入手時はシルエットで表示する。

## 4. キャラクター

### 4.1 自機

- 未決。

### 4.2 敵

| 対象 | 見た目 |
|---|---|
| 雑魚 | 単純な形状で、星を一つ取り込んでいる |
| 硬めの敵 | 星を2つ取り込んでいる |
| 強敵と大物 | [敵一覧](catalog/enemies.md) の星座と星の数をモチーフにする |

- 取り込んでいる星は、基本的に赤く光る。
- 輪郭で種類を見分けられるようにする。
- その種類の特性を示す主な特徴は一つに絞る。
- 小型の敵ほど細部を減らす。
- 世界観の装飾は控えめにする。

自爆型（`bomber`）・ぼうえんきょう座（`telescope`）・レチクル座（`reticle`）・みなみのさんかく座の中央（`triangle`）と頂点の星（`triangle_star`）・みずがめ座（`aquarius`）・かに座（`crab`）・いるか座（`dolphin`）・かじき座（`marlin`）・みなみのかんむり座（`corona`）・みなみじゅうじ座（`cross`）・わし座（`aquila`）は、`assets/pixel/` 内の各専用フォルダのベース画像に装甲画像を重ね、装甲の法線マップで陰影を付ける。専用フォルダへ追加する敵画像は、画像全体の幅・高さを基準に、自機と共通の `config.character_scale` と、敵データの `visual_settings.scale` によるサイズ倍率を掛けた寸法で描く。当たり判定は敵データの半径を使う。左上からの主光と右下からの補助光を使い、敵の回転に応じて装甲面の明るさを変える。ベースの赤い光と、攻撃・自爆の予告は発光として見せる。

### 4.3 中ボス

- 金色のパーツを取り込んでいることが分かるデザインにする。
- それぞれのボスの印象が被らないカラーリング・デザインにする。

| 中ボス | 方針 |
|---|---|
| いっかくじゅう座 | 未定 |
| ケンタウルス座 | 未定 |
| おおいぬ座 | 明るい星であることを生かした設定にする |
| うみへび座 | 巨大な本体と、瓦礫の塊が連なった首。本体に大きな羅針盤の文字盤を描く |

うみへび座の素材は、本体1枚、首の節（瓦礫の塊を2〜3種類）、頭6種類（噛みつく首・渦の首・瓦礫の首・ビームの首・ホーミング弾の首・不死の首）。頭は口を閉じた絵と開けた絵の2コマを用意し、首の節は深く重ねて連なりを表す。予告は頭の光で見せ、羅針盤の文字盤は動いていても方位が読める大きさにする。素材の実装状況は [敵一覧](catalog/enemies.md)。

うみへび座の仮演出は、予告を黄、実行を赤、攻めどきを緑、頭への実ダメージを白で示す。以下は差し替え用の演出草案とし、最終アートと演出の強さを試遊で調整する。接続・調整手順は [設計書 6.1](architecture.md#61-敵とボスの-ai)。

| 技 | 仮演出で見せるもの | 本番素材への差し替え口 |
|---|---|---|
| 北 | 自機周辺を追う着地点の輪と各首先からの線、淡い色への変化で狙い固定を示す。固定後に複数首が同じ側へ伸び、攻めどきは先端を残す | 固定根元、溜める口、標的位置の輪、噛みつく口と先端の衝撃 |
| 東 | 瓦礫の展開、ビーム首の発光と向き、薙ぎと砕ける瓦礫、終了後の緑の輪 | 瓦礫・溜めの光・ビーム・破片の素材 |
| 西 | 左右の首の発光と向き、挟む2本のビーム、終了後の緑の輪 | 左右の溜めとビームの素材 |
| 南 | 回る瓦礫の壁と通れる隙間の案を保持する。回避難度は未決、演出と技の接続は保留 | 隙間を読み取れる壁と渦の素材を、回避の試遊に合わせて決める |

### 4.4 伝説のモジュール

- 金色。
- 入手したときは錆びている。形だけはモジュールに似ていて、「もしかして？」と思わせる程度。

### 4.5 英雄の星座と目印の星

- 英雄の星座は恒星のように強く光り、遠くからも特別なものと見分けられる。星どうしを薄い点線で結び、なぞった線は明るく光る。
- 目印の星は、金色とも白ともつかない特別な光を放つ。ミニマップでの見せ方は3.3。
- 特別な枠のアイコンは、借りている英雄の星座を表す。配置とクールダウンの表示は [仕様書](spec.md) の17章。

### 4.6 みなみのかんむり座

- 本体は青い装甲と赤い中心の星を持つ冠。`speed/assets/pixel/corona/` の `crown_base.png`・`crown_armor.png`・`crown_normal.png` を使い、[敵の共通の描画](#42-敵)に従って陰影を付ける。
- 渦は淡い紫の短い弧が中心の周りを回り、保持した敵本体を見せる。予告は冠の周囲にたまる赤い弧と、選ばれた個体の明滅する赤い輪で示す。
- 投擲中は敵本体より大きい赤い頭に橙の前縁と後ろへ伸びる尾を付け、小さな彗星のように見せる。赤は既存の敵弾、橙は敵の爆発と同系統の攻撃色を使う。頭の中央を薄くして元の敵の種類を見せる。尾は装飾とする。
- 渦・予告・投擲は `scripts/enemies/corona_vortex.gd` の `draw()` にまとめた仮の図形。動きと当たり判定を保って描画だけ差し替えられる。頭の大きさは [仕様書 11.8](spec.md#118-みなみのかんむり座) に従う。
