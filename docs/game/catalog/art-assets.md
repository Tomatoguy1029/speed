# 共有アート素材リスト

Godot 本番の `speed/` で必要な絵と、制作範囲を相談する候補を共有する。**素材の洗い出しは途中**。新しく必要と決まった素材を随時追加する。

## 根拠と状態の読み方

仕様資料には現実装との照合待ちがある。[敵一覧](enemies.md)の区分・星数・採用状態・登場ステージだけを根拠に制作を開始する扱いを避ける。この一覧の実装確認は、現行シーン・データ・描画処理の静的な照合による。実画面の品質、全ステージの採用状況、手元にある納品物との対応は未確認。

- **素材状態**と**依頼／制作状態**を分ける。「画像割当なし」はコードで描いている状態を示す。正式素材の納品有無と、画像へ置き換える必要性は別に確認する。
- 素材 ID は改名・移動しても維持し、再利用しない。納品先・組込先・確認結果を根拠に、納品済み／組込済み／確認済みへ状態を更新する。
- 読む AI は、画像の存在やコード描画だけで完成・制作中・新規制作が必要と推測せず、要照合・要相談を残す。納品寸法・枚数・差分・担当・締切は合意を得て確定する。

見た目の参考は[アートスタイル](../art-style.md)、ステージ4の資料は[個別仕様](../stages/stage-4.md)。依頼内容が未確定の候補は、制作開始前に現仕様と実装を照合する。

- **要照合／要相談**：絵の内容・寸法・向き・差分・枚数。見た目と挙動・数値の調整が必要であり、今の形や配置を完成仕様として依頼規格へ転記する扱いを避ける。

## 洗い出しが残る範囲

各ステージの敵の採用・削除・作り直し、通常の攻撃と使用時 ULT・武器・特性の演出、UI と図鑑、導入・結果・画面切替の素材は全体を照合できていない。画像・コード描画の存在を手掛かりに、必要な箇所を追加する。

割当確認では、ステージ4の `biter` は[ステージの指定](../../../speed/data/stages/stage_4.tres)で `snake.png` を使い、`bomber`・`telescope`・`reticle` などは `LAYERED_ENEMIES` の別フォルダ画像を使う。単純な同名 PNG の有無だけで未制作と判断せず、ステージ別の指定・重ねる画像・コード描画・アニメーションの接続を確認する。
