# 共有アート素材リスト

Godot 本番の `speed/` で必要な絵と、制作範囲を相談する候補を共有する。新しく必要と決まった素材を随時追加する。素材の洗い出しと納品物の照合は継続中。

## 根拠と状態の読み方

- **制作が必要な素材**、**画像組込済み**、**要相談**、**制作対象外・保留**を分ける。採否は現在の合意と[敵一覧](enemies.md)・[武器一覧](weapons.md)、画像の割当は現行マスタと描画実装で照合する。定義ファイルや未使用フェーズに残っているだけの敵もある。
- **素材状態**と**依頼／制作状態**を分ける。画像割当なし・コード描画は、正式素材の未納品や新規発注の確定を意味しない。画像組込済みでも正式採用・品質確認は別に確認する。
- 素材 ID は改名・移動しても維持し、再利用しない。納品先・組込先・確認結果を根拠に状態を更新する。読む AI は未確認の完了・制作中を推測せず、寸法・枚数・差分・担当・締切は合意を得て確定する。

見た目の基準は[アートスタイル](../art-style.md)。敵の割当は、ステージの `enemy_looks` と種類名で選ぶ[EnemyLookの外観マスタ](../../../speed/data/visuals/looks)（本体・装甲・法線）を確認し、外観がなければ単体 PNG、さらに画像がなければコード描画へ分岐する[実装](../../../speed/scripts/render/run_presentation.gd)を読む。実画面の品質と納品物の照合は、素材ごとに行う。

- **用途／必要な内容**：中ボス撃破後の獲得演出と図鑑に使う、4種の正式絵。
- **素材状態**：4種とも絵の `preview_texture` は未設定で、[部品図](../../../speed/scripts/ui/module_preview.gd)を使う。獲得オーラのマスク・ベイクは設定済み。オーラの素材とモジュール本体の正式絵を区別する。

### ULT 獲得カットイン

**ART-005：ULT 獲得カットイン**

- **用途／必要な内容**：英雄の星座の解放時、力を獲得したことを見せる正式な素材。
- **素材状態**：[現行シーン](../../../speed/scenes/run/ult_cutin.tscn)は[コード](../../../speed/scripts/ui/ult_cutin.gd)で星座の点・線と光を描く仮カットイン。[報酬表示](../../../speed/scripts/ui/reward_presentation.gd)へ接続済み。
- **依頼／制作状態**：未確認。
- **要相談**：[英雄4種](../../../speed/data/heroes)の共通部分と描き分け、絵の内容・動き・枚数・コマ数。差し替えの基準座標 800×450 は 640×360 の描画先を経て拡縮される。納品画像の解像度は未決。ULT使用時の演出は別に確認する。

### 鉄のがれき

**ART-020：鉄のがれき（`iron`）の絵**

- **用途／必要な内容**：フィールドの障害物として使う鉄のがれきの絵。
- **素材状態**：[フィールド処理](../../../speed/scripts/runtime/systems/field_system.gd)が配置する。[描画側](../../../speed/scripts/render/run_presentation.gd)には外観マスタ・`iron.png` の割当がなく、[敵データ](../../../speed/data/enemies/iron.tres)の形を使う図形描画へ分岐する。
- **依頼／制作状態**：依頼予定。連絡済みか、制作・納品済みかは未確認。
- **要相談**：絵の内容・寸法・向き・差分・枚数。現在の形や配置を完成した依頼規格として扱う前に確認する。

## 要相談：素材の制作範囲を決める

### クリティカルランスへの槍演出の転用

**ART-030：クリティカルランス発動時の槍演出（追加素材の要否は未確定）**

- **用途／表示場所**：特性「クリティカルランス」の効果発動時だけ、槍を飛ばす演出として表示する。
- **見た目**：[T06 の発動演出](traits.md)にピクセル調の槍の見た目を使う。[W24 の廃止状態](weapons.md#廃止)と別の突進火力武器の扱いは武器一覧を参照する。
- **実装状態**：コード描画を組込済み。演出の品質は本人確認待ち。
- **素材状態・参照**：演出は[槍のコード描画](../../../speed/scripts/render/light_lance.gd)と[shader](../../../speed/shaders/light_lance.gdshader)。
- **依頼／制作状態**：独立武器用の絵は制作対象外。転用に伴って正式な追加素材が必要かは未確定。必要性を確認してから内容・納品寸法・分割・アニメーション枚数を相談する。
