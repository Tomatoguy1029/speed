# SPEED の絵の依頼書

見た目の基準は[アートスタイル](../art-style.md)。元画像のサイズは、指定のあるものを除き未決。

## 依頼と素材の状態

優先して追加制作する絵は、最後のカットシーンで吠える子犬と[英雄の星座4種類](#英雄の星座)。エフェクトは現行分の制作を完了扱いとし、追加が必要になったものを個別に扱う。画像の追加制作・納品・ゲームへの組込・見た目の確認は別々に管理する。

本文の組込状態は `main` の素材と参照を基準とする。`claude/sweet-feynman-wiewbo` の最終決着演出・ULT獲得カットインは未統合で、英雄の仮画像と共通アイコンにも差分がある。未統合の演出を含む見た目の最終確認は残る。既存素材がある項目の追加差分・共用方法が未決の場合は、その部分だけを制作対象として照合する。

`main` の獲得演出用の画像条件は次のとおり。星座を解放したときの獲得演出で、星座の点・線に重ねて描き出す。昔の星図のような線画で、線は白か明るい灰色、背景は透明。色は表示側で英雄ごとに乗せる。キャンバスは、星座の星の範囲に上下左右160の余白を足し、星座の座標の1を3画素にした大きさ（ペルセウス座1980×2550、しし座2610×1920、ふたご座1530×1980、ヘルクレス座1890×2250）で、星の位置は[英雄の定義](../../../speed/data/heroes)の `stars` と合わせる。分割・ポーズ・細かなデザインは未決。

`main` の `speed/assets/heroes/acquire/` は星と星座線だけの仮画像で、人物・動物の完成絵とは別に扱う。未統合ブランチではこの仮画像を使わず、ULT獲得カットインを別に表示する。この画像条件を未統合のカットインへ適用するかと、フィールド・獲得演出での最終的な共用方法・組込方法は要確認。
