## 本番の番号と参照

武器・特性の表示番号は図鑑の並び順から、それぞれ `No.01` を起点に連番で付ける。表示番号は一覧・図鑑の見出し・詳細で一致させる。データとコードの `W`・`T` に続くIDは保存・録画・文言・参照に使う固定キーであり、表示番号に合わせて変更しない。既存の内部IDを別の項目に再利用しない。

本番の数値パラメータは Godot の `.tres`（[設計書](../../architecture.md) 8章）を正とする。一覧には現行の名称・発動と効果・経路への影響・参照先・未決事項を記し、数値を重複管理しない。仕様書では `config.xxx`（`speed/data/config.tres` の項目）やデータファイルを示す。demo の数値はdemo側の一覧で管理する。

## 更新ルール

1. 武器・特性を図鑑へ加えたら、図鑑順の表示番号と対象側の一覧を同じ作業で更新する。内部IDは既存の本番・demo両方を確認し、別項目に重複させない。
2. 名前・効果・発動条件・数値・実装を変えたら、対象の現行仕様と参照先を更新する。未決事項は未決のまま示す。経緯や過去の項目は一覧に残さず、git履歴でたどる。
3. 武器のレベル別効果と特性の重ね掛け効果は対象側の一覧に表示番号で記す。実装値は `.tres` を参照する。
4. 経路に関係する効果には、通り方や突破後の変化を記す。操作・成長・全体バランス・課題は上の表にある文書へ置き、個別一覧を複製しない。
5. 敵はコードのtype IDを使い、実装状態と未決事項を敵の一覧で区別する。

## 追加時の記入例

- 武器・特性：表示番号／名称／発動・効果／ルートへの影響／参照先／未決事項
- 敵：type ID／名称／実装状態／基礎数値／行動・攻撃／出現／未決事項
