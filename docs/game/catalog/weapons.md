# 本番の武器一覧

[一覧の運用ルール](rules.md) に従う。管理 ID は demo から引き継ぐ。共通のルール（枠・Lv・係数・段階の色）は [仕様書](../../spec.md) の8章。demo の保留・候補（W09〜W16、W18）は本番に登録していない。

表示用の名前・説明は [ゲーム内文言](../text.md) を正とする。

数値の正は文書ではなく `.tres`。各武器の数値は `speed/data/weapons/<ID>_<内部ID>.tres` が正で、Godot エディタの「データ編集」（メニューバーの「プロジェクト → ツール」）で見て調整する。

Lv ごとの強化項目は武器ごとに決める。威力・頻度・範囲を毎 Lv 同時に上げることは必須としない。

## 彗星限定

### 通常育成完了後の適用先

[追加強化の抽選・累積ルール](../../spec.md#通常育成完了後の追加強化)に従い、`data/post_max.tres` の `targets` で実適用先を明示する。分類名をプレイヤーへ付与する代わりに、カードへ対象の半径・距離・攻撃を表示する。

| 追加効果 | 対象 | 実際の適用先 |
|---|---|---|
| 巻き込み範囲 | W03 | 押し出した船体・飛ばした死体・破片の接触半径 |
| 巻き込み範囲 | W04・W08 | 接触波動・攻撃中のソニックブームの半径 |
| 巻き込み範囲 | W17 | 電撃が隣の敵へ届く距離 |
| 巻き込み範囲 | W21・W22 | 船体回収半径・ビームの実判定幅 |
| 巻き込み範囲 | W26 | 固定した編隊の各機の接触半径。編隊幅と光跡は現在の値を保つ |
| 追撃威力 | W01・W02・W23・W05・W07・W25 | ブラスター弾・散弾・後方弾・バリア波動・機雷・迎撃弾の威力 |
| 追撃威力 | W21・W22 | 牽引した船体弾・双極ビームの威力 |

武器共通威力は全装備武器へ適用する。W27は通常RAM威力を使う装甲判定を保持し、分配する追撃ダメージへ武器共通威力を掛ける。W27の役割別追加威力と、ほかの未指定の役割への追加対象は未決。

弾速はW01・W02・W23・W25の射出弾、W03で飛ばす船体・破片、W21の船体弾へ適用する。持続はそれらの弾とW07の機雷・W08の攻撃持続へ適用する。W22のビーム演出寿命とW26の光跡は表示用の値として扱う。攻撃間隔は周期攻撃・防弾・連射の間隔へ適用し、W07の配置間隔は距離として保つ。W21の現在の発射間隔は安全下限より短いため、単独では間隔短縮の候補を除く。

### W08のLv別威力

威力は `data/weapons/W08_sonic.tres` の `damage_by_level` を攻撃力に掛ける。範囲と頻度には共通の段階別係数を使う。威力は試遊用の暫定値。

| Lv | 威力の役割 |
|---|---|
| 1 | 標準雑魚を小さく押し戻し、HPを削る |
| 2 | Lv1より広い敵の群れを削り、ほかの攻撃につなげる |
| 3〜5 | Lvごとに威力が上がる |

### W23のLv別強化

取得時だけ自機へ提供PNGのタレットベースと砲塔を装着する。機体→ベース→砲塔の順で重ね、砲塔は取り付け軸を中心に射撃方向へ向く。弾は砲口から発射する。素材は `assets/pixel/airship_turret_base.png` と `airship_turret.png`。

共通の段階別係数は適用せず、`.tres` のLv別配列を使う。前段階の強化は保持する。

| Lv | 強化内容 |
|---|---|
| 1 | 後方へ自動射撃 |
| 2 | 同時発射数が増加 |
| 3 | 発射間隔が短縮 |
| 4 | 1発の威力が上昇 |
| 5 | 同時発射数がさらに増加 |

### W25のLv別強化と射撃

迎撃ドローンは近い敵を分担して撃つ武器として扱う。Lv別配列を使い、機数・連射・威力を武器の `.tres` で調整する。数値は試遊用の仮値。

| Lv | 強化内容 |
|---|---|
| 1 | 複数機が周回し、近敵を分担して弾を撃つ |
| 2 | 機数が増え、射撃の間隔が短くなる |
| 3 | 機数・連射数が増え、射撃の間隔が短くなり、弾の威力が少し上がる |
| 4 | 機数が増え、射撃の間隔が短くなる |
| 5 | 機数・連射数がさらに増え、射撃の間隔が短くなり、弾の威力が少し上がる |

弾は近い敵へ分散する。同じ敵へのダメージ間隔は編隊全体で共有する。惑星・月で弾が止まり、盾の正面では反射を受ける。描画・なぞり中は自機周囲の編隊を保って新規射撃を休み、発射済みの弾は着弾まで進む。

機体は `drone.png` に左右の装甲・二連の砲口を重ね、発射時に銃口を発光させる。弾はミント色の階段状の光と白い芯で描く。HUDはドローンの既存アイコンを共用し、図鑑は護衛編隊と弾を表示する。

### W26のLv別強化

左右の機数・編隊幅・専用威力・光跡は `data/weapons/W26_dashRangeDrone.tres` のLv別配列で調整する。数値は試遊用の暫定値。ほかのドローンと別の武器枠で装備し、専用威力には共通の段階別係数を掛けず、編隊全体で同じ敵へ1突進1回の追加直撃を与える。通常の体当たりは独立計算する。曲がり角は前後の経路の法線を平均し、鋭い角ほど幅を畳む。描画は `scripts/render/dash_range_drone.gd`、アイコンは `assets/ui/combat/dash_range_drone_icon.svg` を使う。

| Lv | 強化内容 |
|---|---|
| 1 | 左右の小編隊を展開し、自機の横を掃く |
| 2 | 編隊幅と光跡が伸びる |
| 3 | 左右の機数が増え、並列の光跡を引く |
| 4 | さらに機数・幅・光跡が伸びる |
| 5 | 多数の機体が横へ広がり、長いピクセル調の光跡を並べて一斉に貫く |

### W27のLv別強化

`data/weapons/W27_afterimage.tres` の `echo_count_by_level` で機数、`echo_total_by_level` で全機合計の追撃倍率、`echo_delay` で各機の時間差を独立して調整する。各分身の直撃威力は「通過区間を記録した時点の通常ram威力 × 合計追撃倍率 ÷ 機数」。取得時に控えめな追撃、最大強化でも本体より小さい合計追撃に収める仮値を設定し、数値と品質は本人確認待ちとする。各Lvで機数と合計倍率を増やす。

通常ram威力は `CombatSystem.attack_power()` を使い、通常の装甲貫通可否と敵の盾・特殊条件を確認して当てる。判定の太さは `config.trace_radius`。残像の直撃は `afterimage` として記録し、クリティカルと武器・特性の接触発動、撃破による武器・特性の発動、攻撃する船体破片の生成を除外する。実際に通過した区間を有限に保持し、最後の分身の消滅・装備解除・ラン終了で解放する。ポーズ・カード選択・ヒットストップは再生も停止する。

表示は `scripts/render/afterimage.gd` と `shaders/afterimage.gdshader` が現在の機体絵を使い、青白い輪郭・走査線・段階的な残光を重ねる。カードと装備枠は `assets/ui/combat/afterimage_icon.svg` を使う。
