# 本番の敵一覧

[一覧の運用ルール](rules.md) に従う。type ID は demo から引き継ぐ。星と HP の属性による HP、サイズ・エリートの補正、出現、動きの共通ルールは [仕様書](../../spec.md) の4.2・11章。

数値の正は `.tres`。基礎値（半径・HP・装甲・速度・経験値・倒し方・行動の値）は `speed/data/enemies/<type ID>.tres`、ボスは `speed/data/bosses/`、出現の重みは `speed/data/phases/` が正で、Godot エディタの「データ編集」（メニューバーの「プロジェクト → ツール」）で見て調整する。

敵とボスの種類ごとの停止時間は `hitstop_multiplier` で調整する。[ヒットストップの適用条件・継承・上限](../../spec.md#74-ヒットストップ)に従い、[敵設定の編集手順](../../dev/stage-production.md#53-保存戻すエディターで編集する)から保存する。

同じ敵をステージ別に調整する値は `speed/data/stages/stage_*.tres` の `enemy_tuning` に持つ。[ステージ敵調整](../../spec.md#20-調整機能)で編集する。

ステージ1の強敵と三角の星のHP上書きは、[Stage1の調整箇所](../stages/stage-1.md#調整する場所)を参照する。

強敵の攻撃の重なりは、出現タイムラインの時間帯の予算と、ステージの種類ごとの個体value（`enemy_attack_values`）と、クリップの攻撃優先度（`attack_priority`）と任意の共有overrideで調整する。[攻撃の管理](../../spec.md#117-敵の攻撃の形)を参照。

## 敵設計の6分類

雑魚・強敵・ボスの攻撃を「近距離／遠距離」と「点／線／面」の2軸で整理し、高速移動する自機への脅威と、避け方・攻め方の偏りを確認する。

**点**は頭・噛みつき・塊の局所的な攻撃、**線**はビームや風刃のように長さを持つ攻撃、**面**は爆発など一定の範囲を占める攻撃を表す。近距離／遠距離の数値境界と距離を測る基準は未決。個別の技に記載された分類を保ち、射程・動作・狙う位置と併せて確認する。

| 分類 | 定義済みの例 |
|---|---|
| 近距離・点 | ヒュドラの突き噛み |
| 近距離・線 | ヒュドラの横薙ぎ |
| 近距離・面 | ヒュドラの風の帯 |
| 遠距離・点 | ヒュドラの塊投げ |
| 遠距離・線 | ヒュドラの三日月の風刃、固定照射 |
| 遠距離・面 | ヒュドラの散らし吐き、先回り落雷 |

各例の動作と対処は[ヒュドラの通常攻撃](../bosses/hydra.md#4-通常攻撃)を参照する。帯電頭突きの「近距離・点→面」のように、技の途中で変わる形も確認する。

敵を考えるときは、次を確認する。

- 単体では何を脅かし、高速移動・突進でどう切り抜け、どこを攻めると気持ちよいか。
- 同じ山の雑魚・強敵・ボスを並べたとき、分類だけでなく避け方・攻め方まで重複していないか。
- 予兆→狙い固定→攻撃→停止の流れに、進路・方向・攻撃順を選ぶ理由と、反撃する経路があるか。

この分類は敵・技を考えるための設計指標で、弾・ビーム・範囲などの実装クラスとは目的を分ける。形が線でも距離の分類は技ごとに確認する。

### みなみのかんむり座

- **コンセプト**：冠が近くの雑魚を率いる、小さな移動する台風。短距離の吸い込みと旋回で、うみへび座の渦へつながる動きを示す。遅い機体は渦の中心へ引かれ、突進・滑走中は振り切れる。
- **脅威**：旋回している種類から重み付きで選び、その種類の実在する1体を予告する。その個体の可視速度が機体へ向く位置に来ると、攻撃エフェクトをまとって進行方向へ飛び出す。大きな種類ほど選ばれにくく、種類ごとの投擲ダメージが高い。
- **快感**：通常の体当たり・武器で渦の雑魚をまとめて倒し、これから飛んでくる弾薬を減らす。保持中も投擲中も同じ敵の HP・装甲・弱点を使う。

| 項目 | 決まり |
| --- | --- |
| 捕捉する敵 | `params.throw_weight_<type ID>` と `throw_damage_<type ID>` の両方に登録した、星2以下の通常の雑魚。ボス・部位・障害物・特殊な防御条件を持つ敵は対象外。石化・吹き飛ばし中は通常の状態へ従う。生成済みの個体を捕捉する |
| 捕捉の範囲と数 | 保持できる数は `capture_max`、吸い込みの範囲は `pull_radius`、旋回の半径は `ring`。種類ごとの保持数が増えても抽選の重みは一定 |
| 投擲の条件 | 機体が旋回半径と機体半径の和の内側にいる間は、投擲を止めて予告を解除する。外側で種類を抽選し直したときは `telegraph` の予告を最初から見せる。抽選した種類のうち、予告のあと最も早く機体の方を向く個体を投げる。予告中の個体を倒すと、その個体の投擲を取り消す。空の渦は雑魚を捕捉するまで接近を続ける |
| 当たり判定 | 投擲の頭にだけ攻撃判定を付け、通常の接触は通常の戦闘判定に従う。頭の大きさは敵半径に `throw_effect_scale` を掛ける。1投につき1回、既存の盾と被弾後の無敵を通して判定する |
| 投擲の終わり | 命中・`throw_life` の経過・天体との衝突・冠の死亡で攻撃を終え、生きている個体は通常行動へ戻る。機体の攻撃で先に倒した個体は投擲ダメージを与えない |
| 調整値 | 正は `corona.tres` の `params`。捕捉間隔・保持数・吸い込み・旋回・予告・投擲速度と持続時間・種類の重みと威力は試遊用の仮値。投擲威力は種類ごとの固定値 |

### 見た目の実装

通常敵とパーツの種類ごとの外観調整・保存は、[実験場の仕様](../../spec.md#201-敵ルート実験場)に従う。見た目・当たり判定を共に変えるサイズ倍率と、当たり判定のみの倍率を種類ごとに保存する。調整値と装甲片ごとの塗装色の正は、各敵データの `visual_settings`・`armor_colors` とする。

- `ruler`（じょうぎ座）は `assets/pixel/ruler/` の上下の専用画像を重ねて出現し、分離後は各個体が片側の画像を使う。装甲の塗装は上下を選んで編集する。

- 各敵は `speed/assets/pixel/` のピクセルスプライトを Nearest で描く（`RunPresentation`・`InstanceBatch`）。素材の一覧は [素材README](../../../speed/assets/pixel/README.md)。
- `splitter`・`splitling` は各専用フォルダのBase・Armor・Normalを使い、透明な余白を含む元画像の寸法で表示する。エリートも同じ基準サイズ。接触半径とその調整値は各敵データに従う。
- `phoenix`（ほうおう座）は `assets/pixel/phoenix/` のBase・Decoration・Armorを重ね、装甲へNormalの陰影を適用する。装甲の塗装でも羽のディテールを保持する。

- 全敵とボスの表示と当たり判定に `config.character_scale` を掛ける。
- 静止スプライトで、個別のアニメーションはない。

## かじき座の突進

- 回遊中は目標へ鼻先を旋回し、その向きへ泳ぐ。速度だけを横へ補間して顔と進行方向をずらさない。突進後は一度止まり、休み明けも鼻先へ加速する。
- 停止予告の開始時に自機の現在位置を固定し、光ってからその方向へ高速で泳ぎ抜ける。予告中は完全に停止し、突進中は発進方向を保つ。
- 停止中は吻先から実際の直進区間へ赤いレーザーを照射し、本体の接触幅を薄く示す。地形で止まる場合はその位置で切り、画面外から進路が入る場合も画面端から射線を示す。発進に近づくほど光を強める。
- 実際の移動区間と本体の接触半径で進路を判定する。敵は既存の倒し方と無敵時間に従い、倒せる対象を共通の撃破処理へ渡す。経験値・ドロップ・撃破時効果は通常の撃破と同じ扱いにする。
- ボスと所属部位は各ボスの戦闘規則に従う。丸鋸・固定瓦礫など攻撃で壊れない対象はその防御を保つ。惑星・月とボスの固定外周は共通の地形衝突を使う。
- 隕石は敵テーブルの障害物として破壊対象に含める。惑星・月は地形として保持する。
- 回遊速度は `marlin.tres` の `speed`、距離・予告・突進速度・持続・休みは `params.keep`・`telegraph`・`dash_speed`・`dash_time`・`recover` で調整する。ステージ別の敵調整でも同じ項目を上書きできる。

### 見た目の実装

- 2種類の画像（`meteor_spritesheet.png`・`meteor2_spritesheet.png`）から、配置の ID で決まった方を原寸で表示する。`config.character_scale` は掛けない。
- 残りの HP に応じて、横3コマを左から右へ切り替える。壊れると右端のコマを破片として飛ばし、回転させながら消す。
- 被弾しても白く光らせない。
- 月と惑星は `moon.png`・`planet.png` を障害物の半径に合わせて表示する。
