## 段階2 1回のランの芯

### 2-1 フィールドとカメラ

- FieldManager：惑星、周回する月（世界の時間で回る）、宇宙塵、危険度、外縁の押し戻し、障害物との線分の判定。
- カメラは RunManager が仕様書13章の式で求め、RenderManager が Camera2D に反映する。

### 2-2 機体の移動

- ShipManager：マウス（カーソルの方向へ進む）とタッチ（仮想スティック）、速さの減り方、なぞり後の勢い、地形との衝突、被弾。
- InputRouter はカーソルの位置を動きのイベントから追う（UI の上でも位置を保つため）。

### 2-3 ゲージと描画

- DrawManager：充填、描き始め（クリック・Space）、点の記録、確定（もう一度クリック・長さ切れ・障害物）、消費。

### 2-4 なぞりと勢い

- 始点へのワープ、決まった実秒でのなぞり、なぞり中の世界の速さ、なぞり後の勢い。
- 撮影の手順（`--steps=dash`）でマウスを模擬し、描画 → なぞり → 勢い → 撃破まで画面で確認した。

### 2-5 敵の土台

- EnemyManager：敵は `Enemy`（RefCounted）の配列（仮の判断。行動の状態が多く、正しく書きやすいため）。
- 雑魚11種の行動、時間帯の表、補充・再配置・群れ・危険度・エリート・同時数の上限もここで作った（3-1〜3-3 の分）。

### 2-6 戦闘

- CombatManager：当たり判定の格子、接触（普段・高速）、装甲、クリティカル、背面の弱点、弾かれ、なぞりの波動の帯、ヒットストップ、撃破、範囲攻撃。

### 2-7 経験値と3択とブラスター

- BuildManager：経験値の式、レベル（0から、仮）、3択（所持品が出やすい重み、足りなければ回復のカード）、能力値（強化画面の強化を含む）、ブラスター。
- PickupManager：経験値の結晶・部品・カプセル・修理キット・回収ビーコン・出力コア（3-8 の分を含む）。
- ProjectileManager：敵の弾、大型の敵の破片（3-9 の分を含む）。
- 更新の順番は demo に合わせた（仮。設計書4.3を更新済み）。
- RenderManager：仮の図形で、仕様書15章の見分けの色・形に合わせた。

- 敗北：最後の被弾で止まって暗くなり、爆発、GAME OVER。

## 段階5 見た目

### 5-1 層と段の仕組み

- `scripts/render/render_pipeline.gd`。
- 豪華版（Forward+・Mobile）：2D の HDR と Godot のグロー。

### 5-2・5-3 演出のシェーダー

- `shaders/xp_crystal.gdshader`（経験値の結晶の面と縁）、`shaders/enemy.gdshader`（敵の縁を明るく）、`shaders/shockwave.gdshader`（ソニックブーム・大きな爆発・ボスの爆発で画面を歪める）、`shaders/bloom_blur.gdshader`（簡易版の光のにじみ）。
