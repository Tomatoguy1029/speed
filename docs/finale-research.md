# 締め（最後の決着）の作品調査

最終更新：2026-10-07。Tomatoguy1029 の世界観の相談（[wakida.md](wakida.md) 82〜）のための調査メモ。確定仕様ではない。

## 調べた観点

条件は「通常のプレイ（高速で敵を貫く・吹き飛ばす）の延長線上にありながら、特別な決着」。各作品について次の3点を見た。

- 普段の行動（その作品の基本の動詞）
- 締めの決着（最後に何をするか）
- 普段と同じ動詞のまま、何が締めを特別にしているか

ゲームを中心に、映画・アニメ・漫画・神話や昔話まで、約90本。記憶に基づく部分が多く、細部は作品で確かめていないものがある。スーパーメトロイド、ソニック3&ナックルズ、ベヨネッタ、エースコンバット7、登龍門は検索で確認した。

## 分析：普段の動詞のまま、締めを特別にしている型

| 型 | 内容 | 主な例 |
|---|---|---|
| A. 制限解除 | 普段の動詞から、一番大事な制限が外れる（無敵、無限の飛行、強化された技） | ソニック（1, 2, 49）、風ノ旅ビト（4）、スーパーメトロイド（7）、セレステ（3） |
| B. スケールの飛躍 | 同じ動詞のまま、相手が天体や宇宙規模になる | グレンラガン（55）、塊魂（10）、ポータル2（11）、ベヨネッタ（25）、アスラズラース（26）、BotW（27） |
| C. 上昇・到達 | 同じ動詞で「上へ」向かい、頂にたどり着くことが決着になる | 風ノ旅ビト（4）、ホロウナイト（21）、登龍門（72）、グレンラガンの「天を衝く」（55） |
| D. 巨大なものの内部へ突入して脱出 | 巨大な敵や要塞の中へ入り込み、中枢を叩いて、崩壊より速く抜け出す | ジェダイの帰還（51）、スターフォックス（16）、HALO（37, 38）、メトロイド（7, 8）、一寸法師（75）、マトリックス（61） |
| E. 狭い通路の最大負荷 | 普段の操作を、逃げ場のない一本道で極限まで要求する | 新たなる希望（50）、トップガン（54）、エースコンバット7（40）、オリ（5, 6） |
| F. 総まとめ | それまでに集めた力・仲間・技がすべて集まる | 元気玉（59）、大神（29）、ニーア（18）、セレステ7章（3）、SEKIRO（31） |
| G. 鏡の相手 | 同じ能力を持つ相手との決着 | DMC3（24）、ジョジョ（60） |
| H. ただ一つの技の究極形 | 普段の技が、その人だけの最終形に至る | 霹靂一閃→火雷神（57）、月牙天衝（58）、超究武神覇斬（30） |

気づいたこと：

- 多くの作品が、複数の型を重ねている。例えば、ソニック3&ナックルズは A（スーパー化）＋B（宇宙）＋時間制限。スーパーメトロイドは A（ハイパービーム）＋D（脱出）。グレンラガンは B＋C＋H。
- 印象に残る締めほど、締めの直前に「どん底」を置いている（スーパーメトロイド、風ノ旅ビト、ベヨネッタ、ジョジョ）。追い詰められて負けかける → 普段の動詞の制限が外れる → 一気にひっくり返す、の順番。
- 犠牲を伴う締め（最後のジェダイ、インデペンデンス・デイ、ナウシカ）は、「何かを犠牲にして戦うわけではない」というこのゲームの方針と合わない。
- 普段と別の操作を要求する締め（決着の仕掛けを踏むだけ、言葉で決着する、など）は、通常のプレイの延長にならない。

## SPEED に当てはまりそうな組み合わせ（相談用）

- **A＋C（制限解除して、上へ突き抜ける）:** 最後に、描ける長さや止まった時間の制限が外れ、群れが激流のように降り注ぐ中を、頂まで描き切って貫く。登龍門、風ノ旅ビト、グレンラガンの「天を衝く」の系統。「高みを目指して実際にたどり着く」というこのゲームの方針に一番近い。
- **D＋A（巨大なものの内部へ突入する）:** 群れを生み出している巨大な存在の体内へ入り込み、内部にあふれる群れを貫きながら中枢まで描き、崩壊より速く抜け出す。ジェダイの帰還、スーパーメトロイド、一寸法師の系統。
- **B＋H（天体規模の相手を、一つの技の究極形で貫く）:** 最後の相手は星や宇宙規模の大きさ。普段の高速攻撃が、最後にだけ天体を貫く規模になる。グレンラガン、ベヨネッタ、霹靂一閃→火雷神の系統。
