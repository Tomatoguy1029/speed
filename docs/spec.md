# 現在の仕様

ゲームが今どう動くかの説明。挙動や数値を変えたらここを更新する（経緯は [decisions.md](decisions.md)）。

## コンセプトと時間の流れ

2D 見下ろしのサバイバー系の **試作**。目的は作者が通しで遊んで「面白くなりそうか」を判断すること（作り込みより全要素を一通り体験できることを優先）。

- コンセプト: 突進で宇宙を縦横無尽に駆け回り、群れと障害物を吹っ飛ばしながら機体を強化し、10 分以内に脱出速度へ到達する
- コンセプトチェックの問い: ①止まらず駆け回っているか ②囲まれるスリルがあるか ③高速でぶつかって吹っ飛ばす手応えがあるか
- 1 ラン 10 分。時間で体験曲線を作る: 強化期(0–2:30) → 圧力期(–4:00) → 強化期II(–5:00) → 無双期(5:00–6:00) → 緊張期(–8:30) → 脱出期(–10:00)
- **フェーズは裏のレベルデザイン専用**。名前やバナーをゲーム画面に出さない（ユーザー指示）。ユーザーへの説明でも「〜分ごろ」など時間で言う

| `draw`（既定） | **ふだん = カーソルの方向へ進む（タッチは仮想スティック）、高速攻撃 = ゲージ制で軌跡を描いて駆け抜ける**。移動: **マウスはカーソルの方向へ進む**（クリック不要、`mouse` 方式と同じ操舵で速さは一定）。**タッチ操作のときだけ** 押した点からずらす仮想スティック（遊び 8px、半径 70px で最高速、押した点は固定、輪で表示）。高速攻撃: **経験値でゲージが溜まる**（満タンに必要な経験値 = その時のレベルアップに必要な量 × 0.35 × チャージ時間の倍率。チャージ時間を縮めるモジュールやレベルで溜まりやすくなる。回生ジェネレーターは貫通ごとに少し溜まる。開始時は満タン）。満タンで **Space か画面左下の「高速攻撃」ボタン**（ゲージが円で溜まり、満タンで光る。機体の HP バーの下にも細いゲージ）→ 世界がほぼ停止（×0.05）→ **画面の好きな場所をクリック（または Space＝カーソル位置）して描き始め**、カーソルを動かして軌跡を描く（長さ = 1000 × ゲージ上限 × 最高速度/基礎最高速度 × モジュール倍率、描ける時間 5 秒）→ もう一度 Space／クリック、または長さ・時間切れで確定 → **描き始めの点へワープ**（元の位置に残像が数個残って消える＋光の筋）→ 軌跡を約 0.5 秒（実時間、`drawRunTime`）で一気になぞる。突進の速度はゲージ上限（過充填コンデンサで 1 超え）で計算。描画中・なぞり中は **カメラを固定**。その間の世界の速さは **突進速度に反比例**（260 / 突進速度、下限 0.03）。描画中・なぞり中も **10 分のタイマーは実時間で進む**。攻撃力・脱出判定・抜けた後の勢いは突進の速度で計算。貫けない敵に当たると弾かれて終了。機体本体の当たり判定は半径 16。**なぞった軌跡から波動が出る**: 届く距離（初期 45、= 描いた線の周りの半透明の帯の幅）にいる敵へ攻撃力 × 0.5 のダメージ（装甲無視、パスごとに 1 回）と外向きの吹き飛ばし。プレビューは本体が切る敵に白（弱点なら黄色）、波動だけ届く敵に水色の輪、本体が止められる所に赤×。**同じ敵でも帯がいったん離れて再び重なれば何度でも攻撃が当たる**（2 回目以降が当たった瞬間に「×2」「×3」）。描画モード専用モジュール: 銃「波動増幅器」、銃「大波動」（7:00 以降）、ブースター「高速トレーサー」、ジェネレーター「軌跡延長コイル」「軌跡オーバードライブ」（終盤）。他の方式では出ない。描かずに確定すると機体からカーソル方向へまっすぐ |

| `steer` | WASD で押した画面方向へ進行方向が回る（4.5 rad/s、速度維持）。Space で進行方向へ加速 |
| `relative` | 機体基準 WASD（W 前進 / S ブレーキ / A・D 曲がる、停止中はその場旋回） |
| `nudge` | WASD で画面方向に小さな推力 |

### ポータル操作の試作（2026-10-04）

- 調整パネル `P` →「ポータル連続突進（試作）」で選択。プレビュー URL の `?controls=portal` でも起動できる。`?controls=draw` は現在の描画方式を明示する。既存方式と比較できるよう `draw` の既定値と保存済みの操作設定は維持する。URL 指定はその表示で優先する
- 自動発動は通常移動の線分とポータルの接触（ポータル半径28＋機体半径16）を検出する。行き先があればゲージ残量に関係なく発動。自身の足元への設置、到着後に同じポータル内に留まることでは再発動しない。終了後は世界時間0.6秒の再入場猶予。入場・Spaceともゲージを要求・消費せず、機体のゲージ表示も出さない。突進の出力は従来の満タン相当（`stats.gaugeMax`）
- **元の版を保存**: `dist/draw-original.html` はポータル導入前のコミット `b9ca9b8` の配布HTMLを保存し、初期操作だけを必ず `draw` に固定。通常のビルドはこのファイルを上書きしない。ステーションの「元の版：線を描いて駆け抜ける」と「ポータル試作」からそれぞれ別タブで開ける
- 手置きはラン中残る（最大12個）。敵ドロップは3回の到着で消える（同時最大36個）。B を近くのドロップに使うと、それを残るポータルへ変える。手置き上限や近くに手置きがある場合は設置を拒否し、表示で知らせる
- 敵撃破時、260以内にポータルがあれば新規生成しない。近くのドロップの回数が減っていれば1回補充（上限3、同じポータルへの補充は世界時間1.5秒に一度）。近くにポータルがなければ18%で撃破地点に生成。惑星／小惑星の中には生成しない
- 1区間の到達距離は900、1発動の総移動距離は2400。それぞれ最高速度／基礎最高速度、軌跡延長モジュール、ゲージ上限に比例して伸びる。現在位置から100未満のポータルは選ばない。周囲を上下左右・斜めの重ならない8区画（各45度、方向中心から±22.5度）に分け、その区画で最寄りを選ぶ。WASDは全到達候補から判定し、近い8個の番号表示に含まれないポータルも選べる。境界は時計回り側の区画に属する。到達できる近い8個に番号を付け、番号入力なら同じ方向の複数候補も直接選べる。惑星／小惑星を横切る区間は選べない
- 到着時の選択猶予は実時間3秒、待機中の世界速度は1倍（減速しない）。WASD／番号入力は選択と出発を一操作で行う。WASDの上下左右は60ms（`portalDirectionGrace`）だけ斜め同時押しを受け付け、斜めが成立すればすぐ確定する。到達できるポータルがない区画を入力すると、入力方向への巡航速度（最高速度×0.4）で離脱し、通常移動へ戻る。障害物で遮られる／残り距離で届かない候補も空扱い。突進中に押すと到着位置から解釈して予約し、候補があれば到着後に続行、空なら到着後に離脱。押しっぱなしのキーや自動リピートでは連発しない。入力なしの時間切れには黄色い「次」の行き先へ自動出発。Xで終了。到着時は未訪問／進行方向の候補を優先して自動選択する。敵と弾は動き続ける。各区間は最長0.22秒（高速トレーサーで短縮）。移動中の世界速度は従来の突進同様、突進速度に反比例する。ポータル発動中もランの時計は実時間で進む（既存の撃破ヒットストップ中は停止）
- Bは通常移動中の設置、Spaceは最寄りの到達可能なポータルへの照準不要の即突進（ゲージ不要）。惑星／小惑星を横切る候補、到達距離外、現在重なっているポータルは除外。通常移動からのSpaceは100未満でも接触範囲44以上なら移動できる。選択待ちのSpaceは最寄りの次候補へ即出発し、突進中のSpaceは到着位置から最寄りの次候補を予約して到着後即出発。移動先がなければ発動しない。通常時の黄色いプレビューはSpaceの行き先。Eの旧操作は廃止。入場による自動発動も維持する。通過済みの区間を連続突進の間ずっと水色の実線で表示し、選択待ち中も保持する。次の経路は黄色い点線で区別し、終了・弾かれ・距離切れで通過軌跡を消す。
- 出発地点から実際に線分を走る。通過中は既存の本体貫通・波動・弾かれ・減速を使う。弾かれたら即座に通常操作へ戻る。無敵は付与しない。移動中の軌跡炸裂は走った経路に沿って残る
- 「共振ビーコン」（レーダー枠、ポータル方式のみ抽選）装備時、到着地点の半径160に、到着速度による攻撃力×0.9×レア度倍率の装甲無視ダメージと吹き飛ばし。試作では初期装備。波動増幅器／大波動の範囲・威力強化も乗る。軌跡延長は到達距離・総距離、高速トレーサーは区間の移動速度、過充填コンデンサは突進出力・到達距離・総距離を伸ばす。ゲージ不要のため、チャージ短縮・回生ジェネレーター・チャージ衝撃波はポータル方式の抽選から除く
- **包囲炸裂**（銃枠、ポータル方式のみ抽選、エピック／レジェンド）: 実際に通った軌跡が開始点に戻る、または過去の区間と交差して閉じた瞬間、内側に中心がある敵へ装甲無視の爆発ダメージ。エピックは突進攻撃力×2.88、レジェンドは×4.2（重複強化も乗る）。レジェンドでは囲まれた各敵から半径90の追加爆発（本攻撃の50%）が出て外側も巻き込む。追加爆発から再帰的に爆発は発生しない。閉じた領域を短く発光させ、各敵の爆発と撃破数を表示する。直線の往復や面積64未満は発動しない。一度爆発した閉じた区間は判定から消費し、同じ囲みの連続発動を防ぐ。表示用の軌跡は従来どおり連続突進終了まで残す。未装備では囲んでも発動しない
- 調整パネル `P` の「包囲炸裂を入手」で試用できる（隣のレア度選択のエピック／レジェンドを使用。コモン／レア選択時はエピック扱い）
- 残る／消えるポータルを色と残り回数で区別。待機中は機体周囲に8分割のガイド（W／W+D等のキーと「移動／離脱」）を表示。各候補の番号1〜8と対応する方向キー、黄色い経路線と「次」の表示、出発までの秒数、選択された区間、通過波動の幅、到着波動の範囲、貫通対象と最初の阻害敵、画面外の候補、総距離と選択猶予を表示する。カメラは追従する
- 数値は `src/config.js` に集約し、到達距離・総距離・自動出発の猶予（0.5〜8秒）・世界速度・区間時間・配置間隔・出現率・到着波動を調整パネルで変更できる。ポータル耐久とポータルを狙う敵は未実装

## モジュールの入手（2026-10-02 変更）
- **レベルアップでは入手画面を出さない**。レベルごとに基礎性能が自動で上がる（最高速度 +2%、攻撃力 +2%、最大 HP +4、チャージ時間 −1%（下限 60%）、HP 8% 回復）
- **モジュールは敵が落とす**。確率 = 0.005 × 敵の強さ（= その敵の経験値。種類・レベル・エリートを反映）、上限 50%。レア度も強さで上がる。エリートと戦艦は必ず落とす。落ちたモジュールは近くで吸い寄せられ、45 秒で消える。フィールドの漂流カプセル（中心ほどレア）と出力コアは従来どおり
- **同じモジュールを拾うと選択画面なしで自動強化**（+1 ごとに効果 +15%、レア度は高い方）
- 描画モード専用の終盤モジュール「軌跡オーバードライブ」（ジェネレーター、7:00 以降、エピック/レジェンドのみ、長さ ×2.9 / ×3.8。画面中を駆けめぐれる長さ）

## 画面サイズ
- 機種ごとに比率が違うので **特定の解像度を前提にしない**。描画バッファ・HUD・パネルはすべて実際の幅と高さから配置（幅 600 未満で左上の文字を折り返す、左下の機体図と高速攻撃ボタンは幅・高さの小さい方に合わせて縮む、文字ラベルは画面内に収める）。ズームは画面の短い辺を基準

## 速度・成長・クリア
- 初期の最高速度 500（2.49 km/s）、**レベルごとに +2%**、モジュール（ブースター等）、出力コア（1 個 +18%、8:30 以降に中心付近に出現）、メタ強化で伸びる
- クリア = **実際の速度**が脱出速度 2250 px/s（表示 11.2 km/s）に到達。満タン（過充填なら上限超え）の突進で出す
- **重力はなし**（`planetGM`/`moonGM` = 0。ユーザーが鬱陶しいと判断）。惑星・小惑星は障害物として残る（ぶつかると弾かれる、軌跡もそこで止まる）。重力の仕組み自体は残っていて調整パネルで戻せる
- 攻撃力 = 速度 / 100 × 倍率 × `atkScale`(1.8)。装甲以上なら貫通、未満なら自機がダメージを受けて弾かれる。弱点（黄色い弧）は装甲半分で貫けて必ずクリティカル。満タン突進 1 回でザコ（ドリフター）を一撃で倒せることを保つ
- モジュールはフィールドのカプセル・入手画面・左下の機体図で **部位ごとの宇宙船パーツの形** で表示（6 つ揃うと 1 機の宇宙船になる）
- カメラは **最高速度** に応じて引く（現在速度ではない）
- **敵の狙いは鈍い**: 敵は機体の実際の位置ではなく、遅れて追いかける位置を狙う（`enemyAimLag` 0.5 秒遅れ、`enemyAimSpeed` 最大 450px/s で追う）。射撃・ミサイルの誘導・追跡・突進の構えすべて。ふだんの巡航（約 200px/s）はほぼ追えるが、突進やワープの直後は狙いが元の場所に残る。調整パネルで変更可
- **ヒットストップ**: 満タンの敵を一撃で倒すたびに 0.045 秒（大型 ×1.8、クリティカル ×1.3）。体当たりでも、なぞり中の波動での撃破でも出る（一撃かどうかはその突進で最初に触れた時点の HP で判定）。1 回の突進で合計 0.6 秒まで。突進していない間はこの上限が毎秒 0.3 秒ずつ回復
- 調整パネル（`P`）のボタン: +30/+60 秒、無敵、モジュール入手、出力コア、HP 全快、敵を消す、部品 +100、**機体強化をリセット**（ステーションの強化を全部 0 に戻して使った部品を返す、次のランから反映）、既定値に戻す
- 音は **既定でミュート**（`M` で切替、localStorage `speed-muted`）
