# SPEED 仕様書

## 1. 用語と単位

| 用語 | 意味 |
|---|---|
| 実秒 | 現実の時間。ランの時計、ゲージの充填、線をなぞる時間はこれで数える |
| 世界秒 | ゲーム世界の時間。描画中のスロー・なぞり中のスロー・ヒットストップで遅くなる。敵・弾・効果の寿命はこれで数える |
| 単位 | ゲーム内の距離。止まっているとき、画面の短い辺に `config.base_view` 単位が映る |
| 速度 | 単位/世界秒。画面の表示は km/s に換算する（× `config.speed_to_kms`） |
| A | 攻撃力（7.1） |
| L | レベル（機体・武器の文脈による） |
| n | 特性のLv |
| `config.xxx` | 調整値（`speed/data/config.tres`）の項目 |
| データ | `speed/data/` の `.tres`。値は Godot エディタの「プロジェクト → ツール → データ編集」で見て変える |

- ゲーム世界の更新は固定間隔で行う。
- ポーズ中とカード選択中は、世界・ランの時計・ゲージのすべてが止まる。
- 武器・特性・敵の個別の効果は [武器一覧](game/catalog/weapons.md)・[特性一覧](game/catalog/traits.md)・[敵一覧](game/catalog/enemies.md)。

## 2. ゲームの構成

### 2.1 モード

| モード | 内容 | 未決 |
|---|---|---|
| ストーリー | 5つのステージを順に進む。中ボスのステージが4つと、ラスボスのステージ。ADV パートのようなものはあまり入れない | 各ステージの長さ、失敗したときにどこからやり直すか |
| エンドレス | ハイスコアを目指す。ハイスコアを保存する。ステージ選択の画面から選ぶ | スコアの計算方法、終わる条件、使うフィールド、時間とともにどう難しくなるか、中ボスが出るか |

ストーリーの5ステージを実装済み。エンドレスは、通常の選択画面から遊べるモードとしては未実装。

### 2.2 ステージ

| 順 | 星系 | 星系の主（中ボス） | 個別仕様 |
|---|---|---|---|
| 1 | いっかくじゅう座の星系 | いっかくじゅう座 | [ステージ1](game/stages/stage-1.md) |
| 2 | ケンタウルス座の星系 | ケンタウルス座 | [ステージ2](game/stages/stage-2.md) |
| 3 | おおいぬ座の星系 | おおいぬ座 | [ステージ3](game/stages/stage-3.md) |
| 4 | うみへび座の星系 | うみへび座 | [ステージ4](game/stages/stage-4.md) |
| 5 | 元凶の待つ星系 | りゅう座（核は北極星） | [ステージ5](game/stages/stage-5.md) |

- ステージの順は、中ボスの星の数（中ボスの星座と取り込んだ星座の合計。[世界観とストーリー](game/world.md) の6章）が少ない順。
- クリア条件はボスの撃破。前のステージをクリアすると、次のステージを選べるようになる。
- 各ステージは星系を舞台にした、広めのフィールド。広さは 13.1 のフィールドと同じ。
- ステージの背景とワールドマップは、クリアしたステージの数が増えるほど色鮮やかになる。プレイ中には変わらない。見た目は [デザインとアートスタイル](game/art-style.md) の3.1・3.2。
- フィールドの端の英雄の星座と、そこを指す目印の星を探して動き回る（13.1）。
- 武器・特性などプレイ中に手に入れたものは、ステージをまたいで持ち越さない。
- ステージ1〜3・5は共通の6時間帯を使う。ステージ4（うみへび座）は専用の時間帯と出現のクリップを持つ（4.2・11.3）。追加版の時間帯と敵は調整用に保持する。出現状態は [敵一覧](game/catalog/enemies.md)。
- **未決**：通常ランで敵を倒したとき、星に戻る様子をゲーム中で見せるか。

### 2.3 伝説のモジュール

- 中ボスを倒すと、その中ボスが取り込んでいた星座の伝説のモジュールを1つ手に入れる。全部で4つ。
- 機体の性能に効かない。能力値の計算（7.1、9.1、14.1）に含めない。
- 4体の中ボスをすべて倒すと、4つそろう。
- 入手済みかどうかを保存し、図鑑（14.3）に載せる。
- 入手演出は16章のボス撃破を使い、部品の姿と既存名称を見せる。

| 画面・状態 | 内容 | 次へ |

| タイトル | 「ゲームスタート」「設定」「終了」のボタン | メインメニュー／設定／ゲームの終了 |
| 設定 | 音量、画面の揺れの強さ、ヒットストップの有無、画面モード、キー設定を変える。操作タブ末尾でデバッグ用ボタンの表示を切り替え、設定を保存する。表示の初期値はオンで、機能の状態は保持する。ゲーム内の表示言語は日本語 | 戻る：タイトル |
| メインメニュー | 「ステージ選択」「機体の強化」「図鑑」のボタン | ステージ選択／強化／図鑑。戻る：タイトル |
| 導入 | 場面ごとのイラストに対応する文章を順に表示する。構成と演出は[導入](game/art-style.md#38-導入)に従う | 完了・スキップ・戻る：タイトル |
| エンディング | 通常モードで竜のステージをクリアし、既存の決着演出が終わった後に4場面を再生する。文章送り・自動再生・フェードは導入と共通。報酬とクリア記録はED開始前に一度だけ確定する | 完了・スキップ・戻る：結果 |
| ステージ選択 | ワールドマップで、解放済みのステージ（2.2）とエンドレスモードから選ぶ。ステージは1から表示し、クリアすると次のステージが表示される。円盤や星座をドラッグして回転し、離すと最も近い星座が手前へ揃う。星座をクリックすると、その星座が手前へ移動する。最終ステージの解放後は、下矢印で円盤の下へスクロールして選択し、上矢印で直前の星座に戻る。見た目と開くときの演出は [デザインとアートスタイル](game/art-style.md) の3.2 | ラン。戻る：メインメニュー |
| 強化 | 部品で機体を強化する（14.1） | 戻る：メインメニュー |
| 図鑑 | モジュールを見る（14.3） | 戻る：メインメニュー |
| ラン | 通常のプレイ | ポーズ／カード選択／敗北演出／クリア演出 |
| ポーズ | Esc、またはウィンドウが非アクティブになったとき。「続ける」「設定」「メインメニューに戻る」を選ぶ。「設定」は設定の画面をポーズの上に開き、変えた設定はすぐランに効く。戻るとポーズに戻る。「メインメニューに戻る」でランをやめ、そのランで獲得した部品と記録は残さない | ラン／設定／メインメニュー |
| カードの選択 | 最初の武器の選択、レベルアップの選択（9.2） | ラン |
| 敗北演出 | 最後の被弾から結果画面まで（16） | 結果 |
| クリア演出 | ボスへのトドメから結果画面まで（16） | 結果 |
| 結果 | クリアタイムまたは生存時間、獲得部品・到達レベル・撃破数。クリア時は取得モジュールも表示。「同じステージをプレイ」で新しいランへ | ラン／メインメニュー |

- タイトル以外のすべての画面に、前の画面へ戻る操作がある。
- 初回起動時はタイトルより先に導入を再生する。タイトルの「もう一度イントロを見る」から同じ導入を再生できる。
- 導入の完了と明示スキップは独立した `intro_seen` を保存し、タイトルへ進む。既存セーブにこの項目がなければ未視聴で始める。途中で戻る操作を使った場合は、視聴フラグを保持してタイトルへ戻る。
- 文章は段落ごとに一文字ずつ表示する。初期設定は手動送りで、クリック・タップ・決定ボタンを押すと表示途中の文章を全文表示して待機し、次の操作で次の段落・場面へ進む。導入画面の「自動再生」と設定の「画面／演出」で切り替え、選択を次回の再生にも引き継ぐ。自動再生では全文の表示後に間を置いて進み、切り替えたときは今の段落を保って待ち時間を数え直す。フェード中は次送りを保留し、スキップは受け付ける。

## 4. ランの進行

### 4.1 時計と勝敗

- 時計は、ラン開始からの経過時間を実秒で数え上げる。描画中・なぞり中も進み、ポーズ・カード選択・ヒットストップの間は止まる。
- ステージの `boss_enabled` がオンなら、ボスは `boss_time` に1体現れる（12.2）。負の値なら、`config.boss_time` から `config.boss_time` ＋ `config.boss_time_spread` の間でランごとに時刻を決める。
- ステージの `time_limit` 以上にランの時計が進むと、時間切れになる。ボスが避けられない一撃を放ち、機体は敗北する（16章）。負の値なら制限時間は無効。残り時間は画面に出さず、時計は経過時間のまま。
- **クリア**：ボスを撃破する。時計はトドメの時点で止まる。
- **失敗**：機体の HP が0になるか、時間切れになる。部品と記録は、どちらも同じ扱い。
- 結果で、獲得した部品をセーブに加え、記録を更新する（14.2）。クリアなら毎回、選択ステージの `clear_bonus` を足す。

### 4.2 時間帯

ステージが使う時間帯の並びは `speed/data/stages/*.tres` の `phases`。時間帯の値はステージのデータの中にある。時間帯の名前は画面に出さない。

- 時間帯は開始の時刻（`start`）だけを持ち、次の時間帯の開始まで続く。最後の時間帯の値はボスの出現基準時刻（4.1）までの間で補間し、そのあとはボスを倒すまで続く。
- 敵の数は、時間帯の始めの値と終わりの値（`pop_from`・`pop_to`）を時間帯の中で直線補間し、`config.density_mult` を掛けたもの。
- 補充の速さは `rate` × `config.density_mult`（体/秒）。
- 1体ずつ補充する敵は `mix`（type ID → 重み）から選ぶ。ステージが雑魚の目標の数の曲線（11.3）を持つときは、敵の数と `mix` の代わりに曲線を使う。
- `attack_budget` は、強敵の攻撃の整数予算（11.7）。出現タイムラインの時間帯に表示する「予算」から編集する。
- `wave_interval` があれば、その間隔で群れをまとめて出す（11.3）。
- **強化帯**：ステージの `surge_start`（負の値なら `config.surge_start`）から、`config.surge_interval` ごとに段が1つ上がる（始まった時点で1段）。1段ごとに、目標の敵の数を `config.surge_pop` の割合だけ増やし、撃つ敵（敵の定義の `ranged`）の出現の重みを `config.surge_ranged` の割合だけ増やし、エリートになる確率に `config.surge_elite` を足す。ステージの `surge_end` に達したあとは、その時点の段を保つ。負の終了時刻なら段を増やし続ける。時間帯ごとのON/OFF（ステージの `surge_phases`）を指定した時間帯は、その区間全体をONまたはOFFにする。未指定の時間帯は既存の強化帯を使う。複数のON区間を扱い、ONの累計時間で強化を進め、OFFの間は強さを保つ。隣接するON区間は1つの区間として扱う。強化内容は時間帯の `surge_interval`・`surge_pop`・`surge_ranged`・`surge_elite` で上書きでき、負の値なら共通設定を引き継ぐ。1段進むごとに、その時点の時間帯の設定値を加える。到達済みの増分と途中までの進行は、次の時間帯へ引き継ぐ。

### 4.3 操作練習

ステージ1の通常の出撃は、操作練習を終えるまで、ランの冒頭に操作練習を付ける。練習は通常のランの機体・線・ブースト・敵・星のかけら・カードをそのまま使い、説明と実際の操作を段ごとに交互に進める。

| 段 | 説明の題 | 進む条件 |
|---|---|---|
| 移動 | 移動 | 光る輪へ3回移動する |
| ブースト | ブースト | お手本の線の上に並んだ敵へ向けて、ブーストを1回終える。段の開始時にゲージを満タンへ戻す |
| ゲージ | ゲージ | 機体の左右に置いた2組と、前の段の残りの敵をすべて倒す |
| 星のかけら | 経験値とレベルアップ | 落ちている星のかけらを拾ってレベルアップする |
| カード | 武器と特性 | 武器か特性を1枚選ぶ |

- 段の前に、実際のランを録画した動く絵・題・説明文のパネルを出し、ランを止める。クリック・タップ・決定で閉じると操作が始まる。文章は[ゲーム内文言](game/text.md)の `tutorial.*` を使う。
- 操作中は画面の下に、進む条件と残りの数を表示する。ブーストとゲージの段は、その下に「クリック › 動かす › クリック」の手順を並べ、今の操作に合う項目を明るくする。
- お手本の線は本番の描線と同じ帯を白で描き、始点「1」と終点「2」にマウスの絵を添える。目標が画面の外にある間は、機体から目標の向きへ矢羽根を流す。
- 練習の間、ランの時計・通常の出現・ボス・隕石や彗星などのフィールドの動き・英雄の星座は止まり、機体は被弾しない。置いた敵はその場に留まり、攻撃しない。
- 星のかけらは「星のかけら」の段まで地面に残り、その段から拾える。その段の開始時に、落ちている分を拾い切ると次のレベルへ届く量まで、手持ちの経験値を補う。
- カードを選び終えると「チュートリアル終了」のパネルを出し、ここからが本番であることと操作ガイドの場所を伝える。閉じると練習の敵を消し、最初の武器の選択（9.2）を開いて通常のランを始める。この選択の候補は、練習で取った武器を除く。
- 練習の完了は `tutorial_done` として保存する（14.2）。途中でランを抜けた場合は、次のステージ1の出撃でもう一度始める。エンドレスと審査版は練習を付けない。
- ポーズメニューの「操作ガイド」は、同じ5枚のパネルを1枚ずつ表示し、「前へ」「次へ」と左右キーでめくる。
- 説明と操作中の表示は、戦闘HUDと同じ640×360の原画の寸法で作り、画面に合わせて拡大する。

## 5. 機体

| 項目 | 値 |
|---|---|
| 当たり判定の半径 | `config.ship_radius` |
| 最大 HP | `config.base_hp`。強化で増える |
| 被弾後の無敵 | `config.invuln_time` |
| 最高速度 | `config.base_max_speed`。レベル・特性・強化で伸びる |
| 回収範囲 | `config.pickup_radius`。特性・強化で伸びる |

被弾後の無敵は、攻撃した敵ごとに数える。雑魚・強敵の攻撃を受けると、その敵の攻撃が被弾後の無敵の間だけ当たらなくなり、ほかの敵の攻撃はその間も当たる。ボスの攻撃と、攻撃した敵を特定しない被弾では、すべての攻撃が当たらなくなる。

### 5.1 通常の移動

- **マウス**：機体はカーソルの方向へ進む。カーソルが機体から `config.mouse_dead_zone` 以内なら向きを変えない。向きは毎秒 `config.steer_rate` ラジアンで回る。最高速度 × `config.steer_cruise` に達するまで、毎秒 `config.steer_accel` ずつ加速する。
- **タッチ**：押した点を中心とする仮想スティック。`config.stick_dead_zone`（px）未満のずれは無視する。スティックは向きだけを決め、巡航速度はマウスと同じ最高速度 × `config.steer_cruise`。
- 速さが `config.pivot_speed` より遅いときは、機体の向きを最後に操作した向きのままにする。

### 5.2 速さの減り方

- 発射（なぞりの開始）から `config.boost_duration` の間は減速しない。その後、残す速さを `config.energy_cut` まで落とす。
- 普段は弱い抵抗（`config.cruise_drag`）で減速するが、最高速度 × `config.cruise_floor` より下には落ちない。最高速度を超えた分は毎秒 `config.overcap_decay` の割合で減る。
- なぞり終えたあとの勢い（6.6）がある間は、勢いの決まりで速さが決まり、ほかの減速はかからない。

## 6. ゲージと描画

### 6.1 充填

- ゲージは**容量**と**充填率**（0〜100%）で表す。ラン開始時は満タン。
- 容量 ＝ 1 ＋ 大容量チャージによる増加。容量は回数のストックではなく、1回で描ける長さと勢いを増やす。
- 溜まっている量 ＝ 容量 × 充填率。
- 1単位の充填にかかる時間は `config.dash_charge_time` 実秒。急速充填と強化「充電効率」で短くなる。満タンまでの時間は、容量 × 1単位の充填時間。
- 描画中・なぞり中・ポーズ中・カード選択中は溜まらない。経験値や撃破では溜まらない。

### 6.2 描き始め

- 溜まっている量が `config.draw_min_charge` 以上のとき、容量に関係なく、クリックした位置から描き始められる。補助として Space でも開始でき、タッチでは「描く」ボタンを使う。描き始めの点は、惑星・月の外へ押し出す。
- 描ける長さの上限 ＝ `config.draw_length` × 開始時の充填率 × 容量 ×（最高速度 ÷ `config.base_max_speed`）× 軌跡延長の倍率。自機から線の始点までの移動もこの上限に含め、描画中の残りは上限から接続区間と描いた長さを引く。上限以上に離れた位置には始点を置けない。
- 始点を置く前にカーソルが届く範囲から外れると、リングを不足時の色にし、始点が遠すぎることをカーソルのそばへ表示する。Spaceで描画を始めてから最初の点を置くまでにも適用する。
- 描画中は、ボタンを押し続けずにカーソルを動かすだけで線が伸びる。点は `config.draw_step` 単位ごとに記録する。描く時間に制限はない。
- 描画中、世界の速さは `config.draw_time_scale` 倍。カメラはその場で固定する。
- 描画中・なぞり中の当たり判定の半透明帯は、経路が交差・折り返しても同じ濃さを保つ。帯の始点・終点と曲がり角は丸くつなぎ、幅は `config.trace_radius` に合わせる。中心線は帯と別に重ねる。
- 自機・通常敵・ボス・ドローンの描画には `config.character_scale` を適用する。敵・ボス・ドローンの判定も同倍率、自機の判定は調整した `config.ship_radius` を使う。隕石・月・惑星は対象外で、カメラ倍率は従来どおり。
- カーソル近くのリングに、描画前は溜まっている量を、描画中は残りの長さを表示する。内側のリング1周が容量1にあたり、大容量チャージで増えた容量は外側のリングの弧で表す（容量2で外側も1周）。溜まる量は内側から順に埋まり、描画中は外側から減る。内側のリングの `config.draw_min_charge` の位置に目盛りを置き、それ未満は暗い緑、以上で明るい緑（満タンも同じ）。使えるようになった瞬間にリングから広がる輪を出し、内側・外側のリングがそれぞれ溜まりきった瞬間に一瞬白く光る。

### 6.3 確定

次のどれかで線が確定し、なぞりが始まる。

- もう一度クリックする（描き始めてから `config.draw_confirm_delay` 実秒たち、線ができているときだけ。それ以外のクリックでは描き続ける）
- 描ける長さを使い切る
- 線が惑星・月に届く（その位置で線を切り詰める）

線ができないまま惑星・月に届いたときは、描くのをやめ、ゲージは減らない。

### 6.4 消費

- 消費する割合 ＝ 開始時の充填率 ×（自機から線の始点までの距離 ＋ 実際に描いた長さ）÷ 今回の上限。例：満タンから上限の40%だけ描くと、60%残る。
- 確定したら、途中で敵に止められても消費は戻らない。
- 残りが使える充填率以上なら、なぞり終えたあとすぐ次の線を描ける。足りなければ、残りから充填を再開する。

### 6.5 なぞり

- 機体は自機から線の始点までの区間を含む経路を `config.draw_run_time` 実秒でなぞる（ヒットストップの分だけ延びる）。
- 突進の速さ ＝ 最高速度 × `config.launch_ratio` × 充填の量 ＋ 同じ向きの今の速さ × `config.carry`（最高速度 × max(1, 充填の量) が上限）。
- なぞり中の世界の速さ ＝ `config.draw_run_slow_ref` ÷ 突進の速さ。ただし `config.draw_run_scale_min` 倍より遅くしない。カメラは固定。
- 機体は常に実際の進行方向へ向く。炎・火花のアニメーションは描画中・ヒットストップ中は停止し、移動中は速さに応じて再生する（なぞり中は線上の移動速度を使う）。
- なぞり中の機体の当たり判定は、線の左右 `config.trace_radius` 単位の帯（機体本体の半径より太い）。帯に触れた敵には体当たりの判定（7.2）を行う。貫いた敵は吹き飛び、機体は減速しない。
- 帯から一度外れて再び触れた敵には、もう一度当たる。実際に再貫通したときは「×2」「×3」と表示する。
- 装甲を突破できない敵や障害物に当たると、その場で止まる（弾かれ）。
- 満タンから始めた線をなぞっている間は「ギアアップ」の効果がかかる。

### 6.6 なぞり終えたあとの勢い

- なぞりを最後まで終えると、勢いに入る。勢いの速さ ＝ 突進の速さ × `config.glide_speed_ratio`（巡航の速さ（5.1）より下にはしない）。カーソル／スティックで向きを変えられ、この間は5.2の減速をかけない。
- 勢いの保持・減速時間は、走り切った経路の距離を `config.draw_length` で割った割合（0〜1）に応じて伸縮する。描き始めまでの接続区間も距離に含める。`config.glide_hold`・`config.glide_fade` にこの割合と[慣性航行](game/catalog/traits.md)の時間倍率を掛け、保持のあと巡航の速さまで直線で落として終わる。
- なぞり終了時の速さが描画開始前より低ければ、終了時の進行方向のまま描画開始前の速さを引き継ぐ（勢いの速さはこの速さから求める）。弾かれて途中終了した場合も、弾かれた方向を保って同じ下限を適用する。
- 雑魚を貫いても減速しない。
- 次のときに通常の移動へ戻る：装甲を突破できない敵・惑星・月への衝突、敵の弾を受けたとき。
- この間、無敵にはならない。

## 7. 戦闘の計算

### 7.1 攻撃力

- A ＝ `config.base_attack` × 攻撃力倍率 × `config.atk_scale` × ギアアップの倍率。
- 攻撃力倍率は、特性「攻撃力」・強化「パワースパイク」で上がる。
- 威力は移動の速さと関係しない。

### 7.2 接触

通常敵に触れると、こちらの攻撃になる。ボスとの接触は、攻撃中の部位・高速の体当たり・通常接触の順で扱う。

- **高速の接触**：なぞり中、なぞり終えたあとの勢いがある間、または最高速度 × `config.ram_speed_ratio` 以上で動いているとき。敵への体当たり攻撃になる。
  - A ≥ 敵の装甲 なら貫通し、ダメージを与える。貫いたあとの減速は、勢いがない普段の高速の接触のときだけ。倒した敵1体ごとに約8%（大きい敵ほど少し増える）、倒しきれなかった敵では約1割落ちる。群れに深く突っ込むと失速し、高速の接触の速さを下回る。
  - A < 敵の装甲 なら弾かれて止まる（失敗）。跳ね返り、速さを `config.bounce_keep` の割合だけ残す（最低 `config.bounce_min_speed`）。敵には A の 1/4 を与える。被弾はしない。
- **普段の接触**：上記以外。弱い攻撃になり、A × `config.touch_damage` を与える。倒した敵1体ごとに約3%（大きい敵ほど少し増える）減速する。
- **特殊な倒し方**：倒し方の条件を持つ敵（敵の定義の `gate`）には、条件を満たさない攻撃ではダメージが通らない。体当たりは貫通する（止まらない）。ただし、たて座の前面への体当たりは弾かれる（失敗）。条件ごとの扱いは [敵一覧](game/catalog/enemies.md)。
- ケンタウルス座・おおいぬ座・いっかくじゅう座への高速の体当たりでダメージが通ると、見えている本体画像の縁で火花とヒットストップを出し、停止後に進行方向の反対側の縁へ機体を移す。部位の姿勢と透過部分を接触・移動先・火花で共用する。演出値と通常接触のダメージ量は `speed/data/visuals/fx_reference.tres` を使う。
- ボスの接触攻撃が有効な部位に当たると、その技のダメージを受け、通常の白い点滅を出す。対象部位と有効区間は各ボスの仕様に従う。通常のボス本体への低速の接触でも機体がダメージを受ける。ボスの接触・着地・装甲不足の体当たりでは自機の位置・速度・描画中の経路を保ち、装甲不足の体当たりはAの1/4を与える。
- 同じ敵には `config.contact_cooldown` の間、続けて当たらない。
- **隕石**は固い障害物。普段の速さで触れると押し出されて跳ね返り、A の 1/4 を与える（同じ隕石には0.25世界秒に1回）。上は通り抜けられない。高速で装甲を破れなければ弾かれる。
- 惑星・月にぶつかると、`config.crash_restitution` の反発で跳ね返る。

### 7.3 クリティカル

- クリティカルは体当たりで判定する。武器・破片などの当たりはクリティカルにならない。
- 確率は `config.base_crit_chance`（急所見切りと[通常育成完了後の追加強化](#通常育成完了後の追加強化)で上がる。上限は急所見切りの `max`）。威力は × `config.crit_mult` に追加強化分を足した倍率。装甲の判定に × `config.crit_armor` の値を使う。
- 背面の弱点を持つ敵（敵の `weak_arc` が0より大きい種類）は、背面に体当たりすると必ずクリティカル。背面を黄色い弧で示す。

### 7.4 ヒットストップ

- 体当たりで敵を一撃で倒したとき、戦闘シミュレーションを `config.kill_hitstop` 実秒止める。大型の敵は × `config.hitstop_big_mult`、クリティカルは × `config.hitstop_crit_mult`。
- 体当たりクリティカルにも停止時間があり、撃破時は長くなる。同じ命中の一撃撃破とクリティカルは、長い方の時間を1回使う。HPの実減少がある命中を対象にする。
- 敵・ボスの種類ごとの `hitstop_multiplier` を停止実時間に掛ける。未指定と1は共通時間を継承し、0はその種類の停止を無効にする。0より大きい値はその倍率の長さで完全停止する。世界の速度倍率とボスの白色化・振動はそれぞれ独立して扱う。
- 一撃かどうかは、その突進で最初に体当たりが当たった時点の HP で判定する。
- 一撃撃破・クリティカルを合わせ、1回の突進で要求する停止時間の合計を `config.kill_hitstop_cap` までに収める。同時命中では残り時間の最大値を使い、各要求を残予算で切り詰める。突進していない間、この上限は毎秒 `config.kill_hitstop_regen` ずつ戻る。
- 機体がダメージを受けると、戦闘シミュレーションを `config.hurt_hitstop` 実秒止める。この停止は突進ごとの上限に数えない。HPが0になる一撃では止めず、敗北演出（16）へ移る。
- 停止残量は実時間でゼロまで減らし、再開は固定更新の境界で判定する。1更新より短い要求も1更新分の停止になる。ポーズ・カード選択・敗北・決着・終了へ移ると解除し、操作ロック・被弾保護中の演出とヒットストップ設定OFFでも解除する。
- 設定でヒットストップを切ると、ヒットストップは起きない。

### 7.5 敵の狙い

- 敵は機体の実際の位置ではなく、遅れて追いかける位置を狙う。`config.enemy_aim_lag` 秒遅れで、その位置は毎秒 `config.enemy_aim_speed` より速く動かない。なぞり中は照準位置を固定し、終了後は同じ速度上限で追従を再開する。射撃・誘導・追跡・突進の構えの共通照準として使う。個別の照準を持つかじき座の突進は [敵一覧](game/catalog/enemies.md#かじき座の突進) に従う。
- 遅れて追う位置は、画面の半径の55%（最低300）より機体から離れないように補正する。

## 8. 武器と特性

- **枠**：武器 `config.weapon_slots` 個、特性 `config.trait_slots` 個。
- **上限**：武器は Lv `config.weapon_max_level`、特性は Lv `config.trait_max_stacks` まで育つ。
- **最初の武器**：ラン開始時に選ぶ（9.2）。
- **武器の強さ**：表示 Lv を性能段階 P（武器の `level_steps`）に対応させる。威力係数 D ＝ 1 ＋ 0.3（P−1）、頻度係数 F ＝ 1 ＋ 0.12（P−1）、範囲係数 R ＝ 1 ＋ 0.1（P−1）。
- **彗星限定の武器**：アンカーキャノンと双極ビームは、レアな彗星（13.1）を壊したときだけ手に入る。レベルアップの候補には出ず、強化もない。手に入れたときから Lv の上限（`config.weapon_max_level`）の強さで装備する。
- **彗星限定の武器の受け取り**：カプセルを拾ったら、描画中・なぞり中が終わってから受け取る。空き枠があれば装備する。枠が満員なら、所持武器から交換対象を選ぶ画面を出す。提示中の新武器を破棄する選択では、現在の装備を保って画面を閉じる。レベルアップの回数は使わず、リロールはできない。
- **個別の性能**：各武器のLv別配列と発動条件は[武器一覧](game/catalog/weapons.md)、特性の条件と倍率は[特性一覧](game/catalog/traits.md)に従う。範囲・射撃弾数・射撃頻度・全攻撃の威力を共通の倍率として扱う。
- **色**：段階1＝白、2＝緑、3＝青（#3989ff）、4＝紫、5＝金。武器の Lv と特性のLvに共通。カードは取得後の段階、装備一覧は現在の段階で色を決める。
- 味方の弾と攻撃する破片は、惑星・月に当たると消える（敵を貫く弾も地形は貫かない）。波動・範囲攻撃・ビームは地形に遮られない。

### 8.1 英雄の星座の力

- **特別な枠**：武器・特性とは別の1枠。英雄の星座（13.1）を解放すると、その星座の力が入る。Q（キー設定で変えられる）で発動する。
- **クールダウン**：発動してから次に使えるまでの時間と、効いている時間は、星座ごとに決める（`speed/data/heroes/<ID>.tres` の `cooldown`・`duration`）。クールダウンは効いている時間を含み、実秒で進む。
- 力はそのステージの間だけ使える。ランの状態と一緒に、ステージが終わると無くなる。
- エンドレスモードでは、新しい星座を解放すると、特別な枠の力が入れ替わる。

| 英雄の星座 | 捕らわれているステージ | 力 |
|---|---|---|
| しし座 | 1 | 獅子まとい |
| ペルセウス座 | 2 | メドゥーサの首 |
| ふたご座 | 3 | 光と影の兄弟 |
| ヘルクレス座 | 4 | 火の隕石 |

- **しし座（獅子まとい）**：効いている間、機体は星の獅子になり、カーソル／スティックの向きへいつも `speed` の速さで駆ける（曲がる速さは `config.steer_rate` × `turn_mult`）。なぞり（6章）は始められず、武器と特性は働かない。被弾しない。当たり判定は、機体の向きにそって前へ `front`・後ろへ `back` の線分に半径 `radius` をつけた獅子の体。体に触れた敵（大物・ボスも同じ）には、装甲や特殊な倒し方に関係なく、`config.base_attack` × `config.atk_scale` × `power` のダメージを与え、同じ敵には `hit_interval` 世界秒ごとに当たる。弾かれも減速もしない。触れた隕石は砕け、触れた敵の弾は消える。惑星・月には普段どおりぶつかる。描画中・なぞり中には発動しない。
- **ペルセウス座（メドゥーサの首）**：発動すると、機体の上でメドゥーサの目が開く。発動から `open_delay` 実秒で目が開ききると、画面の中の敵（ボスと障害物のほか）と敵の弾が石になって止まる（石の時間は世界秒で進む）。さらに `shatter_delay` 実秒たつと、石になった敵は装甲や特殊な倒し方に関係なく一斉に砕けて倒れ、石になった弾は消える。大物（星6以上）は砕けずに石が解け、最大HPの `big_damage_ratio` のダメージを受ける。画面の中のボスは石にならず、目が開ききった瞬間から `boss_stun` 実秒だけ止まり、砕ける瞬間に最大HPの `boss_damage_ratio` のダメージを受ける。大物とボスへのダメージも、装甲や特殊な倒し方に関係なく通る。
- **ふたご座（光と影の兄弟）**：発動すると、機体が光の機体と影の機体に分かれ、効いている間は2機で動く。影は機体の右横（機体の絵の40ドット）を並走し、並走中も機体の接触（7.2）と同じ決まりで当たる。線は1本だけ描く。突進すると、機体は描いた線を、影はその線を「突進を始めた機体の位置を通り、それまでの機体の向きに平行な線」で左右反転した経路を、同じ速さで同時に駆け抜ける。影は機体の分身で、体当たりは機体の突進の体当たり（6.5）と同じ決まりで当たる（威力・装甲・会心・弾かれ・ボスや隕石への当たり方、接触で働く武器も同じ）。弾かれたら、影の突進もそこで終わる。影は被弾せず、影が敵やボスに触れても機体は被弾しない。影は機体の武器を同じように使う。武器が撃った弾は影の位置からも同じ向きに出て、突進の終わりに使う武器は影が走り終えた所で使い、突進に付いていく武器（ソニックブーム・ミラージュ・エスコートウィング・質量牽引）は影にも付く。発射間隔は機体と共通。分かれきるまで（発動から1.15実秒）は影は武器を使わず、影のドローンはそのあと0.6実秒かけて現れる。効果が切れても、走り出した影は経路の終わりまで走る。
- **ヘルクレス座（火の隕石）**：発動から `start_delay` 実秒（画面に炎が燃え広がる間）待ち、そこから効いている間、`interval` 実秒ごとに、機体の周り（画面の半分くらいの範囲）に火の隕石を1つ落とす。落ちる場所はランダムで、範囲に敵がいればその敵の所に寄せる（うみへび座との関係は [専用仕様](game/bosses/hydra.md#9-実装調整接続)）。`fall_time` 実秒の影のあと、半径 `radius` の範囲の敵を、装甲に関係なく A × `power` で焼く。落ちた跡は `burn_time` 実秒燃え、入ってきた敵を 0.25 秒ごとに A × `power` × `burn_power` で焼く。
- 力の値（`speed` など）は `speed/data/heroes/<ID>.tres` の `params`。

## 9. 成長

### 9.1 経験値とレベル

- レベルは0から始まる。レベル L から次へ必要な経験値 ＝ `config.xp_base` ＋ `config.xp_growth` × L ＋ `config.xp_curve` × L²。係数は全レベルで共通とし、複数レベル分を一度に取得した余剰も次へ持ち越す。
- 成長調整はステージ1・2のボス前の装備完成度と序盤の選択機会を基準にする。ステージ3・4・5の成長調整は後続の確認対象とする。過去録画からの成長換算は、星のかけらの位置と回収時刻を再現しない参考値として扱う。
- レベルが1上がると、最大 HP × `config.level_heal` を回復する。最高速度・攻撃力・最大 HP などの能力値は、選択した装備・追加強化から求める。
- ゲージの充填時間はレベルでは短くならない。

### 9.2 カードの選択

**最初の武器**：狙ったビルドを組みやすくするために、ラン開始時に最初の武器を選ぶ。

- 全武器からランダムに `config.start_weapon_choices` 種類を出し、1つを選んで Lv1 で始める。選ぶまで時計は止まる。

**レベルアップの選択**

- レベルが1上がるごとに最大3枚のカードを出し、1枚を選ぶ。
- 武器が未完成の間は「新しい武器」「武器の強化」「特性（新規またはLv上昇）」を混ぜて抽選する。同じ候補を1画面に重複させない。
- 持っているものは × `config.owned_card_bias` の重みで出やすくする。枠が埋まったら新規取得のカードは出さない。上限に達したものは出さない。
- 通常育成中の有効候補が1〜2枚なら、その枚数を提示する。候補が尽きたレベルアップは選択画面を開かずに完了する。
- 複数のレベルが一度に上がったら、1レベルにつき1回ずつ選ぶ。選択画面同士の間に待ち時間はない。
- **おまけ**：武器・特性のレベルアップカードを選んだあと、確率 `config.levelup_bonus_chance` で、持っている武器・特性のうち上限に達していないものからランダムに1つが、選ぶ画面を出さずに1段上がる（2つ目）。起きたら確率 `config.levelup_bonus_more` で3つ目、さらに `config.levelup_bonus_last` で4つ目が上がり、そこで止まる。各確率は直前の段階に到達したあとの条件付き確率とし、2つ目・3つ目・4つ目へ進むほど下げる。上がったものは1つずつカードで見せ、カードが止まったらクリックで次へ進む。見た目は[連続強化の演出](game/art-style.md#連続強化の演出)に従う。最初の武器の選択と、彗星限定の武器の入れ替えでは起こらない。
- 継続回数は選んだカードの強化を1つ目に数え、最大4Comboとする。

どちらもクリックまたは数字キー1〜3で選ぶ。

#### 通常育成完了後の追加強化

武器枠と特性枠がともに埋まり、装備中の全武器が `config.weapon_max_level`、所持中の全特性が `config.trait_max_stacks` に達すると、その後のレベルアップは同じ選択画面で追加強化と即時回復を抽選する。彗星限定の武器も装備枠のMAXとして数える。どちらかに空き枠や未完成の装備があれば、通常の取得・強化候補を優先する。ゲーム全体の未取得特性までMAXにする必要はない。

- 育成完了後は各画面に追加強化を最低1枚提示し、残りも追加強化から重み付き抽選する。追加強化は各候補の重みを等しくする。
- 追加強化の候補はレアリティを持たず、同じ色で短い効果名と今回の増分を表示する。累計や対象ごとの実効値は詳細表示で確認できる。
- 同じ画面では候補を重複させず、別のレベルアップでは同じ追加強化を繰り返し取得できる。対象武器がない効果・上限に達した効果・満HPでの即時回復は候補から除く。
- カード正面は次の増分を示す。詳細には育成完了後の累計増分、機体能力の現在値と取得後の値、範囲・追撃威力の対象を示す。
- 増分と安全上限の正は `config.post_max` が参照する `speed/data/post_max.tres`。値は試遊用の仮調整とし、実際の操作感・終盤の火力・生存性を試遊して調整する。
- 増分はそのランだけに保持する。倍率項目は基礎値へ特性・永続強化を反映した基準に追加強化の合計を掛け、同じ効果を繰り返し選ぶ場合は基準に対して加算する。武器共通威力と対象武器の追撃威力も同じ基準へ足す。クリティカル率と修理キット回復割合の「+1%」は、実効割合へ0.01を加える。

| 候補 | 増分キー（`post_max.tres` の `increments`） | 適用 |
|---|---|---|
| 武器威力・攻撃間隔 | `weapon_damage`・`weapon_interval` | 装備武器の実際の攻撃に適用。間隔短縮は周期発動・発射・防弾の待ち時間を持つ武器に適用 |
| 武器の弾速・持続・吹き飛ばし | `projectile_speed`・`duration`・`knockback` | 武器弾・攻撃する船体と破片、機雷、攻撃中の衝撃波など、実際の適用先を持つ武器に適用 |
| クリティカル率・倍率 | `crit_chance`・`crit_mult` | 既存の体当たりのクリティカル経路に適用 |
| 巻き込み範囲・追撃威力 | `area`・`followup` | [武器一覧の適用先](game/catalog/weapons.md#通常育成完了後の適用先)と `targets` に従う |
| 最高速度・加速・旋回・線の長さ | `max_speed`・`acceleration`・`turn_rate`・`line_length` | 通常の操縦・線の予算に適用 |
| 充填時間 | `charge_time` | 特性・永続強化込みの充填時間を基準に短縮 |
| 最大HP・被弾後無敵・修理キット | `max_hp`・`invulnerability`・`repair` | 最大HPは固定量を加え、現在HPを維持する。無敵は世界秒、修理キットは最大HPに対する回復割合を加算 |
| 即時回復 | `heal` | 選択時の最大HPに対する割合を即座に回復し、最大HPで止める。通常のレベルアップ回復を先に行う |
| XP吸引範囲・吸引速度・XP獲得量 | `pickup_radius`・`pickup_speed`・`xp_gain` | 星のかけら専用の半径を拡大し、速度は星のかけらの吸引式全体を倍率化。硬貨・カプセルは既存の基準を使う。獲得量は[星のかけらの共通取得入口](#102-取得と保持)で、機体の永続強化とラン内強化を取得時に一度だけ適用 |

時間短縮は基準時間に `minimum_time_ratio` を掛けた値と、攻撃間隔の `minimum_interval`・充填時間の `minimum_charge_time` のうち長い値まで適用する。基準自体がその下限より短い場合は基準を保つ。被弾後無敵は `maximum_invulnerability`、修理キットは `maximum_repair_fraction` で止める。

急所見切りの増分は特性自身の `per_stack`・`late_per_stack` を使い、特性自身の `max` を適用する。追加クリティカル率の上限は「急所見切りの `max` から、急所見切りを最大Lvまで取得した基礎込みの確率を引いた残り」とする。取得順にかかわらず、急所見切りを取得するための余地を確保して追加分を合算する。


### 9.3 リロール

狙ったビルドを組みやすくするために、表示中のカードを引き直せる。

- 最初の武器の選択と、レベルアップの選択の両方で使える。新しいカードは、それぞれ9.2と同じ決まりで抽選する。
- 回数は1回のランで `config.reroll_count` 回。強化「リロール」（14.1）で増える。
- 選択画面のボタン、または R キー。ボタンに残りの回数を表示し、残り0回では押せない。

### 9.4 保留

- 描画中・なぞり中に上がったレベルのカード選択は、なぞりが終わってから出す（弾かれて止まった場合も終わってから）。
- カード選択を閉じたら、直前の速度を引き継いで再開する。

## 10. ドロップと回収

### 10.1 星のかけら

星のかけらは `low`・`mid`・`high` の3種類。種類ごとの通常の基準XPは `config.xp_crystal_values` を正とし、保持XPは獲得量の倍率を掛ける前の基準量として扱う。[外観](game/art-style.md#39-星のかけら)は全種類で同じ形・寸法を使う。

| 種類 | 通常の基準XP |
|---|---|
| `low` | `config.xp_crystal_values[0]` |
| `mid` | `config.xp_crystal_values[1]` |
| `high` | `config.xp_crystal_values[2]` |

実際の撃破1回ごとに、敵定義の星数 `rank` と[種類別上書き](game/catalog/enemies.md#撃破報酬)から報酬を決める。個数は次の規則で固定する。

| 星 | 確定ドロップ | 黄色の追加抽選 |
|---:|---|---|
| 1 | 水色1個 | — |
| 2 | 水色2個 | — |
| 3〜4 | 紫1個 | 撃破1体につき1回 |
| 5〜10 | 紫2個 | 撃破1体につき1回 |

黄色の追加抽選は `config.strong_gold_chance` を使い、当選時に黄色1個を確定報酬へ加える。抽選単位は実撃破の敵個体で、紫の個数にかかわらず1回とする。召喚された通常敵にも同じ種類・星数の規則を使い、エリートも基準個数を共用する。退却・再配置・部位整理・場面終了の削除と実撃破を区別する。

星のかけらの基準XPは種類と上書きから求める。HP、敵のサイズ、エリートの強さ、フェーズ、現在Lvから独立させる。星0は敵定義へ明示した対象に報酬を持たせ、ボス本体は専用の決着処理を使う。

### 10.2 取得と保持

通常回収と回収ビーコンは同じ取得入口を使い、保持基準XPの合計 × 機体の経験値強化倍率 × ラン内の経験値獲得量倍率を実取得XPへ加える。小数は内部で保持する。ビーコンは取得開始時の倍率を全対象へ一度だけ適用する。開発操作で最終取得XPを直接指定する入口は、この星のかけらの取得入口と分ける。

回収範囲に入った星のかけらは機体に吸い寄せられ、地面の星のかけらは回収されるまで保持する。画面外と吸い寄せ中を含む全色合計を `config.gem_max` 個まで保持する。カメラ範囲を各辺128px広げた範囲から、機体に近い順に `config.gem_draw_max` 個まで描く。同距離は生成IDの小さい順に選ぶ。描画対象から外れた星のかけらも保持し、回収判定・経験値は制限しない。

上限で新規の枠が足りないときは、既存の画面外の星のかけらを優先し、保持基準XPが低い、機体から遠い、地面への配置が古い順に必要数を取り除く。不足分は画面内から同じ順で選ぶ。取り除いた個数と基準XPを消失として記録し、空いた枠に撃破現場の新しい星のかけらを生成する。複数個の報酬と同時に戻る運搬分は、生成前にまとめて必要枠を確保する。同じドロップの新規分はこの選択の対象外とする。分裂する雑魚の固有報酬6個にも同じ規則を使う。

からす座は星のかけらごとの種類・個数と実際の保持基準XPを運ぶ。倒したからす座が戻す星のかけらも、運搬時の種類・個数と保持基準XPを引き継いで生成入口へ戻す。運搬と再ドロップは供給済みXPの移動として扱い、取得倍率は機体への回収時に適用する。持ったままの退場は持ち去りとして記録する。

### 10.3 その他の報酬とドロップ

| もの | 出どころ | 効果 | 寿命 |
|---|---|---|---|
| 修理キット | 隕石の破壊で確率 `config.meteor_heal_chance` | 最大 HP × 実効回復割合（基準は `config.meteor_heal_frac`、追加強化を加算）を回復（上限を超えない） | `config.pickup_life` |
| 回収ビーコン | 隕石の破壊で確率 `config.meteor_magnet_chance`（修理キットとは別に抽選） | フィールド上の全色の星のかけらを[共通取得入口](#102-取得と保持)で回収 | `config.pickup_life` |
| 部品 | 隕石で確率 `config.meteor_coin_chance`（1〜3個）、エリートで3〜6個、ほかの敵は3%で1個 | 抽選数を `config.coin_gain_percent` %でラン内に蓄積し、1個に達するたびに部品数へ即時加算する。ラン終了時は整数分を持ち越し、機体の強化に使う（14.1） | — |
| 彗星限定の武器のカプセル | レアな彗星の破壊で必ず。中身の武器は彗星が現れたときに決まる | 彗星限定の武器を受け取る（8章） | — |

- 修理キットと回収ビーコンは回収範囲に入ると機体に吸い寄せられる。
- HP が満タンのとき、修理キットはその場に残る。
- 彗星限定の武器のカプセルは機体が触れたときに拾う。

## 11. 敵

種類ごとの基礎値・行動の値は `speed/data/enemies/*.tres`。

### 11.1 見た目と強さ

- 区分は敵の定義の `rank`（取り込んでいる星の数）。星1が雑魚、星2が硬めの敵、星3〜5が強敵、星6〜10が大物。強敵と大物は星座をモチーフにする。種類と星の数は [敵一覧](game/catalog/enemies.md)。
- 星の数を強さの目安にする。見た目は [デザインとアートスタイル](game/art-style.md) の4.2。
- 星1〜5の敵の HP の基礎は、星と HP の属性（敵の定義の `toughness`：柔らかめ −1・標準 0・硬め ＋1）で決める。回数 n ＝ max(1, 星の標準の体当たりの回数（`config.rank_hits`）＋ 属性)、HP の基礎 ＝ `config.base_attack` ×（n − 1）＋ `config.base_attack` ÷ 2。素の体当たりでちょうど n 回で倒れる。
- 星6〜10は試遊調整用として、同じ HP の決め方を暫定適用する。星ごとに標準回数を増やし、星10で増え幅を広げる。回数は [config.tres](../speed/data/config.tres) の `rank_hits` の各要素、種類ごとの差は敵の定義の `toughness` で調整する。武器を揃えた状態の試遊で見直し、星6以降の恒久的な決め方は未決。
- 星6〜10の暫定値は次のとおり。基礎 HP は標準属性・標準サイズで、`config.base_attack` が10のときの値。回数は HP の目安とし、装甲の突破条件には種類ごとの `armor` を使う。

| 星 | 暫定の標準回数 | 暫定の基礎 HP | 対象の通常敵 |
| --- | --- | --- | --- |
| 6 | 5 | 45 | `corona` |
| 7 | 6 | 55 | `phoenix`・`cepheus` |
| 8 | 7 | 65 | 対象の定義は未実装 |
| 9 | 8 | 75 | 対象の定義は未実装 |
| 10 | 10 | 95 | `aquarius`・`aquila` |

- 星のない敵（障害物・部位など）の HP の基礎は、敵の定義の `hp`。装甲・速さなどの基礎値は、種類ごとの定義で調整する。

### 11.2 強さの補正

同じ種類の敵は、出る時刻・場所に関係なく同じ強さ。サイズ比 z ＝ 実際の半径 ÷ 標準の半径（エリートの補正前）について：

| 項目 | 式 | エリート |
|---|---|---|
| HP | 基礎 × z² × `config.enemy_hp_mult` | さらに3倍 |
| 装甲 | 基礎 × z × `config.enemy_armor_mult` | さらに1.3倍 |
| 弾のダメージ | 基礎 | — |
| 経験値 | [星数と種類別上書きの個数](#101-星のかけら) | 同じ種類・星数の個数を共用 |
| 速度 | 基礎 | — |
| 半径 | — | 1.25倍 |

- エリートになる確率 ＝ 1% ＋ 強化帯による強まり（4.2）。同時に出る数の上限を持つ種類（強敵）はエリートにならない。
- 大きさが変わる種類（`size_var`）は、標準の0.85〜1.30倍で生成する。

### 11.3 出現と補充

- 敵は画面の四辺の外（余白 `config.spawn_margin` ＋ 0〜80）に出す。外周にいる敵が少ない辺を優先し、辺の長さも考慮する。
- いる数は、再配置の範囲（11.4）の中の敵を数える。画面の中心から見て上下左右の4つと中心付近（画面の幅・高さの 45% の内側）の5つの領域に分け、1つの領域で数えるのは目標の数 × `config.spawn_region_cap` まで。一か所に固まった敵だけでは目標の数に届かないので、ほかの辺から湧き続ける。ただし、再配置の範囲の中の敵の実際の数が目標の数 × `config.spawn_total_cap` に達したら、通常補充と波状出現を止める。
- 目標の数に足りないときは、時間帯の補充の速さと「不足数 ÷ `config.spawn_refill_time`」の大きい方で補充する。出現に失敗した試行は数えない。
- 雑魚の目標の数の曲線：ステージの `zako_curves` は、雑魚（星1）の種類ごとに、時刻と目標の数の点を持つ。点は、行き過ぎないなめらかな曲線でつなぐ（最初の点より前と最後の点より後は端の点の数）。曲線があれば、種類ごとの目標の数は曲線の値そのもの（`config.density_mult` は掛けない。10:00 以降の強まりは掛ける）、目標の数はその合計。補充では、目標の数に足りない分が大きい種類ほど選ばれやすい。
- 群れ：時間帯の `wave_interval` ごとに、`wave_type` の敵を画面を囲む輪か、一方向からの流れでまとめて出す。
- 強敵の群れ：強敵は、ステージの出現のクリップ（`clips`）から群れで出す。ステージは、そのステージに出る敵の一覧（`enemies`）を持つ。クリップは、タイムラインの開始の時刻（`time`）から長さ（`length`）の間だけ働き、ステージの敵の一覧から選んだ種類の組み合わせ（`types`）と、いくつかのフォーメーション（`formations`。敵の組み合わせのシーン `speed/data/formations/*.tscn`）を持つ。働いている間、そのクリップから出た群れが同時の群れの数（`groups`）より少なく、前の群れから出す間隔（`interval`）秒経っていれば、フォーメーションをランダムに1つ選んで群れを出す。配置は、クリップの使う並び（`layouts`。「フォーメーションのファイル名/配置の名前」）から選ぶ。使う並びが1つもないフォーメーションは選ばず、使う並びが空なら、すべての配置から選ぶ。群れには、クリップで選んだ種類の敵だけを出す。同じ時間に働いているクリップが複数あれば、それぞれから出す。
- フォーメーションの出し方：フォーメーションは、配置（群れの中心と正面に対する、各敵の位置と向き）と出現位置（機体を原点に置き、機体が上を向いているとしたときの点。向きは機体の方）を何種類かずつ持つ。それぞれ重みで1つずつ選び、配置の中心と正面を出現位置にそろえ、機体の進む向き（止まっているときは最後に描いた向き）に合わせて回して置く。出現位置の距離は、映る範囲の短い辺と `config.base_view` の比（1未満なら1）だけ伸ばす。出た敵は機体の方を向き、そのあとはそれぞれの動きで動く。
- 敵の定義に同時に出る数の上限（`max_alive`）がある種類は、その数までしか出さない。強敵を一度に出しすぎないために使う。上限に達する種類を含むフォーメーションは選ばない。
- 敵の技・構成に必要な生成（分裂、召喚、群れの構成員、部位、ボスの技で生まれる瓦礫）は、通常補充の目標数・総数上限を超えて成立させる。数・間隔・再生成の条件は各行動の定義で管理する。即時生成と更新末尾の予約生成に同じ規則を使い、撃破時の分裂は親が消えたあとも成立させる。生成された個体も通常補充の数へ含め、成立した群れ・構成の実数を次の通常補充・波状出現の判断に反映する。クリップはクリップごとの同時群れ数・間隔と種類ごとの `max_alive` で管理する。
- ボス戦の間は、通常補充・群れ・強敵のクリップから新しい敵を出さない。ボス戦の敵は、各ボスが技と構成のために必要な数だけ生成する。ボスの出現時にいる敵は残す。
- ボスと隕石は目標数に含めない。目標数が下がっても、すでにいる敵は消さない。

### 11.4 遠くの敵の再配置

- 画面の中心から、画面の半幅・半高 × `config.spawn_recycle_scale` ＋ 200 より離れた敵は、画面外の出現地点へ移す。HP・個体は保ち、撃破・経験値・ドロップは発生しない。
- ボスは移さない。
- 出現のクリップの群れ（11.3）は、隊列を保ったまま近づけるため、一度画面に入るまでは移さない。画面に入ったあとは、ほかの敵と同じく移す。

### 11.5 動き

- 共通の追跡を使う敵は、機体の今の位置へ種類ごとの旋回速度（`EnemyDef.turn`）を上限に向き直り、鼻先へ種類ごとの速さで進む。旋回は移動と同じ世界秒で進める。噛みつく雑魚と、守る相手がいない守る雑魚もこの追跡を使う。猟犬の群れとボスの指示による移動は個別の制御に従う。
- 自機のブーストの突進中（線をなぞっている間）は、通常敵・強敵・大物・ボス・追尾する部位と複製の、自機を追う方向転換を停止する。操舵と視線・再照準の向きを保ち、速さ・位置・攻撃時間を更新する。予告と新しい攻撃も保持した方向へ揃える。線をなぞり終えると、高速滑走中でも既存の旋回速度・補間で通常の追尾を再開する。技で確定した円運動・薙ぎ払い・扇状掃射・挟み込み・形態移行と、吸引・捕捉・吹き飛ばし・天体との衝突による外力は、それぞれの処理を続ける。既に発射した弾は、その弾の移動規則を保つ。
- 距離の維持、構えて撃つまでの時間、爆発、分裂などは、それぞれの種類の行動の値（`params`）を使う。
- 距離を保つ移動では、進む向きと機体（の遅れた位置）への向きを混ぜた向きを向く。進む向きの割合は `config.enemy_face_move` で、遅いときほど機体の方を向く。向きは敵の種類ごとの速さまでしか回らない。撃つ前の予告の間は機体の方を向き、構えて撃つ敵は撃つ向きで止まる。
- 雑魚同士はゆるく押し合う。半径の和の7割より近づいた分を、重さ（半径の2乗）の比で少しずつ戻し、群れの密度を保ったまま個体の形を見分けられるようにする。移動中でない雑魚は押し返すだけで動かない。移動中の雑魚は強敵とボスの身体を回り込み、内部へ入った場合も通常速度の範囲で離れる。吸引中のポンプ座、予告・攻撃・外力で動く雑魚はそれぞれの行動を優先する。強敵・ボスの位置と攻撃移動は雑魚との重なりで変えない。
- 敵は惑星・月の表面で止まり、横方向の速度は残す。敵の弾も、惑星・月に最初に当たった時点で消える。
- 体当たりや攻撃で敵が吹き飛ぶ強さは、星ごとの倍率（`config.rank_knockback`、左から星1、星2、…）を掛けたもの。星6以上は吹き飛ばない。星のない敵（障害物・部位など）は倍率 1。星砕きで押し出す勢いにも同じ倍率を掛ける。
- クリティカルランスを受けて生き残った雑魚は、短い間追跡をやめて吹き飛んだ勢いを保つ。ソニックブームは進路の横へ押して減速する（ボスを除く）。

### 11.6 攻撃する破片

攻撃する破片は、星砕きと、破片を出すギミックを持つ敵（ポンプ座・うみへび座）から飛ぶ。

- 星砕きの発動・威力・連鎖は[武器一覧](game/catalog/weapons.md)に従う。破片の初速・寿命は星砕きの定義値を使う。
- ギミックの破片の数・速さ・威力は、各敵の行動の値で決める。
- ギミックの破片は `config.hull_debris_life` 世界秒残る。破片は敵を貫き、吹き飛ばし `config.hull_debris_knock` で周りを巻き込む。
- 隕石とボスの破片化は対象外。破片の命中にはクリティカルが乗らない。

### 11.7 敵の攻撃の形

敵の攻撃は、弾（敵の弾・ミサイル）と、次の形を組み合わせて作る。どれも予告のあとに当たり判定を持つ。残る線のほかは、1つの攻撃は機体に1回だけ当たる。地形では止まらない。

| 形 | 中身 | 予告の見せ方 |
|---|---|---|
| ビーム | 撃った位置から、決まった長さと幅の線。予告のあと少しの間当たる。十字は4方向のビーム | 砲口に光が集まっていく |
| 遅れて弾ける範囲 | 円の範囲が、予告のあと一瞬弾ける | 照準の模様（照準・落雷）、または中心の点滅（爆発） |
| 広がる波 | 1点から輪や扇が広がる。切れ目を空けられる。何層もの輪は、層ごとに少し遅れて広がり、切れ目の向きが少しずつずれる | 中心に光が集まる |
| 残る線 | 決まった長さと幅の線が、しばらく残る。触れている間は危ない（被弾後の無敵の間は当たらない） | 線が薄く現れてから濃くなる |

- 予告は、攻撃する敵の側の光・模様・点滅で見せる。当たる範囲そのものは画面に出さない。
- 画面の外で画面から離れていく敵の弾（ホーミングしない弾）は、消える。
- 吸い寄せ（ポンプ座、みなみのかんむり座の渦）は、周囲の敵を集める力。対象と動きは[敵一覧](game/catalog/enemies.md)に従う。
- ビームの長さはゲーム内の距離で決め、画面の端の少し先まで届く長さを目安に調整する。
- 長さ・幅・予告の時間・ダメージは、その攻撃を使う敵の定義（`speed/data/enemies/<type ID>.tres` の行動の値）で決める。
- ステージでは通常敵の能動攻撃を、星の数にかかわらず実効valueで管理する。正のvalueを持つ攻撃は予告前に一度枠を取り、一続きの予告・照射・連射・帯生成中は同じ枠を使う。value 0の個体・共有override群れは管理対象外として、予算確認・待機登録・予算用の攻撃追跡を省く。種類別と編成の共有overrideの管理対象は実行用データの生成時に確定し、実効valueとともに出現する個体へ渡す。時間帯の `attack_budget` は0以上の整数で、タイムラインの「予算」から編集する。通常は攻撃する個体ごとに、ステージの `enemy_attack_values`（type ID → 0以上の小数）のvalueを消費する。未設定の種類は互換用の仮値1を使い、種類別の確定値はステージで指定する。使用量と次の個体のvalueの合計が予算以下なら開始を許可する。
- 攻撃待ちの優先度は、選択したクリップのインスペクターの `Attack Priority`（`attack_priority`）で0〜5の整数として設定する。初期値と保存項目のないクリップは0。クリップの値は0を含めてステージの `enemy_attack_priorities` より優先し、そのクリップが出す全個体と、そこから生まれる部位・分裂体・群れの仲間・増援へ引き継ぐ。クリップ以外から出る敵はステージの種類別優先度を使い、未設定は0。大きい値を先にし、同じ値は種類・クリップ・画面内外にかかわらず同率とする。待ち時間を同じ割合で加点して公平に順番を決め、同点は待機登録の順とする。先頭の必要量が空くまで後続を待たせ、予算全体を超える要求は先頭候補から外す。生存中の攻撃は完了まで枠を保つ。
- クリップの「Formations」は、配置ごとに、選んだ種類のvalueと実際の配置数を掛け合わせた `Auto`（個体合計） を表示する。使う並びをチェックで選び、使用OFFの並びも比較用に合計を表示する。自動合計は全員が同時に攻撃した場合の消費量の目安で、実行中は攻撃している個体だけが消費する。
- 並びの `Override`（群れ共有） をONにすると、その並びから1回で出た群れ全体で指定valueを共有する。同じ群れの複数の個体が攻撃しても指定量を1回分だけ消費し、別に出現した群れは別枠として消費する。overrideは `formation_values`（「シーンのファイル名/並びのノード名」→0以上の小数）に保存する。保存済みの整数の項目も明示overrideとして保持する。OFFにするとそのキーを外し、個体ごとの消費を使う。キーがない並びも個体ごとの消費を使う。
- 予算0は正の実効valueを持つ敵の新しい攻撃を待たせ、value 0の敵は固有の行動条件で攻撃する。許可済みの枠は各個体が1回ずつ攻撃でき、同じ個体の次の攻撃はその枠が返るまで待つ。枠は参加した個体の攻撃行動が終わり、紐づく最後の弾・攻撃範囲が消えたときに返す。常時帯を生成する行動は生成中ずっと枠を使う。撃破や中断では生成を終え、発射済みの独立した判定は元の寿命まで残す。許可まで各種類の移動・距離の取り方を続ける。攻撃の分類は記録に使う。出現数・時刻・配置はクリップとフォーメーション、コンボはレティクルの行動条件で決める。ボス・接触ダメージ・撃破時の受動効果はそれぞれの行動条件で発生する。時間帯の予算が下がった場合、開始済みの攻撃は完了まで続け、新しい攻撃を予算内になるまで待たせる。

### 12.2 ボスの出現

- ボスを機体から少し離れた位置に出し、惑星の中とフィールドの外を避ける。撃破まで保持する。

- ボス戦中は通常の敵を出さない（11.3）。ボスが使う敵は各ボスが生成する。画面外のボスは各役者の移動で管理する。

## 13. フィールド

### 13.1 フィールドの要素

| 要素 | 内容 |
|---|---|
| 広さ | 半径 `config.field_radius` の円。外へ出ようとすると押し戻す力（`config.boundary_push`）がかかる |
| 開始位置 | 中心から `config.start_radius` |
| 惑星 | 中心に半径 `config.planet_radius`。障害物 |
| 月 | `config.moon_count` 個。中心の周りの軌道を毎秒 `config.moon_orbit_speed` ラジアンで回る。障害物 |
| 重力 | 普通の彗星を壊した地点に発生。開発用の手動配置にも対応。下記 |
| 隕石 | 下記 |
| 鉄のがれき | 下記 |
| 回る丸鋸 | 下記 |
| ワープホール | 下記 |
| 英雄の星座 | 下記 |

**隕石**

- ラン開始時に、世界の決まった位置へ配置する：隕石地帯（各8個）と、まばらに漂う岩。数は `config.meteor_count` を基準にする。惑星の中やフィールドの外に入る岩は除く。
- 漂流隕石の軌道と回転は世界秒で進む。描画中・なぞり中は敵と同じ倍率で遅くなり、停止中に実時間の分だけ軌道が先へ飛ぶことはない。

**彗星**

- `config.comet_interval_min`〜`config.comet_interval_max` 世界秒ごとに1つ現れ、画面の端の近くを `config.comet_speed` でまっすぐ横切る。惑星を通らない向きを選ぶ。画面を抜けたら消える。
- 隕石と同じく壊せる（基礎値は隕石と同じで、大きさに応じて HP が増える）。見た目は [デザインとアートスタイル](game/art-style.md) の3.6。
- ランの時計が `config.rare_comet_after` 実秒を過ぎたあと、確率 `config.rare_comet_chance` でレアな彗星になる。レアな彗星は、まだ持っていない彗星限定の武器（8章）のどれか1つを持ち、壊すとそのカプセルを必ず落とす。彗星限定の武器をすべて持っていれば、レアな彗星は出ない。
- レアな彗星の HP は、普通の彗星の `config.rare_comet_hp_mult` 倍。画面の外にいる間は、画面の端に金色の矢印でその向きを出す（文字は出さない）。
- 隕石の基礎値は `speed/data/enemies/meteor.tres`。
- 画面の近くに入ったら有効にし、離れたら無効にする。
- 壊した隕石はそのランの間は戻らない。追跡・再配置・補充はしない。

**重力**

- 普通の彗星を機体の攻撃で壊した地点に1つ現れる。開発用の操作でも配置できる。空中からの定期発生はしない。
- 現れたときの届く半径は `config.gravity_radius`、中心の引き寄せる加速は `config.gravity_pull`。中心から離れるほど弱く、`config.gravity_life` 世界秒かけて縮んで消える。
- 敵・敵の弾・遅い機体を引き寄せ、敵や弾の進路を曲げる。高速の機体（7.2の高速の接触と同じ条件）には効かない。ボス・障害物・部位には効かない。

**鉄のがれき**

- ラン開始時に、`config.iron_count` 個の塊（1つの塊に3〜5個）を世界の決まった位置へ置く。動かない。置き方は仮。
- 隕石と同じく固い障害物で、普段の速さで触れると押し出されて跳ね返る。装甲がとても高く（`speed/data/enemies/iron.tres`）、十分な攻撃力の体当たりなら割れる。ぶつかると火花が出る。

**回る丸鋸**

- ラン開始時に、`config.saw_count` 個を世界の決まった位置へ散らして置く。その場で回る。置き方は仮。
- 機体が触れると（速さによらない）、機体の進んでいた向きへ、`config.saw_speed` と機体の速さの速い方で飛んでいく。飛ぶ丸鋸は敵を貫いて巻き込み、攻撃力 × `config.saw_power` を与え、`config.saw_life` 世界秒で壊れる。1回使うと戻らない。
- 武器や敵の攻撃では壊れない。

**英雄の星座**

- ステージ1〜4に、そのステージに捕らわれた英雄の星座（8.1）が1つある。ラン開始時に、フィールドの端のほう（中心から `config.field_radius` の72%〜外縁の600手前）の、機体から離れたランダムな位置とランダムな向きに置く。星の位置は `speed/data/heroes/<ID>.tres` の形に `config.hero_scale` を掛ける。配置は発見範囲より機体から離す。
- エンドレスモードでは、最初に4つのうちランダムに1つが現れる。解放すると、`config.hero_next_time` 実秒あとに、別の星座（ランダム）が別の場所に現れる。
- 星座の見え方は [デザインとアートスタイル](game/art-style.md#45-英雄の星座と目印の星) の4.5。機体が星座の中心から `config.hero_glow_range` より近づくと、その星座を発見する（近接発見）。
- 初めて目印の星を回収したときと、近接発見または目印の星2体で初めて英雄の星座を発見したときは、それぞれ専用の説明を表示して戦闘を止める。表示済みの状態をセーブへ保存する。説明・設定・報酬が重なる場合は順に表示し、Spaceまたは右下の再開ボタンで閉じる。説明画面と英雄の力の効果説明は同じ大きさで画面中央に置く。
- 近接発見または目印の星2体で場所が判明すると、短い発見通知を1つの星座につき1回表示する。通知中も操作を続けられる。場所が判明した未解放の星座は、画面外にある間、黄色の画面端矢印で方向を示す。
- 通常ステージのボス戦開始後は、英雄の発見通知・画面端矢印・ミニマップの星座と目印の線を隠し、戦闘の案内へ表示を絞る。獲得済みの英雄の力は引き続き使用できる。
- 機体が星座の中心から `config.hero_guard_range` より近づくと、周りにそのステージの強敵（大物を除く）を `config.hero_guards` 体出して守らせる。1つの星座に1回だけ。
- **解放**：1回の突進（なぞり）の中で、星座線でつながった2つの星を続けて通ると、その間の線が光る。星を通るとは、機体が星の半径 `config.hero_star_radius` の中を通ること。全部の線が光ると解放され、特別な枠（8.1）にその星座の力が入る。何回の突進に分けてもよい。解放すると時間が止まり、フィールドで獲得演出を見せる。カメラが星座全体の入るところまで引き、星座に英雄の絵（星図の線画）が描き出されて英雄の色で光り、粒になって機体へ流れ込む。線画は描き出してから2実秒見せる（全体で約4.3実秒、クリック・タップ・Space で飛ばせる）。そのあと画面を暗くして力の名前と効果説明を表示し、Spaceまたは右下の再開ボタンで閉じて操作へ戻る。

**目印の星**

- 英雄の星座が未解放の間、1体目は `config.landmark_first_window`、2体目は `config.landmark_second_window` の時間帯内に必ず目印持ちを出す。時間帯の開始・終了はランの時計の秒数。各枠の時刻をランの乱数で秒単位に選び、確率による見送りを行わない。ポーズ・カード選択・報酬表示・ヒットストップ・ボーナス中は出現時期を進めない。エンドレスでは、各英雄の配置時を時間帯の起点にする。
- 各枠は独立し、1体目が生きていても2体目を出す。機体の近く（画面の対角の半分 × 1.3 の範囲）の星2〜5の敵から、部位・ボス・既に目印を持つ個体を除いて選ぶ。英雄の星座・回収済みの目印位置・別の目印持ちから `config.landmark_spacing` 以上離れた敵を優先し、該当しなければ距離条件を緩める。
- 近くに適格な敵がいなければ、そのステージの既に始まった有効な出現クリップまたは現在の補充対象から、適格種類を1体だけ補充して目印を持たせる。クリップは選択済み配置の実際の構成員、通常補充は曲線があれば曲線、なければ現在の時間帯の配分を使う。この補充は通常補充の人数上限より予定時刻を優先する。星数・敵の能力・報酬は通常の出現と共通にする。英雄のあるステージは、最初の時間帯までに適格種類を出現対象へ含める。撃破以外で目印持ちが消えた場合は、未回収の同じ枠を補充する。
- 英雄を先に解放した場合は残る出現予定を取り消し、生存中の敵の目印を外す。英雄のないステージと実験場では目印持ちを出さない。開発用の途中時刻開始では、経過済みの未回収枠を開始後に補う。ランの終了前に到達しなかった時間帯は対象にしない。
- 目印の星を持つ敵の外観は[デザインとアートスタイル](game/art-style.md#45-英雄の星座と目印の星)に従う。倒すと目印の星を取り戻し、その位置から英雄の星座を通る線が1本、ミニマップに出る。2体目で場所が判明し、線を消して英雄の星座の点と画面端矢印で示す。英雄の星座が入れ替わると（エンドレスモード）、目印と発見状態をリセットする。

**ワープホールとボーナスステージ**

- ワープホールは、彗星が現れる時刻に、確率 `config.warp_chance` で彗星の代わりに現れる。ランの時計が `config.rare_comet_after` を過ぎてから、ボスが出るまでの間だけ。同時に1つまで。
- 画面の端の近くに現れ、`config.warp_life` 世界秒で消える。半径は `config.warp_radius`。機体が触れるとボーナスステージに入る。
- ボーナスステージは `config.bonus_time` 実秒。入るとき、周りの敵（ボスと障害物のほか）と敵の攻撃を消す。背景と画面の見た目が変わる（[ワープホールとボーナスステージの見た目](game/art-style.md#310-ワープホールとボーナスステージ)）。
- 中では、そのステージの出現の割り振りから、雑魚と硬めの敵だけを `config.bonus_pop` × `config.density_mult` 体保つ。種類別曲線があるステージはその時点の曲線値、曲線のないステージは時間帯の `mix` を相対配分に使う。候補は種類ごとの `max_alive` と敵の区分に従って絞り、候補が空なら補充を休止する。強敵クリップと通常の波は、ボーナスの終了後に補充を再開する。中身は仮。
- ゲージは無制限：1本の線の長さは普段の上限のままで、放つとすぐに満タンに戻る。
- ボーナスステージの間は、ランの時計（4.1）が止まる。終わると、ボーナスステージの敵と敵の攻撃を消し、その場で通常の出現に戻る。

### 13.2 ステージの仕掛け

ステージ固有の仕掛けは、そのステージの個別仕様（2.2）に定義する。仕掛けを持つかどうかはステージごとに決める。うみへび座の渦の首の攻撃は [専用仕様](game/bosses/hydra.md#4-通常攻撃) に定義する。

## 14. ランをまたぐ成長と保存

### 14.1 機体の強化

強化画面で部品を使って上げる。強化はラン開始時に反映する。項目の値は `speed/data/meta_upgrades/*.tres`（伸ばす能力、1段階ごとの効果、段階ごとの費用。費用の数が最大段階）。

| 強化 | 伸ばすもの |
|---|---|
| ブースター | 最高速度 |
| フレーム強度 | 最大 HP |
| パワースパイク | 攻撃力 |
| 充電効率 | ゲージの充填時間（短くする） |
| 学習回路 | 経験値 |
| リロール | 3択のリロールの回数（9.3） |
| エンジンタンク | 線の長さ |
| コレクター | 回収範囲 |

各ステージは、機体の強化が次の程度まで育った状態で臨むものとして、難易度と成長を調整する。育ち具合は、全項目の段の合計が、最大の段の合計に占める割合で表す。

| ステージ | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 想定する育ち具合 | 0割 | 2割 | 5割 | 7割 | 9割 |

強化画面は機体の分解図を表示する。各パーツまたは名前のボックスへカーソルを合わせると、パーツ・ボックス・接続線をシアンにする。パーツの輪郭内全体をホバー・クリックの判定に含める。クリックで右側に名前・効果・強化段階・必要部品を表示し、強化ボタンで購入する。エンジンタンクは描ける線の長さを伸ばす。

メインメニューの枠は、幅・高さを変えても2pxの線幅と四隅の1pxの欠けを保つ。機体強化を選ぶと、その枠が強化画面の右側の枠へ移動・変形し、続いて機体やパーツがフェードインする。強化画面から戻ると、機体やパーツがフェードアウトしてから枠がメインメニューへ戻る。ステージ選択から戻ると、円が右側へ戻りきってからメニュー枠をフェードインする。メインメニューは左上の戻るアイコンからタイトルへ戻る。

### 14.2 保存する内容

- 持っている部品の数、各強化の段階。
- 記録：ラン数、クリア数、最速クリア時間、最高速度。
- クリアしたステージ、入手した伝説のモジュール、図鑑で獲得済みのモジュール、エンドレスモードのハイスコア。
- 導入の視聴済み状態（3章）と操作練習の完了（4.3）。

### 14.3 図鑑

- メインメニューとラン中のEscメニューから開く。ラン中は進行と選択・報酬演出を停止したまま表示し、Escまたは「戻る」でポーズメニューへ戻る。
- 武器・特性・伝説のモジュールのタブで一覧を切り替え、番号・名前・種類・説明文と投影を表示する。彗星限定の武器は金色の「彗星の遺物」の区切りへ並べる。
- 武器と発動する特性は短い実演を投影する。能力値の特性は装備のアイコンを縦の軸でゆっくり回す。伝説のモジュールは部品図を表示する。
- 未入手は名前を「？？？」にして説明を伏せ、投影口と薄い市松の「？」を表示する。
- 一覧のサムネイルは実演の途中の静止画を保持する。項目の選択は選択枠と詳細だけを更新する。
- 一覧と詳細はスクロールでき、画面が縦長のときは上下に並べる。投影の色と後処理は[アートスタイル](game/art-style.md)に従う。

## 15. カメラ

- 止まっているとき、画面の短い辺に `config.base_view` 単位が映る。
- 最高速度（現在の速さではない）が上がるほど引く：基準 `config.zoom_ref_speed`、指数 `config.zoom_exp`、最も引いたとき `config.zoom_min` 倍。進む方向へ速さ × `config.look_ahead` だけ先を見せる。

- ソニックブームなどの発動ではズームしない。

## 17. 画面と HUD

- 特定の解像度・縦横比を前提にしない。すべての UI を実際の幅と高さから配置する。
- ウィンドウで起動したときは、ウィンドウの大きさを端末の画面の大きさに合わせる。
- 戦闘 HUD は素材の共通キャンバスを画面内へ縦横比を保って拡縮し、枠・数字・アイコンと操作範囲を揃える。

## 18. 音

- 最初は消音。M で切り替え、設定を保存する。音量は設定画面で変えられる。BGMの音量は効果音と別に設定する。
- 効果音とBGMは、出来事ごとの欄に割り当てる。欄ごとの音・音量・ピッチの範囲・同時に鳴らす数・ループ・曲の開始と終わりとループの戻り先は、音の表 `speed/assets/audio/sound_table.tres` に従う（[設計書13](architecture.md#13-音)）。欄の一覧と鳴る時は表の欄の一覧 `speed/scripts/data_types/sound_slots.gd` が持つ。
- 音のある欄だけを鳴らす。音なしにした欄は、素材や合成音を持っていても無音にする。曲のない欄へ切り替えるときは、今の曲を続ける。素材のない間だけ仮の合成音を使う欄があり、素材を割り当てた欄は素材を鳴らす。
- 鳴らすたびに、欄のピッチの最小〜最大から1つ選ぶ。
- 同じ効果音が0.05秒より近く続けて来たら1つの音にまとめ、ずれて来た音は必ず鳴らす。同じ効果音の重なりは再生中の音を含めて欄の同時に鳴らす数まで（指定がなければ2つ）にし、超えるときは一番古い音を止めて新しい音を鳴らす。ビームを撃つ敵の溜め音は、同時に2つまで鳴らす。溜め音は敵ごとの溜め時間でちょうど鳴り終わるよう、再生の速さ（音の高さも）を0.25〜4倍の範囲で変える。
- ダッシュはブーストの開始・移動中ループ・終了の3つの欄を使う。ダッシュ開始時に開始音、移動中にループ、終了時に余韻を再生する。ダッシュ専用の再生口を使い、短い移動や別の効果音・次のダッシュでも開始音と余韻を途中で切らない。ループと余韻は再生速度と音源の長さに応じてフェードする。
- HPが少ない間（16）は心音の欄をループ再生し、抜けると0.3秒でフェードアウトする。
- 描画・突進中とボス撃破のスロー再生中は、BGM・通常の効果音・エンジン音を通常の35%にする。ダッシュの開始・移動中・終了音はスロー減衰の対象から外し、マスター音量・効果音量・消音設定に従う。スロー減衰は0.15秒で下げ、解除・ポーズ・画面退出時は0.25秒で設定された音量へ戻す。途中で切り替えた場合も現在の音量からつなぐ。
- 通常戦闘は戦闘の曲、ボス出現後はボスの曲を流す。ボス出現時は通常曲を1秒でフェードアウトしてボス曲を流す。戦闘画面の退出時に停止し、実験場では自動再生しない。タイトル・強化・設定・図鑑・リザルトなどのメニューはメニューの曲を継続して流す。ステージセレクトはステージ選択の曲をフェードインで流す。ゲームオーバー表示時は戦闘曲・ボス曲を1秒でフェードアウトし、ゲームオーバーの曲を0.6秒でフェードインして一度再生する。敗北リザルトへ移っても曲の再生を引き継ぐ。
- メニュー曲とステージセレクト曲は、それぞれ停止した再生位置を起動中のメモリに保持する。離脱から実時間で10秒以内に同じ曲へ戻ると、その停止位置から再開する。初回と10秒を超えた復帰は、欄の開始位置から再生する。切り替えには既存の音楽フェードを使い、フェードアウト中に元の曲へ戻ると再生を保って音量を戻す。
- デバッグ版の強化画面は全強化のリセットと部品返還、起動中だけ有効な部品無消費の切り替えを持ち、試聴のために強化を繰り返せる。
- **未決**：音の方向性。

## 20. 調整機能

審査版は通常の時間制限・所持枠で遊び、一時停止メニューの「カスタム設定（審査版のみ）」で武器・特性の追加・入れ替え・削除とレベル上下、英雄の力、機体強化、無敵を変更できる。無敵の初期値はオフ。最大HPの増加時は増加分を現在HPへ加え、減少時は新しい最大HPまで切り詰める。変更はそのランだけに適用する。全ステージ解放はステージ選択で任意に切り替え、クリアは審査版の通常進行へ保存する。審査版は専用のセーブ・設定を使う。

審査版の「ボス戦へ移動」は、通常プレイのボス出現前に使う。武器・特性・英雄の力・HPを保持し、敵と敵味方の弾を消して、同じランのボス出現時刻で通常の登場を開始する。

開発版では、プレイ中に値を変えて試せる調整パネル（P）と、性能の表示（F3）と、プレイの記録（Ctrl+F9。[設計書](architecture.md) 14.3）を使える。

ステージ固有の敵調整は、Godotエディター右側の「ステージ敵調整」dockと、プレイ中のF4で開く移動可能なパネルを使う。左側の敵一覧と分類ツリーで対象を選び、右側の編集領域で共通値・現在値・差分を比較する。分類は耐久・移動・攻撃・固有行動の階層を持ち、各グループを折り畳める。敵名・IDと項目名・説明で検索でき、変更した項目だけにも絞れる。項目名にカーソルを重ねると説明と単位を表示する。区切りをドラッグして領域の比率を調整し、パネル右下のハンドルで全体のサイズを変える。位置とサイズは同じ起動の間に引き継ぐ。狭い表示では「敵・分類」で選択画面と編集画面を切り替える。標準HP（星の計算後）・装甲・移動値・弱点角度と、敵固有の攻撃力・範囲・間隔などを扱う。XP・成長・武器・倒した報酬は共通の基準を使う。同時攻撃の予算は11.7で調整する。

各項目は「共通値（参照）」「ステージ設定」「実効値・状態」を表示する。共通値は全ステージの基準として参照する。「このステージで上書き」のチェックをONにすると、このステージだけの数値編集欄を表示する。OFFの項目は「共通値を使用」と表示し、実効値に共通値を使う。チェックOFFと項目の↶は、その項目の上書きを解除する。共通値と同じ数値でも、チェックONの間はステージ上書きとして保持する。

値の変更はメモリ内の試行へ反映し、Saveで当該ステージの設定へ保存する。「共通値へ」のメニューは選択中の敵または全敵の上書きを解除し、「再読込」は試行を破棄して保存済みの設定へ戻す。未保存の項目は実効値欄と敵一覧の「*」で示す。閉じる操作は試行を保持する。プレイ中の変更は既存個体の能力値と定義へ反映し、残HP割合・位置・行動状態を保つ。固有の行動値は次に行動側が参照するときから使い、発射済みの攻撃と生成済みの配置を保つ。エディターからの実行ではSaveでソースを保存・生成し、製品用のexportは保存済みの調整を使う。

- ステージ選択：「デバッグ全開放」をオンにすると全ステージが表示され、オフにすると保存済みの進行に応じた表示に戻る。切り替えはセーブに書き込まず、クリアの記録は通常の進行として保存する。
- 時間：+30秒／+60秒、ボス出現の時刻へ進める、ボスを倒す
- 機体：無敵、HP 全快、レベルアップ、ゲージ満タン、被弾・致命傷の演出を確認
- 動き：巡航の速さ、なぞり終えたあとの勢いの速さ・続く秒数・落とす秒数
- 装備：武器・特性を指定した段階で直接入手、装備のリセット
- ULT：英雄の一覧から選んで「ULTを獲得」を押すと、このランの英雄の力を切り替える。発動中の効果を終了し、クールダウンは引き継ぐ。保存済みの進行は保つ。
- 敵：すべて消す、指定数のランダムな通常敵を画面内に追加（負荷計測用。通常の出現上限を超えて生成可能）、密度、追跡の広がり、ボスの HP・装甲・出現時刻、隕石の密度と各ドロップ率、彗星・レアな彗星・重力・ワープホールを出す
- ヒットストップ：Pの「ヒットストップ」タブで★1〜★10の停止時間倍率を個別に試す。種類別・ステージ別の実効倍率に星別の倍率を掛け、共通の累積上限を使う。0倍は停止なし、1倍は保存された種類別の設定。現在の敵と次に出現する敵へ即時反映し、ボス・星のない障害物は対象外とする。「星別の倍率をすべて1倍に戻す」で星別の試行を解除する。設定画面のヒットストップがOFFなら停止を無効にする。試行値はこのランの間だけ保持する。
- ゲージ：充填時間、描き始められる量、描画中の世界の速さ（0〜1）
- 成長：必要経験値、武器・特性の枠の数
- 部品+100、強化のリセット
- 機体の強化の段：項目ごとに、ランで使う段を0〜最大で決める。「0割」「2割」「5割」「7割」「9割」のボタンで、段の合計を最大の段の合計のその割合（四捨五入）にし、各項目へ最大の段に比べて均等に振り分ける（端数の段は小数部の大きい項目から、同じなら強化画面の並び順で前の項目から足す）。「セーブの段に戻す」でセーブの段に戻す。次のランから反映し、セーブの段は変えない。同じ起動の間だけ有効。
- 調整パネルで変えた値はそのランの間だけ有効で、データは変えない。「既定値に戻す」でデータの値に戻る。

性能の表示（F3）は、押すたびに簡易表示 → 詳細表示 → 非表示と切り替わる。初期位置は画面の右上（ボスの HP バーの下）で、つかんで動かせる。表示の段階と位置は、同じ起動の間は次のランにも引き継ぐ。数値は1秒に4回更新し、その間の平均と最大を出す。

- 簡易表示：FPS、フレーム時間の平均と最大、1フレームに実行した物理更新の回数（2回を超えると赤）、敵・敵弾・味方の弾・星のかけら・部品の数
- 詳細表示：簡易表示に加えて次を出す
  - 処理時間：1フレームあたりのゲーム処理・出来事の受け渡し・表示側の処理と、残り（描画エンジン・GPU・待ち）の時間、ゲーム更新1回の時間、処理ごとの時間（世界側の更新1回あたり）
  - 表示側（右の列）：表示の更新と描画の層ごとの1フレームあたりの時間と1回の最大、敵の描画の内訳（行を回す・GPUへ送る・種類ごとの層）、敵の描画1回あたりの行の数（見た行・生存・一括で描いた・個別に描いた・飾り）、ゲーム側の内訳（敵の行動・武器と特性・弾・星のかけらなどの種類ごと、1フレームあたりの多い順に10件）
  - 描画：描画命令・オブジェクト・頂点の数、シェーダーのコンパイル数（累計と直近の増加）
  - メモリ：RAM・VRAM、オブジェクト・ノード・どこにもつながっていないノードの数
  - 表の行：敵・弾・星のかけら・部品の使用中の行と、空きを含む行数（設計書 6）
  - 直近120フレームのフレーム時間のグラフ（16.7ms と 33.3ms に線、25ms を超えたフレームは赤）

開発版のタイトル右上の「背景エディター」から専用画面を開く。ステージ全体の地色を編集し、星と背景素材を同時に確認する。星の表示切替はプレビューだけに適用する。ステージを選び、素材一覧から背景を複数配置する。開始地点を原点とする位置、サイズ倍率、回転、明るさ、色、重なり順、背景ごとの移動倍率を編集し、ドラッグ・ズーム・パンで確認する。移動倍率は1で通常の物体と同じ速さ、0でカメラ移動に対して画面上に固定し、その間は遠景としてゆっくり流す。既定値は1とし、視差プレビュー中のパンで流れを確認する。配置のドラッグはプレビューをOFFにして行う。背景の実体部分は背後の星を隠し、元画像の透明部分を保って明るさを変える。背景は接触判定を持たず、取り消し・やり直し、複製・削除に対応する。未保存のまま画面・ステージを変えると破棄を確認する。ステージへ保存すると次の開始から反映する。保存前にステージの外部変更を検出する。

### 20.1 敵・ルート実験場

開発版のメインメニューから専用の実験場を開く。通常の敵と調整用に保持する敵・ボスを同じパレットから配置する。通常ステージの出現は敵一覧の通常構成を使い、全ステージを最初から選べる。

中央には本番のランの画面（描画・カメラ）をそのまま映し、その上に編集用の層を重ねる。編集用の層は、選択・攻撃の発生元と範囲・ID・編集する線・配置の目印だけを描く。左の敵一覧は画像・名前・星の数を表示する。並びは、雑魚・硬めの敵・強敵・大物を敵一覧（[catalog/enemies.md](game/catalog/enemies.md)）の星の数の順（同じ区分の中は採用した敵の順）にし、そのあとに障害物・仕掛け、ボス、出現から外した敵を置く。障害物・仕掛けは、惑星（小・中・大）・隕石・彗星・鉄のがれき・回る丸鋸・うみへび座の瓦礫・重力・ワープホール。惑星は動かない障害物として置き、彗星は置いた位置から機体の方へまっすぐ横切り、重力とワープホールは通常の出現と同じ大きさ・時間で置く。置いたことは操作の履歴に記録する。区分（雑魚・硬めの敵・強敵・大物・障害物と仕掛け・ボス・出現から外した敵）と星の数（★1〜★5、★6〜10）で絞り込み、名前と type ID で検索する。右の調整パネルは敵の選択時に開き、姿・HP・撃破可否・基本値を優先して表示する。名前とHPの下に、その種類の「動き」（どう動いて攻撃するか）と「倒し方」を短く出す。文章は `speed/data/text/strings.csv` の `lab.enemy.<type ID>.move`・`.kill`。攻撃・行動の詳細、個体の条件、実効値と待機理由は折りたたみから開く。

実験条件・ランダム配置・保存は上部から専用パネルを開く。下部に再生操作と時間バーを置く。再生操作の「リセット」は、最後に再生を始めた時刻（試遊やルートを試すを始めた時点）の完成した状態を一度に表示する。配置は残し、それ以降の記録は分岐として残して、そこから新しく遊べるようにする。配置・線・履歴をすべて消すのは実験条件のパネルで行う。「最初の時刻へ戻す」は配置を残して時刻0に戻す。「機体を固定」は、押した時点の位置に機体を止め、敵だけを動かす（もう一度押すと解除）。固定も操作の履歴に記録し、巻き戻しても同じに再生される。履歴から攻撃などの時間軸と分岐を開く。

左右の一覧は境界をドラッグして幅を変え、画面端の矢印で折りたたみ・再展開する。下部の境界でトラックの高さを変え、履歴を開き直すと調整した高さに戻す。下向き矢印で再生操作を含む下部バー全体を隠し、画面下端の上向き矢印で元の表示と高さに戻す。時間軸は、拡大率1で1画面に10秒を見せる。記録の長さが変わっても目盛りの間隔は変わらず、再生中は再生位置が右から2割の所を越えると、目盛りごと左へ流れる。目盛りは、切りのいい間隔（0.1・0.2・0.5・1・2・5・10秒…）で、ちょうどの時刻に打つ。時間軸はホイールと＋／−で拡大縮小し、中ドラッグ・Shift＋ホイール・横スクロールバーで表示範囲を動かす。全体表示ボタンで、記録全体が1画面に収まる拡大率にする。

外観メニューは、敵の選択を切り替えた後や空白クリックで選択を解除した後も開いた状態を保ち、種類ごとの未保存値を保持する。本番の描画を使って選択した敵を8倍を上限に全体が収まる倍率へ拡大し、停止したまま回転して確認する。ホイールで最大16倍まで拡大できる。自爆型の配置・拡大ボタンを備える。通常敵とそのパーツは、種類ごとのサイズ倍率を見た目と当たり判定の両方へ即時に適用する。当たり判定のみの倍率は見た目の大きさを保って接触半径を調整する。選択中の敵には実際の判定半径をオレンジの円で表示する。同じ種類の配置済み個体と、その後に出現する個体が同じ設定を使う。法線付き装甲は、種類ごとに主光・補助光の強さと角度、光の高さ、環境光、法線の強調度を調整する。編集を履歴に記録し、保存済みの外観へ戻せる。ボスと地形はそれぞれ専用の編集を使う。

「変更した外観を一括保存」は、現在の外観と保存済みの外観に差分がある種類をまとめて保存する。対象は通常敵のサイズ・当たり判定の倍率・照明・装甲の塗装と、ボスのパーツ外観で、次回開始する全ステージへ適用する。未保存の種類数は選択の有無にかかわらず表示し、取り消し・やり直し後の現在値から更新する。「この種類の設定をステージへ保存」は選択した通常敵だけを保存する。どちらも保存前に対象データの外部変更を検出し、保存先の他の項目を保って外観だけを書き換える。一括保存の一部が失敗したときは成功数と失敗した種類を表示し、失敗した種類の編集値と未保存状態を保持する。

外観の「装甲の塗装」では、元画像の向きで拡大した装甲片をクリックして塗る。透過ピクセルを境とし、上下左右につながるピクセルだけを同じ装甲片として扱う。斜めだけの接触は別の片とする。色を選んで左クリックすると、その片に適用し、右クリックすると元画像の色へ戻す。同じ種類の敵へ即時に適用し、外観の保存・復元と編集履歴にも塗装を含める。塗装は画像ごとに区別し、保存した透過マスクと一致する画像へ適用する。

再生・停止・取り消しなどは操作アイコンを使い、独自の道具は短い名前を添える。名前・IDの一括表示と攻撃範囲は表示メニューで切り替える。本番の HUD（HP・装備など）、ミニマップ、背景の星は初めは出さず、表示メニューで選んだときだけ出す。

数値変更は同じ種類の実験用定義に、エリートは選択個体に反映する。HP の基礎値を変えると残り HP の割合を保つ。

| 操作 | 内容 |
| --- | --- |
| 敵を配置 | 敵一覧の画像をフィールドへドラッグする。画像をクリックしてからフィールドをクリックすると1回配置して選択へ戻る。Shift を押しながらの配置と、上部の「配置」ツールでは連続配置できる。数は一覧下部で選ぶ |
| 選択・移動 | 選択モードで空白をクリックすると選択を解除し、選択中の円を消す。敵はドラッグで動かす。Shift で複数選択、Alt で重なった敵を選び直す。Q/E で回転、Ctrl+D で複製、Delete で削除する |
| 範囲・向き | 選択した敵からドラッグし、対応する攻撃の射程と方向を変える |
| 線を編集 | 「自由に描く」はクリックで描き始め、マウスの軌跡を線にし、もう一度クリックで確定する。ドラッグして離す操作でも描ける。新しい線で現在の線を置き換え、描画中の右クリック・Escで元に戻す。「点を編集」はクリックで点を追加し、点をドラッグする。右クリックで近くの点を削除する。Alt＋ドラッグで線全体を動かす。「線を消す」で線を消す（取り消しで戻せる） |
| ルートを試す | 描いた線を、今の場面のまま本番の描画と同じ処理（描画の時間・長さの上限・地形・角の補正・始点へのワープ）で描いて確定し、駆け抜けさせる。そのまま普通に再生し、カメラは機体を追う。ホイール・中ドラッグで視点を動かすと追うのをやめる。操作の履歴に記録するので、巻き戻しても同じに再生される |
| 取り消す・やり直す | 外観の色・数値は現在の敵の位置と攻撃時計を保って編集だけを戻す。配置・削除は現在時刻の完成した状態へ復元し、線は編集履歴から戻す。Cmd+Z / Cmd+Shift+Z（Windows・Linux は Ctrl）を外観パネル・色ピッカー・パーツ編集でも使える。文字入力中は入力欄の取り消し・やり直しを優先する |
| 再生・停止・1コマ | Space で再生・停止を切り替える（文字の入力中を除き、どこにフォーカスがあっても効く）。固定更新で進める。時間軸は再生済みの任意 tick へ戻す。過去で編集すると元の履歴を分岐として残す |
| 中ボタン・ホイール | 試遊以外のとき、描画のカメラだけを動かすパン・ズーム。ゲームの表示範囲と狙いは変えない |
| 自機で試遊 | 試遊を選ぶと再生が始まり、ほかのモードへ切り替えると止まる。本番と同じ入力・カメラで操作する（カーソルで移動、クリックで線を描く、Q で英雄の星座の力。Space は実験場の再生・停止に使う）。毎回の入力を操作の履歴に記録し、シードと固定の時間刻みで同じ展開を再生する。記録済みの時刻を再生している間は記録どおりに進み、クリックなどの押す操作をすると、そこから新しい分岐になる。HUD は表示だけで、ポーズ・3択の入力は受けない。ウィンドウのフォーカスを外すと停止する |

実験条件のパネルの「敵の組み合わせ」で、組み合わせ・配置・出現位置を選び、機体のまわりに本番と同じ出し方（11.3）で並べる。並べたことは操作の履歴に記録する。

空の実験と、ステージの地形・装備を使った実験を切り替える。天体、隕石・がれき、フィールドの仕掛け、自動出現を個別に選べる。出現レーンは敵・数・開始・終了・間隔・確率・領域を持ち、手動配置と併用できる。部位は親の配置と動きに従う。手動配置は地形や外縁と重なる例外も許し、選択情報に表示する。

実験場の攻撃管理は、攻撃の許可と残る弾・範囲の追跡（11.7）を共用し、種類ごとの重さを実験場の設定で動かす。有効・無効、予算、待ち方のばらつき、通常敵の種類ごとの攻撃の重さを変えられ、今の重さの合計と予算を表示する。実験場のボスの攻撃は1回分として数える。撃破時の受動効果はその場で発生させ、残った弾と範囲が消えるまで危険として数える。攻撃の発生元、待機理由、時間軸を対応付けて表示し、管理の有効・無効を比較できる。

調整パネルの「描いた線を隔離して再生」は、編集元から隔離した本番ランで描画の時間、始点ワープ、長さ制限、なぞり、装備、地形、敵、攻撃の判定を実行する。元の敵・時刻・乱数は保つ。線を実行している途中は、開始前へ巻き戻して別の線を評価する。結果に撃破、被ダメージ、弾かれ・停止の印、終点、残り充填を示し、線を複製して比較する。

| 評価の表示 | 対象と条件 |
| --- | --- |
| 静止配置で成立 | 線分全体と機体の半径・余裕幅・入力点補正の余裕を掃引し、長さ、地形、確実に貫く弱い敵、装甲、現在の危険範囲を検査する |
| この再生条件で成立 | 指定 seed・開始 tick・描画時間・装備で、終点到達と無被弾を隔離した本番処理で確認する |
| 指定時間幅で成立 | 開始時間幅に描画・なぞり・ヒットストップの猶予を加えた保守的な包絡を検査する。停止した非攻撃の通常敵、直進する通常弾、位置と向きが固定されたビーム・円・輪・壁に対応する |
| 未対応 | 動く敵・地形、ストリーミングされる岩、追尾・入力への反応、付着して動く範囲、複合ボス技、受動効果や条件付き能力など、保守的な時間モデルを持たない対象を含む。隔離再生で個別に試す |
| 再確認が必要 | 配置、時刻、装備、線、基準データが変わった結果。新しい条件で検査する |
| 未発見 | 限定した探索範囲で成立候補が見つからない。条件や探索範囲を変えて試す |

配置からルートと敵の移動領域を取得し、領域の中心と半径、巻き込む群れ・避ける対象、種類と数の範囲、回転・長さ・余裕幅・時間幅を指定する。生成はルートを先に変形し、許可領域内で配置を変え、検査した候補だけを提示する。候補の小さな配置図とフィールドへの重ね表示で比較し、現在状態との一致を確認して追加する。認証した開始時間幅を保護する間は新しい能動攻撃と自動出現を見送る。成立区分は指定条件の範囲を示し、本番の見つけやすさと蹂躙の楽しさは単体・混成の試遊で判断する。

保存先は `user://enemy_lab/`。プリセットは初期条件・現在配置・定義差分・出現レーン・攻撃枠・ルート条件を、記録は seed・命令履歴・分岐・再生位置・結果・基準ハッシュを保存する。実験は専用設定を複製し、通常の部品・クリア・強化を保存する出口から独立して動く。

AI 用の書き出しは `user://enemy_lab/exports/<実験名>/` に `record.json`、`preset.json`、`changes.json`、`adoption.json`、`overview.png` をまとめる。書き出す対象ステージ・時間帯・敵 ID を明示する。AI は基準ハッシュと対象を照合し、指定した敵の `.tres` と `StageDef.encounter_profile` の採用設定へ反映し、反映後の依存データのハッシュを採用設定へ記録する。採用設定自身を含むステージのファイルは依存ハッシュから除く。採用設定は指定したステージ・時間帯で攻撃管理と候補生成を有効にする。通常5ステージの既定の採用設定は空で、実験から段階的に採用する。「本番データを再読込して新しい実験」で敵・ボス・時間帯・共通値を新しいリソースとして読み直し、プリセットと同じ線で確認する。

## 21. 性能

- 目標は60fps。最も敵が多い無双期（1300体前後）でも保つ。
- PC を最優先し、最終的にはスマホでも同じ目標を満たせるようにする。ブラウザは最低限動けばよい。
