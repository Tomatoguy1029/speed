# 現在の仕様

ゲームが今どう動くかの説明。挙動や数値を変えたらここを更新する（経緯は [decisions.md](decisions.md)）。

## コンセプトと時間の流れ

2D 見下ろしのサバイバー系の **試作**。目的は作者が通しで遊んで「面白くなりそうか」を判断すること（作り込みより全要素を一通り体験できることを優先）。

- コンセプト: 突進で宇宙を縦横無尽に駆け回り、群れと障害物を吹っ飛ばしながら機体を強化し、10 分以内に脱出速度へ到達する
- コンセプトチェックの問い: ①止まらず駆け回っているか ②囲まれるスリルがあるか ③高速でぶつかって吹っ飛ばす手応えがあるか
- 1 ラン 10 分。時間で体験曲線を作る: 強化期(0–2:30) → 圧力期(–4:00) → 強化期II(–5:00) → 無双期(5:00–6:00) → 緊張期(–8:30) → 脱出期(–10:00)
- **フェーズは裏のレベルデザイン専用**。名前やバナーをゲーム画面に出さない（ユーザー指示）。ユーザーへの説明でも「〜分ごろ」など時間で言う

## 操作（調整パネル `P` で切り替え。選択は localStorage `speed-controls-v2` に保存）
| id | 内容 |
|---|---|
| `draw`（既定） | **ふだん = カーソルの方向へ進む（タッチは仮想スティック）、高速攻撃 = ゲージ制で軌跡を描いて駆け抜ける**。移動: **マウスはカーソルの方向へ進む**（クリック不要、`mouse` 方式と同じ操舵で速さは一定）。**タッチ操作のときだけ** 押した点からずらす仮想スティック（遊び 8px、半径 70px で最高速、押した点は固定、輪で表示）。高速攻撃: **経験値でゲージが溜まる**（満タンに必要な経験値 = その時のレベルアップに必要な量 × 0.35 × チャージ時間の倍率。チャージ時間を縮めるモジュールやレベルで溜まりやすくなる。回生ジェネレーターは貫通ごとに少し溜まる。開始時は満タン）。満タンで **Space か画面左下の「高速攻撃」ボタン**（ゲージが円で溜まり、満タンで光る。機体の HP バーの下にも細いゲージ）→ 世界がほぼ停止（×0.05）→ **画面の好きな場所をクリック（または Space＝カーソル位置）して描き始め**、カーソルを動かして軌跡を描く（長さ = 1000 × ゲージ上限 × 最高速度/基礎最高速度 × モジュール倍率、描ける時間 5 秒）→ もう一度 Space／クリック、または長さ・時間切れで確定 → **描き始めの点へワープ**（元の位置に残像が数個残って消える＋光の筋）→ 軌跡を約 0.5 秒（実時間、`drawRunTime`）で一気になぞる。突進の速度はゲージ上限（過充填コンデンサで 1 超え）で計算。描画中・なぞり中は **カメラを固定**。その間の世界の速さは **突進速度に反比例**（260 / 突進速度、下限 0.03）。描画中・なぞり中も **10 分のタイマーは実時間で進む**。攻撃力・脱出判定・抜けた後の勢いは突進の速度で計算。貫けない敵に当たると弾かれて終了。機体本体の当たり判定は半径 16。**なぞった軌跡から波動が出る**: 届く距離（初期 45、= 描いた線の周りの半透明の帯の幅）にいる敵へ攻撃力 × 0.5 のダメージ（装甲無視、パスごとに 1 回）と外向きの吹き飛ばし。プレビューは本体が切る敵に白（弱点なら黄色）、波動だけ届く敵に水色の輪、本体が止められる所に赤×。**同じ敵でも帯がいったん離れて再び重なれば何度でも攻撃が当たる**（2 回目以降が当たった瞬間に「×2」「×3」）。描画モード専用モジュール: 銃「波動増幅器」、銃「大波動」（7:00 以降）、ブースター「高速トレーサー」、ジェネレーター「軌跡延長コイル」「軌跡オーバードライブ」（終盤）。他の方式では出ない。描かずに確定すると機体からカーソル方向へまっすぐ |
| `mouse` | カーソルを置いた方向へ進行方向が回る（クリック不要）。Space かクリック長押しでチャージ→離すとカーソル方向へ突進 |
| `steer` | WASD で押した画面方向へ進行方向が回る（4.5 rad/s、速度維持）。Space で進行方向へ加速 |
| `relative` | 機体基準 WASD（W 前進 / S ブレーキ / A・D 曲がる、停止中はその場旋回） |
| `nudge` | WASD で画面方向に小さな推力 |
| `rotate` | A/D で照準を回す、W で進行方向に合わせる、S で反転 |
| `aim8` | WASD で 8 方向に狙う |
| `drag` | 最初の方式。押してドラッグ→離すと逆方向へ突進 |

- 機体の絵は **どの方式でも回転しない丸い機体**（ユーザーが回転に違和感を訴えたため）。外側の矢印が「今 Space を離すと飛ぶ方向」
- ゲージは押している時間で溜まる。発射速度 = 上限 × 0.8 × ゲージ ＋ 同じ向きの勢いの 65%（上限で頭打ち、過充填で超えられる）

## モジュールの入手（2026-10-02 変更）
- **レベルアップでは入手画面を出さない**。レベルごとに基礎性能が自動で上がる（最高速度 +2%、攻撃力 +2%、最大 HP +4、チャージ時間 −1%（下限 60%）、HP 8% 回復）
- **モジュールは敵が落とす**。確率 = 0.005 × 敵の強さ（= その敵の経験値。種類・レベル・エリートを反映）、上限 50%。レア度も強さで上がる。エリートと戦艦は必ず落とす。落ちたモジュールは近くで吸い寄せられ、45 秒で消える。フィールドの漂流カプセル（中心ほどレア）と出力コアは従来どおり
- **同じモジュールを拾うと選択画面なしで自動強化**（+1 ごとに効果 +15%、レア度は高い方）
- 描画モード専用の終盤モジュール「軌跡オーバードライブ」（ジェネレーター、7:00 以降、エピック/レジェンドのみ、長さ ×2.9 / ×3.8。画面中を駆けめぐれる長さ）

## 画面サイズ
- 機種ごとに比率が違うので **特定の解像度を前提にしない**。描画バッファ・HUD・パネルはすべて実際の幅と高さから配置（幅 600 未満で左上の文字を折り返す、左下の機体図と高速攻撃ボタンは幅・高さの小さい方に合わせて縮む、文字ラベルは画面内に収める）。ズームは画面の短い辺を基準

## 速度・成長・クリア
- 初期の最高速度 500（2.49 km/s）、**レベルごとに +2%**、モジュール（ブースター等）、出力コア（1 個 +18%、8:30 以降に中心付近に出現）、メタ強化で伸びる
- クリア = **実際の速度**が脱出速度 2250 px/s（表示 11.2 km/s）に到達。満タン（過充填なら上限超え）の突進で出す
- **重力はなし**（`planetGM`/`moonGM` = 0。ユーザーが鬱陶しいと判断）。惑星・小惑星は障害物として残る（ぶつかると弾かれる、軌跡もそこで止まる）。重力の仕組み自体は残っていて調整パネルで戻せる
- 攻撃力 = 速度 / 100 × 倍率 × `atkScale`(1.8)。装甲以上なら貫通、未満なら自機がダメージを受けて弾かれる。弱点（黄色い弧）は装甲半分で貫けて必ずクリティカル。満タン突進 1 回でザコ（ドリフター）を一撃で倒せることを保つ
- モジュールはフィールドのカプセル・入手画面・左下の機体図で **部位ごとの宇宙船パーツの形** で表示（6 つ揃うと 1 機の宇宙船になる）
- カメラは **最高速度** に応じて引く（現在速度ではない）
- **ヒットストップ**: 満タンの敵を一撃で倒すたびに 0.045 秒（大型 ×1.8、クリティカル ×1.3）。体当たりでも、なぞり中の波動での撃破でも出る（一撃かどうかはその突進で最初に触れた時点の HP で判定）。1 回の突進で合計 0.6 秒まで。突進していない間はこの上限が毎秒 0.3 秒ずつ回復
- 音は **既定でミュート**（`M` で切替、localStorage `speed-muted`）
