# SPEED — ブラウザ demo

本番開発は Godot の `../speed/` へ移行しました。このフォルダは既存のブラウザ試作を保存し、新機能・新スキルを手早く試す実験場として引き続き使います。本番の案内は [ルートの README](../README.md) を参照してください。

[AGENTS.md](AGENTS.md) は移行前の指示をそのまま保存しています。コマンドと `src/`・`dist/`・`docs/` のパスは、この `demo/` フォルダを基準に読みます。GitHub Actions・`vercel.json` はリポジトリのルートにある公開設定を使います。

敵の大群に対して高速移動で立ち向かい、一気に吹き飛ばして圧倒する快感を楽しむゲーム。迫り来る敵の脅威に対して、高速移動によって敵を蹂躙することで、脅威を快感へと変える。

宇宙を舞台にした2D見下ろしのサバイバーゲームの試作です。高速移動による体当たりと波動で敵を倒し、モジュールを組み合わせて機体を強化します。現在は軌跡を描く高速攻撃と自動の通常攻撃、武器・特性のビルドを組み合わせて検証しています。ポータルなど以前の操作も比較用に保持しています。

通常の入口はブラウザに保存した操作方式を使い、未選択なら描画操作になります。`?controls=portal`、`?controls=draw`、`?controls=draw-wasd` は操作方式を指定するだけで、同じ公開版を開きます。元の描画版は比較用に保存した別のHTMLです。

現在のクリア条件は、7分ごろに出現するボスを10分以内に撃破すること。ボスの出現後も通常敵は湧き続けます。描画版では敵を倒して経験値を集め、レベルアップごとに3枚から1枚をクリック／数字キー1〜3で選びます。武器は4枠・各Lv5まで、特性は6枠（試作値）・各5重ねまで。出発時はランダムな武器3種類から1つ選び、その武器をLv1で装備して開始します。選択中は時間も敵も進みません。ランで獲得した部品はステーションで機体の基礎強化に使えます。トドメは機体アップのスローで見せた後、ボスの爆発で全敵を一掃し、破片を2秒かけて消してからCLEAR!を表示します。結果画面から「もう一回やる」「メニューに戻る」を選べます。ボスのギミックは暫定で、ゲームシステム・バランスは検討中です。

現在は描画版を軸に検証しています。敵の密度と補充速度は従来の約5倍に増やし、敵同士の過剰な重なりと追跡先の集中を抑えています。

## 操作

### ポータル版（キーボード）

| 状態 | キー | 動作 |
|---|---|---|
| 通常移動 | WASD / 矢印 | 移動 |
| 通常移動 | B | 足元にポータルを設置 |
| 通常移動 | Space短押し | 最寄りの到達可能なポータルへ突進 |
| ポータル上 | A / D | 次の行き先を反時計回り / 時計回りに選択 |
| ポータル上 | Space短押し | 選択したポータルへ移動（キーを離すと出発） |
| ポータル上・移動中 | Spaceを0.5秒長押し | 通常移動へ離脱 |

移動可能なポータルへ薄い線が出て、選択中の経路は黄色い太線で表示されます。移動中も次の行き先を選び、Spaceで次の出発を予約できます。通常移動でポータルに入って乗ることもできます。

- ゲージ不要。設置したポータルはラン中残り、最大12個まで配置できます。敵からのランダムなポータルドロップは停止中です。
- 通った辺は逆方向も含めて10秒クールダウンします。離脱しても解除されず、同じアタック中は時間が経っても再利用できません。
- 移動可能な接続先がなくなると自動離脱します。待機中も敵と弾は通常速度で動きます。
- 通過した軌跡は離脱まで残ります。「包囲炸裂」モジュールを装備すると、閉じた軌跡の内側にいる敵を爆破できます。

### 描画版（マウス / タッチ）

1. カーソルの方向へ通常移動します。タッチでは仮想スティックで移動します。
2. 時間経過で高速攻撃ゲージを溜めます（基礎6秒で満タン）。カーソル付近のリングが25%以上になると描けます。急速充填で待ち時間、大容量チャージで描ける長さを変えられます。
3. 好きな場所をクリックすると、その場所からすぐ描き始められます。ボタンは離し、マウスを動かすだけで描けます。描画中は敵が0.1倍速で動きます。Pの「描画中の世界の速さ」で0（停止）〜1（通常）に調整できます。
4. もう一度クリックするか、描ける長さを使い切ると、描き始めの点へワープし、軌跡を高速で駆け抜けます。

描画中はリングが残りの長さを示し、描くほど減ります。描いた長さの分だけゲージを消費し、使わなかった分は次回へ持ち越します。残量が25%以上なら経路終了後すぐ次の軌跡を描けます。描画時間の制限はありません。Spaceの補助操作とタッチ用の「描く」ボタンも使えます。

線の終了後も高速を維持し、カーソル／スティックで方向を変えられます。ザコを貫通しても減速しません。硬い敵や障害物への衝突などで通常移動へ戻ります。移動中のレベルアップ画面は線の終了後に表示され、閉じると勢いを引き継いで再開します。経験値カプセルのドロップは撃破ごとの確率抽選です。描画・経路実行・ポーズ・カード選択中は充填しません。レベルアップ間隔は従来より長くしています。威力は攻撃力倍率で決まり、速度には依存しません。小型敵の弱点狙いは不要です。装甲型と大型戦艦は黄色い背面から攻撃すると突破しやすくなります。

### スマートフォン

タッチ主体の端末では自動でスマホ用の描画版に切り替わります。縦持ち／横持ちに合わせて、表示を引き伸ばさずゲーム領域のアスペクト比を変えます。下の操作帯は設けず、セーフエリアを除く画面全体をフィールドに使います。操作ボタンとHUDはフィールド上に小さく重ねます。

- フィールドに触れると、その位置を中心にバーチャルジョイスティックが出ます。指をずらした方向へ操舵し、離すと消えます。通常攻撃は自動です。
- 25%以上溜まったら右下に重ねた小さな「描く」をタップ。フィールドに指で軌跡を描き、指を離すか長さを使い切ると発動します。移動中の指を保持したまま、別の指で描画できます。「描く」の準備中はフィールドの新しいタッチを描画に使います。充填率はボタン外周のリングで確認でき、数値は表示しません。
- 線を描く前は「取消」で戻れます。短く描いた場合は未使用ゲージを残します。OSがタッチを中断したときや画面を回転したときは、描きかけの線をキャンセルします。
- 強化カードはタップで選択。一時停止・調整は左上のハンバーガーメニューから開けます。
- PC用の操作方式／通過点入力の保存設定は書き換えません。スマホでは指で描く入力を使い、ポータルなどの旧操作は選択対象外です。

PCでスマホ用UIを確認する場合は `?mobile=1` を付けて画面幅を狭めます。ブラウザで390×844／844×390の表示・操作を確認済みです。実機での複数指入力と長時間の性能確認は今後行います。

### WASD描画版（キーボード＋マウス）

Pパネルの操作方法から「WASD移動＋マウスで軌跡描画」を選べます。通常移動と線の終了後の高速移動はWASD／矢印で操舵し、マウスは軌跡を描くときに使います。キーを離すと勢いのまま進み続けます。クリックで即座に描き始め、マウスを動かすだけで描き、再クリックか描ける長さを使い切ると発動します。残量は線の先端の円形ゲージで確認できます。ゲージやモジュール、波動などはカーソル移動版と共通です。

### 共通

Pから欲しい武器／特性を選び、強化回数を指定して待機なく直接入手できます。通常候補は武器9種・特性14種。オービットブレード、リターンディスク、追尾ミサイル、アークコイルは「保留」枠に分け、通常抽選には出しません。「装備をリセット」「レベルアップ」「ゲージ満タン」で比較できます。

Pメニューの「軌跡の入力」で、従来の描画に加えて「クリックで通過点を置く」を試せます。左クリックで開始点と通過点を置き、点の間を直線で結びます。右クリックまたはSpaceで発動し、長さを使い切ると自動発動します。カーソル移動版とWASD移動版の両方で使え、選択はブラウザに保存されます。

| キー | 動作 |
|---|---|
| Enter | ステーションから出発 / リザルトから戻る |
| Esc | ポーズ |
| M | ミュート切り替え（初期状態はミュート） |
| P | 調整パネルを開閉。操作方式・数値の変更、モジュールの試用など |

強化データと操作設定はブラウザのlocalStorageに保存されます。ポータル操作はスマートフォン未対応です。

## ローカルで起動

ビルド・テストにはNode.jsを使います。外部パッケージへの依存はなく、`npm install` は不要です。以下の配信例はPython 3を使います。

```bash
git clone https://github.com/Tomatoguy1029/speed.git
cd speed/demo
node build.js
python3 -m http.server 8766 --bind 127.0.0.1
```

ブラウザで [ローカル版](http://127.0.0.1:8766/dist/index.html) または [ローカルのポータル版](http://127.0.0.1:8766/dist/index.html?controls=portal) を開きます。ソース変更後は `node build.js` を再実行し、ページを再読み込みしてください。

`dist/speed.html` はJavaScriptを内包した単体配布用HTMLです。サーバーなしでブラウザから開くこともできます。

## 開発

```bash
node --test                    # テスト
node build.js                  # 配布用HTMLを生成
node tools/balance.js 3 1 god   # 自動プレイ計測（3回、シード1、無敵）
```

自動プレイ計測は描画・ポータル操作の手触りを評価するものではありません。これらの操作の評価は実際に遊んで行います。

| パス | 内容 |
|---|---|
| `src/` | ゲームのJavaScript。描画はCanvas、音はブラウザで合成 |
| `src/config.js` | 操作・速度・戦闘などの調整値 |
| `src/controls.js`, `src/input.js` | 操作方式とキー・ポインター入力 |
| `src/run-build.js`, `src/run-weapons.js` | 武器・特性のLv／3択・時間充填・自動攻撃・経路効果 |
| `src/experimental-weapons.js` | 保留武器のデバッグ試用（通常抽選外） |
| `src/portals.js`, `src/portal-loops.js` | ポータル移動と囲み判定 |
| `index.html`, `build.js` | 画面テンプレートと独自バンドラ |
| `dist/` | 生成した配布用HTMLと元の描画版 |
| `test/`, `tools/` | テストと自動プレイ計測 |

ビルドはES Modulesを1つのIIFEに結合します。トップレベルの名前はファイルをまたいで重複できません。`dist/index.html` と `dist/speed.html` は同じ内容で、両方をGit管理します。`dist/draw-original.html` は通常のビルドでは上書きされません。

demo または公開設定を変更してpushすると、ルートのGitHub Actionsと `vercel.json` が `node demo/build.js` を実行し、`demo/dist/` を公開します。`main` は公開版、それ以外のブランチはプレビューです。

武器は5段階（白・緑・青・紫・金）に圧縮し、Lv5で以前のLv8の最終性能になります。紫の結晶は経験値、赤いリングは敵弾、金属色と橙の残光は攻撃判定のある破片です。隕石は8%でHP10%回復の修理キット、別抽選4%で全経験値を一括回収する磁石型の回収ビーコンを落とします。

隕石は世界に隕石地帯と漂流軌道・彗星として配置し、近傍だけ読み込みます。倒した岩は再訪しても復活せず、プレイヤーを追って補充しません。敵同士の押し戻しは撤去しました。接触電撃は敵との接触で発動し、Lv1〜5で近隣2〜10体へ伝播します。強化カードは四角い武器バッジと丸い特性バッジで区別できます。

光る隕石を壊すと、隕石限定の「双極ビーム」「質量牽引砲」を入手できます。双極ビームは高速経路の開始点と終点を結ぶ直線を攻撃、質量牽引砲は高速攻撃で倒した船体を大型敵も含めて牽引し、経路終了後に順番に高速発射します。武器は4枠のまま、満枠時は交換／見送りを選べます。取得済みの限定武器は通常の強化カードでもLv5まで強化。Pの「武器：隕石限定」と限定隕石の配置ボタンで試せます。
