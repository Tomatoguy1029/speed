# 現在の仕様

ゲームが今どう動くかの説明。挙動や数値を変えたらここを更新する（経緯は作業ユーザーごとの [wakida.md](wakida.md)・[shumak.md](shumak.md)・[keporusu.md](keporusu.md)）。

## コンセプトと時間の流れ

2D 見下ろしのサバイバー系の **試作**。目的は作者が通しで遊んで「面白くなりそうか」を判断すること（作り込みより全要素を一通り体験できることを優先）。

- コンセプト: 敵の大群に対して高速移動で立ち向かい、一気に吹き飛ばして圧倒する快感を楽しむゲーム。迫り来る敵の脅威に対して、高速移動によって敵を蹂躙することで、脅威を快感へと変える。
- コンセプトチェックの問い: ①迫り来る敵の大群に脅威を感じるか ②自分の操作による高速移動で立ち向かう手応えがあるか ③一気に吹き飛ばして圧倒することで、脅威が快感に変わるか
- 現在のクリア条件は10分以内にボスを撃破すること（詳細は「速度・成長・クリア」）。ボスのギミックは別途検討し、現時点では大型戦艦を使う。
- 1 ラン 10 分。時間で体験曲線を作る: 強化期(0–2:30) → 圧力期(–4:00) → 強化期II(–5:00) → 無双期(5:00–6:00) → 緊張期(–8:30) → 脱出期(–10:00)
- **フェーズは裏のレベルデザイン専用**。名前やバナーをゲーム画面に出さない（ユーザー指示）。ユーザーへの説明でも「〜分ごろ」など時間で言う

## 操作（調整パネル `P` で切り替え。選択は localStorage `speed-controls-v2` に保存）

|---|---|
| `portal`（試作） | WASD／矢印で通常移動、Bで設置。Space短押しで最寄りへ突進（ゲージ不要）。入場するとポータルに乗る。全ての移動可能なポータルへ薄い線を表示し、A/Dで角度順に選択、黄色い太線の行き先へSpace短押しで移動。Space0.5秒長押しで離脱。移動可能な接続先がなくなると自動離脱。自動出発なし。通った辺は逆向きも含めて実時間10秒クールダウンし、離脱しても残る。同じ辺は一回のアタックで再利用不可。移動中も次の選択と出発予約が可能。待機中も敵・弾は通常速度。通過軌跡は離脱まで保持。 |
| `draw`（既定） | カーソル方向へ通常移動（クリック不要）、タッチは仮想スティック。時間充填のゲージが25%以上でクリックした位置から描画開始。押し続けずマウス移動だけで描き、再クリック／長さ消費／障害物で発動。開始点へワープ後、経路を約0.5実秒でなぞる。通常攻撃は自動、武器・特性を3択カードで育てる。描画中0.1倍速（Pで0〜1）、経路実行中は260/突進速度（下限0.03）。描画／実行中カメラ固定、ラン時計は実時間。カーソル付近のリングに充填率／長さ残量を表示。 |
| `draw-wasd` | 通常移動と経路終了後の操舵はWASD／矢印。画面方向へ4.5rad/sで旋回し、低速時は巡航へ加速。描画・時間充填・自動攻撃・3択強化はdrawと共通。クリックで即描き始め、再クリックで発動。キーを離すと勢いのまま進む。Pと`?controls=draw-wasd`で選択可能。 |
| `mouse` | カーソルを置いた方向へ進行方向が回る（クリック不要）。Space かクリック長押しでチャージ→離すとカーソル方向へ突進 |
| `steer` | WASD で押した画面方向へ進行方向が回る（4.5 rad/s、速度維持）。Space で進行方向へ加速 |

- 機体の絵は **どの方式でも回転しない丸い機体**（ユーザーが回転に違和感を訴えたため）。外側の矢印が「今 Space を離すと飛ぶ方向」
- 描画版以外の旧操作では、ゲージは押している時間で溜まる。発射速度 = 上限 × 0.8 × ゲージ ＋ 同じ向きの勢いの 65%（上限で頭打ち、過充填で超えられる）

### ポータル操作の試作（2026-10-04）

- 調整パネル `P` →「ポータル連続突進（試作）」で選択。プレビュー URL の `?controls=portal` でも起動できる。`?controls=draw` は現在の描画方式を明示する。既存方式と比較できるよう `draw` の既定値と保存済みの操作設定は維持する。URL 指定はその表示で優先する
- 通常移動の線分とポータルの接触（半径28＋機体半径16）を検出し、入場すると中心へ乗る。入場しただけでは次へ出発しない。足元への設置や到着後その場に留まることでは再入場しない。終了後は世界時間0.6秒の再入場猶予。入場・Spaceともゲージを要求・消費せず、ゲージを表示しない。突進出力は満タン相当（`stats.gaugeMax`）
- **元の版を保存**: `dist/draw-original.html` はポータル導入前のコミット `b9ca9b8` の配布HTMLを保存し、初期操作だけを必ず `draw` に固定。通常のビルドはこのファイルを上書きしない。ステーションの「元の版：線を描いて駆け抜ける」と「ポータル試作」からそれぞれ別タブで開ける
- 手置きはラン中残る（最大12個）。敵からのランダムなポータル生成・回数補充は一旦停止（出現率0）。Bで設置したポータルのみを使う。手置き上限や近くに手置きがある場合は設置を拒否し、表示で知らせる
- ドロップの仕組みは再検討用に残す。Pパネルで出現率を0より大きくした場合のみ有効。260以内にポータルがあれば新規生成しない。近くのドロップの回数が減っていれば1回補充（上限3、同じポータルへの補充は世界時間1.5秒に一度）。近くにポータルがなければ設定した確率で撃破地点に生成。惑星／小惑星の中には生成しない。ドロップは3回の到着で消える（同時最大36個）、Bで手置きに変換可能
- 1区間の到達距離は900、1アタックの総移動距離は2400。最高速度／基礎最高速度、軌跡延長モジュール、ゲージ上限に比例して伸びる。ポータル間の100未満の区間、惑星／小惑星を横切る区間、残り総距離で届かない区間は候補から除外
- 乗っているポータルから到達可能な**全候補**へ薄い実線。選択中の区間は黄色い太い実線・矢印・行き先のリングと「次」で強調する。Aは反時計回り、Dは時計回りに、画面上方向からの角度順で循環選択。同じ角度に複数ある場合は距離順。8個の候補上限・8方向区画・方向による出発・番号操作は廃止。A/Dのキーリピートでも選択可能
- Spaceは短く押して**離したとき**に選択先へ移動。押している間は移動せず、実時間0.5秒（`portalExitHold`）に達するとその場から通常移動へ離脱。長押しの進捗と残り秒を表示し、離したときに誤出発しない。離脱方向はWASD入力があればその方向、なければ機体の進行方向。Space長押し中の再入場は抑止する。Xによる離脱・時間切れによる自動出発は廃止。使用済みの辺などで移動可能な接続先がなくなった場合は、長押しを待たず進行方向へ自動離脱する。移動途中では中断せず、最後の区間の移動と到着波動・包囲炸裂を処理してから離脱。自動離脱時にSpaceを押していた場合、離したときの再出発を抑止する
- 通常移動中のSpace短押しは最寄りの到達可能なポータルへ突進（接触範囲44以上なら100未満も可能）。Bは設置。移動中のA/Dは到着位置の候補を選び、Space短押しは到着後の出発予約。長押しなら移動途中でも離脱する。予約がなければ到着後に待機し、敵と弾は通常速度で動く。各区間は最長0.22秒（高速トレーサーで短縮）。移動中の世界速度は突進速度に反比例する。ランの時計は実時間で進む（既存の撃破ヒットストップ中は停止）
- 一回のアタック中に使用した辺は、逆向きも含めて再利用不可。同じ座標のポータルが再生成されても同じ辺として扱う。A→B→Aは不可、A→B→C→Aは可能。移動開始時に辺を使用済みとし、候補の薄い線から除外する。一回のアタックの使用済み記録は離脱でリセットするが、辺のクールダウンはラン全体で保持。通過完了から実時間10秒間は、離脱・再入場・逆向き・同じ座標のポータル再生成でも再利用できない。移動開始時にもクールダウンを設定し、途中で弾かれたり離脱した場合は開始から10秒。ヒットストップ・世界のスロー中も経過し、ポーズ・モジュール選択中は停止する。10秒後も同じアタック内の使用済み辺は使用不可。通常移動中の最寄り突進にも適用し、ポータル接触範囲内では中心の座標で判定する。全通過軌跡は水色の線で離脱まで保持し、包囲炸裂の判定も従来通り
- 出発地点から実際に線分を走る。通過中は既存の本体貫通・波動・弾かれ・減速を使う。弾かれたら即座に通常操作へ戻る。無敵は付与しない。移動中の軌跡炸裂は走った経路に沿って残る
- 「共振ビーコン」（レーダー枠、ポータル方式のみ抽選）装備時、到着地点の半径160に、到着速度による攻撃力×0.9×レア度倍率の装甲無視ダメージと吹き飛ばし。試作では初期装備。波動増幅器／大波動の範囲・威力強化も乗る。軌跡延長は到達距離・総距離、高速トレーサーは区間の移動速度、過充填コンデンサは突進出力・到達距離・総距離を伸ばす。ゲージ不要のため、チャージ短縮・回生ジェネレーター・チャージ衝撃波はポータル方式の抽選から除く
- **包囲炸裂**（銃枠、ポータル方式のみ抽選、エピック／レジェンド）: 実際に通った軌跡が開始点に戻る、または過去の区間と交差して閉じた瞬間、内側に中心がある敵へ装甲無視の爆発ダメージ。エピックは突進攻撃力×2.88、レジェンドは×4.2（重複強化も乗る）。レジェンドでは囲まれた各敵から半径90の追加爆発（本攻撃の50%）が出て外側も巻き込む。追加爆発から再帰的に爆発は発生しない。閉じた領域を短く発光させ、各敵の爆発と撃破数を表示する。直線の往復や面積64未満は発動しない。一度爆発した閉じた区間は判定から消費し、同じ囲みの連続発動を防ぐ。表示用の軌跡は従来どおり連続突進終了まで残す。未装備では囲んでも発動しない
- 調整パネル `P` の「包囲炸裂を入手」で試用できる（隣のレア度選択のエピック／レジェンドを使用。コモン／レア選択時はエピック扱い）
- 残る／消えるポータルを色と残り回数で区別。選択番号／全候補数、次の経路、画面外の候補、総距離、離脱の長押し進捗、通過波動の幅、到着波動の範囲、貫通対象と最初の阻害敵を表示。カメラは追従する
- 数値は `src/config.js` に集約し、到達距離・総距離・Space長押しで離脱する秒数（0.5〜3秒）・辺のクールダウン（0〜30秒、既定10秒）・待機中の世界速度・区間時間・配置間隔・出現率・到着波動をPパネルで変更できる。ポータル耐久とポータルを狙う敵は未実装

### 描画版の高速移動と応答

- 描画中・経路実行中のレベルアップは予約し、実際の経路が終わった後に3択カードを出す。硬い敵に弾かれた場合も終了後。複数のレベルが上がった場合は1レベルにつき1枚ずつ選ぶ。閉じると速度を引き継ぐ。選択画面同士の待機時間はない。
- 線を走り切った後も速度を維持し、カーソル／スティック（draw）、WASD（draw-wasd）で方向を変えられる。巡航減速・上限超過減衰・宇宙塵抵抗は適用しない。ザコ貫通では減速せず、硬い敵・障害物への衝突や減速型の吸収・敵弾の減速で通常移動へ戻る。無敵は付与しない。
- 経路から半径45の波動が出て、装甲無視で攻撃力×0.5を与える。帯から一度離れて再び重なると再命中できる。本体の当たり判定は半径16。実際の再貫通時は×2、×3を表示する。
- 事前の敵ごとの撃破予告・赤×は描画版で表示しない。実際の弾かれには目立つ火花と接触面の発光、確率クリティカルの貫通には赤熱を出す。吹き飛ばした船体破片は実際の飛翔位置を残光として残す。
- ゲージUIはカーソル付近のリングのみ。充填率25%以上で緑、満タンで金、描画中は長さ残量を表示。画面下の速度メーター・経験値バー・HPは維持する。ポータル操作と保存した元の描画版も維持。

## 描画版の武器・特性・時間充填（2026-10-07）

- 通常プールは武器9種・特性14種。武器4枠・各Lv5、特性6枠・各5重ね。初期装備ブラスターLv1。保留4武器と採否未判断の既存候補は別枠でデバッグ試用でき、通常の新規取得には出ない。すでにデバッグで装備した場合の強化はカードに出る。
- 通常攻撃は自動。射撃は進行方向、散弾は扇状、バリアとソニックは周期範囲攻撃、ドローンは周回射撃と遅延追走。吹き飛ばし・接触波動・機雷は実際の高速接触／通過経路に連動する。個別の数値・Lv変化は [武器一覧](weapons.md)、特性の条件・1〜5重ねは [特性一覧](traits.md)。
- 1単位の充填は6実秒。描画・経路実行・ポーズ・カード選択中は充填しない。経験値・通常の撃破では充填しない。開始時満タン、25%以上で発動可能。描ける長さは開始時の充填率に比例し、確定時に実際に描いた長さの分だけ消費する。消費率＝開始時充填率×描いた長さ/今回の描画上限。例：満タン時の最大長さの40%だけ描くと60%残る。残量が25%以上なら経路終了後すぐ次の描画を始められ、それ未満なら残量から時間充填を再開する。描画が成立しなかった場合は消費しない。敵に途中で弾かれても確定した軌跡の消費は返さない。容量は1+0.2×大容量チャージの重ね数。充填時間は容量×6/(1+0.25×急速充填の重ね数)（メタ強化でさらに短縮）。容量は回数ストックではなく1回の長さ・勢いを増やす。Pで充填時間／最低発動率を変更できる。
- 描ける長さは1000×実際に消費した容量×最高速度/基礎最高速度×軌跡延長倍率。満タン突撃は満タンから始めた経路実行の間だけ装甲無視と威力倍率を付ける。
- 装備の入手・強化はレベルアップごとに3枚から1枚。新しい武器／武器強化／特性の混合抽選、同じ候補を1画面に重複させない。クリック／数字キー1〜3。装備済みをやや出やすくし、枠が埋まると新規取得は出ない。最大Lv・5重ねの候補は除外し、候補が足りない場合だけHP30%回復で補充。
- カードの枠と装備一覧の文字色は種類でなく強化段階に対応。1＝白、2＝緑、3＝青、4＝紫、5＝金。武器のLvと特性の重ね数に共通適用し、カードは取得後の段階、装備一覧は現在値で色を決める。回復カードは装備ではないため従来の緑。
- 経験値は紫の結晶（#b8a0ff、暗紫の縁#39265e、明るい面付き）。画面上の高さは最低8pxで、白い飛散粒子と区別する。XPカプセル・バー・取得文字も紫に揃える。敵弾は暗い中心の赤いリング、味方弾は水色の細長い弾、攻撃判定付きの船体破片は金属色と橙の残光に分ける。当たり判定は変えない。
- 必要経験値はLv Lで90+42L+6L²（従来10+7Lから延長）。レベル基礎成長は最高速度+2%、攻撃力+2%、最大HP+4、HP8%回復を維持。描画版の充填時間はレベルでは自動短縮せず特性・メタ強化で短縮する。必要経験値・枠数はPで調整可能。
- 全ての攻撃の基礎威力は速度と独立。通常速度での接触は被弾、高速経路・終了後の勢い・最高速度65%以上の接触では体当たり攻撃。小型敵の弱点方向はなし、装甲型と大型戦艦の背面弱点を保持、クリティカルは基礎5%・威力2.5倍の確率判定。
- 敵からの旧モジュールカプセルはXPカプセルへ変更（現在のレベルに必要なXPの15%）。漂流カプセルは20%。敵撃破ごとの確率 `min(dropMax,dropBase×敵XP^dropPowerExp)`、基本0.5%・上限50%は維持。漂流カプセル最大4個／16秒補充はフィールド配置の設定であり、装備入手の待機時間ではない。
- 6秒、25%、特性6枠、経験値曲線と各効果の数値は実装を遊ぶための試作値。本番の確定仕様ではない。通常プール12武器・20特性は未採用の規模案で、既存候補を勝手に通常プールへ足していない。

## 旧6部位方式のモジュール入手（描画版以外）
- **レベルアップでは入手画面を出さない**。レベルごとに基礎性能が自動で上がる（最高速度 +2%、攻撃力 +2%、最大 HP +4、チャージ時間 −1%（下限 60%）、HP 8% 回復）
- **モジュールは敵が落とす**。確率 = 0.005 × 敵の強さ（= その敵の経験値。種類・レベル・エリートを反映）、上限 50%。レア度も強さで上がる。エリート・戦艦も確率抽選。落ちたモジュールは近くで吸い寄せられ、45 秒で消える。フィールドの漂流カプセル（中心ほどレア）と出力コアは従来どおり

## 軌跡の入力方法（試作）
- Pメニューの「軌跡の入力」で「マウスで描く（従来）」と「クリックで通過点を置く」を切り替える。既定値は従来のフリーハンド。入力方法はブラウザに保存し、カーソル移動の`draw`・WASD移動の`draw-wasd`の両方に適用する。通常移動やゲージ・モジュールは共通。
- 通過点方式は、満タン時の左クリックで開始点を置き、以降の左クリックで通過点を追加。点間を直線で結び、マウスを移動するだけでは線を追加しない。右クリック／Spaceで確定した点列を高速で走る。確定時にカーソル位置へ新たな線は追加しない。開始点だけの場合は発動せず追加のクリックを待つ。
- 長さを使い切る、または惑星・小惑星に線が届くと、その位置まで切り詰めて自動発動する。残量リング・モジュール選択の保留・終了後の速度維持は従来と共通。Pで入力方法を変更中の未確定経路は破棄し、そのゲージを戻す。発動済みの経路はそのまま最後まで走る。

## 敵の密度と分散（2026-10-06）

## 隕石と回復
- 隕石は絶対座標の隕石地帯、疎らな漂流軌道、彗星の軌道をラン開始時に決める。世界の配置密度18（P、次のランから）を基準に8地帯×8個、漂流45個、彗星3軌道。惑星／フィールド外の岩は除外。プレイヤー位置は近傍の有効化・解除だけに使い、画面端への再配置や破壊後の補充はしない。HP・ID・破壊状態をラン内で保持。詳細は敵一覧と `meteor-field.js`。
- 隕石を破壊した時だけ8%の確率で修理キットを1個落とす。回復量は最大HPの10%、現在の最大HPまで。通常攻撃・高速攻撃・連鎖のどれで壊しても抽選する。取得は即時で、選択画面や停止を追加しない。既存の経験値・部品ドロップは維持する。

- 隕石は灰茶色の不規則な輪郭・岩の面・複数のクレーターを持つ。敵の目／船首、赤い装甲リング、HPバーは描かず、損傷時は亀裂を表示する。Pに隕石配置密度・回復ドロップ率・回復量・経験値一括回収アイテムのドロップ率の調整を追加。

## 速度・成長・クリア

- **重力はなし**（`planetGM`/`moonGM` = 0。ユーザーが鬱陶しいと判断）。惑星・小惑星は障害物として残る（ぶつかると弾かれる、軌跡もそこで止まる）。重力の仕組み自体は残っていて調整パネルで戻せる
- 惑星・周回する月には通常敵とボスも衝突する。接触面へ押し戻し、内向きの速度だけ止めて横方向の動きは残す。敵弾・味方弾・攻撃用破片・保留武器のミサイル／ディスクも衝突し、弾は消失、ミサイルは接触地点で爆発する。高速の移動区間全体から最初の接触を求め、障害物の向こうの対象へ弾が届かないようにする。波動・範囲攻撃・ビームはこの物理弾判定の対象外。絶対座標の隕石軌道は維持。Pに「月の近くへ」を追加。

- 描画版の装備は左下に武器Lv・特性の重ね数を一覧表示。描画版以外は従来の6部位の機体図を維持
- カメラは **最高速度** に応じて引く（現在速度ではない）

- 参考: [Vampire Survivorsのオンライン版を共同開発したcoherenceの技術記事](https://coherence.io/blog/tradecraft/vampire-survivors-online-coop-case-study)では、継続的な敵の生成・プレイヤーへの直接追跡・敵同士の押し合いを確認した。画面外での再配置や具体的な補充計算の公式コードは確認できていないため、上記の距離・補充時間・広域移動・四辺の補充は本作向けの設定であり、本家の実装と同一ではない。
