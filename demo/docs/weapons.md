# 武器一覧

最終更新：2026-10-07。対象はブラウザdemo。[共通設計](module-plan.md)／[運用ルール](catalog.md)／[特性一覧](traits.md)。

描画版 `draw` / `draw-wasd` は武器4枠・各Lv5。初期装備はブラスターLv1。武器種類ごとのレア度は付けず、カードと装備一覧を強化後／現在のLvに応じて白・緑・青・紫・金（Lv1・2・3・4・5）で表示する。以下の9種を通常のレベルアップ候補に実装した。数値はdemoで触るための試作値で、本番の確定値ではない。

## 通常候補：9種（実装済み）

`A = 基礎攻撃力10 × 攻撃力倍率 × atkScale(1) × 満タン突撃の倍率`。表示Lv1〜5に旧性能段階1・3・5・6・8を割り当てる。性能段階をLとし、威力係数 `D=1+0.3×(L−1)`、頻度係数 `F=1+0.12×(L−1)`、範囲係数 `R=1+0.1×(L−1)`。各攻撃には確率クリティカルが別に適用される。

| ID / 実装ID | 名称 | 採用状態 | 発動・効果（試作数値） | ルートへの影響 | 実装・参照 |
|---|---|---|---|---|---|
| W01 / `forward` | ブラスター | demo採用 | 0.45/F秒ごとに進行方向へ自動射撃。威力0.8AD。弾数1→3、追加貫通0→2（Lv1→5） | 通常移動の向きが射撃方向になる | `run-weapons.js`。描画・経路実行中は新規射撃を休止 |
| W02 / `scatter` | 散弾砲 | demo採用 | 1.05/F秒ごとに扇状射撃。1発0.55AD。弾数5→8、弾の寿命0.45秒 | 群れに向けて進み、近距離の広がりを当てる | `run-weapons.js`。W01とは独立武器 |
| W03 / `knockback` | 吹き飛ばし衝角 | demo採用 | 高速接触で生きた敵を突進方向へ吹き飛ばす。撃破時は船体破片が飛ぶ。二次衝突は0.7AD、速度800+90L | 他の敵に船体をぶつけられる方向から入る | `onRunContact` / `updateShovedEnemies`。大型の接触撃破は6〜12個の破片を扇状に飛ばす（0.9秒、0.7AD、吹き飛ばし500）。小型は従来の1片。破片は残光を引く |
| W04 / `contactWave` | 接触波動 | demo採用 | 高速接触のたびに半径90R、威力0.45ADの波動。弾かれた接触でも発動 | 密集した群れを通る。波動の撃破から再帰発動しない | `onRunContact` |
| W05 / `barrier` | バリアシステム | demo採用 | 半径70Rに0.7/F秒ごとの0.4ADの波動。0.8/F秒に1発の敵弾を遮断 | 敵・弾に近づく際の状況を変える | `updateRunWeapons`。全ての弾を常時無効化するものではない |
| W06 / `drone` | 追走ドローン | demo採用 | 通常は半径90で周回し、0.65/F秒ごとに敵へ0.45ADの射撃。高速経路は1機ごと0.12秒遅れて追い、接触0.5AD | 自機が抜けた後にも同じ経路を掃く | `updateRunFollowers`。機数1→4、同じ敵への接触間隔0.3実秒 |
| W07 / `mines` | 軌跡機雷 | demo採用 | 実際に通った高速経路に75/F距離ごとに機雷。0.25秒後に有効、寿命6秒、半径110R、威力AD | 敵が後から入る経路を残す | `onRunTrail` / `effects.js`。最大250個 |
| W08 / `sonic` | ソニックブーム | demo採用 | 高速攻撃の開始時、および通常移動の5/F秒ごとに半径310R、威力1.8ADの波動。0.5実秒、機体とともに実際の経路を掃く。吹き飛ばし1000 | 発射地点だけでなく進路も一掃。同じ波動では各敵に1回。撃破数条件のT05とは別 | `runSonic`。発動時のカメラズームなし。大型敵の撃破で6〜12個の貫通破片（1.2A、初速1100）が飛び、周囲を巻き込む |

| W17 / `contactArc` | 接触電撃 | demo採用 | 通常／高速で敵に接触すると対象に0.65AD、近隣2・4・6・8・10体へ伝播（Lv1〜5）。1回の伝播距離240。同じ敵を1連鎖で再攻撃しない | 群れの繋がった配置を経路で跨ぎ、接触点から離れた敵まで処理する | `onRunElectricContact`。隕石は対象外。自動発射する保留W12とは別。稲妻を0.22世界秒表示、連鎖ダメージから接触電撃は再発動しない |

表示Lv1→5でDは1→3.1、Fは1→1.84、Rは1→1.7。旧8段階の最終威力・連射・範囲・弾数・機数・吹き飛ばす速さを維持し、取得・強化回数だけを減らす。威力は移動速度と独立。
