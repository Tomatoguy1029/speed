# demo の武器・特性整理

2026-10-07の検討内容。次の更新対象はブラウザdemo。Godotにはまだ実装しない。
共通方針は描画版demoへ実装済み。この文書は共通設計と候補規模の管理用で、実装済みの挙動は [spec.md](spec.md) を参照する。

## 共通方針

- 高速攻撃は、自分で軌跡を描いて駆け抜ける方式を採用する。
- 通常攻撃はヴァンサバ式の自動攻撃。高速移動のゲージは時間経過で充填し、特性でチャージ時間を短縮できる。
- モジュールを武器モジュールと特性モジュールに分ける。武器は各Lv8まで、同じ特性は5回まで重ねられる。
- 同時装備できる種類を増やすため、候補の種類数も増やす。武器の同時装備枠は4を目安にする（暫定）。特性6枠をdemoの試作値として実装しPで変更可能。候補の最終的な種類数は未決定。
- レベルアップごとに新武器／武器強化／特性の3枚から1枚を選ぶ。クリックまたは数字キー1〜3。レベルアップ間隔は従来より長くする。必要経験値は試作値60+28L+4L²を実装（Lは現在レベル）。
- 威力は速度ではなく攻撃力倍率で決まる。
- 雑魚の弱点方向判定は外す。ボスの弱点ギミックは別途検討する。クリティカル率は弱点方向判定と別に扱う。
- ビルドによって通したいルート・倒せる敵・突破後の状況が大きく変わり、以前できなかったことができる状態を目指す。

## 候補数と成長ペース：提案・未確定

装備は武器4枠・特性6枠を試作値として実装済み。通常候補を武器12種・特性20種程度へ増やす案は未採用。後述の追加検討枠4武器は通常候補数に含めない。現時点のユーザー案は武器8種・特性14種なので、それぞれ4種・6種の追加候補を検討する。

装備枠の拡大とレベルアップ間隔の延長を両立させるため、全装備の最大強化を毎ランの前提にはしない案を検討する。武器4種をLv8・特性6種を5重ねにするには取得62回分（初期装備が武器Lv1なら選択61回）が必要で、10分ランでは平均約10秒に一度の選択になる。初回取得で経路や攻撃に影響する効果を使え、以後は主力の強化と他の装備の取得を選べる設計が候補。今回の通常プールはユーザー案の武器8種・特性14種。追加4武器・6特性と成長配分の最終調整は未採用。全装備の最大強化を毎ランの前提にはしない。
