# demo の武器・特性整理

2026-10-07の検討内容。次の更新対象はブラウザdemo。Godotにはまだ実装しない。
この文書は次の更新方針と候補の管理用で、実装済みの挙動は [spec.md](spec.md) を参照する。

## 共通方針

- 高速攻撃は、自分で軌跡を描いて駆け抜ける方式を採用する。
- 通常攻撃はヴァンサバ式の自動攻撃。高速移動のゲージは時間経過で充填し、特性でチャージ時間を短縮できる。
- モジュールを武器モジュールと特性モジュールに分ける。武器は各Lv8まで、同じ特性は5回まで重ねられる。
- レベルアップごとに新武器／武器強化／特性の3枚から1枚を選ぶ。クリックまたは数字キー1〜3。レベルアップ間隔は従来より長くする。具体的な必要経験値は未決定。
- 威力は速度ではなく攻撃力倍率で決まる。
- 雑魚の弱点方向判定は外す。ボスの弱点ギミックは別途検討する。クリティカル率は弱点方向判定と別に扱う。
- ビルドによって通したいルート・倒せる敵・突破後の状況が大きく変わり、以前できなかったことができる状態を目指す。

## 武器候補：ユーザー案

個々の効果・強化段階・数値は引き続き検討する。

| 武器案 | 効果・狙い |
|---|---|
| 進行方向への射撃 | 進行方向へ弾を撃つ |
| 散弾 | 散弾状の射撃。旧ブラスターの扇状射撃を土台にできる |
| ノックバック | 接触した敵を突進方向へ吹き飛ばし、狙った敵へぶつけるために進入方向を考える。既存の吹き飛ばし衝角は撃破した敵の破片を飛ばす効果で、差がある |
| 接触波動 | 敵にぶつかるたびに周囲へ波動。密集地点を通ることを促す。既存の連鎖パルスは貫通時だけ発動する |
| バリアシステム | 詳細未決定 |
| ドローン | 自機から少し離れて飛ぶ。高速移動中は少し遅れて同じ経路を追う |
| 軌跡への機雷投下 | 通過した経路に機雷を残す |
| ソニックブーム | 広範囲の衝撃波。武器としての基本発動条件は未決定。既存は速度閾値で発動する |

## 武器：追加検討枠

軌跡との直接的な関係が薄いため、上の武器候補とは別に管理する。
**削除しない。採用決定までは通常のレベルアップ抽選に追加しない。**
現行demoでは巻き戻されているが、コミット `980f27b` の `src/weapons.js` に定義・Lv1〜8の強化・実行処理が保存されている。
復帰する場合も、この4種を通常候補から区別できる状態で保持する。

| 武器 | 保存されている効果 |
|---|---|
| オービットブレード | 自機の周囲を回り、接触した敵を切る刃 |
| リターンディスク | 敵へ投げ、減速して戻る貫通刃。往復とも攻撃する |
| 追尾ミサイル | 近くの敵を追尾し、着弾で範囲爆発する |
| アークコイル | 近くの敵へ稲妻を撃ち、他の敵へ連鎖する |

## その他の既存武器候補：採否未判断

前の棚卸しで提示したもの。今回の武器案への採用を自動では決めない。

- 自動砲台：最寄りの敵へ自動射撃。現行demoにある。
- パルスノヴァ：一定間隔で自機中心に衝撃波。旧版の履歴にある。
- レーザーランス：最寄りの敵へ貫通ビーム。旧版の履歴にある。クリティカル時のビームの処理として再利用できる。
- 軌跡炸裂：通った場所が遅れて爆発する。現行demoにある。

## 特性候補：ユーザー案

| 特性案 | 効果・検討事項 |
|---|---|
| 移動終了時に爆発 | 終点を密集地点にする判断を促す。途中の撃破数を発動条件にするかは未決定。既存の終端爆縮器は無条件、炸裂弾頭は貫通数条件 |
| 交差爆破 | 過去の高速移動の軌跡と交差すると交点が爆発。対象とする過去軌跡の範囲・保存期間は未決定 |
| 余韻の渦 | 終点に渦を残し、敵を引き寄せる |
| 満タン突撃 | 満タンからの高速攻撃は硬い敵にも弾かれず、攻撃力が上がる。満タンでしか描けない場合、発動条件に選択の余地がないため要整理 |
| 一定撃破数でソニックブーム | 高速移動中に一定数の敵を倒すと衝撃波。武器のソニックブームとの関係は未決定 |
| クリティカル時の貫通ビーム | クリティカルヒットした瞬間、突進方向へビームを発射 |
| 急速充填 | ゲージの充填時間を短縮 |
| チャージ最大値上昇 | ゲージ容量か使用回数のストック数かは未決定。既存の過充填コンデンサと旧版の予備セルは異なる効果 |
| クリティカル率上昇 | 雑魚の弱点方向判定とは別の仕組み |
| 最高速度上昇 | 移動速度を強化。攻撃力上昇とは分ける |
| 攻撃力上昇 | 攻撃力倍率を強化 |
| 回収範囲上昇 | アイテムの回収範囲を拡大 |
| 被弾時の衝撃波 | 被弾すると周囲へ衝撃波 |
| 軌跡延長 | 描ける線を長くする |

## 既存特性の追加候補：採否未判断

波動増幅器／大波動、包囲炸裂、経路の実行速度を上げる高速トレーサー、最大HP上昇、被ダメージ軽減、自己修復、弾かれた際の勢い保持。
雑魚の弱点方向判定を広げる弱点特攻・弱点スキャナは、今回の採用候補から外す。
