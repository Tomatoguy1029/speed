# demo の武器・特性整理

2026-10-07の検討内容。次の更新対象はブラウザdemo。Godotにはまだ実装しない。
共通方針は描画版demoへ実装済み。この文書は共通設計と候補規模の管理用で、実装済みの挙動は [spec.md](spec.md) を参照する。

## 共通方針

- 高速攻撃は、自分で軌跡を描いて駆け抜ける方式を採用する。
- 通常攻撃はヴァンサバ式の自動攻撃。高速移動のゲージは時間経過で充填し、特性でチャージ時間を短縮できる。25%以上（既定値）で短い軌跡を使え、描いた長さに応じて消費する。使わなかった分は次回へ残す。
- 武器種類ごとのレア度は付けず、強化段階を色で示す。1＝白、2＝緑、3＝青、4＝紫、5＝金。武器はLv、特性は重ね数を使用し、カードは選んだ後の段階、装備一覧は現在の段階の色を使う。武器と特性の両方を5段階に揃える。武器の最終性能は従来Lv8を維持する。
- モジュールを武器モジュールと特性モジュールに分ける。武器は各Lv5まで、同じ特性は5回まで重ねられる。
- 同時装備できる種類を増やすため、候補の種類数も増やす。武器の同時装備枠は4を目安にする（暫定）。特性6枠をdemoの試作値として実装しPで変更可能。候補の最終的な種類数は未決定。
- レベルアップごとに新武器／武器強化／特性の3枚から1枚を選ぶ。クリックまたは数字キー1〜3。レベルアップ間隔は従来より長くする。必要経験値は試作値90+42L+6L²を実装（Lは現在レベル）。
- 威力は速度ではなく攻撃力倍率で決まる。
- 小型敵の弱点方向判定は外す。装甲型と大型戦艦の背面弱点は保持する。ボスの弱点ギミックは別途検討する。クリティカル率は弱点方向判定と別に扱う。
- ビルドによって通したいルート・倒せる敵・突破後の状況が大きく変わり、以前できなかったことができる状態を目指す。

## 候補数と成長ペース：提案・未確定

装備は武器4枠・特性6枠を試作値として実装済み。通常候補を武器12種・特性20種程度へ増やす案は未採用。後述の追加検討枠4武器は通常候補数に含めない。現行通常プールは接触電撃を加えた武器9種・特性14種。追加候補の採否は別途検討する。

装備枠の拡大とレベルアップ間隔の延長を両立させるため、全装備の最大強化を毎ランの前提にはしない案を検討する。武器4種をLv5・特性6種を5重ねにするには取得50回分（初期装備が武器Lv1なら選択49回）が必要で、10分ランでは平均約12秒に一度の選択になる。初回取得で経路や攻撃に影響する効果を使え、以後は主力の強化と他の装備の取得を選べる設計が候補。今回の通常プールは武器9種・特性14種。追加4武器・6特性と成長配分の最終調整は未採用。全装備の最大強化を毎ランの前提にはしない。

## 隕石限定武器の試作（2026-10-08）

W21質量牽引砲・W22双極ビームをdemoに採用。通常新規プールから分離した隕石限定の入手先とし、武器4枠内で装備する。満枠時は交換か見送り、同種はLv5まで強化。所有後は通常Lv強化カードにも出す。限定武器の取得は通常レベルアップ回数を消費せず、高速経路終了後へ保留。数値は [武器一覧](weapons.md) を正本とする。本番Godotの採用は未決。
