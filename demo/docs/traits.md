# 特性一覧

最終更新：2026-10-07。対象はブラウザdemo。[共通設計](module-plan.md)／[運用ルール](catalog.md)／[武器一覧](weapons.md)。

描画版は同じ特性を5回まで重ねる。特性6枠をdemoの試作値として設定し、Pで変更できる。T01〜T14を通常候補に実装。以下の数値は試作値であり、本番の確定仕様ではない。nは取得回数（1〜5）、Aは武器一覧で定義した速度と独立した攻撃力。

## 通常候補：14種（実装済み）

| ID / 実装ID | 名称 | 採用状態 | 発動・重ね効果（試作数値） | ルート・成長への影響 | 実装／条件 |
|---|---|---|---|---|---|
| T01 / `endBlast` | 終端爆縮 | demo採用 | 終点で半径180+30n、威力A(1+0.5n)の爆発 | 終点を密集地点にする | 撃破数条件なし。硬い敵に弾かれた地点でも発動 |
| T02 / `crossBlast` | 交差爆破 | demo採用 | 過去12実秒の高速軌跡を横切ると交点で半径100+25n、威力A(0.8+0.4n)の爆発 | 前の高速攻撃の軌跡を横切る | 実際の移動のみ記録、最大160区間。同じ交点は1攻撃1回 |
| T03 / `vortex` | 余韻の渦 | demo採用 | 終点に1.5+0.4n秒、半径180+35nの渦。吸引速度200+70n、敵サイズで軽減 | 次の群れ形成にも終点を使う | 世界時間で寿命・吸引。ボスは引き寄せない |
| T04 / `fullCharge` | 満タン突撃 | demo採用 | 満タンからの経路実行中は装甲無視、攻撃力×(1.25+0.25n) | 半分以上で早く撃つか、満タンで硬い敵を抜くか | 経路が終わると解除。障害物は貫通しない |
| T05 / `killSonic` | 連鎖ソニック | demo採用 | 1回の高速攻撃で9−n体倒すたび波動。半径230+40n、威力A(0.8+0.4n) | 多くの敵を倒せる経路を選ぶ | 発動自身の撃破からは再帰発動しない。W08とは別 |
| T06 / `critBeam` | クリティカルランス | demo採用 | クリティカル時に進行方向へ射程480+100n、幅14+4n、威力A(0.8+0.4n)の貫通ビーム | 命中先に別の敵が並ぶ経路 | 最短発動間隔0.15実秒、ビームからは再発動しない |
| T07 / `quickCharge` | 急速充填 | demo採用 | 充填速度+25n%。1単位の充填時間6/(1+0.25n)秒（メタ強化前） | 次の高速攻撃が早く使える | 経験値ではなく実時間で充填 |
| T08 / `capacity` | 大容量チャージ | demo採用 | 容量+20n%。満タンまでの時間と描ける長さ・射出の勢いが伸びる | 1回で長い経路を通る | 回数ストックではない。満タン時間は容量×1単位の充填時間 |
| T09 / `critRate` | クリティカル率 | demo採用 | 基礎5%+8n%、上限90%。クリティカル倍率2.5 | T06の発動頻度が上がる | 弱点方向不要。接触クリティカルは装甲判定も半分 |
| T10 / `speed` | 最高速度 | demo採用 | 最高速度+12n% | 移動と描ける距離が伸びる | 威力は上がらない |
| T11 / `attack` | 攻撃力 | demo採用 | 全攻撃の攻撃力倍率+20n% | 倒せる／装甲を突破できる敵が変わる | 武器・経路波動・特性に適用 |
| T12 / `pickup` | 広域回収 | demo採用 | 回収範囲+30n% | アイテムに近づく必要が減る | XP倍率は含めない |
| T13 / `reactive` | 反応波動 | demo採用 | 被弾時に半径170+30n、威力A(0.8+0.4n)の波動 | 被弾後の周囲を押し返す | 実際にダメージを受けた時のみ。既存の被弾無敵時間で連続発動を防ぐ |
| T14 / `length` | 軌跡延長 | demo採用 | 描ける経路+25n% | 複数の群れを1回で通る | チャージ容量・最高速度と別の倍率 |

## その他の既存処理：採否未判断・デバッグで試用可能

通常の新規取得抽選には出さない。Pで直接装備した場合の強化はカードに出る。採用判断待ちのためコードを保持する。

| ID / 実装ID | 名称 | 採用状態 | 5重ね式の試作効果 | 経路・突破後への影響 |
|---|---|---|---|---|
| T15 / `wave` | 波動増幅 | 候補 | 軌跡波動の範囲+25n%、威力+30n% | 経路から離れた敵を巻き込む |
| T16 / `loop` | 包囲炸裂 | 候補 | 今回の実際の軌跡で囲んだ敵へA(1+0.6n)。3重ね以上は各敵から半径90の追加爆発（本攻撃50%） | 群れを囲む。閉じた判定部分を消費、面積64未満は無効 |
| T17 / `traceSpeed` | 高速トレーサー | 候補 | 経路の実行速度+25n% | 駆け抜ける時間が変わる |
| T18 / `hp` | 複合装甲 | 候補 | 最大HP+25n | 生存能力 |
| T19 / `guard` | 衝撃吸収 | 候補 | 被ダメージ・被弾減速を1/(1+0.2n)倍 | 被弾後の勢い |
| T20 / `regen` | 自己修復 | 候補 | 毎世界秒0.8n HP回復 | 生存能力 |
| T21 / `reflect` | 反射スラスター | 候補 | 弾かれ後の速度65+6n%（上限95%）、衝突ダメージ1/(1+0.2n)倍 | 弾かれた後の状況 |
| T22 / `pierce` | 貫通弾頭 | 候補 | 接触の装甲判定に攻撃力×(1+0.2n)を使用 | 描画版の貫通では元から減速しないため装甲判定の緩和へ変更 |
| T23 / `inertia` | 慣性保持 | 候補 | 衝突後の加速持続+30n%、射出への勢い持ち越し+5n%（上限95%） | 描画終了後の無減速状態と役割を区別 |
| T24 / `recovery` | 回生充填 | 候補 | 高速接触で容量の2n%回復 | 接触数で攻撃間隔が変わる |

実装は [run-build.js](../src/run-build.js)（定義・合成）と [run-weapons.js](../src/run-weapons.js)（発動）。
