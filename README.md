# SPEED

敵の大群に対して高速移動で立ち向かい、一気に吹き飛ばして圧倒する快感を楽しむゲーム。迫り来る敵の脅威に対して、高速移動によって敵を蹂躙することで、脅威を快感へと変える。

宇宙を舞台にした2D見下ろしのサバイバーゲームの試作です。高速移動による体当たりと波動で敵を倒し、モジュールを組み合わせて機体を強化します。現在は「ハイパードライブ（スロー中にクリックした地点へ直線ジャンプを連続で決める操作）」を軸に、操作の気持ちよさとスリルを検証しています。設置したポータルをつなぐ操作も比較用に残しています。

| バージョン | リンク |

| ポータル操作の試作 | [ポータル版](https://speed-nine-kappa.vercel.app/?controls=portal) |
| ハイパードライブ | [ハイパードライブ版](https://speed-nine-kappa.vercel.app/?controls=hyper) |
| ポータル導入前の保存版 | [元の描画版](https://speed-nine-kappa.vercel.app/draw-original.html) |

通常の入口はブラウザに保存した操作方式を使い、未選択（または削除した描画操作が保存されている）ならハイパードライブになります。`?controls=portal`、`?controls=hyper` は操作方式を指定するだけで、同じ公開版を開きます。線を描く操作は削除しました。元の描画版は比較用に保存した別のHTMLです。

現在のクリア条件は、7分ごろに出現するボスを10分以内に撃破すること。ボスの出現後も通常敵は湧き続けます。敵の撃破やカプセルからモジュールを入手し、同じモジュールを拾うと自動強化されます。ランで獲得した部品はステーションで機体の基礎強化に使えます。トドメは機体アップのスローで見せた後、ボスの爆発で全敵を一掃し、破片を2秒かけて消してからCLEAR!を表示します。結果画面から「もう一回やる」「メニューに戻る」を選べます。ボスのギミックは暫定で、ゲームシステム・バランスは検討中です。

現在はハイパードライブ版を軸に検証しています。敵の密度と補充速度は従来の約5倍に増やし、敵同士の過剰な重なりと追跡先の集中を抑えています。

## 操作

### ポータル版（キーボード）

| 状態 | キー | 動作 |
|---|---|---|
| 通常移動 | WASD / 矢印 | 移動 |
| 通常移動 | B | 足元にポータルを設置 |
| 通常移動 | Space短押し | 最寄りの到達可能なポータルへ突進 |
| ポータル上 | A / D | 次の行き先を反時計回り / 時計回りに選択 |
| ポータル上 | Space短押し | 選択したポータルへ移動（キーを離すと出発） |
| ポータル上・移動中 | Spaceを0.5秒長押し | 通常移動へ離脱 |

移動可能なポータルへ薄い線が出て、選択中の経路は黄色い太線で表示されます。移動中も次の行き先を選び、Spaceで次の出発を予約できます。通常移動でポータルに入って乗ることもできます。

- ゲージ不要。設置したポータルはラン中残り、最大12個まで配置できます。敵からのランダムなポータルドロップは停止中です。
- 通った辺は逆方向も含めて10秒クールダウンします。離脱しても解除されず、同じアタック中は時間が経っても再利用できません。
- 移動可能な接続先がなくなると自動離脱します。待機中も敵と弾は通常速度で動きます。
- 通過した軌跡は離脱まで残ります。「包囲炸裂」モジュールを装備すると、閉じた軌跡の内側にいる敵を爆破できます。

### ハイパードライブ版（マウス / タッチ）

1. カーソルの方向へ通常移動します。タッチでは仮想スティックで移動します。
2. ジャンプのチャージは時間で1つずつ溜まり、最大5つまで貯められます。機体の下の5つの目盛りが残りの数です。
3. Spaceでハイパードライブに入ると、世界がスローになり、届く範囲の円が出ます（タッチは左下の「ハイパー」ボタン）。
4. クリックした地点へまっすぐジャンプします。円の外をクリックすると円の端まで跳びます。チャージが残っている間はクリックを続けて連続ジャンプできます。
5. Space／右クリックで解除します。チャージを使い切るか、照準の時間（実時間3秒、ジャンプ中は数えない）が尽きても自動で解除され、使わなかったチャージは残ります。

ジャンプの通り道の敵は貫通し、周りに波動が出ます。照準中は、切れる敵が白（弱点は黄色）、波動だけ届く敵が水色、弾かれる位置が赤い×で表示されます。ジャンプ後は勢いが少し残り、徐々に巡航速度まで減速します。ハイパードライブ外のクリックは何もしません。

武器のブラスターが進行方向へ自動で撃ちます（止まっていても最後に進んだ方向へ）。レベルが上がるたびに3枚から1つ選び、新しい武器（追尾ミサイル・オービットブレード・パルスノヴァ・アークコイル・レーザーランス・リターンディスク、最大6つまで持てる）を得るか、持っている武器を強化するか、ハイパードライブの特性（3回目のジャンプが爆発、満タンから跳ぶと弾かれない、着地点に敵を引き寄せる渦が残る など）を得ます。同じ特性は重ねて強化できます。ハイパードライブ中に拾ったモジュールの選択画面は解除後に表示されます。敵からのドロップは撃破ごとの確率抽選で、Pからドロップ率を調整できます。ドロップと選択画面に時間による待機はありません。

### 共通

| キー | 動作 |
|---|---|
| Enter | ステーションから出発 / リザルトから戻る |
| Esc | ポーズ |
| M | ミュート切り替え（初期状態はミュート） |
| P | 調整パネルを開閉。操作方式・数値の変更、モジュールの試用など |

強化データと操作設定はブラウザのlocalStorageに保存されます。ポータル操作はスマートフォン未対応です。

## ローカルで起動

ビルド・テストにはNode.jsを使います。外部パッケージへの依存はなく、`npm install` は不要です。以下の配信例はPython 3を使います。

```bash
git clone https://github.com/Tomatoguy1029/speed.git
cd speed
node build.js
python3 -m http.server 8766 --bind 127.0.0.1
```

ブラウザで [ローカル版](http://127.0.0.1:8766/dist/index.html) または [ローカルのポータル版](http://127.0.0.1:8766/dist/index.html?controls=portal) を開きます。ソース変更後は `node build.js` を再実行し、ページを再読み込みしてください。

`dist/speed.html` はJavaScriptを内包した単体配布用HTMLです。サーバーなしでブラウザから開くこともできます。

## 開発

```bash
node --test                    # テスト
node build.js                  # 配布用HTMLを生成
node tools/balance.js 3 1 god   # 自動プレイ計測（3回、シード1、無敵）
```

自動プレイ計測はハイパードライブ・ポータル操作の手触りを評価するものではありません。これらの操作の評価は実際に遊んで行います。

| パス | 内容 |
|---|---|
| `src/` | ゲームのJavaScript。描画はCanvas、音はブラウザで合成 |
| `src/config.js` | 操作・速度・戦闘などの調整値 |
| `src/controls.js`, `src/input.js` | 操作方式とキー・ポインター入力 |
| `src/portals.js`, `src/portal-loops.js` | ポータル移動と囲み判定 |
| `index.html`, `build.js` | 画面テンプレートと独自バンドラ |
| `dist/` | 生成した配布用HTMLと元の描画版 |
| `test/`, `tools/` | テストと自動プレイ計測 |

ビルドはES Modulesを1つのIIFEに結合します。トップレベルの名前はファイルをまたいで重複できません。`dist/index.html` と `dist/speed.html` は同じ内容で、両方をGit管理します。`dist/draw-original.html` は通常のビルドでは上書きされません。

`main` へのpushでVercelが `node build.js` を実行し、`dist/` を公開します。作業ブランチへのコミットだけでは公開版は更新されません。
