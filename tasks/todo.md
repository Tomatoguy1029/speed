# タスク一覧（作業用・一時）

[計画](plan.md) の段階ごとのタスク。上から順に進める。各タスクは1回の作業で終わる大きさにし、触るファイルは5つ前後までにする。パスは `speed/`（`res://`）からの相対。

## 段階0 計測

- [x] **0-1 敵1300体の計測シーン**
  - 内容：敵を配列で持ち、追跡（18秒周期の接近と広域移動）、格子での近傍探索、自機との接触、線分の掃引判定を1秒に120回回す。`MultiMeshInstance2D` で描く。
  - 完了の条件：1回の更新の平均・95パーセンタイルの時間と、1フレームの時間をログに出す。
  - 確認：計測シーンを実行し、ログの数値を記録する。
  - ファイル：`gyms/perf_enemies/perf_enemies.tscn`、`perf_enemies.gd`
- [x] **0-2 レンダラの比較**
  - 内容：同じシーンに、層ごとの SubViewport と HDR の光のにじみを加え、Forward+ と Mobile で切り替えて比べる。
  - 完了の条件：両方の GPU 時間・フレーム時間と、書き出した画面がそろっている。
  - 確認：`--rendering-method` を変えて2回実行する。
  - ファイル：`gyms/perf_enemies/` の中だけ
- [x] **0-3 報告**（チェックポイント0）
  - 内容：数値と画面をまとめて報告し、C++ が要るか・レンダラをどちらにするかを決めてもらう。

## 段階1 土台と画面の流れ

- [x] **1-1 プロジェクトの設定とフォルダ**
  - 内容：画面の拡大縮小（`canvas_items`・`expand`）、固定更新120回、入力のアクション、設計書3章のフォルダ。
  - 完了の条件：取り込みでエラーが出ない。
  - 確認：`--headless --import`
  - ファイル：`project.godot`、フォルダ
- [x] **1-2 Autoload 4つ**
  - 内容：GameManager（画面の状態機械とシグナル）、SaveManager（`user://` への保存と版番号）、ConfigManager（`data/config.tres` と実行時の複製）、AudioManager（バスと音量）。
  - 完了の条件：起動時に4つが読み込まれ、セーブの読み書きができる。
  - 確認：`--headless --import` と起動ログ
  - ファイル：`scripts/managers/` の4つ、`scripts/data_types/game_config.gd`、`data/config.tres`
- [x] **1-3 タイトルとメインメニュー**
  - 内容：タイトル（ゲームスタート・設定・終了）、メインメニュー（ステージ選択・機体の強化・図鑑）、戻る操作。設定・強化・図鑑は中身が空の画面だけ置く。
  - 完了の条件：ボタンで画面が移り、戻る操作で前の画面へ戻る。
  - 確認：書き出した画面
  - ファイル：`scenes/app/` と `scripts/ui/` の該当ファイル
- [x] **1-4 ステージ選択と結果**
  - 内容：ステージ1〜5（前のステージのクリアで解放）、エンドレスの入口（中身なし）、結果画面（もう一回・メインメニューに戻る）。解放の状態をセーブする。
  - 完了の条件：ステージ1だけ選べ、クリア扱いにするとステージ2が選べるようになり、再起動しても残る。
  - 確認：書き出した画面
  - ファイル：`scenes/app/stage_select.tscn`、`result.tscn` と対応する `scripts/ui/`
- [x] **1-5 空のランと RunManager**
  - 内容：ランのシーン、Managers ノード、RunManager（実秒と世界秒の時計、更新の順番の骨組み、イベントのリスト、命令の受け口）、RunState。調整用に「クリア扱い」で結果へ進む操作。
  - 完了の条件：ステージ選択 → ラン → 結果 → メインメニューが一本道でつながる。
  - 確認：書き出した画面と起動ログ
  - ファイル：`scenes/run/run.tscn`、`scripts/managers/run_manager.gd`、`scripts/managers/run_state.gd`
- [x] **1-6 ステージの直接起動**
  - 内容：record の `debug_launcher` と同じ仕組み（ツールバーのボタン、`user://` の1回だけの予約、エディタ実行時だけ消費）。
  - 完了の条件：ボタンで選んだステージから始まり、F5 はタイトルから始まる。
  - 確認：エディタで押して確かめる
  - ファイル：`addons/stage_launcher/`、`scripts/debug/debug_launch.gd`、Main
- [x] **1-7 決まりの自動チェック**
  - 内容：Manager がコンテンツ（ステージ・ボス・仕掛けのシーン）を参照していないか、Autoload が4つだけか、を確かめるスクリプト。
  - 完了の条件：違反があると一覧を出して失敗する。
  - 確認：`--headless --script res://tests/check_rules.gd`
  - ファイル：`tests/check_rules.gd`
- [x] **チェックポイント1**：F5 で画面の一本道を確認してもらい、push する。
